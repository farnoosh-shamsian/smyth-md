# FORMATION OF ADJECTIVES

<!-- page 236 -->

##### <a id="s857"></a> §857

Adjectives are formed by the same suffixes as are used in substantives, the same formation producing in one case a substantive, in another an adjective. Many words formed with certain suffixes (<span lang="grc">**ιο**, **μο**, **νο**, **ρο**, **το**</span>) are used as adjectives or as abstract substantives (usually feminine or neuter). Thus <span lang="grc">φιλίᾱ</span> _friendly_ or _friendship;_ so <span lang="grc">στέφ-ανο-ς</span> _crown_ (<span lang="grc">στέφ-ω</span> _encircle_) was originally an adjective. Many suffixes have no characteristic signification.

Adjectives are either primitive (from roots or verb-stems) or denominative (from substantives or other adjectives). But this distinction is often obliterated and difficult to determine.

##### <a id="s858"></a> §858

The following are the chief adjectival suffixes:

\1. <span lang="grc">**ο**, **ᾱ**</span> (nom. <span lang="grc">-ο-ς, -η</span> or <span lang="grc">-ᾱ, -ο-ν</span>): primary: <span lang="grc">λοιπ-ό-ς</span> _remaining_ (<span lang="grc">λείπ-ω</span> _leave_, <span lang="grc">λιπ-, λειπ-, λοιπ-</span>), <span lang="grc">λευκ-ό-ς</span> _bright_ (<span lang="grc">λεύσσω</span> _shine_, <span lang="grc">λευκ-ῖω</span>).

\2. <span lang="grc">**ιο**, **ιᾱ**</span>: a common suffix expressing that which _pertains_ or _belongs_ in any way to a person or thing. By union with a preceding stem vowel we have <span lang="grc">αιο, ειο, οιο, ῳο, υιο</span>.

Primary (rare): <span lang="grc">ἅγ-ιο-ς</span> _sacred_ (<span lang="grc">ἅγος</span> expiation); with a comparative force: <span lang="grc">ἄλλος</span> _other_ (<span lang="grc">ἀλ-ῖο-ς</span> _alius_), <span lang="grc">μέσος</span> _middle_ (<span lang="grc">μεθ-ῖο-ς</span> _medius_, [113](../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s113)).

Secondary in <span lang="grc">τί̄μ-ιο-ς</span> _worthy_, _costly_ (<span lang="grc">τῑμή</span> _honour_); <span lang="grc">φίλ-ιο-ς</span> _friendly_ (<span lang="grc">φίλο-ς</span> _dear_); <span lang="grc">ὄρθ-ιο-ς</span> _steep_ (<span lang="grc">ὀρθό-ς</span> _straight_); <span lang="grc">πλούσ-ιο-ς</span> _rich_ (<span lang="grc">πλοῦτο-ς</span> _riches_, [115](../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s115)); <span lang="grc">δίκα-ιο-ς</span> _just_ (<span lang="grc">δίκ-η</span> _right_, 834 b); <span lang="grc">οἰκε-ῖο-ς</span> _domestic_ (<span lang="grc">οἶκο-ς</span> _house_, 834 f); <span lang="grc">πάτρ-ιο-ς</span> _hereditary_ (<span lang="grc">πατήρ</span> _father_, <span lang="grc">πατρ-</span>, [262](../part-2-inflection/04-substantives/05-third-declension.md#s262)); <span lang="grc">βασίλειο-ς</span> _royal_ (<span lang="grc">βασιλεύ-ς</span> _king_); <span lang="grc">θέρε-ιο-ς</span> _of summer_ (<span lang="grc">θέρος</span>, stem <span lang="grc">θερεσ-</span>); <span lang="grc">αἰδο-ῖο-ς</span> _venerable_ (<span lang="grc">αἰδώς</span> _shame_, stem <span lang="grc">αἰδοσ-</span>, [266](../part-2-inflection/04-substantives/05-third-declension.md#s266)); <span lang="grc">ἡρῷος</span> _heroic_ (<span lang="grc">ἥρως</span> _hero_, <span lang="grc">ἡρωϝ-</span>, [267](../part-2-inflection/04-substantives/05-third-declension.md#s267)); <span lang="grc">πήχυ-ιο-ς</span> _a cubit long_ (<span lang="grc">πῆχυ-ς</span>, [268](../part-2-inflection/04-substantives/05-third-declension.md#s268)). The feminines are often abstract substantives, as <span lang="grc">φιλ-ίᾱ</span> _friendship_.

**a.** The ending <span lang="grc">-αῖος</span> has been transferred from <span lang="grc">ᾱ</span> stems, as in <span lang="grc">χερσ-αῖο-ς</span> _of_ or _from dry land_ (<span lang="grc">χέρσ-ος</span>). The form <span lang="grc">ι-αῖος</span> occurs: <span lang="grc">δραχμ-ιαῖο-ς</span> _worth a drachma_ (<span lang="grc">δραχμή</span>). <span lang="grc">-εῖος</span> has become independent in <span lang="grc">ἀνδρ-εῖος</span> _manly_ (<span lang="grc">ἀνήρ</span>). On gentiles in <span lang="grc">-ιος</span>, see [844](02-formation-of-substantives.md#s844). 3.

**b.** Ionic <span lang="grc"> **η-ϊο** </span> (nom. <span lang="grc">-ηϊος</span>), properly from stems in <span lang="grc">ευ</span> (<span lang="grc">ηυ</span>), as Hom. <span lang="grc">χαλκή-ϊο-ς</span> _brazen_ (pertaining to a <span lang="grc">χαλκεύ-ς</span> _brazier;_ Attic <span lang="grc">χάλκεος, -οῦς</span>, see [858](#s858). 4), <span lang="grc">βασιλή-ϊο-ς</span> _royal;_ and transferred in Ionic to other stems, as in <span lang="grc">πολεμήϊο-ς</span> _warlike_, <span lang="grc">ἀνθρωπ-ήϊο-ς</span> _human_ (Attic <span lang="grc">ἀνθρώπειο-ς</span>), <span lang="grc">ἀνδρ-ήϊο-ς</span> _manly_.

\3. <span lang="grc"> **εντ** </span> for <span lang="grc">ϝεντ</span> (nom. <span lang="grc">-εις</span>) forms denominative adjectives denoting _fulness_ or _abundance_ (mostly poetic).

<span lang="grc">τῑμή-εις</span> (<span lang="grc">τῑμῆς</span>) _honoured_, and by analogy <span lang="grc">δενδρ-ήεις</span> _woody_ (<span lang="grc">δένδρο-ν</span> _tree_); <span lang="grc">χαρί-εις</span> _graceful_ (<span lang="grc">χάρι-ς</span>), <span lang="grc">δολό-εις</span> _wily_ (<span lang="grc">δόλο-ς</span>), and by analogy <span lang="grc">αἱματ-ό-εις</span> _bloody_ (<span lang="grc">αἷμα, -ατ-ος</span> _blood_, 834 j), <span lang="grc">ἰχθυ-ό-εις</span> _full of fish_, <span lang="grc">κρυ-ό-εις</span> _chilling_ (<span lang="grc">κρύ-ος</span> _chill_). Also in <span lang="grc">εὐρώ-εις</span> _mouldy_ (<span lang="grc">εὐρώς, -ῶτος</span>).

\4. <span lang="grc"> **εο** </span> (nom. <span lang="grc">-εο-ς, -οῦς</span>, [290](../part-2-inflection/04-substantives/07-adjectives.md#s290)) forms denominative adjectives denoting _material:_ <span lang="grc">χρύ̄σεος, χρῡσοῦς</span> _golden_ (<span lang="grc">χρῡσό-ς</span> _gold_). <!-- page 237 -->

**a.** <span lang="grc">εο</span> is derived from <span lang="grc">ε-ῖο</span>, seen in <span lang="grc">χρύ̄σειος</span> (poetic). Here <span lang="grc">ε</span> is part of the stem ([834 f](01-word-formation-introductory.md#s834)). On <span lang="grc">-ηϊος</span> see [858](#s858). 2 b.

\5. <span lang="grc"> **ες** </span> (nom. <span lang="grc">-ής, -ές</span>): primitive: <span lang="grc">ψευδ-ής</span> _false_ (<span lang="grc">ψεύδ-ω</span> _deceive_), <span lang="grc">σαφ-ής</span> _clear_, <span lang="grc">πρην-ής</span> _prone_, <span lang="grc">ὑγι-ής</span> _healthy_. Very common in compounds, as <span lang="grc">ἀ-σφαλ-ής</span> _unharmed_, _secure_ (<span lang="grc">ἀ-</span>priv. + <span lang="grc">σφαλ-</span> in <span lang="grc">σφάλλω</span> _trip_).

\6. <span lang="grc">**κο**, **ακο**, **ικο**</span> (nom. <span lang="grc">-κος</span>, very common, cp. [864](04-list-of-noun-suffixes.md#s864). 1): many denominatives formed by these suffixes denote _relation_, many others _fitness_ or _ability_.

**a.** Denominatives: <span lang="grc">μαντι-κό-ς</span> _prophetic_ (<span lang="grc">μάντι-ς</span> _prophet_); <span lang="grc">φυσι-κό-ς</span> _natural_ (<span lang="grc">φύσι-ς</span> _nature_); <span lang="grc">θηλυ-κό-ς</span> _feminine_ (<span lang="grc">θῆλυ-ς</span> _female_); <span lang="grc">Δᾱρει-κό-ς</span> _Daric_ (<span lang="grc">Δᾱρεῖο-ς</span> _Darius_).

**b.** From <span lang="grc">φυσι-κό ς</span>, etc., <span lang="grc">ικο</span> was taken as an independent suffix in <span lang="grc">μουσ-ικό-ς</span> _musical_ (<span lang="grc">μοῦσα</span> _muse_); <span lang="grc">βαρβαρ-ικό-ς</span> _barbaric_ (<span lang="grc">βάρβαρο-ς</span> _barbarian_, _foreigner_); <span lang="grc">διδασκαλ-ικό-ς</span> _able to teach_ (<span lang="grc">διδάσκαλο-ς</span> _teacher_); <span lang="grc">μαθηματικό-ς</span> _fond of learning_ (<span lang="grc">μάθημα, -ματος</span> _thing learnt_); <span lang="grc">Κεραμε-ικό-ς</span> _Potters' quarter_, _Ceramīcus_ (<span lang="grc">κεραμεύ-ς</span> _potter_); <span lang="grc">βασιλ-ικό-ς</span> _royal_ (<span lang="grc">βασιλεύ-ς</span> _king_); <span lang="grc">ἡρω-ϊκό-ς</span> _heroic_, from <span lang="grc">ἥρω</span>(<span lang="grc">ϝ</span>), <span lang="grc">-ος</span> _hero;_ <span lang="grc">Ἀχαι-ικό-ς</span> or <span lang="grc">Ἀχᾱ-ικό-ς</span> ([38](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s38)) _Achaean_ (<span lang="grc">Ἀχαιό-ς</span> _Achaean_).

N.—<span lang="grc">ἀρχ-ικό-ς</span> _able to rule_ (<span lang="grc">ἀρχ-ή</span>), <span lang="grc">γραφ-ικό-ς</span> _able to write_ or _draw_ (<span lang="grc">γραφ-ή</span>), need not be derived directly from the root.

**c.** <span lang="grc">Κορινθι-ακό-ς</span> _Corinthian_ (<span lang="grc">Κορίνθ-ιο-ς</span> _Corinthian_); <span lang="grc">σπονδει-ακό-ς</span> _consisting of spondees_ (<span lang="grc">σπονδ-εῖο-ς</span> _spondee_).

**d.** <span lang="grc"> **τ-ικό** </span> represents <span lang="grc">ικό</span> added to the verbal in <span lang="grc">τό-</span> (cp. also <span lang="grc">μαθηματ-ικό-ς</span>). Thus, <span lang="grc">λεκ-τικό-ς</span> _suited to speaking_ (<span lang="grc">λέγ-ω</span> _speak_); <span lang="grc">αἰσθη-τικό-ς</span> _capable of feeling_ (<span lang="grc">αἰσθ-άνομαι</span> _feel_); <span lang="grc">ἀριθμη-τικό-ς</span> _skilled in numbering_ (<span lang="grc">ἀριθμέω</span> _to number_); <span lang="grc">πρᾱκ-τικό-ς</span> _practical_, _able to do_ (<span lang="grc">πρά̄ττω</span> _do_); <span lang="grc">σκεπτικό-ς</span> _reflective_ (<span lang="grc">σκέπ-τ-ομαι</span> _look carefully, consider_). Added to a noun-stem: <span lang="grc">ναυ-τικό-ς</span> _nautical_ (<span lang="grc">ναῦ-ς</span> _ship_).

\7. <span lang="grc"> **λο** </span> (nom. <span lang="grc">-λο-ς</span>): primary (usually active) and secondary. Cp. [860](04-list-of-noun-suffixes.md#s860). 1. Primary in <span lang="grc">δει-λό-ς</span> _cowardly_ (<span lang="grc">δέδοι-κα</span> _fear_, <span lang="grc">δι-, δει-, δοι-</span>); <span lang="grc">στρεβ-λό-ς</span> _twisted_ (<span lang="grc">στρέφ-ω</span> _turn_); <span lang="grc">τυφ-λό-ς</span> _blind_ (<span lang="grc">τύ̄φ-ω</span> _raise a smoke_); <span lang="grc">κοῖλος</span> _hollow_ ( = <span lang="grc">κοϝ-ιλο-ς</span>, Lat. _cav-us_); <span lang="grc">τροχ-αλό-ς</span> _running_ (<span lang="grc">τρέχ-ω</span> _run_); <span lang="grc">εἴκ-ελο-ς</span> _like_ (<span lang="grc">ἔοικα</span> _am like_, <span lang="grc">εἰκ-</span>); <span lang="grc">καμπ-ύλο-ς</span> _bent_ (<span lang="grc">κάμπ-τ-ω</span> _bend_); <span lang="grc">φειδ-ωλό-ς</span> _sparing_ (<span lang="grc">φείδ-ομαι</span> _spare_). <span lang="grc">ἀπατ-η-λός</span> _deceitful_ (<span lang="grc">ἀπάτη</span> _deceit_, <span lang="grc">ἀπατά-ω</span> _deceive_) may be a primitive or a denominative. Cp. [860](04-list-of-noun-suffixes.md#s860). 1.

<span lang="grc"> **α-λεο** </span> denoting _quality_ in <span lang="grc">ἁρπ-αλέο-ς</span> _attractive_, _ravishing_ (<span lang="grc">ἁρπάζω</span> _seize_), <span lang="grc">θαρσ-αλέο-ς</span> _bold_ (<span lang="grc">θάρσ-ος</span> _boldness_).

\8. <span lang="grc"> **μο** </span> (nom. <span lang="grc">-μο-ς</span>, 861. 1): primary: <span lang="grc">θερ-μό-ς</span> _warm_ (<span lang="grc">θέρ-ω</span> _warm_); secondary in <span lang="grc">ἕβδ-ο-μο-ς</span> _seventh_.

\9. <span lang="grc">**ι-μο**, **σ-ιμο**</span> (nom. <span lang="grc">-ιμο-ς, -σιμο-ς</span>): often denoting _able to_ or _fit to_. Adjectives in <span lang="grc">ιμο</span> are primitive or denominative, and are derived from <span lang="grc">ι-</span>stems; those in <span lang="grc">-σιμο</span> are denominative and come mostly from stems in <span lang="grc">σι ¨ μο</span> (as <span lang="grc">χρή-σι-μο-ς</span> _useful_, from <span lang="grc">χρῆ-σι-ς</span> _use_); but <span lang="grc">σιμο</span> has thence been abstracted as an independent suffix.

<span lang="grc">δόκ-ιμο-ς</span> _approved_ (<span lang="grc">δοκ-έ-ω</span> _seem good_); <span lang="grc">μάχ-ιμο-ς</span> _warlike_ (<span lang="grc">μάχη</span> _battle_); <span lang="grc">νόμ-ιμο-ς</span> _conformable to law_ (<span lang="grc">νόμο-ς</span>); <span lang="grc">ἐͅδ-ώδ-ιμο-ς</span> _eatable_ (<span lang="grc">ἐδ-ωδ-ή</span> _food_, poet. <span lang="grc">ἔδ-ω</span> _eat_); <span lang="grc">καύσι-μο-ς</span> _combustible_ (<span lang="grc">κά̄ω</span> _burn_, <span lang="grc">καῦ-σι-ς</span> _burn-_ <!-- page 238 --> _ing_); <span lang="grc">λύσι-μο-ς</span> _able to loose_ (<span lang="grc">λύ-σι-ς</span> _loosing_); <span lang="grc">ἱππά-σιμο-ς</span> _fit for riding_ (<span lang="grc">ἱππάζομαι</span> _ride_); <span lang="grc">ἁλώ-σιμο-ς</span> _easy to take_ (<span lang="grc">ἁλίσκομαι, ἑά̄λων</span>).

\10. <span lang="grc"> **μον** </span> (nom. <span lang="grc">-μων, -μον</span>): primary in <span lang="grc">μνή-μων</span> _mindful_ (<span lang="grc">μι-μνῄ-σκομαι</span> _remember_), <span lang="grc">τλή-μων</span> _enduring_, _wretched_ (<span lang="grc">ἔ-τλη-ν</span> _endured_). Cp. [861](04-list-of-noun-suffixes.md#s861). 8.

\11. <span lang="grc"> **νο** </span> (nom. <span lang="grc">-νο-ς</span>, 861. [11](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s11)): primary (usually passive) and secondary ([829 a](01-word-formation-introductory.md#s829)). Sometimes denoting that which _may_, _can_, or _must be done_.

Primary in <span lang="grc">δει-νό-ς</span> _fearful_ (<span lang="grc">δέ-δοι-κα</span> _fear_, <span lang="grc">δι-, δει-, δοι-</span>); <span lang="grc">σεμ-νό-ς</span> _to be revered_ (<span lang="grc">σέβ-ομαι</span> _revere_); <span lang="grc">πιθ-ανό-ς</span> _persuasive_ (<span lang="grc">πείθ-ω</span> _persuade_, <span lang="grc">πιθ-, πειθ-, ποιθ-</span>); <span lang="grc">πίσ-υνο-ς</span> _trusting_ (<span lang="grc">πείθ-ω</span>). Secondary in <span lang="grc">σκοτει-νό-ς</span> _dark_ ( = <span lang="grc">σκοτεσ-νο-ς</span> from <span lang="grc">σκότ-ος</span> _darkness_).

\12. <span lang="grc"> **ινο** </span> (nom. <span lang="grc">-ινο-ς</span>, 861. [11](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s11)): forms denominative _adjectives of material_, as <span lang="grc">λίθ-ινο-ς</span> _of stone_ (<span lang="grc">λίθο-ς</span>), <span lang="grc">ξύλ-ινο-ς</span> _wooden_ (<span lang="grc">ξύλο-ν</span>); to denote _time_, and derived from such forms as <span lang="grc">ἐαρι-νό-ς</span> _vernal_ (<span lang="grc">ἔαρ</span> _spring_), as in <span lang="grc">ἡμερ-ινό-ς</span> _by day_ (<span lang="grc">ἡμέρᾱ</span>), <span lang="grc">χθεσ-ινό-ς</span> _of yesterday_ (<span lang="grc">χθές</span>); other uses: <span lang="grc">ἀνθρώπ-ινο-ς</span> _human_ (<span lang="grc">ἄνθρωπο-ς</span> _man_), <span lang="grc">ἀληθ-ινό-ς</span> _genuine_ (<span lang="grc">ἀληθής</span> _true_).

<span lang="grc"> **ινεο** </span> in <span lang="grc">λα-ΐνεο-ς ῀ λά-ϊνο-ς</span> _stony_ (<span lang="grc">λᾶς</span> _stone_). On <span lang="grc">-ηνος, -ῑνος</span> in gentiles, see [844](02-formation-of-substantives.md#s844). 3.

\13. <span lang="grc">**ρο**, **ρᾱ**</span> (nom. <span lang="grc">-ρό-ς, -ρά̄</span>): primary, and secondary. Primary, in <span lang="grc">ἐχθ-ρό-ς</span> _hated_, _hostile_ (<span lang="grc">ἔχθ-ω</span> _hate_), <span lang="grc">λαμπ-ρό-ς</span> _shining_ (<span lang="grc">λάμπ-ω</span> _shine_), <span lang="grc">χαλα-ρό-ς</span> _slack_ (<span lang="grc">χαλά-ω</span> _slacken_). Secondary, in <span lang="grc">φοβε-ρό-ς</span> _fearful_ (<span lang="grc">φόβο-ς</span> _fear_, <span lang="grc">φοβόε-</span>, 834 f), <span lang="grc">κρατ-ερό-ς</span> _mighty_ (<span lang="grc">κράτ-ος</span> _might_); primary or secondary in <span lang="grc">ἀνιᾱ-ρό-ς</span> _grievous_ (<span lang="grc">ἀνίᾱ</span> _grief_, <span lang="grc">ἀνιά-ω</span> _grieve_). See [860](04-list-of-noun-suffixes.md#s860). 3.

\14. <span lang="grc"> **τηρ-ιο** </span> (nom. <span lang="grc">-τήριο-ς</span>): in denominatives, derived from substantives in <span lang="grc">-τηρ</span> (or <span lang="grc">-της</span>) by the suffix <span lang="grc">ιο</span>; but the substantive is not always found.

<span lang="grc">σω-τήρ-ιο-ς</span> _preserving_ (<span lang="grc">σω-τήρ</span> _saviour_), whence the abstract <span lang="grc">σωτηρίᾱ</span> ([858](#s858). 2) _safety;_ <span lang="grc">θελκ-τήρ-ιο-ς</span> _enchanting_ (<span lang="grc">θελκ-τήρ</span> _charmer_, <span lang="grc">θέλγ-ω</span> _enchant_), whence <span lang="grc">θελκτήριον</span> ([842](02-formation-of-substantives.md#s842). 4), <span lang="grc">λυ-τήρ-ιο-ς</span> _delivering_ (<span lang="grc">λυ-τήρ</span>), <span lang="grc">ὁρμητήριον</span> _starting-place_ (<span lang="grc">ὁρμάω, ὁρμῶμαι</span> _start_).

\15. <span lang="grc"> **υ** </span> (nom. <span lang="grc">-ύ-ς, -εῖα, -ύ</span>): primitives are <span lang="grc">ἡδύ-ς</span> _sweet_ (<span lang="grc">ἥδ-ομαι</span> _am pleased_), <span lang="grc">ταχ-ύ-ς</span> _swift_ (<span lang="grc">τάχ-ος</span> _swiftness_), <span lang="grc">βαθ-ύ-ς</span> _deep_ (<span lang="grc">βάθ-ος</span> _depth_). Cp. [859](04-list-of-noun-suffixes.md#s859). 8.

\16. <span lang="grc"> **ωδες** </span> (nom. <span lang="grc">-ώδης, -ῶδες</span>): in primitives (rare), as <span lang="grc">πρεπ-ώδης</span> _proper_ (<span lang="grc">πρέπ-ω</span> _beseem_); usually in denominatives denoting _fulness_ or _similarity:_ <span lang="grc">ποι-ώδης</span> _grassy_ (<span lang="grc">ποίᾱ</span>), <span lang="grc">αἱματ-ώδης</span> _looking like blood_ (<span lang="grc">αἷμα</span>). See [833 a](01-word-formation-introductory.md#s833).

\17. Suffixes of Degree: <span lang="grc"> **ῑον** </span> and <span lang="grc"> **ιστο** </span> ([318](../part-2-inflection/05-comparison-of-adjectives.md#s318)) usually form primitives; <span lang="grc"> **τερο** </span> and <span lang="grc"> **τατο** </span> ([313 f](../part-2-inflection/05-comparison-of-adjectives.md#s313)f.), denominatives. <span lang="grc">τερο</span> occurs also in <span lang="grc">πό-τερο-ς</span> _which of two?_ <span lang="grc">πρό-τερο-ς</span> _earlier_, <span lang="grc">ὕσ-τερο-ς</span> _later_, <span lang="grc">ἑκά-τερο-ς</span> _each_. On the suffix <span lang="grc">τερο</span> apparently without comparative force, see [1066](../part-4-syntax/14-adjectives.md#s1066), [1082](../part-4-syntax/14-adjectives.md#s1082) b. <span lang="grc">ἔν-τερο-ν</span> is substantivized (_bowel_); from <span lang="grc">ἐν</span> _in_.
