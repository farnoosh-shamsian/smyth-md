# Word Formation: Introductory

##### <a id="s822"></a> §822

Inflected words generally consist of two distinct parts: a stem and an inflectional ending ([191](../part-2-inflection/01-parts-of-speech.md#s191)):

|  |  |  |  |
| --- | --- | --- | --- |
| <span lang="grc">δῶρο-ν</span> | _gift_, | stem <span lang="grc">δωρο-</span>, | inflectional ending <span lang="grc">ν</span>; |
| <span lang="grc">λύ̄ο-μεν</span> | _we loose_, | stem <span lang="grc">λῑο-</span>, | inflectional ending <span lang="grc">μεν</span>. |

**a.** The inflectional endings of nouns and verbs, and the formation of verbal stems, have been treated under Inflection. The formation of words, as discussed here, deals primarily with the formation of noun-stems, of verbal stems derived from nouns, and of compound words. Uninflected words (adverbs, prepositions, conjunctions, and particles) are mostly of pronominal origin and obscure; such adverbs as show case forms are mentioned in 341 ff.

##### <a id="s823"></a> §823

Some stems are identical with roots (_root-stems_, [193](../part-2-inflection/01-parts-of-speech.md#s193)) to which only an inflectional ending, or no ending at all, has been added.

|  |  |  |
| --- | --- | --- |
| <span lang="grc">βοῦ-ς</span> _ox_, _cow_ | <span lang="grc">μῦ-ς</span> _mouse_ | <span lang="grc">ὗ-ς</span> _hog_, _sow_ |
| <span lang="grc">εἷς</span> _one_ (stem <span lang="grc">ἑν-</span>) | <span lang="grc">ναῦ-ς</span> _ship_ | <span lang="grc">φλόξ</span> _flame_ (<span lang="grc">φλέγ-ω</span> _burn_) |
| <span lang="grc">θήρ</span> _wild beast_ (gen. <span lang="grc">θηρ-όσ</span>) | <span lang="grc">ὄψ</span> _voice_ (stem <span lang="grc">ὀπ-</span>) | <span lang="grc">χείρ</span> _hand_ (gen. <span lang="grc">χειρ-όσ</span>) |
| <span lang="grc">κλώψ</span> _thief_ (<span lang="grc">κλέπ-τ-ω</span> _steal_) | <span lang="grc">πούς</span> _foot_ (stem <span lang="grc">ποδ-</span>) | <span lang="grc">χθών</span> _earth_ (stem <span lang="grc">χθον-</span>) |

##### <a id="s824"></a> §824

Most stems are derived from roots by the addition of one or more formative suffixes.

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| <span lang="grc">δῶ-ρο-ν</span> | _gift_, | stem <span lang="grc">δωρο-</span>, | root <span lang="grc">δω</span> (<span lang="grc">δί-δω-μι</span> _give_), | suffix <span lang="grc">ρο-</span>. |
| <span lang="grc">γραμ-ματ-εύ-ς</span> | _scribe_, | stem <span lang="grc">γραμματευ-</span>, | root <span lang="grc">γραφ</span>, | suffixes <span lang="grc">ματ</span> and <span lang="grc">ευ</span>. |

**a.** Most words are therefore built up from root, suffix, and inflectional ending by a process of composition analogous to that seen in compounds ([869 f](06-compound-words.md#s869)f.), in which the union of the various elements yields an idea different from that seen in each of the parts.

##### <a id="s825"></a> §825

A stem is _primary_ if only one suffix is added to the root (<span lang="grc">δῶ-ρο-ν</span>); _secondary_, when more than one suffix is added to the root (<span lang="grc">γραμ-ματ-εύ-ς</span>).

##### <a id="s826"></a> §826

There are two kinds of stems: noun-stems (substantive and adjective) and verb-stems.

##### <a id="s827"></a> §827

Words containing a single stem are called _simple_ words, as <span lang="grc">λόγο-ς</span> _speech;_ words containing two or more stems are called _compound_ words, as <span lang="grc">λογο-γράφο-ς</span> _speech-writer_. <!-- page 226 -->

##### <a id="s828"></a> §828

According to the character of the suffix words are called:

**a. Primitive** (or **Primary**): formed by the addition of a suffix either to a root or to a verb-stem to which a vowel, usually <span lang="grc">ε</span>, has been added ([485](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s485), [486](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s486)).

Root <span lang="grc">γραφ</span>: <span lang="grc">γράφ-ω</span> _write_, <span lang="grc">γραφ-ή</span> _writing_, <span lang="grc">γραφ-εύ-ς</span> _writer_, <span lang="grc">γράμ-μα</span> _something written_, <span lang="grc">γραμ-μή</span> _line_.

Verb-stem <span lang="grc">γεν-ε</span> in <span lang="grc">γενέ-σθαι</span> _become_ (<span lang="grc">ἐγενόμην, γί-γν-ομαι</span>): <span lang="grc">γένε-σι-ς</span> _genesis_, _origin;_ <span lang="grc">τερ-ε</span> (<span lang="grc">τέρω</span> _bore_): <span lang="grc">τέρε-τρο-ν</span> _gimlet_, _instrument for boring_.

**b. Denominative** (or **Secondary**): formed from a noun-stem (substantive or adjective) or adverb.

<span lang="grc">γραμ-ματ-εύς</span> _writer_ (stem <span lang="grc">γραμματ-</span>, nom. <span lang="grc">γράμμα</span>); <span lang="grc">εὐδαιμον-ίᾱ</span> _happiness_ (stem <span lang="grc">εὐδαιμον-</span>, nom. <span lang="grc">εὐδαίμων</span>); <span lang="grc">δικαιο-σύνη</span> _justice_, <span lang="grc">δίκα-ιο-ς</span> _just_ (<span lang="grc">δίκη</span> _right_); <span lang="grc">φίλ-ιο-ς</span> _friendly_ (<span lang="grc">φίλο-ς</span> _dear_); <span lang="grc">δουλό-ω</span> _enslave_ (<span lang="grc">δοῦλο-ς</span> _slave_); <span lang="grc">παλαι-ό-ς</span> _ancient_, _of old date_, from the adverb <span lang="grc">πάλαι</span> _long ago_.

##### <a id="s829"></a> §829

Suffixes forming primitive words are called _primary_ suffixes; suffixes forming denominative words are called _secondary_ suffixes.

**a.** The distinction between primary and secondary suffixes is not original and is often neglected. Thus, in <span lang="grc">δεινός</span> _terrible_ (<span lang="grc">δει-</span> _fear_), <span lang="grc">νο</span> is a primary suffix; in <span lang="grc">σκοτεινός</span> _dark_ (<span lang="grc">σκότος</span>, 858. [11](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s11)), it is secondary. So English _-able_ is both primary (_readable_) and secondary (_companionable_).

**b.** It is often difficult to determine whether a suffix is added to a verb-stem or to a noun-stem: <span lang="grc">ἰσχῡ-ρός</span> _strong_ (<span lang="grc">ἰσχύ̄-ς</span> _strength_, <span lang="grc">ἰσχύ̄-ω</span> _am strong_).

**c.** A primitive word may be formed from a verb-stem which is itself denominative: <span lang="grc">τοξευ-τής</span> _bowman_ from <span lang="grc">τοξεύ-ω</span> _shoot with the bow_, derived from <span lang="grc">τόξο-ν</span> _bow_. A primitive may be formed with a suffix derived from a denominative: <span lang="grc">φλεγ-υρό-ς</span> _burning_ (<span lang="grc">φλέγ-ω</span> _burn_) with <span lang="grc">υρο</span> from <span lang="grc">λιγυ-ρό-ς</span> (<span lang="grc">λιγύ-ς</span>) _shrill_.

**d.** A denominative often has no corresponding primitive; sometimes the latter has been lost, sometimes it was presumed for the purpose of word-formation by the imitative process always at work in the making of language. Thus, <span lang="grc">δέμ-ν-ιο-ν</span> _bed_, from <span lang="grc">δεμ-νο-ν</span> (<span lang="grc">δέμ-ω</span> _build_, _construct_).

##### <a id="s830"></a> §830

To determine the root all suffixes must be removed from the stem until only that part remains which contains the fundamental idea.

**a.** Most roots are noun-roots or verb-roots; but originally a root was neither noun or verb ([193](../part-2-inflection/01-parts-of-speech.md#s193)). Some roots are pronominal, and express direction or position. Greek has many words whose roots cannot be discovered. The form of a root in Greek is not necessarily that which Comparative Grammar shows was common to the cognate languages.

**b.** Since the origin of many words, even with the help of the cognate languages, is uncertain, we are often at a loss where to make the dividing line between root and suffix. Suffixes are often preceded by a vowel which may be regarded as a part of the suffix or as an expansion of the root (by some scholars regarded as a part of the root itself).

##### <a id="s831"></a> §831

**Changes of the root-vowel**.—**a.** The root-vowel is sometimes strong, <!-- page 227 --> sometimes weak: <span lang="grc">**ει**, **οι**</span> (weak <span lang="grc"> **ι** </span>); <span lang="grc">**ευ**, **ου**</span> (weak <span lang="grc"> **υ** </span>); <span lang="grc"> **η** </span> or <span lang="grc"> **ω** </span> (weak <span lang="grc"> **α** </span> or <span lang="grc"> **ε** </span>). <span lang="grc">λεῖμ-μα</span> _remnant_, <span lang="grc">λοιπ-ό-ς</span> _remaining_, cp. <span lang="grc">λείπ-ω, ἔ-λιπ-ον; ζεῦγ-ος</span> _team_, cp. <span lang="grc">ζεύγ-νῡ-μι, ζυγ-όν</span> _yoke;_ <span lang="grc">σπουδ-ή</span> _zeal_, <span lang="grc">σπεύδ-ω</span> _hasten;_ <span lang="grc">λήθ-η</span> _forgetfulness_, <span lang="grc">λανθάνω</span> (<span lang="grc">λαθ-</span>) _forget;_ <span lang="grc">ἦθ-ος</span> _disposition_, <span lang="grc">ἔθ-ος</span> _custom_, _habit;_ <span lang="grc">ῥωχ-μός</span> _cleft_, <span lang="grc">ῥήγ-νῡ-μι</span> _break_ (<span lang="grc">ῥαγ-, ῥηγ-, ῥωγ-</span>). Cp. [36](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s36).

**b.** <span lang="grc"> **ε** </span> often varies with <span lang="grc"> **ο** </span>, sometimes with <span lang="grc">**α**; **η**</span> sometimes varies with <span lang="grc">**ω**. γόν-ο-ς</span> _offspring_, <span lang="grc">γί-γν-ομαι</span> (<span lang="grc">γεν-</span>); <span lang="grc">τόν-ο-ς</span> _tone_, <span lang="grc">τείνω</span> (<span lang="grc">τεν-</span>) _stretch;_ <span lang="grc">τραφ-ερός</span> _well-fed_, <span lang="grc">τροφ-ή</span> _nourishment_, <span lang="grc">τρέφ-ω</span> _nourish;_ <span lang="grc">ἀρωγ-ό-ς</span> _helping_, <span lang="grc">ἀρήγ-ω</span> _help_. Cp. [36](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s36).

##### <a id="s832"></a> §832

**Root-determinatives**.—A consonant standing between root and suffix (or ending), and not modifying the meaning of the root, is called a _root-determinative_.

<span lang="grc">βά-θ-ρο-ν</span> _pedestal_, from <span lang="grc">βαίνω</span> _go_ (<span lang="grc">βα-</span>); <span lang="grc">ἔσ-θ-ω</span> (poetical for <span lang="grc">ἐσθίω</span>) _eat_, for <span lang="grc">εδ-θ-ω</span>, cp. Ionic <span lang="grc">ἔδ-ω; πλή-θ-ω</span> (poet.) _am full_, <span lang="grc">πλῆ-θ-ος</span> _crowd_, <span lang="grc">πλη-θ-ώρη</span> _satiety_, cp. <span lang="grc">πίμ-πλη-μι; στα-θ-μός</span> _day's journey_, <span lang="grc">στά-θ-μη</span> _a rule_, from <span lang="grc">ἵστημι</span> (<span lang="grc">στα-</span>); <span lang="grc">σμή-χ-ω</span> _wipe_, cp. <span lang="grc">σμάω</span> _wipe_.—On the insertion of <span lang="grc">ς</span>, see [836](#s836).

**a.** The origin of root-determinatives is obscure. In part they may be relics of roots, in part due to the analogy of words containing the consonants in question.

##### <a id="s833"></a> §833

**Suffixes**.—A suffix is a formative element added to a root (or to a stem) and standing between the root and the ending. Suffixes limit or particularize the general meaning of the root; but only in a few cases is the distinct meaning of the suffix known to us.

**a.** The origin of the Greek suffixes is often obscure; of those inherited from the parent language only some were employed to make new words; others were formed by Greek itself (productive suffixes). From the analogy of the modern languages we infer that some suffixes were once independent words, which, on becoming a part of a compound, lost their signification. Thus _-hood_, _-head_ in _childhood_, _godhead_ are derived from Old Eng. ‘hād,’ Gothic ‘haidus’ _character_, _nature; -ship_ in _ownership_, _courtship_, comes from a lost word meaning ‘shape’; _-ly_ in _friendly_ from Old Eng. ‘līc’ _body_. So <span lang="grc">-ώδης</span> meaning _smelling_ (<span lang="grc">ὄζω</span>), as in <span lang="grc">εὐώδης</span> _fragrant_, acquired a range of meaning originally inappropriate to it by passing into the general idea of ‘full of,’ ‘like,’ as in <span lang="grc">ποιώδης</span> _grassy_ (<span lang="grc">ποίᾱ</span>), <span lang="grc">λοιμώδης</span> _pestilential_ (<span lang="grc">λοιμός</span>), <span lang="grc">σφηκώδης</span> _wasp-like_ (<span lang="grc">σφήξ</span>). This suffix is distinct from <span lang="grc">-ειδής</span> _having the form of, like_ ([898 a](06-compound-words.md#s898)).

Conversely, many suffixes, themselves insignificant, acquired a definite meaning by reason of the root with which they were associated.—Irrespective of its meaning, one word may serve as a model for the creation of another word; as _starvation_, _constellation_, etc., are modelled on _contemplation_, etc.

**b.** Many dissyllabic suffixes, due to a combination of the final letter or letters of the stem and an original monosyllabic suffix, adapt themselves to independent use. Cp. _ego-tism_ for _ego-ism_ because of _patriot-ism_, _-able_ in _laughable_ and _probable_ (from _proba-bilis_). Thus, patronymics in <span lang="grc">-άδης, -ιάδης</span> 845. 2, 3; words in <span lang="grc">-αινα</span> 843 b, 5; <span lang="grc">-αῖος</span> 858. 2 a; <span lang="grc">-εῖον</span> 851. 1; <span lang="grc">-έστερος</span> 316; <span lang="grc">-έτης</span> 843 a, N.; <span lang="grc">-ήεις</span> 858. 3; <span lang="grc">-ήϊος</span> 858. 2 b; <span lang="grc">-εῖος</span> 858. 2 a; <span lang="grc">-όεις</span> 858. 3; <span lang="grc">-ίδιον</span> 852. 2; <span lang="grc">-ί̄της</span> 843 a, N., 844. 2 a; <span lang="grc">-σιμος</span> 858. 9; <span lang="grc">-ώτης</span> 843 a, N., 844. 2 a; and many others.

**c.** Simple suffixes are often added to case forms or adverbs, thus producing, <!-- page 228 --> by contamination, dissyllabic suffixes; as <span lang="grc">ἀρχαῖ-ο-ς</span> _ancient_ 858. 2 a; <span lang="grc">παλαι-ό-ς</span> _of old date_ 828 b, <span lang="grc">ἐαρι-νό-ς</span> _vernal_ 858. 12; <span lang="grc">φυσι-κό-ς</span> _natural_ 858. 6 b; cp. <span lang="grc">ἐν-άλι-ο-ς</span> _marine_ (<span lang="grc">ἅλς</span>).

**d.** Many compound suffixes are formed by the union of two suffixes, new stems being created by the addition of a suffix to a stem, as: <span lang="grc">τηρ-ιο</span> 851. 2, <span lang="grc">ισκ-ιο</span> 852. 6, <span lang="grc">ισκ-ιδιο</span> 854. See [854](02-formation-of-substantives.md#s854).

**e.** Suffixes often show gradations: <span lang="grc">**τηρ**, **τωρ**, **τερ**, **τρ**</span> ([36](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s36) N. 1) as in <span lang="grc">δο-τήρ, δώ-τωρ, δότειρα</span> (out of <span lang="grc">δοτερ-ῖα</span>) _giver;_ <span lang="grc">ψάλ-τρ-ια</span> _harp-player;_ <span lang="grc"> **μην μν** </span>: <span lang="grc">λι-μήν</span> _harbour_, <span lang="grc">λί-μν-η</span> _lake;_ <span lang="grc"> **μωρ μαρ** </span>: <span lang="grc">τέκ-μωρ, τέκ-μαρ</span> _goal;_ <span lang="grc"> **ωρ ρ** </span>: <span lang="grc">ὕδ-ωρ</span> _water_, <span lang="grc">ὕδ-ρᾱ</span> _hydra;_ <span lang="grc"> **ων αν** </span>: <span lang="grc">τέκτ-ων</span> _carpenter_, fem. <span lang="grc">τέκταινα</span>, from <span lang="grc">τεκταν-ῖα</span>; and in <span lang="grc">λέων</span> _lion_, fem. <span lang="grc">λέαινα</span> ([843 b](02-formation-of-substantives.md#s843). 5).

##### <a id="s834"></a> §834

**Changes in stems**.—Various changes occur when a suffix is added to a stem.

**a.** The final vowel of a stem is contracted with the initial vowel of a suffix: <span lang="grc">ὀφί̄διον</span> _small snake_ (<span lang="grc">ὄφι- ¨ ιδιον</span> from <span lang="grc">ὄφι-ς</span>). So when a consonant is dropped at the end of a stem: <span lang="grc">αἰδο-ῖο-ς</span> _venerable_ (<span lang="grc">αἰδώς</span> _reverence_, stem <span lang="grc">αἰδοσ-</span>), <span lang="grc">βασιλε-ίᾱ</span> _kingdom_ (<span lang="grc">βασιλεύ-ς</span> _king_, stem <span lang="grc">βασιλεϝ-</span> for <span lang="grc">βασιλεῦ-</span>. [43](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s43)), <span lang="grc">ἀστε-ῖο-ς</span> _refined_ (<span lang="grc">ἄστυ</span> _city_, stem <span lang="grc">ἀστεϝ-</span> for <span lang="grc">ἀστεῦ-</span>, [43](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s43)). Cp. [858](03-formation-of-adjectives.md#s858). 2.

**b.** A long final vowel of a stem may be shortened before the initial vowel of a suffix: <span lang="grc">δίκᾰ-ιο-ς</span> _just_, <span lang="grc">δίκη</span> _right_, stem <span lang="grc">δικᾱ-</span>. (Properly <span lang="grc">δίκαι</span> is an old case form, 833 c, to which <span lang="grc">-ο-ς</span> is added.)

**c.** A final vowel or diphthong may be dropped before the initial vowel of a suffix: <span lang="grc">σοφ-ίᾱ</span> _wisdom_ (<span lang="grc">σοφό-ς</span> _wise_), <span lang="grc">τί̄μ-ιο-ς</span> _honoured_, _costly_ (<span lang="grc">τῑμή</span> _honour_, stem <span lang="grc">τῑμᾱ-</span>), <span lang="grc">βασιλ-ικό-ς</span> _royal_ (<span lang="grc">βασιλεύ-ς</span> _king_), <span lang="grc">πολῑτ-ικό-ς</span> _civic_ (<span lang="grc">πολί̄της</span> _citizen_, stem <span lang="grc">πολῑτᾱ-</span>).

**d.** The final letter or letters of a consonant stem may be dropped: <span lang="grc">σωφρο-σύνη</span> _temperance_, _moderation_ (<span lang="grc">σώφρων</span> _temperate_, stem <span lang="grc">σωφρον-</span>), <span lang="grc">μελ-ύδριον</span> _little song_ (<span lang="grc">μέλ-ος</span> _song_, <span lang="grc">μελεσ-</span>), <span lang="grc">ἀληθ-ινό-ς</span> _genuine_ (<span lang="grc">ἀληθής -ές</span> _true_). So apparently in the case of a vowel stem in <span lang="grc">δεσπό-συνος</span> _belonging to the master_ (<span lang="grc">δεσπότης</span>).

**e.** The final consonant of a stem undergoes regular euphonic change before the initial consonant of a suffix: <span lang="grc">βλέμ-μα</span> _glance_ (<span lang="grc">βλέπ-ω</span> _look_), <span lang="grc">δικασ-τής</span> _a judge_ (<span lang="grc">δικαδ-της</span>, from <span lang="grc">δικάζω</span> _judge_, stem <span lang="grc">δικαδ-</span>), <span lang="grc">πίσ-τι-ς</span> _faith_ ( = <span lang="grc">πιθ-τι-ς</span>, from <span lang="grc">πείθ-ω</span> _persuade_, stem <span lang="grc">πιθ-</span>), <span lang="grc">λέξις</span> _style_ ( = <span lang="grc">λεγ-σι-ς</span>, from <span lang="grc">λέγ-ω</span> _speak_).

**f.** Stems in <span lang="grc">ο</span> have an alternative in <span lang="grc">ε</span> (cp. <span lang="grc">ἵππο-ς</span>, voc. <span lang="grc">ἵππε</span>; 229 b). This <span lang="grc">ε</span> often appears in denominatives: <span lang="grc">οἰκέ-ω</span> _dwell_, <span lang="grc">οἰκέ-της</span> _house-servant_, <span lang="grc">οἰκε-ῖο-ς</span> _domestic_ (<span lang="grc">οἶκο-ς</span> _house_).

**g.** Derivatives of <span lang="grc">ᾱ</span> stems may apparently show <span lang="grc">ω</span> in place of <span lang="grc">ᾱ</span>; as <span lang="grc">στρατιώ-της</span> _soldier_ (<span lang="grc">στρατιά̄</span> _army_), <span lang="grc">Ἰ̄ταλιώ-της</span> _an Italiote_, Greek inhabitant of Italy (<span lang="grc">Ἰ̄ταλίᾱ</span> _Italy_). See [843 a](02-formation-of-substantives.md#s843), N. Stems in <span lang="grc">ᾱ</span> have <span lang="grc">η</span> in <span lang="grc">τῑμή-εις</span> _honoured_ (<span lang="grc">τῑμή</span>, stem <span lang="grc">τῑμᾱ-</span>).

**h.** Vowel stems, especially those derived from verbs, often lengthen a final short vowel before a suffix beginning with a consonant: <span lang="grc">ποίη-μα</span> _poem_, <span lang="grc">ποίη-σι-ς</span> _poetry_, <span lang="grc">ποιη-τή-ς</span> _poet_, <span lang="grc">ποιη-τι-κό-ς</span> _creative_, _poetical_ (<span lang="grc">ποιέ-ω</span> _make_); <span lang="grc">δεσμώ-τη-ς</span> _prisoner_ (<span lang="grc">δεσμό-ς, δεσμά</span> _fetters_). Verbs with stems in <span lang="grc">α, ε, ο</span> usually show in derivatives the stem vowel as found in the tenses other than the present; as <span lang="grc">δηλό-ω</span> _manifest_, fut. <span lang="grc">δηλώ-σω, δήλω-σι-ς</span> _manifestation;_ <span lang="grc">ἀρόω</span> _plough_, fut. <span lang="grc">ἀρό-σω, ἄρο-σι-ς</span> _arable land_, <span lang="grc">ἀρο-τήρ</span> _ploughman;_ <span lang="grc">εὑρ-ίσκ-ω</span> _find out_, fut. <span lang="grc">εὑρ-ή-σω, εὕρ-η-μα</span> _discovery_, but <span lang="grc">εὕρ-ε-σις</span> _discovery_, <span lang="grc">εὑρ-ε-τής</span> _discoverer_. <!-- page 229 -->

**i.** Vowel stems sometimes insert a vowel before a suffix beginning with a consonant: <span lang="grc">πολι-ή-τη-ς</span>, Ionic for <span lang="grc">πολί̄-τη-ς</span> _citizen_, <span lang="grc">πτολί-ε-θρο-ν</span> (poetic) _city_.

**j.** Consonant stems, and vowel stems not ending in <span lang="grc">ο</span>, often show <span lang="grc">ο</span> before a suffix in denominatives; a stem in <span lang="grc">-ον</span> is thus replaced by one in <span lang="grc">-ο</span>: <span lang="grc">σωφροσύνη</span> _temperance_ (<span lang="grc">σώφρων</span> _temperate_, <span lang="grc">σωφρον-</span>); <span lang="grc">αἱματ-ό-εις</span> _bloody_ (<span lang="grc">αἷμα, -ατος</span> _blood_) and <span lang="grc">σκι-ό-εις</span> _shadowy_ (<span lang="grc">σκιά̄</span> _shadow_) by analogy to <span lang="grc">δολό-εις</span> _wily_, 858. 3. Cp. [873](06-compound-words.md#s873)-875.

##### <a id="s835"></a> §835

Several substantives are formed by reduplication: <span lang="grc">ἀγ-ωγ-ή</span> _training_ (<span lang="grc">ἄγ-ω</span> _lead_), <span lang="grc">ἐδ-ωδ-ή</span> _food_ (Ionic <span lang="grc">ἔδ-ω</span> _eat_), <span lang="grc">γί-γᾱς, -αντος</span> _giant_. Some, by metathesis ([128 a](../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s128)): <span lang="grc">τμῆ-σι-ς</span> _cutting_ (<span lang="grc">τέμ-ν-ω</span> _cut_).

##### <a id="s836"></a> §836

**Insertion of sigma**.—Between root (or stem) and suffix <span lang="grc">ς</span> is often found, and in some cases it has become attached to the suffix. This parasitic letter spread from the perfect middle, where it is properly in place only in stems in <span lang="grc">τ, δ, θ,</span> or <span lang="grc">ς</span>; as in <span lang="grc">σχι-σ-μό-ς</span> _cleaving_ with <span lang="grc">ς</span> from <span lang="grc">ἔ-σχι-σ-μαι</span> by analogy to <span lang="grc">ἔ-σχισ-ται</span> for <span lang="grc">ἐ-σχιδ-ται</span> (<span lang="grc">σχίζω</span> _cleave_). In <span lang="grc">-σ-της</span> the transference was made easier by words like <span lang="grc">σχισ-τός</span> _cloven_ for <span lang="grc">σχιδ-τος</span>. This <span lang="grc">ς</span> appears before many suffixes, and usually where the perfect middle has acquired it ([489](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s489)).

<span lang="grc">**μα**· σπά-σ-μα</span> _spasm_ (<span lang="grc">σπάω</span> _rend_, <span lang="grc">ἔσπασμαι</span>), <span lang="grc">κέλευ-σ-μα</span> _command_ (<span lang="grc">κελεύ-ω</span> _command_, <span lang="grc">κεκέλευσμαι</span>), <span lang="grc">μία-σ-μα</span> _stain_ (<span lang="grc">μιαίνω</span> _stain_, <span lang="grc">μεμίασμαι</span>).—<span lang="grc"> **μο** </span>: <span lang="grc">σπα-σ-μός ῀ σπά-σ-μα, κελευ-σ-μός</span> _command_.—<span lang="grc"> **μη** </span>: <span lang="grc">δύ-σ-μη</span> _setting_ (<span lang="grc">δύ̄ω</span> _set_).—<span lang="grc"> **της** </span>: <span lang="grc">κελευσ-τής</span> _signal-man_, <span lang="grc">ὀρχη-σ-τής</span> _dancer_ (<span lang="grc">ὀρχ-έ-ομαι</span> _dance_), <span lang="grc">δυνά-σ-της</span> _lord_ (<span lang="grc">δύνα-μαι</span> _am able_). Also in <span lang="grc">δρα-σ-τήριος</span> _efficacious_ (<span lang="grc">δρά-ω</span> _do_), <span lang="grc">ὀρχή-σ-τρᾱ</span> _dancing-place_, <span lang="grc">πλη-σ-μόνη</span> _fulness_. <span lang="grc">-σ-μ</span> has displaced <span lang="grc">δμ, -θ-μ</span> ([832](#s832)) in <span lang="grc">ὀσμή</span> _odour_ (earlier <span lang="grc">ὀδμή</span>), <span lang="grc">ῥυ-σ-μός</span> (and <span lang="grc">ῥυ-θ-μός</span>) _rhythm_.

##### <a id="s837"></a> §837

**Insertion of tau**.—In a few words <span lang="grc">τ</span> is inserted before the suffixes <span lang="grc">μο, μα, μη, μην</span>. Thus, <span lang="grc">ἐφ-ε-τ-μή</span> _command_ (<span lang="grc">ἐφί̄ημι</span>, root <span lang="grc">ἑ, ἡ</span>), <span lang="grc">λαῖ-τ-μα</span> _depth of the sea_, <span lang="grc">ἀϋ-τ-μή</span> and <span lang="grc">ἀϋ-τ-μήν</span> _breath_ (<span lang="grc">ἄημι</span> _blow_). In <span lang="grc">ἐρετ-μό-ν</span> _oar_ the <span lang="grc">τ</span> may be part of the verb-stem (<span lang="grc">ἐρέσσω</span>, [515](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s515)), and have spread thence to the other words.
