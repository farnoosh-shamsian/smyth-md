# LIST OF NOUN SUFFIXES

The list includes the chief suffixes used in substantives and adjectives. Separation of a suffix from the root is often arbitrary and uncertain. <!-- page 239 -->

##### <a id="s859"></a> §859

**VOWEL SUFFIXES**

\1. <span lang="grc"> **ο** </span>: nom. <span lang="grc">-ο-ς</span> masc., fem., <span lang="grc">-ο-ν</span> neut. A common suffix in primitives denoting persons (usually male agents) or things (often abstracts).

<span lang="grc">ἀρχ-ό-ς</span> _leader_ from <span lang="grc">ἄρχ-ω</span> _lead;_ <span lang="grc">ζυγ-ό-ν</span> _yoke_ from <span lang="grc">ζεύγ-νῡ-μι</span> _yoke_ (<span lang="grc">ζυγ-, ζευγ-</span>); <span lang="grc">λόγ-ο-ς</span> _speech_ from <span lang="grc">λέγ-ω</span> _speak;_ <span lang="grc">νόμ-ο-ς</span> _custom_, _law_ from <span lang="grc">νέμ-ω</span> _distribute;_ <span lang="grc">στόλ-ο-ς</span> _expedition_ from <span lang="grc">στέλλω</span> (<span lang="grc">στελ-</span>) _send;_ <span lang="grc">τροφ-ό-ς</span> (<span lang="grc">ὁ, ἡ</span>) _nurse_ from <span lang="grc">τρέφ-ω</span> _nourish;_ <span lang="grc">φόρ-ο-ς</span> _tribute_ from <span lang="grc">φέρ-ω</span> _bear_, _bring_.

**a.** The roots of some words appear only in other languages: <span lang="grc">οἶκ-ο-ς</span> _house_, Lat. _vīc-u-s_.

**b.** The suffix has the accent when the agent is denoted. <span lang="grc">ε</span> of the root varies with <span lang="grc">ο</span> ([831 b](01-word-formation-introductory.md#s831)).

\2. <span lang="grc"> **ᾱ** </span>: nom. <span lang="grc">-ᾱ</span> or <span lang="grc">-η</span> fem. A common suffix in primitives, usually to denote things, often abstracts (_action_).

<span lang="grc">ἀρχ-ή</span> _beginning_ from <span lang="grc">ἄρχ-ω</span> _begin;_ <span lang="grc">λοιβ-ή</span> _pouring_ from <span lang="grc">λείβ-ω</span> _pour;_ <span lang="grc">μάχ-η</span> _fight_ from <span lang="grc">μάχ-ομαι</span> _fight;_ <span lang="grc">σπουδ-ή</span> _haste_ from <span lang="grc">σπεύδ-ω</span> _hasten;_ <span lang="grc">στέγ-η</span> _roof_ from <span lang="grc">στέγ-ω</span> _shelter;_ <span lang="grc">τροφ-ή</span> _nourishment_ from <span lang="grc">τρέφ-ω</span> _nourish;_ <span lang="grc">τύχ-η</span> _chance_ from <span lang="grc">τυγχάνω</span> _happen_ (<span lang="grc">τυχ-</span>); <span lang="grc">φορ-ά̄</span> _crop_ from <span lang="grc">φέρ-ω</span> _bear;_ <span lang="grc">φυγ-ή</span> _flight_ from <span lang="grc">φεύγω</span> _flee_ (<span lang="grc">φυγ-, φευγ-</span>).

**a.** The roots of some words appear only in other languages: <span lang="grc">γυν-ή</span> _woman_ (Eng. _queen_).

**b.** Most substantives accent the suffix; but many accent the penult.

\3. <span lang="grc"> **ᾱ** </span>: nom. <span lang="grc">-ᾱς, -ης</span>, in a few masculines, usually compounds: <span lang="grc">παιδο-τρίβ-η-ς</span> _trainer of boys in gymnastics_ (<span lang="grc">τρί̄βω</span> _rub_).

\4. <span lang="grc">**ῐ**, **ῑ**</span>: primary, in <span lang="grc">ὄφ-ι-ς</span> _snake_, poet. <span lang="grc">τρόχ-ι-ς</span> _runner_ (<span lang="grc">τρέχ-ω</span> _run_), <span lang="grc">πόλ-ι-ς</span> _city_ (originally <span lang="grc">πόλ-ῑ-ς</span>), <span lang="grc">ἤν-ῑ-ς</span> _yearling_. Many words with the <span lang="grc">ι-</span>suffix have taken on <span lang="grc">δ</span> or <span lang="grc">τ</span>; as <span lang="grc">ἐλπ-ί-ς</span> _hope_ <span lang="grc">ἐλπί-δ-ος</span> (<span lang="grc">ἔλπ-ομαι</span> _hope_), <span lang="grc">χάρ-ι-ς</span> _grace_ <span lang="grc">χάρι-τ-ος</span> (<span lang="grc">χαίρω</span> _rejoice_, <span lang="grc">χαρ-</span>).

\5. <span lang="grc"> **ιο** </span>: in a few primitive verbal adjectives (<span lang="grc">ἅγ-ιο-ς</span> 858. 2), but common in denominate adjectives ([858](03-formation-of-adjectives.md#s858). 2), rare in substantives: <span lang="grc">νυμφ-ίο-ς</span> _bridegroom_ (<span lang="grc">νύμφη</span> _bride_); in names of things more concrete than those ending in <span lang="grc">-ιᾱ</span>: <span lang="grc">μαρτύρ-ιο-ν</span> _a testimony_ (cp. <span lang="grc">μαρτύρ-ιᾱ</span> _testimony_); in gentiles ([844](02-formation-of-substantives.md#s844). 3); in diminutives ([852](02-formation-of-substantives.md#s852). 1), often in combination with other diminutive suffixes (<span lang="grc">αριο, ιδιο, υλλιο</span>, etc. [852](02-formation-of-substantives.md#s852)); often in combination with a final stem vowel ([851](02-formation-of-substantives.md#s851). 1, 858. 2).

\6. <span lang="grc">**ιᾰ**, **ιᾱ**</span>: rarely primary, in <span lang="grc">φύζα</span> _flight_ (<span lang="grc">φεύγ-ω</span> _flee_); in verbal abstracts: <span lang="grc">μανίᾱ</span> _madness_ ([840 a](02-formation-of-substantives.md#s840). 9); usually secondary in the fem. of adj. in <span lang="grc">-ύς</span>: <span lang="grc">βαρεῖα ῀ βαρεῦ-ια, πίττα</span> _pitch_ (= <span lang="grc">πικ-ῖα</span>, cp. Lat. _pic-us_), <span lang="grc">γλῶττα</span> _tongue_ = <span lang="grc">γλωχ-ια</span> (cp. <span lang="grc">γλωχ-ί̄-ς</span> _point_, <span lang="grc">γλῶχ-ες</span> _beards of corn_), <span lang="grc">θῆττα</span> _serf_ ([843 b](02-formation-of-substantives.md#s843). 4); in the nom. fem. of participles in <span lang="grc">ντ, οτ</span> (<span lang="grc">λύ̄ουσα</span> from <span lang="grc">λῡοντ-ῖα, λελυκυ-ῖα</span>); in denominative abstracts expressing quality ([840 b](02-formation-of-substantives.md#s840). 1, 2); in names of persons: <span lang="grc">ταμ-ίᾱ-ς</span> _steward_ (<span lang="grc">τέμ-ν-ω</span> _cut_, <span lang="grc">ἔ-ταμ-ον</span>), <span lang="grc">Νῑκ-ίᾱ-ς</span> _Nicias_ (<span lang="grc">νί̄κη</span> _victory_).—Often in combination with other suffixes: <span lang="grc">αινα</span> 843 b. 5; <span lang="grc">-ε-ια</span> 840 a. 9; <span lang="grc">ισσα</span> 843 b. 4; <span lang="grc">τρια, τειρᾱ</span> 839 b. 2, 3.

\7. <span lang="grc">**Ϝο**, **Ϝᾱ**</span>: primary, in <span lang="grc">ὅρος</span> for <span lang="grc">ὅρ</span>(<span lang="grc">ϝ</span>)<span lang="grc">ος</span> _boundary_, <span lang="grc">κεν</span>(<span lang="grc">ϝ</span>)<span lang="grc">ός</span> _empty_, <span lang="grc">λᾱι</span>(<span lang="grc">ϝ</span>)<span lang="grc">ός</span> _left_ (Lat. _laevus_), <span lang="grc">καλ</span>(<span lang="grc">ϝ</span>)<span lang="grc">ός</span> _beautiful;_ (probably) secondary in verbals in <span lang="grc">-τέος</span> (<span lang="grc">λυτέος</span> _that must be loosed_) and in adj. in <span lang="grc">-αλέος</span> ([860](#s860). 1). <!-- page 240 -->

\8. <span lang="grc"> **υ** </span> (<span lang="grc"> **ευ** </span>): primary, in adjectives ([858](03-formation-of-adjectives.md#s858). [15](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s15)), in substantives: <span lang="grc">γέν-υ-ς</span> _chin_, <span lang="grc">πῆχ-υ-ς</span> _fore-arm_.—9. <span lang="grc"> **ῡ** </span>: primary, in feminines: <span lang="grc">ἰσχ-ύ̄-ς</span> _strength_, <span lang="grc">ὀφρ-ῦ-ς</span> _eye-brow_, <span lang="grc">νέκ-ῡ-ς</span> (Hom.) _corpse_, cf. Lat. _nec-are_.—10. <span lang="grc"> **ευ** </span> (<span lang="grc"> **ηυ** </span>): primary of the agent ([839 a](02-formation-of-substantives.md#s839). 5); rarely of things: <span lang="grc">κοπ-εύ-ς</span> _chisel_ (<span lang="grc">κόπ-τ-ω</span> _cut_); secondary, of the person concerned ([843 a](02-formation-of-substantives.md#s843). 1), in gentiles ([844](02-formation-of-substantives.md#s844). 1), rarely of things: <span lang="grc">δονακ-εύ-ς</span> _reed-thicket_ (<span lang="grc">δόναξ</span> _reed_); in diminutives in <span lang="grc">-ιδεύς</span> ([853](02-formation-of-substantives.md#s853)).—11. <span lang="grc"> **οι** </span> (nom. <span lang="grc">-ώ</span>): primary in <span lang="grc">πειθ-ώ πειθοῦς</span> _persuasion_ ([279](../part-2-inflection/04-substantives/05-third-declension.md#s279)).—12. <span lang="grc"> **ωϜ** </span> (nom. <span lang="grc">-ως</span>): primary in <span lang="grc">ἥρ-ως ἥρω-ος</span> _hero_ ([267](../part-2-inflection/04-substantives/05-third-declension.md#s267)).

****SUFFIXES WITH LIQUIDS** (<span lang="grc">**λ**, **ρ**</span>)**

\1. <span lang="grc">**λο**, **λᾱ**</span>: primary, in <span lang="grc">φῦ-λο-ν</span> _race_, <span lang="grc">φῡ-λή</span> _clan_ (<span lang="grc">φύ̄-ω</span> _produce_), <span lang="grc">πῖ-λο-ς</span> _felt_ (Lat. _pi-lu-s_), <span lang="grc">ζεύγ-λη</span> _loop of a yoke_ (<span lang="grc">ζεύγ-νῡ-μι</span> _yoke_); <span lang="grc">ἆθ-λο-ς</span> _contest_, <span lang="grc">ἆθλο-ν</span> _prize_, <span lang="grc">τυφ-λό-ς</span> _blind_ (<span lang="grc">τύ̄φ-ω</span> _raise a smoke_), <span lang="grc">στρεβ-λό-ς</span> _twisted_ (<span lang="grc">στρέφ-ω</span> _turn_). Cp. [858](03-formation-of-adjectives.md#s858). 7. Secondary, in <span lang="grc">παχυ-λό-ς</span> _thickish_ (dimin.). <span lang="grc">**αλο**, **αλᾱ**</span>: primary, in <span lang="grc">ὀμφ-αλό-ς</span> _navel_, <span lang="grc">κρότ-αλο-ν</span> _clapper_ (<span lang="grc">κρότ-ο-ς</span> _noise_), <span lang="grc">κεφ-αλή</span> _head_, <span lang="grc">τροχ-αλό-ς</span> _running_ (<span lang="grc">τρέχ-ω</span>), <span lang="grc">πί̄-αλο-ς</span> _fat_ (<span lang="grc">πῑαίνω</span> _fatten_); secondary, in <span lang="grc">ὁμ-αλό-ς</span> _level_ (<span lang="grc">ὁμό-ς</span> _one and the same_). Developed from this are <span lang="grc">**αλεο**, **αλεᾱ**</span>: <span lang="grc">πῑ-αλέο-ς</span> _fat_, <span lang="grc">κερδ-αλέο-ς</span> _wily_ (<span lang="grc">κέρδ-ος</span> _gain_), see [858](03-formation-of-adjectives.md#s858). 7. <span lang="grc">**ελο**, **ελᾱ**</span>: primary (prob.), in <span lang="grc">εἴκ-ελο-ς</span> _like_ (<span lang="grc">ἔοικα</span> _am like_, <span lang="grc">εἰκ-</span>), <span lang="grc">νεφ-έλη</span> _cloud_ (Lat. _nebula_); secondary, in <span lang="grc">θυ-μέ-λη</span> _altar_. <span lang="grc">**ηλο**, **ηλᾱ**</span>: <span lang="grc">κάπ-ηλο-ς</span> _huckster_ (agency), <span lang="grc">θυ-ηλή</span> _sacrifice_ (<span lang="grc">θύ̄-ω</span>), <span lang="grc">ὑψ-ηλό-ς</span> _lofty_ (<span lang="grc">ὕψ-ος</span> _height_); primary or secondary: <span lang="grc">ἀπατ-η-λό-ς</span> _guileful_ (<span lang="grc">ἀπάτη</span> _guile_, <span lang="grc">ἀπατά-ω</span> _cheat_), <span lang="grc">σῑγ-ηλό-ς</span> _mute_ (<span lang="grc">σῑγή</span> _silence_, <span lang="grc">σῑγά-ω</span> _am mute_). <span lang="grc">**ιλο**, **ιλᾱ**</span>: primary, in <span lang="grc">τροχ-ίλο-ς</span> _sandpiper_ (<span lang="grc">τρέχ-ω</span> _run_); secondary, in <span lang="grc">ὀργ-ίλο-ς</span> _passionate_ (<span lang="grc">ὀργή</span>). <span lang="grc">**ῑλο**, **ῑλα**</span>: primary, in <span lang="grc">στρόβ-ῑλο-ς</span> _top_ (<span lang="grc">στρέφ-ω</span> _turn_); secondary, in <span lang="grc">πέδ-ῑλο-ν</span> _sandal_ (<span lang="grc">πέδ-η</span> _fetter_, <span lang="grc">πούς</span> _foot_). <span lang="grc">**υλο**, **υλᾱ**</span>: primary, in <span lang="grc">δάκτ-υλο-ς</span> _finger_, <span lang="grc">σταφυλή</span> _bunch of grapes_. Secondary, in <span lang="grc">μῑκκ-ύλο-ς</span> _small_ (<span lang="grc">μῑκκ-ό-ς</span>). <span lang="grc">**ῡλο**, **ῡλᾱ**</span>: <span lang="grc">σφονδ-ύ̄λη</span> _beetle_. <span lang="grc">**ωλο**, **ωλᾱ**</span>: primary, in <span lang="grc">εἴδ-ωλο-ν</span> _image_ (<span lang="grc">εἴδ-ομαι</span> _resemble_), <span lang="grc">εὐχ-ωλή</span> _prayer_ (<span lang="grc">εὔχ-ομαι</span>). Rare forms: <span lang="grc">**αλιο**, **αλιμο**, **ελιο**, **ηλιο**</span>.

\2. <span lang="grc"> **λυ** </span>: primary, in <span lang="grc">θῆ-λυ-ς</span> _female_ (root <span lang="grc">θη</span> _give suck_).

\3. <span lang="grc">**ρο**, **ρᾱ**</span>: primary, in substantives: <span lang="grc">ἀγ-ρό-ς</span> _field_, Lat. _ager_ (<span lang="grc">ἄγ-ω</span>), <span lang="grc">νεκ-ρό-ς</span> _corpse_ (cp. <span lang="grc">νέκ-ῡ-ς</span>), <span lang="grc">γαμ-β-ρό-ς</span> _son-in-law_ (<span lang="grc">γαμ-έ-ω</span> _marry_, for <span lang="grc">β</span> see [130](../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s130)), <span lang="grc">ἐχθ-ρό-ς</span> _enemy_, <span lang="grc">ἔχθ-ρᾱ</span> _hatred_ (<span lang="grc">ἔχθ-ω</span> _hate_), <span lang="grc">ἄργυ-ρο-ς</span> _silver_, <span lang="grc">ὕδ-ρᾱ</span> _hydra_ (<span lang="grc">ὕδ-ωρ</span> _water_); rarely, of instrument 842. 6; of place, in <span lang="grc">ἕδ-ρᾱ</span> _seat;_ primary, in adjectives ([858](03-formation-of-adjectives.md#s858). [13](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s13)). <span lang="grc">**αρο**, **αρᾱ**</span>: primary, in <span lang="grc">βλέφ-αρο-ν</span> _eye-lid_ (<span lang="grc">βλέπ-ω</span> _look_), <span lang="grc">τάλ-αρο-ς</span> _basket_ (<span lang="grc">τλάω, τλῆναι</span> _bear_), <span lang="grc">λιπ-αρό-ς</span> _shiny_ (cp. <span lang="grc">λίπ-ος</span> _fat_). <span lang="grc"> **ᾱρο** </span> (<span lang="grc"> **ηρο** </span>), <span lang="grc"> **ᾱρᾱ** </span> (<span lang="grc"> **ηρᾱ** </span>): primary or secondary, in <span lang="grc">ἀνι-ᾱ-ρό-ς</span> _grievous_ (<span lang="grc">ἀνίᾱ</span> _grief_, <span lang="grc">ἀνιά-ω</span> _grieve_), <span lang="grc">λῡπ-η-ρό-ς</span> _painful_ (<span lang="grc">λύ̄πη</span> _pain_, <span lang="grc">λῡπέ-ω</span> _grieve_); secondary, in <span lang="grc">ἀνθ-ηρό-ς</span> _flowery_ (<span lang="grc">ἄνθ-ος</span>), and perhaps in <span lang="grc">πον-ηρό-ς</span> _toilsome_ (<span lang="grc">πόνο-ς, πονέ-ομαι</span> _toil_). <span lang="grc">**ερο**, **ερᾱ**</span>: secondary, in <span lang="grc">φοβε-ρό-ς</span> _terrible_ (<span lang="grc">φόβο-ς</span> _terror_), whence <span lang="grc">σκι-ερό-ς</span> _shady_ (<span lang="grc">σκιά̄</span> _shade_); also in <span lang="grc">πενθ-ερό-ς</span> _father-inlaw_ = lit. one who binds (cp. <span lang="grc">πεῖσμα ῀ πενθ-σμα</span> _cable_), <span lang="grc">ἔν-εροι</span> _those below the earth_ (<span lang="grc">ἐν</span>). <span lang="grc">**υρο**, **υρᾱ**</span>: secondary, in <span lang="grc">λιγυ-ρό-ς</span> (<span lang="grc">λιγύ-ς</span>) _shrill_, whence primary <span lang="grc">ἄχ-υρο-ν</span> _chaff_, <span lang="grc">φλεγ-υρό-ς</span> _burning_ (<span lang="grc">φλέγ-ω</span> _burn_). <span lang="grc">**ῡρο**, **ῡρᾱ**</span>: primary or secondary, in <span lang="grc">ἰσχῡ-ρό-ς</span> _strong_ (<span lang="grc">ἰσχύ̄-ω</span> _am strong_, <span lang="grc">ἰσχύ̄-ς</span> _strength_); primary, in <span lang="grc">λέπ-ῡρο-ν</span> _rind_ (<span lang="grc">λέπ-ω</span> _peel_), <span lang="grc">γέφ-ῡρα</span> _bridge_. <span lang="grc">**ωρο**, **ωρᾱ**</span>: primary, in <span lang="grc">ὀπ-ώρᾱ</span> _late summer_ (<span lang="grc">ὄπ-ισθεν</span> _at the rear, after_). <!-- page 241 -->

\4. <span lang="grc"> **ρι** </span> (rare): primary, in <span lang="grc">ἄκ-ρι-ς</span> _hill-top_ (<span lang="grc">ἄκ-ρο-ς</span> _highest_), <span lang="grc">ἴδ-ρι-ς</span> _knowing_ (<span lang="grc">εἶδον, ἰδεῖν</span>).

\5. <span lang="grc"> **ρυ** </span> (rare): primary, in <span lang="grc">δάκ-ρυ</span> _tear;_ cp. Old Lat. _dacruma_ for _lacrima_.

\6. <span lang="grc"> **αρ** </span>: primary, in <span lang="grc">ἧπ-αρ, ἥπατ-ος</span> _liver_ ([253 b](../part-2-inflection/04-substantives/05-third-declension.md#s253)), <span lang="grc">πῖ-αρ</span> _fat_, <span lang="grc">ἔ-αρ</span> _spring_.—7. <span lang="grc"> **ερ** </span>, <span lang="grc"> **ηρ** </span>: primary, in <span lang="grc">ἀ̄ή̄ρ ἀ̄έρ-ος</span> _air_ (<span lang="grc">ἄημι</span> _blow_, of the wind), <span lang="grc">αἰθ-ήρ, -έρ-ος</span> _upper air_ (<span lang="grc">αἴθ-ω</span> _kindle_).—8. <span lang="grc"> **ωρ** </span>: primary: gen. <span lang="grc">-ατ-ος</span>: <span lang="grc">ὕδ-ωρ</span> _water;_ gen. <span lang="grc">-ωρος</span>: <span lang="grc">ἰ̄χώρ</span> _ichor_, _serum;_ gen. <span lang="grc">-ορος</span>: by analogy in <span lang="grc">αὐτο-κράτ-ωρ</span> _possessing full powers_ (<span lang="grc">κράτ-ος</span> _power_).—9. <span lang="grc"> **ωρᾱ** </span>: primary, in <span lang="grc">πλη-θ-ώρη</span> (Ionic) _satiety_, cp. [832](01-word-formation-introductory.md#s832).

##### <a id="s861"></a> §861

****SUFFIXES WITH NASALS** (<span lang="grc">**μ**, **ν**</span>)**

\1. <span lang="grc">**μο**, **μᾱ**</span> (nom. <span lang="grc">μο-ς; -μᾰ</span> and <span lang="grc">-μη</span>): primary, in substantives denoting actions or abstract ideas ([840 a](02-formation-of-substantives.md#s840). 5-7), and in some concretes: <span lang="grc">χῡ-μό-ς</span> _juice_ (<span lang="grc">χέω</span> _pour_, <span lang="grc">χυ-</span>), <span lang="grc">γραμ-μή</span> _line_ (<span lang="grc">γράφ-ω</span> _write_, _draw_); in adjectives ([858](03-formation-of-adjectives.md#s858). 8, 9). On <span lang="grc">-τ-μο -τ-μα, -θ-μο -θ-μα, -σ-μο -σ-μα</span> see [837](01-word-formation-introductory.md#s837), [832](01-word-formation-introductory.md#s832), 836; secondary, rarely in substantives: <span lang="grc">δρῡ-μό-ς</span> _coppice_ (<span lang="grc">δρῦ-ς</span> _tree_, _oak_), or adjectives: <span lang="grc">ἔτυ-μο-ς</span> _true_ (<span lang="grc">ἐτεϝός</span> _real_).—<span lang="grc"> **ι-μο** </span>: secondary, derived from <span lang="grc">ι</span> stems ([858](03-formation-of-adjectives.md#s858). 9).—2. <span lang="grc"> **ματ** </span> (nom. <span lang="grc">-μα</span>): primary, denoting result ([841](02-formation-of-substantives.md#s841). 2). ##### <a id="s863"></a> §863

****SUFFIXES WITH DENTALS** (<span lang="grc">**τ**, **δ**, **θ**</span>)**

**a.** Suffixes with <span lang="grc"> **τ** </span>.

\1. <span lang="grc"> **τ** </span>: primary, at the end of stems, as <span lang="grc">ἀ-γνώς, ἀ-γνῶ-τ-ος</span> _unknown_ (<span lang="grc">γι-γνώ-σκω</span> _know_).

\2. <span lang="grc">**το**, **τᾱ**</span>: primary, in verbal adjectives in <span lang="grc">-τό-ς</span> ([471](../part-2-inflection/09-verbs/08-endings-of-the-verb-personal-endings.md#s471)) with the force of a perfect participle, as <span lang="grc">γνω-τό-ς</span> _known_ (<span lang="grc">γι-γνώ-σκω</span> _know_), <span lang="grc">στα-τό-ς</span> _placed_, _standing_ (<span lang="grc">ἴ-στη-μι</span> _set_, _place_), or with the idea of possibility, as <span lang="grc">λυ-τό-ς</span> _able to be loosed;_ in verbal abstracts, which sometimes become concrete: <span lang="grc">κοί-το-ς, κοί-τη</span> _bed_ (<span lang="grc">κεῖ-μαι</span> _lie_), <span lang="grc">βρον-τή</span> _thunder_ (<span lang="grc">βρέμ-ω</span> _roar_), <span lang="grc">φυ-τό-ν</span> _plant_ (<span lang="grc">φύ̄ω</span> _produce_), <span lang="grc">πο-τό-ν</span> _drink_ (<span lang="grc">πί̄νω</span> _drink_, <span lang="grc">πο-</span> [529](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s529)), <span lang="grc">βιο-τός, βιο-τή</span> _life_, _means of living_ (<span lang="grc">βίο-ς</span> _life_)_;_ in numerals, <span lang="grc">τρί-το-ς</span> _third_, <span lang="grc">ἕκ-το-ς</span> _sex-tu-s_.—In superlatives, <span lang="grc"> **ισ-το** </span> primary, as <span lang="grc">ἥδ-ιστο-ς</span> _sweetest_ (<span lang="grc">ἡδ-ύ-ς</span>); secondary, to denote the person concerned ([843 a](02-formation-of-substantives.md#s843). 2).—<span lang="grc">**ατο**, **ατᾱ**</span>: primary, in <span lang="grc">θάν-ατο-ς</span> _death_ (<span lang="grc">θνῄ-σκω, θαν-εῖν</span> _die_), <span lang="grc">κάμ-ατο-ς</span> _weariness_ (<span lang="grc">κάμ-νω, καμ-εῖν</span> _am weary_). <span lang="grc">**ετο**, **ετᾱ**</span>: primary, in <span lang="grc">παγ-ετό-ς</span> _frost_ (<span lang="grc">πήγ-νῡ-μι</span> _make hard_); secondary, in <span lang="grc">εὐν-έτη-ς</span> _bed-fellow_ (<span lang="grc">εὐνή</span> _bed_, 843 a. N.). <span lang="grc">**ᾱτᾱ ᾱτιδ**, **ητᾱ ητιδ**, **ῑτᾱ ῑτιδ**, **ωτᾱ ωτιδ**</span>, in gentiles ([844](02-formation-of-substantives.md#s844). 2).

See [859](#s859). 4.—21. <span lang="grc"> **ῑτιδ** </span> (nom. <span lang="grc">-ῖτις</span>, fem.): secondary in words denoting place ([851](02-formation-of-substantives.md#s851). 4).—22. <span lang="grc"> **ωτ** </span>: primary, in <span lang="grc">γέλως, -ωτος</span> _laughter_ (<span lang="grc">γελά-ω</span> laugh).—23. <span lang="grc"> **ντ** </span>: primary, in active participles (except the perfect), as <span lang="grc">λύ̄ο-ντ-ος</span>; in some adjectives inflected like participles (<span lang="grc">ἑκών</span> _willing_), and in participial substantives: <span lang="grc">δράκ-ων</span> _serpent_ (<span lang="grc">δέρκ-ομαι</span> _gleam_, <span lang="grc">δρακ-εῖν</span>), also in <span lang="grc">λέων</span> _lion_, <span lang="grc">ἀδάμᾱς</span> _adamant_. —24. <span lang="grc"> **ϝεντ** </span> (nom. <span lang="grc">-εις</span>): secondary, in adjectives denoting _fulness_ ([858](03-formation-of-adjectives.md#s858). 3), and in some proper names of places: <span lang="grc">Ὀποῦς</span> _Opus_ from <span lang="grc">Ὀποϝεντ-ς</span> ([844](02-formation-of-substantives.md#s844). 3).

**b.** Suffixes with <span lang="grc"> **δ** </span>.

\1. <span lang="grc"> **δ** </span>: secondary, in patronymics ([845](02-formation-of-substantives.md#s845). 1).—2. <span lang="grc"> **δ-ανο** </span>: secondary, in <span lang="grc">οὐτιδανό-ς</span> _a nobody_ (<span lang="grc">οὔτις</span> _nobody_), properly from <span lang="grc">τιδ</span>, neuter of <span lang="grc">τὶ</span>, + <span lang="grc">ανό-ς</span>. —<span lang="grc"> **ε-δανο** </span>: primary, in <span lang="grc">ῥῑγ-ε-δανό-ς</span> _chilling_ (<span lang="grc">ῥῑγ-έω</span> _shudder_).—3. <span lang="grc"> **δ-απο** </span>: secondary, in <span lang="grc">ἀλλοδαπός</span> _foreign_, properly = <span lang="grc">ἀλλοδ</span>, neuter of <span lang="grc">ἄλλος</span> (cp. _aliud_), + <span lang="grc">από-ς</span>.—4. <span lang="grc"> **δ-ᾱ** </span>: secondary, in patronymics ([845](02-formation-of-substantives.md#s845). 1).—5. <span lang="grc"> **δ-ιο** </span>: <span lang="grc">στά-δ-ιο-ς</span> _standing_ (<span lang="grc">ἴ-στη-μι</span>), with <span lang="grc">δ</span> prob. from a word containing the suffix <span lang="grc">δ</span>, as <span lang="grc">ἀμ-φάδιο-ς</span> _public_ from <span lang="grc">ἀμ-φαδό-ν</span> _publicly_.—6. <span lang="grc"> **δων** </span>: primary, in <span lang="grc">μελ-ε-δών</span> _care_ (<span lang="grc">μέλει</span> _is a care_), <span lang="grc">ἀλγ-η-δών</span> _pain_ (<span lang="grc">ἀλγέ-ω</span> _suffer_); secondary, in <span lang="grc">κοτυληδών</span> _a cup-shaped hollow_ (<span lang="grc">κοτύλη</span> _cup_); cp. <span lang="grc">ἀχθ-η-δών</span> _distress_ (<span lang="grc">ἄχθ-ος</span> _burden_).—7. <span lang="grc"> **δωνᾱ** </span>: primary, in <span lang="grc">μελ-ε-δώνη</span> _care_ (see <span lang="grc">δων</span>).

\8. <span lang="grc"> **αδ** </span>: primary, in <span lang="grc">νιφ-άς, -άδ-ος</span> _snow-flake_ (<span lang="grc">νί̄φ-ω</span>, better <span lang="grc">νείφ-ω</span>, _snow_), <span lang="grc">φυγ-άς</span> _exile_ (<span lang="grc">φεύγ-ω</span> _flee_, <span lang="grc">φυγ-</span>), <span lang="grc">λαμπ-άς</span> _torch_ (<span lang="grc">λάμπ-ω</span> _shine_); secondary, in abstract feminines denoting number ([840 b](02-formation-of-substantives.md#s840). 5).—9. <span lang="grc"> **ιαδ** </span>, 10. <span lang="grc"> **ιαδᾱ** </span>: secondary, in patronymics ([845](02-formation-of-substantives.md#s845). 3).—11. <span lang="grc"> **αδιο** </span>: secondary, in <span lang="grc">κατ-ωμ-άδιο-ς</span> _from the shoulder_ (<span lang="grc">ὦμο-ς</span>), derived from <span lang="grc">διχθ-άδ-ιο-ς</span> _divided_ (<span lang="grc">διχθάς, -άδος</span> _divided_).—12. <span lang="grc"> **ιδ** </span>: primary, in <span lang="grc">ἀσπ-ίς, -ίδ-ος</span> _shield_, <span lang="grc">ἐλπ-ίς</span> _hope_ (<span lang="grc">ἔλπομαι</span> _hope_); secondary, in adj. as <span lang="grc">συμμαχίς</span> _allied_ (<span lang="grc">πόλις</span>) from <span lang="grc">σύμμαχο-ς</span> _allied with;_ in words denoting the person concerned ([843 b](02-formation-of-substantives.md#s843). 2); in gentiles ([844](02-formation-of-substantives.md#s844). 1), as <span lang="grc">Περσίς</span> _Persian woman;_ in feminine patronymics ([845](02-formation-of-substantives.md#s845). 4).—13. <span lang="grc"> **ιδᾱ** </span>: secondary, in patronymics <!-- page 244 --> ([845](02-formation-of-substantives.md#s845). 4).—14. <span lang="grc"> **ιδεο** </span>: secondary, in names of relationship ([850](02-formation-of-substantives.md#s850)).— 15. <span lang="grc"> **ιδευ** </span>: secondary, in diminutives ([853](02-formation-of-substantives.md#s853)).—16. <span lang="grc"> **ιδιο** </span>: secondary, in diminutives ([852](02-formation-of-substantives.md#s852). 2), and transferred in <span lang="grc">μοιρ-ίδιο-ς</span> _doomed_ (<span lang="grc">μοῖρα</span> _doom_). —17. <span lang="grc"> **ῑδ** </span>: secondary, in <span lang="grc">κνημί̄ς</span> _greave_ (<span lang="grc">κνήμη</span> _leg_, _thigh_).—18. <span lang="grc"> **νδᾱ** </span>: secondary, in patronymics ([846](02-formation-of-substantives.md#s846), e).—19. <span lang="grc"> **ωδες** </span>: secondary, in _adjectives of fulness_ ([858](03-formation-of-adjectives.md#s858). [16](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s16)).

**c.** Suffixes with <span lang="grc"> **θ** </span>.

\1. <span lang="grc"> **θ** </span> appears in suffixes that are obscure in relation to root or stem ([832](01-word-formation-introductory.md#s832)): <span lang="grc">ὄρνῑς ὄρνῑθ-ος</span> _bird_, <span lang="grc">ψάμαθος</span> _sand_, <span lang="grc">κύαθος</span> _cup_, <span lang="grc">πέλεθος</span> _ordure;_ several in <span lang="grc">-νθ</span> (probably not Greek), as <span lang="grc">ἐρέβ-ινθος</span> _chick-pea_.—2. <span lang="grc">**θλο**, **θλᾱ**</span>: primary, in <span lang="grc">γέν-ε-θλο-ν, γεν-έ-θλη</span> _race_ (<span lang="grc">γίγ-νομαι</span> _become_, <span lang="grc">γεν-</span>).—3. <span lang="grc"> **θλιο** </span>: secondary, in <span lang="grc">γεν-έ-θλιο-ς</span> _belonging to one's birth_.—4. <span lang="grc">**θρο**, **θρα**</span>: primary, in <span lang="grc">ἄρ-θρο-ν</span> _joint_ (<span lang="grc">ἀραρίσκω</span> _join_, <span lang="grc">ἀρ-</span>), <span lang="grc">ἐπι-βά-θρᾱ</span> _ladder_ (<span lang="grc">βαίνω</span> _go_, <span lang="grc">βα-</span>).

\8. <span lang="grc"> **αγ** </span>: primary, in <span lang="grc">ἅρπαξ</span> _rapacious_, <span lang="grc">ἁρπαγ-ή</span> _seizure_ (cp. <span lang="grc">ἁρπάζω</span> _seize_).— 9. <span lang="grc"> **ῑγ** </span>: primary, in <span lang="grc">μάστιξ, -ῑγ-ος</span> _whip_.—10. <span lang="grc"> **υγ** </span>: primary, in <span lang="grc">ἄντυξ, -υγος</span> _rim_.—11. <span lang="grc"> **γγ** </span>: primary, denoting something hollow, in <span lang="grc">φάλαγξ</span> _phalanx_, <span lang="grc">σάλπιγξ</span> _trumpet_, <span lang="grc">λάρυγξ</span> _larynx_.

##### <a id="s865"></a> §865

**SUFFIXES WITH SIGMA**

\1. <span lang="grc"> **σι** </span> ( = <span lang="grc">τι</span>): primary, denoting actions or abstract ideas ([840 a](02-formation-of-substantives.md#s840). 2); rarely of persons: <span lang="grc">πό-σι-ς</span> _husband_.—2. <span lang="grc"> **σιᾱ** </span>: primary, denoting actions or abstract ideas ([840 a](02-formation-of-substantives.md#s840). 3).—3. <span lang="grc"> **σιο** </span>: primary, in <span lang="grc">μετ-άρ-σιο-ς</span> _raised from the ground_ (<span lang="grc">μετ-αίρω</span> _lift up_, <span lang="grc">ἀρ-</span>).—4. <span lang="grc"> **σιμο** </span>: in adj. ([858](03-formation-of-adjectives.md#s858). 9).—5. <span lang="grc"> **στηνο** </span>: in <span lang="grc">δύ</span>(<span lang="grc">σ</span>)<span lang="grc">στηνο-ς</span> _unhappy_.—6. <span lang="grc"> **στο** </span>: secondary, in <span lang="grc">τριᾱκοστό-ς</span> _thirtieth_ from <span lang="grc">τριᾱκοντ</span> + <span lang="grc">το-ς</span>.—7. <span lang="grc">**συνο**, **συνᾱ**</span>: secondary, in adjectives: <span lang="grc">δουλό-συνος</span> _enslaved_ (<span lang="grc">δοῦλο-ς</span>), <span lang="grc">θάρσυνος</span> _bold_ = <span lang="grc">θαρσο-συνος</span> (<span lang="grc">θάρσ-ος</span> _courage_, 129 c), and in the feminine, to make abstract substantives ([840 b](02-formation-of-substantives.md#s840). 3).

\8. <span lang="grc"> **ας** </span>: primary, in <span lang="grc">γέρ-ας</span> _prize;_ varying with <span lang="grc">ατ</span>, as in <span lang="grc">τέρ-ας τέρατ-ος</span> _portent_ ([258](../part-2-inflection/04-substantives/05-third-declension.md#s258)), or with <span lang="grc">ες</span> ([264 D.](../part-2-inflection/04-substantives/05-third-declension.md#s264) 3).—9. <span lang="grc"> **ες** </span>: primary, denoting quality ([840 a](02-formation-of-substantives.md#s840). 8) or result ([841](02-formation-of-substantives.md#s841). 1) in adjectives ([858](03-formation-of-adjectives.md#s858). 5.)—10. <span lang="grc"> **ις** </span>: primary, in <span lang="grc">κόνις</span> _dust_, found in <span lang="grc">κονί̄ω</span> ( = <span lang="grc">κονισ-ῖω</span>, 500. 2, D).—11. <span lang="grc"> **ισσᾱ** </span>: secondary, in words denoting the person concerned ([843 b](02-formation-of-substantives.md#s843). 4).—12. <span lang="grc"> **ος** </span>: primary, in <span lang="grc">αἰδώς</span> _shame_ (<span lang="grc">αἰδοῦς</span> from <span lang="grc">αἰδο</span> (<span lang="grc">σ</span>)<span lang="grc">-ος</span>, [266](../part-2-inflection/04-substantives/05-third-declension.md#s266)).—13. <span lang="grc"> **ῑος** </span>: primary, in comparatives ([293 d](../part-2-inflection/04-substantives/07-adjectives.md#s293), [318](../part-2-inflection/05-comparison-of-adjectives.md#s318)).
