# ADVERBIAL COMPLEX SENTENCES (2193-2487): Introductory

<!-- page 493 -->

##### <a id="s2191"></a> §2191

In an adverbial complex sentence the subordinate clause denotes some one of the following adverbial relations: purpose ([2193](02-purpose-clauses-final-clauses.md#s2193)), cause ([2240](04-causal-clauses.md#s2240)), result ([2249](05-result-clauses-consecutive-clauses.md#s2249)), condition ([2280](09-conditional-clauses.md#s2280)), concession ([2369](11-concessive-clauses.md#s2369)), time ([2383](12-temporal-clauses.md#s2383)), comparison ([2462](13-clauses-of-comparison.md#s2462)).

##### <a id="s2192"></a> §2192

An adverbial sentence is introduced by a relative conjunction denoting _purpose_, _cause_, _result_, etc.
