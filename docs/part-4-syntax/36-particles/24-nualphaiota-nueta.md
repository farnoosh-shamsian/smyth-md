# PARTICLES: ναί, νή

##### <a id="s2922"></a> §2922

<span lang="grc"> **ναί** </span> (cp. Lat. _nae_) asseverative (_truly_, _yea_), with the accusative in oaths where it is usually followed by <span lang="grc">μά</span> ([1596 b](../18-the-cases/07-accusative.md#s1596)). <span lang="grc">ναί</span> _yes_, in answers, is found only in Attic.

##### <a id="s2923"></a> §2923

<span lang="grc"> **νή** </span> (cp. Lat. _neē_) asseverative (_truly_, _yea_), with the accusative in oaths, and only in an affirmative sense. <span lang="grc">νή</span> is found only in Attic. See [1596 b](../18-the-cases/07-accusative.md#s1596).
