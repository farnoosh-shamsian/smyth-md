# PARTICLES: καίπερ

##### <a id="s2892"></a> §2892

**<span lang="grc">και&lt;\*&gt;περ</span> _although_ is common with participles** ([2083](../22-the-participle.md#s2083)). As a conjunction (cp. _quanquam_) without a main clause it is very rare (<cite data-ref="Plat. Sym. 219c">P. S. 219c</cite>).
