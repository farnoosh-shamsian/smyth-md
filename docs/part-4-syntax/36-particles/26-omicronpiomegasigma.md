# PARTICLES: ὅπως

##### <a id="s2929"></a> §2929

<span lang="grc"> **ὅπως** </span>, originally a relative adverb meaning _how_, is derived from the relative particle <span lang="grc">σϝοδ</span> (with which Eng. _so_ is connected), to which the indefinite <span lang="grc">πώς</span> has been added. Hom. <span lang="grc">ὅππως</span> from <span lang="grc">σϝοδ-πως</span>, as <span lang="grc">ὅττι</span> from <span lang="grc">σϝοδ-τι</span> ([81](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s81) D 2).

**a.** The adverbial meaning of <span lang="grc">ὅπως</span> is still seen in its use as an indefinite relative and as an indirect interrogative; and by the fact that in its place <span lang="grc">ὅπῃ, ὅτῳ τρόπῳ, ἐξ ὅτου τρόπου</span> are sometimes used. By association with the subjunctive <span lang="grc">ὅπως</span> became a conjunction (cp. <span lang="grc">μή πως</span>) used with or without <span lang="grc">ἄν</span> in final clauses (see [2196](../29-adverbial-complex-sentences-2193-2487/02-purpose-clauses-final-clauses.md#s2196), [2201](../29-adverbial-complex-sentences-2193-2487/02-purpose-clauses-final-clauses.md#s2201)). On the use as a conjunction in object clauses after _verbs of effort_ and of _fear_, see [2211](../29-adverbial-complex-sentences-2193-2487/03-object-clauses.md#s2211), [2228](../29-adverbial-complex-sentences-2193-2487/03-object-clauses.md#s2228). So in dependent statements <span lang="grc">ὅπως</span> passed from _how_ into _that_ ([2578 d](../31-dependent-substantive-clauses-2574-2635.md#s2578)).
