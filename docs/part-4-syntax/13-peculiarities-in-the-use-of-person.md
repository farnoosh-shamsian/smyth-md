# PECULIARITIES IN THE USE OF PERSON

##### <a id="s1016"></a> §1016

<span lang="grc">τὶς</span> or <span lang="grc">πᾶς</span> may be used in the drama with the second person of the imperative: <span lang="grc">ἴτω τις, εἰσάγγελλε</span> _go_, _one of you, announce_ <cite data-ref="Eur. Ba. 173">E. Bacch. 173</cite>.

##### <a id="s1017"></a> §1017

The second person singular is used to designate an imaginary person, as in proverbs: <span lang="grc">ψῡχῆς ἐπιμελοῦ τῆς σεαυτοῦ</span> _care for thy own soul_ Men. Sent. 551, and in such phrases as <span lang="grc">εἶδες ἄν</span> _you would have seen_ ([1784 a](20-the-verb-voices/07-the-moods-in-simple-sentences.md#s1784)), <span lang="grc">ἡγήσαιο ἄν</span> _you might think_, as _credideris_ ([1824](20-the-verb-voices/07-the-moods-in-simple-sentences.md#s1824)).

**a.** Hdt. uses the second person in directions to travellers (2. [30](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s30)).

See also [942](08-case-of-the-subject-the-nominative.md#s942).
