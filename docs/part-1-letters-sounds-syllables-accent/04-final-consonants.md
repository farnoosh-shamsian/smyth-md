# FINAL CONSONANTS

##### <a id="s133"></a> §133

No consonant except <span lang="grc">ν, ρ</span>, or <span lang="grc">ς</span> (including <span lang="grc">ξ</span> and <span lang="grc">ψ</span>) can stand at the end of a Greek word. All other consonants are dropped.

**a.** Exceptions are the proclitics ([179](07-accent-general-principles.md#s179)) <span lang="grc">ἐκ</span> _out of_, derived from <span lang="grc">ἐξ</span> (cp. [104](03-euphony-of-consonants.md#s104), [136](05-movable-consonants.md#s136)), and <span lang="grc">οὐκ</span> _not_, of which <span lang="grc">οὐ</span> is another form ([137](05-movable-consonants.md#s137)).

**b.** Examples of dropped final consonants: <span lang="grc">σῶμα</span> _body_ for <span lang="grc">σωματ</span> (gen. <span lang="grc">σώματος</span>); <span lang="grc">παῖ</span> _oh boy_ for <span lang="grc">παιδ</span> (gen. <span lang="grc">παιδ-ός</span>); <span lang="grc">γάλα</span> _milk_ for <span lang="grc">γαλακτ</span> (gen. <span lang="grc">γάλακτ-ος</span>); <span lang="grc">φέρον</span> _bearing_ for <span lang="grc">φεροντ</span> (gen. <span lang="grc">φέροντ-ος</span>); <span lang="grc">κῆρ</span> _heart_ for <span lang="grc">κηρδ</span>, cp. <span lang="grc">καρδ-ίᾱ; ἄλλο</span> for <span lang="grc">ἀλ\[ιγλιδε\]οδ</span> ([110](03-euphony-of-consonants.md#s110)), cp. Lat. _aliud;_ <span lang="grc">ἔφερε-</span> (<span lang="grc">τ</span>) _was carrying_, <span lang="grc">ἔφερο-ν</span> (<span lang="grc">τ</span>) _were carrying_ ([464 c](../part-2-inflection/09-verbs/08-endings-of-the-verb-personal-endings.md#s464), e).

**c.** An original final _m_ preceded by a vowel becomes <span lang="grc">ν</span>, cp. <span lang="grc">ἵππον</span> with Lat. _equum_. So <span lang="grc">ἕν</span> _one_ from <span lang="grc">ἑμ</span> ([349 a](../part-2-inflection/08-numerals.md#s349)), Lat. _sem-el_, <span lang="grc">ἅμα</span> _once_.
