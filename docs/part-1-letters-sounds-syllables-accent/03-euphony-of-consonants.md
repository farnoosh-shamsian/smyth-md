# EUPHONY OF CONSONANTS

##### <a id="s77"></a> §77

**Assimilation**.—A consonant is sometimes assimilated to another consonant in the same word. This assimilation may be either _partial_, as in <span lang="grc">ἐ-πέμφ-θην</span> _I was sent_ for <span lang="grc">ἐ-πεμπ-θην</span> ([82](#s82)), or _complete_, as in <span lang="grc">ἐμμένω</span> _I abide by_ for <span lang="grc">ἐν-μενω</span> ([94](#s94)).

**a.** A preceding consonant is generally assimilated to a following consonant. Assimilation to a preceding consonant, as in <span lang="grc">ὄλλῡμι</span> _I destroy_ for <span lang="grc">ὀλ-νῡ-μι</span>, is rare.

## DOUBLING OF CONSONANTS

##### <a id="s78"></a> §78

Attic has <span lang="grc">ττ</span> for <span lang="grc">σς</span> of Ionic and most other dialects: <span lang="grc">πρά̄ττω</span> _do_ for <span lang="grc">πρά̄σσω, θάλαττα</span> _sea_ for <span lang="grc">θάλασσα, κρείττων</span> _stronger_ for <span lang="grc">κρείσσων</span>.

**a.** Tragedy and Thucydides adopt <span lang="grc">σς</span> as an Ionism. On <span lang="grc">χαρίεσσα</span> see [114 a](#s114).

**b.** <span lang="grc">ττ</span> is used for that <span lang="grc">σς</span> which is regularly formed by <span lang="grc">κ</span> or <span lang="grc">χ</span> and <span lang="grc">ι</span> ([112](#s112)), sometimes by <span lang="grc">τ, θ</span>, and <span lang="grc">ι</span> ([114](#s114)). On <span lang="grc">ττ</span> in <span lang="grc">᾿ Αττικός</span> see [83 a](#s83). <!-- page 25 -->

##### <a id="s79"></a> §79

Later Attic has <span lang="grc">ρρ</span> for <span lang="grc">ρς</span> of older Attic: <span lang="grc"> **θάρρος** </span> _courage_ = <span lang="grc">θάρσος, ἄρρην</span> _male_ = <span lang="grc">ἄρσην</span>.

**a.** But <span lang="grc">ρς</span> does not become <span lang="grc">ρρ</span> in the dative plural (<span lang="grc">ῥήτορ-σι</span> _orators_) and in words containing the suffix <span lang="grc">-σις</span> for <span lang="grc">-τις</span> (<span lang="grc">ἄρ-σις</span> _raising_).

**b.** Ionic and most other dialects have <span lang="grc">ρς. ρς</span> in Attic tragedy and Thucydides is probably an Ionism. Xenophon has <span lang="grc">ρς</span> and <span lang="grc">ρρ</span>.

##### <a id="s80"></a> §80

An initial <span lang="grc">ρ</span> is doubled when a simple vowel is placed before it in inflection or composition. Thus, after the syllabic augment ([429](../part-2-inflection/09-verbs/05-augment.md#s429)), <span lang="grc">ἔ-ρρει</span> _was flowing_ from <span lang="grc">ῥέω</span>; and in <span lang="grc">καλί-ρροος</span> _fair flowing_. After a diphthong <span lang="grc">ρ</span> is not doubled: <span lang="grc">εὔ-ροος</span> _fair flowing_.

**a.** This <span lang="grc">ρρ</span>, due to assimilation of <span lang="grc">σρ</span> (<span lang="grc">ἔ-ρρει, καλί-ρροος</span>), or <span lang="grc">ϝρ</span> (<span lang="grc">ἐρρήθη</span> _was spoken_), is strictly _retained_ in the interior of a word; but simplified to single <span lang="grc">ρ</span> when standing at the beginning, i.e. <span lang="grc">ῥέω</span> is for <span lang="grc">ρρέω</span>. In composition (<span lang="grc">εὔ-ροος</span>) single <span lang="grc">ρ</span> is due to the influence of the simplified initial sound.

**b.** A different <span lang="grc">ρρ</span> arises from assimilation of <span lang="grc">ρς</span> ([79](#s79)), <span lang="grc">ρε</span> (sounded like _py_, 44, [117](#s117)), and <span lang="grc">νρ</span> ([95](#s95)).

##### <a id="s80D"></a> §80 D

In Hom. and even in prose <span lang="grc">ρ</span> may remain single after a vowel: <span lang="grc">ἔ-ρεξε</span> _did_ from <span lang="grc">ῥέζω, καλλί-ροος</span>. So <span lang="grc">ἰσό-ρροπος</span> and <span lang="grc">ἰσό-ροπος</span> (by analogy to <span lang="grc">ῥόπος</span>) _equally balanced_. <span lang="grc">ἐκ χειρῶν βέλεᾱ ῥέον</span> M 159 represents <span lang="grc">βέλεα ρρέον</span>. Cp. [146 D](06-syllables-and-their-quantity.md#s146).

##### <a id="s81"></a> §81

<span lang="grc">β, γ, δ</span> are not doubled in Attic (cp. [75 D](02-euphony-of-vowels.md#s75).). In <span lang="grc">γγ</span> the first <span lang="grc">γ</span> is nasal ([19 a](01-the-letters.md#s19)). <span lang="grc">φ, χ, θ</span> are not doubled in Attic; instead, we have <span lang="grc">πφ, κχ, τθ</span> as in <span lang="grc">Σαπφώ</span> _Sappho_, <span lang="grc">Βάκχος</span> _Bacchus_, <span lang="grc">᾿ Ατθίς</span> (_Atthis_) _Attic_. Cp. [83 a](#s83).

##### <a id="s81D"></a> §81 D

\1. Hom. has many cases of doubled **liquids** and **nasals:** <span lang="grc">ἔλλαβε</span> _took_, <span lang="grc">ἄλληκτος</span> _unceasing_, <span lang="grc">ἄμμορος</span> _without lot in_, <span lang="grc">φιλομμειδής</span> _fond of smiles_, <span lang="grc">ἀγάννιφος</span> _very snowy_, <span lang="grc">ἀργεννός</span> _white_, <span lang="grc">ἔννεπε</span> _relate_. These forms are due to the assimilation of <span lang="grc">ς</span> and <span lang="grc">λ, μ</span>, or <span lang="grc">ν</span>. Thus, <span lang="grc">ἀγά-ννιφος</span> is from <span lang="grc">ἀγα-σνιφος</span>, cp. _sn_ in _snow_.

\2. Doubled **stops:** <span lang="grc">ὅττι</span> _that_ (<span lang="grc">σϝοδ-τι</span>), <span lang="grc">ὁππότε</span> _as_ (<span lang="grc">σϝοδ-ποτε</span>), <span lang="grc">ἔδδεισε</span> _feared_ (<span lang="grc">ἐδϝεισε</span>).

\3. <span lang="grc"> **σς** </span> in <span lang="grc">μέσσος</span> _middle_ (for <span lang="grc">μεθιος</span> _medius_, [114](#s114)), <span lang="grc">ὀπίσσω</span> _backward_, in the datives of <span lang="grc">σ</span>-stems, as <span lang="grc">ἔπεσσι</span> ([250 D.](../part-2-inflection/04-substantives/05-third-declension.md#s250) 2), and in verbs with stems in <span lang="grc">ς</span> (<span lang="grc">τρέσσε</span>).

\4. One of these doubled consonants may be dropped without lengthening the preceding vowel: <span lang="grc">᾿ Οδυσεύς</span> from <span lang="grc">᾿ Οδυσσεύς, μέσος, ὀπίσω</span>. So in <span lang="grc">᾿ Αχιλεύς</span> from <span lang="grc">᾿ Αχιλλεύς</span>. On <span lang="grc">δδ, ββ</span>, see [75 D](02-euphony-of-vowels.md#s75). Aeolic has many doubled consonants due to assimilation ([37 D.](01-the-letters.md#s37) 3).

## CONSONANTS WITH CONSONANTS

### STOPS BEFORE STOPS

##### <a id="s82"></a> §82

A labial or a palatal stop ([16](01-the-letters.md#s16)) before a dental stop **(<span lang="grc">τ, δ, θ</span>)** must be of the same order ([16](01-the-letters.md#s16)).

**a.** <span lang="grc"> **βτ, φτ** </span> become **<span lang="grc">πτ</span>:** (<span lang="grc">τετρῑβ-ται</span>) <span lang="grc">τέτρῑπται</span> _has been rubbed_ from <span lang="grc">τρί̄β-ω</span> _rub;_ (<span lang="grc">γεγραφ-ται</span>) <span lang="grc">γέγραπται</span> _has been written_ from <span lang="grc">γράφ-ω</span> _write_. <span lang="grc">**γτ**, **χτ**</span> become **<span lang="grc">κτ</span>:** (<span lang="grc">λελεγ-ται</span>) <span lang="grc">λέλεκται</span>) _has been said_ from <span lang="grc">λέγ-ω</span> _say;_ (<span lang="grc">βεβρεχ-ται</span>) <span lang="grc">βέβρεκται</span> _has been moistened_ from <span lang="grc">βρέχ-ω</span> _moisten_. <!-- page 26 -->

**b. <span lang="grc">πδ, φδ</span>** become **<span lang="grc">βδ</span>:** (<span lang="grc">κλεπ-δην</span>) <span lang="grc">κλέβδην</span> _by stealth_ from <span lang="grc">κλέπ-τ-ω</span> _steal;_ (<span lang="grc">γραφδην</span>) <span lang="grc">γράβδην</span> _scraping_ from <span lang="grc">γράφ-ω</span> _write_ (originally _scratch_, _scrape_). <span lang="grc"> **κδ** </span> becomes **<span lang="grc">γδ</span>:** (<span lang="grc">πλεκ-δην</span>) <span lang="grc">πλέγδην</span> _entwined_ from <span lang="grc">πλέκ-ω</span> _plait_.

**c. <span lang="grc">πθ, βθ</span>** become **<span lang="grc">φθ</span>:** (<span lang="grc">ἐπεμπ-θην</span>) <span lang="grc">ἐπέμφθην</span> _I was sent_ from <span lang="grc">πέμπ-ω</span> _send;_ (<span lang="grc">ἐτρῑβ-θη</span>) <span lang="grc">ἐτρί̄φθη</span> _it was rubbed_ (<span lang="grc">τρί̄β-ω</span> _rub_). <span lang="grc">**κθ**, **γθ**</span> become **<span lang="grc">χθ</span>:** (<span lang="grc">ἐπλεκ-θη</span>) <span lang="grc">ἐπλέχθη</span> _it was plaited_ (<span lang="grc">πλέκ-ω</span> _plait_); (<span lang="grc">ἐλεγ-θη</span>) <span lang="grc">ἐλέχθη</span> _it was said_ (<span lang="grc">λέγ-ω</span> _say_).

N. 1.—Cp. <span lang="grc">ἑ**πτ**ά</span> _seven_, <span lang="grc">ἕ**βδ**ομος</span> _seventh_, <span lang="grc">ἑ**φθ**ήμερος</span> _lasting seven days_.

N. 2.—But <span lang="grc">ἐκ</span> _out of_ remains unchanged: <span lang="grc">ἐκδίδωμι</span> _surrender_, <span lang="grc">ἐκθέω</span> _run out_ ([104](#s104)).

##### <a id="s83"></a> §83

A dental stop before another dental stop becomes **<span lang="grc">ς</span>.**

<span lang="grc">ἀνυστός</span> _practicable_ for <span lang="grc">ἀνυτ-τος</span> from <span lang="grc">ἀνύτω</span> _complete_, <span lang="grc">ἴστε</span> _you know_ for <span lang="grc">ἰδ-τε, οἶσθα</span> _thou knowest_ for <span lang="grc">οἰδ-θα, πέπεισται</span> _has been persuaded_ for <span lang="grc">πεπειθ-ται, ἐπείσθην</span> _I was persuaded_ for <span lang="grc">ἐπειθ-θην</span>.

**a.** <span lang="grc">ττ, τθ</span> remain unchanged in <span lang="grc">᾿ Αττικός, ᾿ Ατθίς</span> _Attic_, and in <span lang="grc">κατθανεῖν</span> _die_ ([75 D.](02-euphony-of-vowels.md#s75), [81](#s81)). So <span lang="grc">ττ</span> for <span lang="grc">σς</span> ([78](#s78)).

##### <a id="s84"></a> §84

Any stop standing before a stop other than <span lang="grc">τ, δ, θ</span>, or in other combination than <span lang="grc">πφ, κχ, τθ</span> ([81](#s81)) is dropped, as in <span lang="grc">κεκόμι</span>(<span lang="grc">δ</span>)<span lang="grc">-κα</span> _I have brought_. <span lang="grc">γ</span> before <span lang="grc">κ, γ</span>, or <span lang="grc">χ</span> is gamma-nasal ([19 a](01-the-letters.md#s19)), not a stop.

### STOPS BEFORE M

##### <a id="s85"></a> §85

Before <span lang="grc">μ</span>, the labial stops (<span lang="grc">π, β, φ</span>) become <span lang="grc">μ</span>; the palatal stops <span lang="grc">κ, χ</span> become <span lang="grc">γ; γ</span> before <span lang="grc">μ</span> remains unchanged.

<span lang="grc">ὄμμα</span> _eye_ for <span lang="grc">ὀπ-μα</span> (cp. <span lang="grc">ὄπωπα</span>), <span lang="grc">λέλειμμαι</span> _I have been left_ for <span lang="grc">λελειπ-μαι</span> from <span lang="grc">λείπ-ω</span> _leave_, <span lang="grc">τέτρῑμμαι</span> for <span lang="grc">τετρῑβ-μαι</span> from <span lang="grc">τρί̄β-ω</span> _rub_, <span lang="grc">γέγραμμαι</span> for <span lang="grc">γεγραφμαι</span> from <span lang="grc">γράφ-ω</span> _write_, <span lang="grc">πέπλεγμαι</span> for <span lang="grc">πεπλεκ-μαι</span> from <span lang="grc">πλέκ-ω</span> _plait_, <span lang="grc">τέτευγμαι</span> for <span lang="grc">τετευχ-μαι</span> from <span lang="grc">τεύχ-ω</span> _build_.

**a.** <span lang="grc">κ</span> and <span lang="grc">χ</span> may remain unchanged before <span lang="grc">μ</span> in a noun-suffix: <span lang="grc">ἀκ-μή</span> _edge_, <span lang="grc">δραχ-μή</span> _drachma_. <span lang="grc">κμ</span> remains when brought together by phonetic change ([128 a](#s128)), as in <span lang="grc">κέ-κμη-κα</span> _am wearied_ (<span lang="grc">κάμ-νω</span>).

##### <a id="s85aD"></a> §85 a D

So in Hom. <span lang="grc">ἴκμενος</span> _favoring_ (<span lang="grc">ἱκά̄νω</span>), <span lang="grc">ἀκαχμένος</span> _sharpened_.

**b.** <span lang="grc">γγμ</span> and <span lang="grc">μμμ</span> become <span lang="grc">γμ</span> and <span lang="grc">μμ</span>. Thus, <span lang="grc">ἐλήλεγμαι</span> for <span lang="grc">ἐληλεγγ-μαι</span> from <span lang="grc">ἐληλεγχ-μαι</span> (<span lang="grc">ἐλέγχ-ω</span> _convict_), <span lang="grc">πέπεμμαι</span> for <span lang="grc">πεπεμμ-μαι</span> from <span lang="grc">πεπεμπ-μαι</span> (<span lang="grc">πέμπ-ω</span> _send_).

##### <a id="s86"></a> §86

A dental stop (<span lang="grc">τ, δ, θ</span>) before <span lang="grc">μ</span> often appears to become <span lang="grc">ς</span>. Thus, <span lang="grc">ἤνυσμαι</span> for <span lang="grc">ἠνυτ-μαι</span> (<span lang="grc">ἀνύτ-ω</span> _complete_), <span lang="grc">πέφρασμαι</span> for <span lang="grc">πεφραδ-μαι</span> (<span lang="grc">φράζω</span> _declare_), <span lang="grc">πέπεισμαι</span> for <span lang="grc">πεπειθ-μαι</span> (<span lang="grc">πείθ-ω</span> _persuade_).

##### <a id="s87"></a> §87

On the other hand, since these stops are actually retained in many words, such as <span lang="grc">ἐρετμόν</span> _oar_, <span lang="grc">πότμος</span> _fate_, <span lang="grc">ἀριθμός</span> _number_, <span lang="grc">ς</span> must be explained as due to analogy. Thus, <span lang="grc">ἤνυσμαι, πέφρασμαι, πέπεισμαι</span> have taken on the ending <span lang="grc">-σμαι</span> by analogy to <span lang="grc">-σται</span> where <span lang="grc">ς</span> is in place (<span lang="grc">πέφρασται</span> for <span lang="grc">πεφραδ-ται</span>). So <span lang="grc">ἴσμεν</span> _we know_ (Hom. <span lang="grc">ἴδμεν</span>) follows <span lang="grc">ἴστε</span> _you know_ (for <span lang="grc">ἰδ-τε</span>). <span lang="grc">ὀσμή</span> _odor_ stands for <span lang="grc">ὀδ-σμη</span>.

### CONSONANTS BEFORE N

<!-- page 27 -->

##### <a id="s88"></a> §88

<span lang="grc">β</span> regularly and <span lang="grc">φ</span> usually become <span lang="grc">μ</span> before <span lang="grc">ν</span>. Thus, <span lang="grc">σεμνός</span> _revered_ for <span lang="grc">σεβ-νος</span> (<span lang="grc">σέβ-ομαι</span>), <span lang="grc">στυμνός</span> _firm_ for <span lang="grc">στυφ-νος</span> (<span lang="grc">στύ̄φω</span> _contract_).

##### <a id="s89"></a> §89

<span lang="grc">γίγνομαι</span> _become_, <span lang="grc">γιγνώσκω</span> _know_ become <span lang="grc">γί̄νομαι, γῑνώσκω</span> in Attic after 300 B.C., in New Ionic, late Doric, etc.

##### <a id="s90"></a> §90

<span lang="grc">λν</span> becomes <span lang="grc">λλ</span> in <span lang="grc">ὄλλῡμι</span> _destroy_ for <span lang="grc">ὀλ-νῡμι</span>.

<span lang="grc">λν</span> is kept in <span lang="grc">πίλναμαι</span> _approach_. On sigma before <span lang="grc">ν</span> see [105](#s105).

##### <a id="s90D"></a> §90 D

Aeolic <span lang="grc">βόλλα</span> _council_, attic <span lang="grc">βουλή</span> and Doric <span lang="grc">βωλά̄</span> (with compensatory lengthening), probably for <span lang="grc">βολνᾱ</span>.

### N BEFORE CONSONANTS

##### <a id="s91"></a> §91

<span lang="grc">ν</span> before <span lang="grc">π, β, φ, ψ</span> becomes <span lang="grc">μ</span>: <span lang="grc">ἐμπί̄πτω</span> _fall into_ for <span lang="grc">ἐν-πῑπτω, ἐμβάλλω</span> _throw in_ for <span lang="grc">ἐν-βαλλω, ἐμφαίνω</span> _exhibit_ for <span lang="grc">ἐν-φαινω, ἔμψῡχος</span> _alive_ for <span lang="grc">ἐν-ψῡχος</span>.

##### <a id="s92"></a> §92

<span lang="grc">ν</span> before <span lang="grc">κ, γ, χ, ξ</span> becomes <span lang="grc">γ</span>-nasal ([19 a](01-the-letters.md#s19)): <span lang="grc">ἐγκαλέω</span> _bring a charge_ for <span lang="grc">ἐν-καλεω, ἐγγράφω</span> _inscribe_ for <span lang="grc">ἐν-γραφω, συγχέω</span> _pour together_ for <span lang="grc">συν-χεω, συγξύ̄ω</span> _grind up_ for <span lang="grc">συν-ξῑω</span>.

##### <a id="s93"></a> §93

<span lang="grc">ν</span> before <span lang="grc">τ, δ, θ</span> remains unchanged. Here <span lang="grc">ν</span> may represent <span lang="grc">μ</span>: <span lang="grc">βρον-τή</span> _thunder_ (<span lang="grc">βρέμ-ω</span> _roar_).

##### <a id="s94"></a> §94

<span lang="grc">ν</span> before <span lang="grc">μ</span> becomes <span lang="grc">μ</span>: <span lang="grc">ἔμμετρος</span> _moderate_ for <span lang="grc">ἐν-μετρος, ἐμμένω</span> _abide by_ for <span lang="grc">ἐν-μενω</span>.

**a.** Verbs in <span lang="grc">-νω</span> may form the perfect middle in <span lang="grc">-σμαι</span> ([489 h](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s489)); as in <span lang="grc">πέφασμαι</span> (from <span lang="grc">φαίνω</span> _show_) for <span lang="grc">πεφαν-μαι</span> (cp. <span lang="grc">πέφαγ-κα, πέφαν-ται</span>).

**b.** Here <span lang="grc">ν</span> does not _become_ <span lang="grc">ς</span>; but the ending <span lang="grc">-σμαι</span> is borrowed from verbs with stems in a dental (as <span lang="grc">πέφρασμαι</span>, on which see [87](#s87)).

##### <a id="s95"></a> §95

<span lang="grc">ν</span> before <span lang="grc">λ, ρ</span> is assimilated (<span lang="grc">λλ, ρρ</span>): <span lang="grc">σύλλογος</span> _concourse_ for <span lang="grc">συν-λογος, συρρέω</span> _flow together_ for <span lang="grc">συν-ρεω</span>.

##### <a id="s96"></a> §96

<span lang="grc">ν</span> before <span lang="grc">ς</span> is dropped and the preceding vowel is lengthened (<span lang="grc">ε</span> to <span lang="grc">ει, ο</span> to <span lang="grc">ου</span>, [37](01-the-letters.md#s37)): <span lang="grc">μέλᾱς</span> _black_ for <span lang="grc">μελαν-ς, εἷς</span> _one_ for <span lang="grc">ἑν-ς, τιθείς</span> _placing_ for <span lang="grc">τιθεν</span>(<span lang="grc">τ</span>)<span lang="grc">-ς, τούς</span> for <span lang="grc">τόν-ς</span>.

**a.** But in the dative plural <span lang="grc">ν</span> before <span lang="grc">-σι</span> appears to be dropped without compensatory lengthening: <span lang="grc">μέλασι</span> for <span lang="grc">μελαν-σι, δαίμοσι</span> for <span lang="grc">δαιμον-σι</span> _divinities_, <span lang="grc">φρεσί</span> for <span lang="grc">φρεν-σι</span> _mind_. But see [250](../part-2-inflection/04-substantives/05-third-declension.md#s250) N.

| <span lang="grc">γράψω</span> _shall write_ “ <span lang="grc">γραφ-σω</span> | <span lang="grc">βήξ</span> _cough_ “ <span lang="grc">βηχ-ς</span> |

**a.** The only stop that can stand before <span lang="grc">ς</span> is <span lang="grc">π</span> or <span lang="grc">κ</span>, hence <span lang="grc">β, φ</span> become <span lang="grc">π</span>, and <span lang="grc">γ, χ</span> become <span lang="grc">κ</span>. Thus, <span lang="grc">γραφ-σω, ἀγ-σω</span> become <span lang="grc">γραπ-σω, ἀκ-σω</span>.

##### <a id="s98"></a> §98

A dental stop before <span lang="grc">ς</span> is assimilated (<span lang="grc">σς</span>) and one <span lang="grc">ς</span> is dropped.

<span lang="grc">σώμασι</span> _bodies_ for <span lang="grc">σωμασσι</span> out of <span lang="grc">σωματ-σι, ποσί</span> _feet_ for <span lang="grc">ποσσί</span> out of <span lang="grc">ποδ-σι, ὄρνῑσι</span> _birds_ for <span lang="grc">ὀρνῑσσι</span> out of <span lang="grc">ὀρνῑθ-σι</span>. So <span lang="grc">πάσχω</span> _suffer_ for <span lang="grc">πασσχω</span> out of <span lang="grc">παθ-σκω</span> (cp. <span lang="grc">παθ-εῖν</span> and [126](#s126)).

**a.** <span lang="grc">δ</span> and <span lang="grc">θ</span> become <span lang="grc">τ</span> before <span lang="grc">ς</span>: <span lang="grc">ποδ-σι, ὀρνῑθ-σι</span> become <span lang="grc">ποτ-σι, ὀρνῑτ-σι</span>.

##### <a id="s98D"></a> §98 D

Hom. often retains <span lang="grc">σς</span>: <span lang="grc">ποσσί, δάσσασθαι</span> for <span lang="grc">δατ-σασθαι</span> (<span lang="grc">δατέομαι</span> _divide_).

##### <a id="s99"></a> §99

<span lang="grc">κ</span> is dropped before <span lang="grc">σκ</span> in <span lang="grc">διδα</span>(<span lang="grc">κ</span>)<span lang="grc">-σκω</span> _teach_ (<span lang="grc">διδακ-τός</span> _taught_).

<span lang="grc">π</span> is dropped before <span lang="grc">σφ</span> in <span lang="grc">βλα</span>(<span lang="grc">π</span>)<span lang="grc">σ-φημίᾱ</span> _evil-speaking_.

##### <a id="s100"></a> §100

<span lang="grc">ντ, νδ, νθ</span> before <span lang="grc">ς</span> form <span lang="grc">νσς</span> ([98](#s98)), then <span lang="grc">νς</span>, finally <span lang="grc">ν</span> is dropped and the preceding vowel is lengthened ([37](01-the-letters.md#s37)).

<span lang="grc">πᾶσι</span> _all_ for <span lang="grc">πανσ-σι</span> out of <span lang="grc">παντ-σι, τιθεῖσι</span> _placing_ for <span lang="grc">τιθενσ-σι</span> out of <span lang="grc">τιθεντ-σι</span>. So <span lang="grc">γίγᾱς</span> _giant_ for <span lang="grc">γιγαντ-ς, λύ̄ουσι</span> _loosing_ for <span lang="grc">λῡοντ-σι, σπείσω</span> _shall make libation_ for <span lang="grc">σπενδ-σω, πείσομαι</span> _shall suffer_ for <span lang="grc">πενθ-σομαι</span> (<span lang="grc">πένθος</span> _grief_).

##### <a id="s101"></a> §101

**a. <span lang="grc">ἐν</span> _in_, <span lang="grc">σύν</span>** _with_ in composition are treated as follows:

<span lang="grc">ἐν</span> before <span lang="grc">ρ, ς</span>, or <span lang="grc">ζ</span> keeps its <span lang="grc">ν</span>: <span lang="grc">ἔν-ρυθμος</span> _in rhythm_, <span lang="grc">ἐν-σκευάζω</span> _prepare_, <span lang="grc">ἐνζεύγνῡμι</span> _yoke in_.

<span lang="grc">σύν</span> before <span lang="grc">ς</span> and a vowel becomes <span lang="grc">συσ-</span>: <span lang="grc">συσ-σῴζω</span> _help to save_. before <span lang="grc">ς</span> and a consonant or <span lang="grc">ζ</span>, becomes <span lang="grc">συ-</span>: <span lang="grc">συ-σκευάζω</span> _pack up_, <span lang="grc">σύ-ζυγος</span> _yoked together_.

**b.** <span lang="grc">**πᾶν**, **πάλιν**</span> before <span lang="grc">ς</span> either keep <span lang="grc">ν</span> or assimilate <span lang="grc">ν</span> to <span lang="grc">ς</span>: <span lang="grc">πάν-σοφος</span> _all-wise_, <span lang="grc">παν-σέληνος</span> or <span lang="grc">πασσέληνος</span> _the full moon_, <span lang="grc">παλίν-σκιος</span> _thick-shaded_, <span lang="grc">παλίσ-συτος</span> _rushing back_.

##### <a id="s102"></a> §102

On <span lang="grc">ρς</span> see [79 a](#s79). <span lang="grc">λς</span> is retained in <span lang="grc">ἄλσος</span> _precinct_. <span lang="grc">ρς, λς</span> may become <span lang="grc">ρ, λ</span> with lengthening of the preceding vowel: <span lang="grc">ἤγειρα</span> _I collected_, <span lang="grc">ἤγγειλα</span> _I announced_ for <span lang="grc">ἠγερ-σα, ἠγγελ-σα</span>.

##### <a id="s102D"></a> §102 D

Hom. has <span lang="grc">ὦρσε</span> _incited_, <span lang="grc">κέρσε</span> _cut_, <span lang="grc">ἐέλσαι</span> _to coop up_, <span lang="grc">κέλσαι</span> _to put to shore_.

### <span lang="grc">Σ</span> BEFORE CONSONANTS

##### <a id="s103"></a> §103

Sigma between consonants is dropped: <span lang="grc">ἤγγελ</span>(<span lang="grc">σ</span>)<span lang="grc">θε</span> _you have announced_, <span lang="grc">γεγράφ</span>(<span lang="grc">σ</span>)<span lang="grc">θαι</span> _to have written_, <span lang="grc">ἕκ</span>(<span lang="grc">σ</span>)<span lang="grc">μηνος</span> _of six months_ (<span lang="grc">ἕξ</span> _six_, <span lang="grc">μήν</span> _month_).

**a.** But in compounds <span lang="grc">ς</span> is retained when the second part begins with <span lang="grc">ς</span>: <span lang="grc">ἔν-σπονδος</span> _included in a truce_. compounds in <span lang="grc">δυσ-</span> _ill_ omit <span lang="grc">ς</span> before a word beginning with <span lang="grc">ς</span>: <span lang="grc">δύσχιστος</span> _hard to cleave_ for <span lang="grc">δυσ-σχιστος</span> (<span lang="grc">σχίζω</span>).

##### <a id="s104"></a> §104

<span lang="grc">ἐξ</span> _out of_ (= <span lang="grc">ἐκς</span>) drops <span lang="grc">ς</span> in composition before another consonant, but usually retains its <span lang="grc">κ</span> unaltered: <span lang="grc">ἐκτείνω</span> _stretch out_, <span lang="grc">ἐκδίδωμι</span> _surrender_, <!-- page 29 --> <span lang="grc">ἐκφέρω</span> _carry out_, <span lang="grc">ἐκθύ̄ω</span> _sacrifice_, <span lang="grc">ἐκσῴζω</span> _preserve from danger_ (not <span lang="grc">ἐξῴζω</span>), <span lang="grc">ἐκμανθάνω</span> _learn thoroughly_. Cp. [82](#s82) N. 2, 136.

##### <a id="s105"></a> §105

<span lang="grc">ς</span> before <span lang="grc">μ</span> or <span lang="grc">ν</span> usually disappears with compensatory lengthening ([37](01-the-letters.md#s37)) as in <span lang="grc">εἰμί</span> for <span lang="grc">ἐσ-μι</span>. But <span lang="grc">σμ</span> stays if <span lang="grc">μ</span> belongs to a suffix and in compounds of <span lang="grc">δυσ-</span> _ill:_ <span lang="grc">δυσ-μενής</span> _hostile_.

**a.** Assimilation takes place in <span lang="grc">Πελοπόννησος</span> for <span lang="grc">Πέλοπος νῆσος</span> _island of Pelops_, <span lang="grc">ἕννῡμι</span> _clothe_ for <span lang="grc">ἑσ-νῡμι</span> (Ionic <span lang="grc">εἵνῡμι</span>), <span lang="grc">ἔρρει</span> _was flowing_ for <span lang="grc">ἐ-σρει</span>, 80 a.

##### <a id="s105D"></a> §105 D

<span lang="grc">ς</span> is assimilated in Aeol. and Hom. <span lang="grc">ἔμμεναι</span> _to be_ for <span lang="grc">ἐσ-μεναι</span> (<span lang="grc">εἶναι</span>), <span lang="grc">ἀργεννός</span> _white_ for <span lang="grc">άργεσ-νος, ἐρεβεννός</span> _dark_ (<span lang="grc">ἐρεβεσ-νος</span>, cp. <span lang="grc">῎ Ερεβος</span>), <span lang="grc">ἄμμε</span> _we_, <span lang="grc">ὔμμες</span> _you_ (<span lang="grc">ἀσμε, ὐσμες</span>). Cp. [81 D](#s81).

##### <a id="s106"></a> §106

<span lang="grc">σδ</span> becomes <span lang="grc">ζ</span> in some adverbs denoting _motion towards_. Thus, <span lang="grc">᾿ Αθήναζε</span> for <span lang="grc">᾿ Αθήνασ-δε</span> _Athens-wards_ ([26](01-the-letters.md#s26), [342](../part-2-inflection/07-adverbs.md#s342) a).

##### <a id="s106D"></a> §106 D

Aeolic has <span lang="grc">σδ</span> for medial <span lang="grc">ζ</span> in <span lang="grc">ὔσδος</span> _branch_ (<span lang="grc">ὄζος</span>), <span lang="grc">μελίσδω</span> _make melody_ (<span lang="grc">μελίζω</span>).

##### <a id="s107"></a> §107

Two sigmas brought together by inflection become **<span lang="grc">ς</span>: <span lang="grc">βέλεσι</span>** for <span lang="grc">βέλεσ-σι</span> _missiles_, <span lang="grc"> **ἔπεσι** </span> for <span lang="grc"> **ἔπεσ-σι** </span> _words_ ([98](#s98)), <span lang="grc">τελέσαι</span> for <span lang="grc">τελέσ-σαι</span> (from <span lang="grc"> **τελέω** </span> _accomplish_, stem <span lang="grc"> **τελεσ-** </span>).

**a.** <span lang="grc">σς</span> when = <span lang="grc">ττ</span> ([78](#s78)) never becomes <span lang="grc">ς</span>.

##### <a id="s107D"></a> §107 D

Homer often retains **<span lang="grc">σς</span>:** <span lang="grc">**βέλεσσι**, **ἔπεσσι**, **τελέσσαι**</span>.

##### <a id="s108"></a> §108

Many of the rules for the euphony of consonants were not established in the classical period. Inscriptions show a much freer practice, either marking the etymology, as <span lang="grc">σύνμαχος</span> for <span lang="grc">σύμμαχος</span> _ally_ ([94](#s94)), <span lang="grc">ἐνκαλεῖν</span> for <span lang="grc">ἐγκαλεῖν</span> _to bring a charge_ ([92](#s92)), or showing the actual pronunciation (phonetic spelling), as <span lang="grc">τὸγ</span> (= <span lang="grc">τὸν</span>) <span lang="grc">κακόν</span> ([92](#s92)), <span lang="grc">τὴμ</span> (= <span lang="grc">τὴν</span>) <span lang="grc">βουλήν</span> ([91](#s91)), <span lang="grc">τὸλ</span> (= <span lang="grc">τὸν</span>) <span lang="grc">λόγον, ἔγδοσις</span> for <span lang="grc">ἔκδοσις</span> _surrendering_ ([104](#s104)), <span lang="grc">ἐχφέρω, ἐχθύ̄ω</span> for <span lang="grc">ἐκφέρω, ἐκθύ̄ω</span> ([104](#s104)).

## CONSONANTS WITH VOWELS

### CONSONANTS BEFORE I AND E

##### <a id="s109"></a> §109

Numerous changes occur before the semivowel <span lang="grc">\[ιγλιδε\]</span> (= _y_, [20](01-the-letters.md#s20)) before a vowel. This _y_ is often indicated by the sign <span lang="grc">\[ιγλιδε\]</span>. In 110-117 (except in [115](#s115)) <span lang="grc">\[ιγλιδε\]</span> is = _y_.

##### <a id="s110"></a> §110

<span lang="grc">λ\[ιγλιδε\]</span> becomes <span lang="grc">λλ</span>: <span lang="grc">ἄλλος</span> for <span lang="grc">ἀλιος</span> Lat. _alius_, <span lang="grc">ἅλλομαι</span> for <span lang="grc">ἁλ\[ιγλιδε\]ομαι</span> Lat. _salio_, <span lang="grc">φύλλον</span> for <span lang="grc">φυλ\[ιγλιδε\]ον</span> Lat. _folium_.

##### <a id="s111"></a> §111

After <span lang="grc">αν, ον, αρ, ορ, \[ιγλιδε\]</span> is shifted to the preceding syllable, forming <span lang="grc">αιν, οιν, αιρ, οιρ</span>. This is called _Epenthesis_ (<span lang="grc">ἐπένθεσις</span> _insertion_).

<span lang="grc">φαίνω</span> _show_ for <span lang="grc">φαν-\[ιγλιδε\]ω, μέλαινα</span> _black_ for <span lang="grc">μελαν-\[ιγλιδε\]α, σπαίρω</span> _gasp_ for <span lang="grc">σπαρ-\[ιγλιδε\]ω, μοῖρα</span> _fate_ for <span lang="grc">μορ-\[ιγλιδε\]α</span>. (So <span lang="grc">κλαίω</span> _weep_ for <span lang="grc">κλαϝ-\[ιγλιδε\]ω</span> 38 a.) On <span lang="grc">ι</span> after <span lang="grc">εν, ερ, ιν, ιρ, υν, υρ</span>, see [37 a](01-the-letters.md#s37).

##### <a id="s112"></a> §112

<span lang="grc">**κ\[ιγλιδε\]**, **χ\[ιγλιδε\]**</span> become <span lang="grc">ττ</span> (= <span lang="grc">σς</span> [78](#s78)): <span lang="grc">φυλάττω</span> _guard_ for <span lang="grc">φυλακ-\[ιγλιδε\]ω</span> (cp. <span lang="grc">φυλακή</span> _guard_), <span lang="grc">ταράττω</span> _disturb_ for <span lang="grc">ταραχ-\[ιγλιδε\]ω</span> (cp. <span lang="grc">ταραχή</span> _disorder_). <!-- page 30 -->

##### <a id="s113"></a> §113

(I) <span lang="grc">τ\[ιγλιδε\], θ\[ιγλιδε\]</span> after long vowels, diphthongs, and consonants become <span lang="grc">ς</span>; after short vowels <span lang="grc">τ\[ιγλιδε\], θ\[ιγλιδε\]</span> become <span lang="grc">σς</span> (not = <span lang="grc">ττ</span> [78](#s78)), which is simplified to <span lang="grc">ς</span>.

<span lang="grc">αἶσα</span> _fate_ from <span lang="grc">αἰτ-\[ιγλιδε\]α, πᾶσα</span> _all_ from <span lang="grc">παντ-\[ιγλιδε\]α, μέσος</span> _middle_ (Hom. <span lang="grc">μέσσος</span>) from <span lang="grc">μεθ-\[ιγλιδε\]ος</span> (cp. Lat. _med-ius_), <span lang="grc">τόσος</span> _so great_ (Hom. <span lang="grc">τόσσος</span>) from <span lang="grc">τοτ-\[ιγλιδε\]ος</span> (cp. Lat. _toti-dem_).

**a.** In the above cases <span lang="grc">τ\[ιγλιδε\]</span> passed into <span lang="grc">τς</span>. Thus <span lang="grc">παντ-\[ιγλιδε\]α, παντσα, πανσσα, πάνσα</span> (Cretan, Thessalian), <span lang="grc">πᾶσα</span> ([37 D.](01-the-letters.md#s37) 3).

##### <a id="s114"></a> §114

(II) <span lang="grc">τ\[ιγλιδε\], θ\[ιγλιδε\]</span> become <span lang="grc">ττ</span> (= <span lang="grc">σς</span> [78](#s78)): <span lang="grc">μέλιττα</span> _bee_ from <span lang="grc">μελιτ-ια</span> (cp. <span lang="grc">μέλι, -ιτος</span> _honey_), <span lang="grc">κορύττω</span> _equip_ from <span lang="grc">κορυθ-\[ιγλιδε\]ω</span> (cp. <span lang="grc">κόρυς, -υθος</span> _helmet_).

**a.** <span lang="grc">χαρίεσσα</span> _graceful_ and other feminine adjectives in <span lang="grc">-εσσα</span> are poetical, and therefore do not assume the native Attic prose form in <span lang="grc">ττ</span>. But see [299 c](../part-2-inflection/04-substantives/07-adjectives.md#s299).

**b.** <span lang="grc">ττ</span> from <span lang="grc">τ\[ιγλιδε\], θ\[ιγλιδε\]</span> is due to analogy, chiefly of <span lang="grc">ττ</span> from <span lang="grc">κ\[ιγλιδε\]</span>.

##### <a id="s115"></a> §115

<span lang="grc">τ</span> before final <span lang="grc">ι</span> often becomes <span lang="grc">ς</span>. Thus, <span lang="grc">τίθησι</span> _places_ for <span lang="grc">τίθητι</span>; also in <span lang="grc">πλούσιος</span> _rich_ for <span lang="grc">πλουτ-ιος</span> (cp. <span lang="grc">πλοῦτος</span> _wealth_).

**a.** <span lang="grc">ντ</span> before final <span lang="grc">ι</span> becomes <span lang="grc">νς</span>, which drops <span lang="grc">ν</span>: <span lang="grc">ἔχουσι</span> _they have_ for <span lang="grc">ἔχοντι</span> ([37](01-the-letters.md#s37)).

##### <a id="s115D"></a> §115 D

Ioric often retains <span lang="grc">τ</span> (<span lang="grc">τίθητι, ἔχοντι</span>). <span lang="grc">σέ</span> is not from (Dor.) <span lang="grc">τέ</span> (cp. Lat. _te_), no is <span lang="grc">σοί</span> from <span lang="grc">τοί</span>.

##### <a id="s116"></a> §116

<span lang="grc">δ\[ιγλιδε\]</span> between vowels and <span lang="grc">γ\[ιγλιδε\]</span> after a vowel form <span lang="grc">ζ</span>: thus, <span lang="grc">ἐλπίζω</span> _hope_ for <span lang="grc">ἐλπιδ-\[ιγλιδε\]ω, πεζός</span> _on foot_ for <span lang="grc">πεδ-\[ιγλιδε\]ος</span> (cp. <span lang="grc">πεδ-ίο-ν</span> _ground_), <span lang="grc">ἁρπάζω</span> _seize_ for <span lang="grc">ἁρπαγ-\[ιγλιδε\]ω</span> (cp. <span lang="grc">ἅρπαξ</span> _rapacious_). After a consonant <span lang="grc">γ\[ιγλιδε\]</span> forms <span lang="grc">δ</span>: <span lang="grc">ἔρδω</span> _work_ from <span lang="grc">ἐργ-\[ιγλιδε\]ω</span>.

##### <a id="s117"></a> §117

<span lang="grc">π\[ιγλιδε\]</span> becomes <span lang="grc">πτ</span>, as in <span lang="grc">χαλέπτω</span> _oppress_ from <span lang="grc">χαλεπ-\[ιγλιδε\]ω</span>. <span lang="grc">ρ\[εγλιδε\]</span> becomes <span lang="grc">ρρ</span> in <span lang="grc">Βορρᾶς</span> from <span lang="grc">Βορέᾱς</span> _Boreas_. Here <span lang="grc">ε</span> was sounded nearly like _y_ ([44](01-the-letters.md#s44), [61](02-euphony-of-vowels.md#s61) a).

### DISAPPEARANCE OF <span lang="grc">Σ</span> AND <span lang="grc">Ϝ</span>

##### <a id="s118"></a> §118

The spirant <span lang="grc">ς</span> with a vowel before or after it is often lost. Its former presence is known by earlier Greek forms or from the cognate languages.

##### <a id="s119"></a> §119

Initial <span lang="grc">ς</span> before a vowel becomes the rough breathing.

<span lang="grc">ἑπτά</span> _seven_, Lat. _septem;_ <span lang="grc">ἥμισυς</span> _half_, Lat. _semi-;_ <span lang="grc">ἵστημι</span> _put_ for <span lang="grc">σι-στη-μι</span>, Lat. _si-st-o;_ <span lang="grc">εἱπόμην</span> _I followed_ from <span lang="grc">ἐ-σεπ-ο-μην</span>, Lat. _sequor_.

**a.** When retained, this <span lang="grc">ς</span> is due to phonetic change (as <span lang="grc">σύν</span> for <span lang="grc">ξύν, σῑγή</span> _silence_ for <span lang="grc">σ\[υγλιδε\]ῑγη</span> Grm. _schweigen_), or to analogy. On the loss of ( see [125 e](#s125).

##### <a id="s120"></a> §120

Between vowels <span lang="grc">ς</span> is dropped.

<span lang="grc">γένους</span> _of a race_ from <span lang="grc">γενε</span>(<span lang="grc">σ</span>)<span lang="grc">-ος</span>, Lat. _gener-is_, <span lang="grc">λύ̄ει</span> _thou loosest_ from <span lang="grc">λύ̄ῃ</span> for <span lang="grc">λῡε-</span>(<span lang="grc">σ</span>)<span lang="grc">αι, ἐλύ̄ου</span> from <span lang="grc">ἐλῡε-</span>(<span lang="grc">σ</span>)<span lang="grc">ο</span> _thou didst loose for thyself_, <span lang="grc">τιθεῖο</span> for <span lang="grc">τιθεῖσο, εἴην</span> from <span lang="grc">ἐσ-ιη-ν</span> Old Lat. _siem_, <span lang="grc">ἀλήθε-ια</span> _truth_ from <span lang="grc">ἀληθεσ-ια</span>. <!-- page 31 -->

**a.** Yet <span lang="grc">ς</span> appears in some <span lang="grc">-μι</span> forms (<span lang="grc">τίθεσαι, ἵστασο</span>), and in <span lang="grc">θρασύς ῀ θαρσύς</span> 128. <span lang="grc">ς</span> between vowels is due to phonetic change (as <span lang="grc">ς</span> for <span lang="grc">σς</span> 107, <span lang="grc">πλούσιος</span> for <span lang="grc">πλουτιος</span> [115](#s115)) or to analogy (as <span lang="grc">ἔλῡσα</span> for <span lang="grc">ἐλῡα</span>, modelled on <span lang="grc">ἐδεικ-σ-α</span>), cp. [35 c](01-the-letters.md#s35).

##### <a id="s121"></a> §121

<span lang="grc">ς</span> usually disappears in the aorist of liquid verbs (active and middle) with lengthening of the preceding vowel ([37](01-the-letters.md#s37)): <span lang="grc">ἔστειλα</span> _I sent_ for <span lang="grc">ἐστελ-σα, ἔφηνα</span> _I showed_ for <span lang="grc">ἐφαν-σα, ἐφήνατο</span> for <span lang="grc">ἐφαν-σατο</span>. Cp. [102](#s102).

##### <a id="s122"></a> §122

Digamma (3) has disappeared in Attic.

The following special cases are to be noted:

**a.** In nouns of the third declension with a stem in <span lang="grc">αυ, ευ</span>, or <span lang="grc">ον</span> ([43](01-the-letters.md#s43)). Thus, <span lang="grc">ναῦς</span> _ship_, gen. <span lang="grc">νεώς</span> from <span lang="grc">νηϝ-ός, βασιλεύς</span> _king_, gen. <span lang="grc">βασιλέως</span> from <span lang="grc">βασιλῆϝ-ος</span> ([34](01-the-letters.md#s34)).

**b.** In the augment and reduplication of verbs beginning with <span lang="grc">ϝ</span>: <span lang="grc">εἰργαζόμην</span> _I worked_ from <span lang="grc">ἐ-ϝεργαζομην, ἔοικα</span> _am like_ from <span lang="grc">ϝεϝοικα</span>. Cp. [431](../part-2-inflection/09-verbs/05-augment.md#s431), [443](../part-2-inflection/09-verbs/06-reduplication.md#s443).

**c.** In verbs in <span lang="grc">εω</span> for <span lang="grc">εϝω</span>: <span lang="grc">ῥέω</span> _I flow_, fut. <span lang="grc">ῥεύ-σομαι</span>.

##### <a id="s123"></a> §123

Some words have lost initial <span lang="grc">σϝ</span>: <span lang="grc">ἡδύς</span> _sweet_ (Lat. _sua_(_d_)_vis_), <span lang="grc">οὗ, οἷ, ἕ</span> _him_, <span lang="grc">ὅς</span> _his_ (Lat. _suus_), <span lang="grc">ἔθος</span> _custom_, <span lang="grc">ἦθος</span> _character_ (Lat. _con-suetus_).

##### <a id="s123D"></a> §123 D

Hom. <span lang="grc">εὔαδε</span> _pleased_ stands for <span lang="grc">ἐϝϝαδε</span> from <span lang="grc">ἐσϝαδε</span>.

### ASPIRATION

##### <a id="s124"></a> §124

A smooth stop (<span lang="grc">π, τ, κ</span>), brought before the rough breathing by elision, crasis, or in forming compounds, is made rough, becoming an aspirate (<span lang="grc">φ, θ, χ</span>). Cp. [16 a](01-the-letters.md#s16).

<span lang="grc">ἀφ᾽ οὗ</span> for <span lang="grc">ἀπ</span>(<span lang="grc">ὸ</span>) <span lang="grc">οὗ, νύχθ᾽ ὅλην</span> for <span lang="grc">νύκτ</span>(<span lang="grc">α</span>) <span lang="grc">ὅλην</span> ([82](#s82)); <span lang="grc">θἄ̄τερον</span> _the other_ ([69](02-euphony-of-vowels.md#s69)), <span lang="grc">θοἰμάτιον</span> for <span lang="grc">τὸ ἱ̄μάτιον</span> _the cloak_ ([66](02-euphony-of-vowels.md#s66)); <span lang="grc">μεθί̄ημι</span> _let go_ for <span lang="grc">μετ</span>(<span lang="grc">ά</span>) <span lang="grc">ἵ̄ημι, αὐθά̄δης</span> _selfwilled_ from <span lang="grc">αὐτός</span> _self_ and <span lang="grc">ἁδεῖν</span> _please_.

**a.** A medial rough breathing, passing over <span lang="grc">ρ</span>, roughens a preceding smooth stop: <span lang="grc">φρουρός</span> _watchman_ from <span lang="grc">προ-ὁρος, φροῦδος</span> _gone_ from <span lang="grc">πρό</span> and <span lang="grc">ὁδός, τέθριππον</span> _four-horse chariot_ (<span lang="grc">τετρ ¨ ἵππος</span>).

##### <a id="s124D"></a> §124 D

New Ionic generally leaves <span lang="grc">π, τ, κ</span> before the rough breathing: <span lang="grc">ἀπ᾽ οὗ, μετίημι, τοὔτερον</span>. But in compounds (9 D.) <span lang="grc">φ, θ, χ</span> may appear: <span lang="grc">μέθοδος</span> _method_ (<span lang="grc">μετά</span> _after_ + <span lang="grc">ὁδός</span> _way_).

##### <a id="s125"></a> §125

Two rough stops beginning successive syllables of the same word are avoided in Greek. A rough stop is changed into a smooth stop when the following syllable contains a rough stop.

**a.** In reduplication ([441](../part-2-inflection/09-verbs/06-reduplication.md#s441)) initial <span lang="grc">φ, θ, χ</span> are changed to <span lang="grc">π, τ, κ</span>. Thus, <span lang="grc">πέφευγα</span> for <span lang="grc">φε-φευ-γα</span> perfect of <span lang="grc">φεύγω</span> _flee_, <span lang="grc">τί-θη-μι</span> _place_ for <span lang="grc">θι-θη-μι, κέ-χη-να</span> for <span lang="grc">χε-χη-να</span> perf. of <span lang="grc">χάσκω</span> _gape_.

**b.** In the first aorist passive imperative <span lang="grc">-θι</span> becomes <span lang="grc">-τι</span> after <span lang="grc">-θη-</span>, as in <span lang="grc">λύ-θη-τι</span> for <span lang="grc">λυ-θη-θι</span>; elsewhere <span lang="grc">-θι</span> is retained (<span lang="grc">γνῶθι</span>).

**c.** In the aorist passive, <span lang="grc">θε-</span> and <span lang="grc">θυ-</span> are changed to <span lang="grc">τε-</span> and <span lang="grc">τυ-</span> in <span lang="grc">ἐ-τέ-θην</span> _was placed_ (<span lang="grc">τίθημι</span>) and <span lang="grc">ἐ-τύ-θην</span> _was sacrificed_ (<span lang="grc">θύ̄ω</span>).

**d.** From the same objection to a succession of rough stops are due <span lang="grc">ἀμπέχω ἀμπίσχω</span> _clothe_ for <span lang="grc">ἀμφ-, ἐκε-χειρίᾱ</span> _truce_ for <span lang="grc">ἐχε-χειριᾱ</span> (from <span lang="grc">ἔχω</span> and <span lang="grc">χείρ</span>). <!-- page 32 -->

**e.** The rough breathing, as an aspirate ([16 a](01-the-letters.md#s16)), often disappeared when either of the two following syllables contains <span lang="grc">φ, θ</span>, or <span lang="grc">χ. ἔχω</span> _have_ stands for <span lang="grc">ἔχω ῀ σεχω</span> ([119](#s119), cp. <span lang="grc">ἔ-σχον</span>), the rough changing to the smooth breathing before a rough stop. The rough breathing reappears in the future <span lang="grc">ἕξω</span>. Cp. <span lang="grc">ἴσχω</span> _restrain_ for <span lang="grc">ἱσχω</span> from <span lang="grc">σι-σχ-ω, ἔδεθλον</span> _foundation_, but <span lang="grc">ἕδος</span> _seat_, Lat. _sedes_.

**f.** In <span lang="grc">θρίξ</span> _hair_, gen. sing. <span lang="grc">τριχ-ός</span> for <span lang="grc">θριχος</span>, dat. pl. <span lang="grc">θριξί; ταχύς</span> _swift_, comparative <span lang="grc">ταχί̄ων</span> (rare) or <span lang="grc">θά̄ττων</span> (<span lang="grc">θά̄σσων</span>) from <span lang="grc">θαχῑων</span> ([112](#s112)).

**g.** In <span lang="grc">ταφ-</span> (<span lang="grc">τάφος</span> _tomb_), pres. <span lang="grc">θάπ-τ-ω</span> _bury_, fut. <span lang="grc">θάψω</span>, perf. <span lang="grc">τέθαμ-μαι</span> ([85](#s85)); <span lang="grc">τρέφω</span> _nourish_, fut. <span lang="grc">θρέψω</span>, perf. <span lang="grc">τέ-θραμ-μαι; τρέχω</span> _run_, fut. <span lang="grc">θρέξομαι; τρυφ-</span> (<span lang="grc">τρυφή</span> _delicacy_), pres. <span lang="grc">θρύπτω</span> _enfeeble_, fut. <span lang="grc">θρύψω; τύ̄φω</span> _smoke_, perf. <span lang="grc">τέ-θῡμ-μαι</span>.

N.—The two rough stops remain unchanged in the aorist passive <span lang="grc">ἐθρέφθην</span> _was nourished_, <span lang="grc">ἐθρύφθην</span> _was enfeebled_, <span lang="grc">ἐφάνθην</span> _was shown forth_, <span lang="grc">ὠρθώθην</span> _was set upright_, <span lang="grc">ἐθέλχθην</span> _was charmed_, <span lang="grc">ἐκαθάρθην</span> _was purified;_ in the perfect inf. <span lang="grc">πεφάνθαι, κεκαθάρθαι, τεθάφθαι</span>; in the imperatives <span lang="grc">γράφηθι</span> _be written_, <span lang="grc">στράφηθι</span> _turn about_, <span lang="grc">φάθι</span> _say_.

##### <a id="s126"></a> §126

**Transfer of Aspiration**.—Aspiration may be transferred to a following syllable: <span lang="grc">πάσχω</span> for <span lang="grc">παθ-σκω</span> (cp. [98](#s98)).

##### <a id="s126D"></a> §126 D

Hdt. has <span lang="grc">ἐνθαῦτα</span> _there_ (<span lang="grc">ἐνταῦθα</span>), <span lang="grc">ἐνθεῦτεν</span> _thence_ (<span lang="grc">ἐντεῦθεν</span>), <span lang="grc">κιθών</span> _tunic_ (<span lang="grc">χιτών</span>).

##### <a id="s127"></a> §127

Some roots show variation between a final smooth and a rough stop; <span lang="grc">δέχομαι</span> _receive_, <span lang="grc">δωροδόκος</span> _bribe-taker;_ <span lang="grc">ἀλείφω</span> _anoint_, <span lang="grc">λίπος</span> _fat;_ <span lang="grc">πλέκω</span> _weave_, <span lang="grc">πλοχυός</span> _braid of hair;_ and in the perfect, as <span lang="grc">ἦχα</span> from <span lang="grc">ἄγω</span> _lead_.

##### <a id="s127D"></a> §127 D

Hom. and Hdt. have <span lang="grc">αὖτις</span> _again_ (<span lang="grc">αὖθις</span>), <span lang="grc">οὐκί</span> _not_ (<span lang="grc">οὐχί</span>). All the dialects except Attic have <span lang="grc">δέκομαι</span>.

### VARIOUS CONSONANT CHANGES

##### <a id="s128"></a> §128

**Metathesis** (_transposition_).—A vowel and a consonant often exchange places: <span lang="grc">Πνύξ</span> _the Pnyx_, gen. <span lang="grc">Πυκνός, τίκτω</span> _bear_ for <span lang="grc">τι-τκ-ω</span> (cp. <span lang="grc">τεκ-εῖν</span>).

**a.** Transposition proper does not occur where we have to do with <span lang="grc">αρ, ρα ῀ ṛ</span> ([20](01-the-letters.md#s20), [35](01-the-letters.md#s35) b) as in <span lang="grc">θάρσος</span> and <span lang="grc">θράσος</span> _courage;_ or with syncope ([44 b](01-the-letters.md#s44)) due to early shifting of accent, as in <span lang="grc">πέτ-ομαι</span> _fly_, <span lang="grc">πτε-ρόν</span> _wing;_ or where a long vowel follows the syncopated root, as in <span lang="grc">τέμ-νω τέ-τμη-κα</span> _I have cut_.

In <span lang="grc">βέβληκα</span> _I have thrown_ (<span lang="grc">βάλλω</span> _throw_), <span lang="grc">βλη</span> is formed from <span lang="grc">βελε</span> found in <span lang="grc">βέλε-μνον</span> _missile_.

##### <a id="s128D"></a> §128 D

Hom. <span lang="grc">κραδίη, καρδίη</span> _heart_, <span lang="grc">κάρτιστος</span> _best_ (<span lang="grc">κράτιστος</span>), <span lang="grc">βάρδιστος</span> _slowest_ (<span lang="grc">βραδύς</span>), <span lang="grc">δρατός</span> and <span lang="grc">-δαρτος</span> from <span lang="grc">δέρω</span> _flay_, <span lang="grc">ἔ-δρακον</span> _saw_ from <span lang="grc">δέρκομαι</span> _see_.

##### <a id="s129"></a> §129

**Dissimilation**.—**a.** <span lang="grc">λ</span> sometimes becomes <span lang="grc">ρ</span> when <span lang="grc">λ</span> appears in the same word: <span lang="grc">ἀργαλέος</span> _painful_ for <span lang="grc">ἀλγαλεος</span> (<span lang="grc">ἄλγος</span> _pain_).

**b.** A consonant (usually <span lang="grc">ρ</span>) sometimes disappears when it occurs also in the adjoining syllable: <span lang="grc">δρύφακτος</span> _railing_ for <span lang="grc">δρυ-φρακτος</span> (lit. _fenced by wood_).

**c.** Syllabic dissimilation or syncope occurs when the same or two similar syllables containing the same consonant succeed each other: <span lang="grc">ἀμφορεύς</span> _a jar_ for <span lang="grc">ἀμφι-φορευς, θάρσυνος</span> _bold_ for <span lang="grc">θαρσο-συνος</span>. This is often called _haplology_.

**d.** See also under 99, 125 a, b. <!-- page 33 -->

##### <a id="s130"></a> §130

**Development**.—<span lang="grc">δ</span> is developed between <span lang="grc">ν</span> and <span lang="grc">ρ</span>, as in <span lang="grc">ἀνδρός</span> _of a man_ for <span lang="grc">ἀνρος</span> from <span lang="grc">ἀνήρ</span> (cp. _cinder_ with Lat. _cineris_); <span lang="grc">β</span> is developed between <span lang="grc">μ</span> and <span lang="grc">ρ</span> (or <span lang="grc">λ</span>), as in <span lang="grc">μεσημβρίᾱ</span> _midday_, _south_ from <span lang="grc">μεσ-ημριᾱ</span> for <span lang="grc">μεσ-ημεριᾱ</span> from <span lang="grc">μέσος</span> _middle_ and <span lang="grc">ἡμέρᾱ</span> _day_ (cp. _chamber_ with Lat. _camera_).

##### <a id="s130D"></a> §130 D

So in Hom. <span lang="grc">μέ-μβλω-κα</span> _have gone_ from <span lang="grc">μλω</span> from <span lang="grc">μολ-</span> in <span lang="grc">ἔ-μολ-ο-ν</span> ([128 a](#s128)). At the beginning of words this <span lang="grc">μ</span> is dropped; thus, <span lang="grc">βλώσκω</span> _go_, <span lang="grc">βροτός</span> _mortal_ for <span lang="grc">μβρο-τος</span> (root <span lang="grc">μρο-, μορ-</span>, as in _mor-tuus_). In composition <span lang="grc">μ</span> remains, as in <span lang="grc">ἄ-μβροτος</span> _immortal;_ but <span lang="grc">ἄ-βροτος</span> _immortal_ is formed from <span lang="grc">βροτός</span>.

##### <a id="s131"></a> §131

Labials and dentals often correspond: <span lang="grc">ποινή</span> and <span lang="grc">τίσις</span> _retribution;_ <span lang="grc">φόνος</span> _murder_, <span lang="grc">θείνω</span> _strike_. <span lang="grc">π</span> and <span lang="grc">κ</span>: <span lang="grc">αἰπόλος</span> _goat-herd_, <span lang="grc">βουκόλος</span> _ox-herd_. <span lang="grc">πτ</span> for <span lang="grc">τ</span> is found in <span lang="grc">πτόλεμος</span> _war_, <span lang="grc">πτόλις</span> _city_ for <span lang="grc">πόλεμος, πόλις</span>. Cp. _Neoptolemus_ and _Ptolemy_. So <span lang="grc">χθ</span> and <span lang="grc">χ</span> in <span lang="grc">χθών</span> _ground_, <span lang="grc">χαμαί</span> _on the ground_.

##### <a id="s132"></a> §132

The dialects often show consonants different from Attic in the same or kindred words.

##### <a id="s132D"></a> §132 D

<span lang="grc"> **τ** </span> for <span lang="grc">ς</span>: Doric <span lang="grc">τύ, τοί, τέ, διᾱκατίοι</span> (<span lang="grc">διᾱκόσιοι</span>), <span lang="grc">ϝί̄κατι</span> (<span lang="grc">εἴκοσι</span>), <span lang="grc">Ποτειδά̄ν</span> (<span lang="grc">Ποσειδών</span>).

<span lang="grc">ς</span> “ <span lang="grc">τ</span>: Doric <span lang="grc">σά̄μερον</span> _to-day_ (<span lang="grc">τήμερον</span> Attic, <span lang="grc">σήμερον</span> Ionic).

<span lang="grc">κ</span> “ <span lang="grc">π</span>: Ionic (not Hom.) <span lang="grc">κότε</span> _when_, <span lang="grc">κότερος</span> _which of two?_ <span lang="grc">ὅκως, κόσος, κῆ</span>.

<span lang="grc">κ</span> “ <span lang="grc">τ</span>: Doric <span lang="grc">πόκα</span> (<span lang="grc">πότε</span>), <span lang="grc">ὅκα</span> (<span lang="grc">ὅτε</span>).

<span lang="grc">γ</span> “ <span lang="grc">β</span>: Doric <span lang="grc">γλέφαρον</span> _eyelid_, <span lang="grc">γλά̄χων</span> (Ion. <span lang="grc">γλήχων</span>) _pennyroyal_.

<span lang="grc">δ</span> “ <span lang="grc">β</span>: Doric <span lang="grc">ὀδελός</span> (<span lang="grc">ὀβολός</span>) _a spit_.

<span lang="grc">π</span> “ <span lang="grc">τ</span>: Hom. <span lang="grc">πίσυρες</span>, Aeol. <span lang="grc">πέσσυρες</span> _four_ (<span lang="grc">τέτταρες</span>); Aeol. <span lang="grc">πήλυι</span> _far off_ (cp. <span lang="grc">τηλόσε</span>), <span lang="grc">πέμπε</span> _five_ (<span lang="grc">πέντε</span>).

<span lang="grc">θ</span> “ <span lang="grc">τ</span>: see [126 D](#s126).

<span lang="grc">φ</span> “ <span lang="grc">θ</span>: Hom. <span lang="grc">φήρ</span> _centaur_ (<span lang="grc">θήρ</span> _beast_).

<span lang="grc">ρ</span> “ <span lang="grc">ς</span>: (_rhotacism_): late Laconian, Elean <span lang="grc">τίρ</span> _who_, Thessal. <span lang="grc">Θεόρδοτος</span> _god-given_.

<span lang="grc">ς</span> “ <span lang="grc">θ</span>: late Laconian <span lang="grc">σιός</span> for <span lang="grc">θεός</span> _god_ ([26 D.](01-the-letters.md#s26)).

<span lang="grc">ν</span> “ <span lang="grc">λ</span>: Doric <span lang="grc">ἐνθεῖν</span> _come_.
