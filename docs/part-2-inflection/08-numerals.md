##### <a id="s348"></a> §348

**Notation**.—The system of alphabetic notation came into use after the second century B.C. The first nine letters stand for units, the second nine for tens, the third nine for hundreds ([27](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s27) letters). In addition to the 24 letters of the alphabet, three obsolete signs are employed: <span lang="grc">ς</span>, a form identical with the late abbreviation for <span lang="grc">στ</span>, in place of the lost <span lang="grc">ϝ</span> (3), once used for 6; ϟ (_koppa_), in the same order as Lat. _q_, for 90; for 900, \[sampi \] _sampi_, probably for _san_, an old form of _sigma_, + _pi._ From 1 to 999 a stroke stands _above_ the letter, for 1000's the same signs are used but with the stroke _below_ the letter (<span lang="grc">α#</span> = 1, <span lang="grc">\[τνυμ \]α</span> = [1000](../part-4-syntax/11-peculiarities-in-the-use-of-number.md#s1000)). Only the last letter in any given series has the stroke above: <span lang="grc">ρνζ#</span> 157, <span lang="grc">υα#</span> 401, <span lang="grc">\[τνυμ \]α\[σαμπι \]ι#</span> 1910. <span lang="grc">α̈</span> is sometimes used for 10,000; <span lang="grc">β̈</span> for 20,000, etc.

**a.** In the classical period the following system was used according to the inscriptions: <span lang="grc">Ι</span> = 1, <span lang="grc">ΙΙΙΙ</span> = 4, <span lang="grc">Γ</span> (<span lang="grc">πέντε</span>) = 5, <span lang="grc">ΓΙ</span> = 6, <span lang="grc">Δ</span> (<span lang="grc">δέκα</span>) = 10, <span lang="grc">ΔΔ</span> = 20, <span lang="grc">Η</span> (<span lang="grc">ἑκατόν</span>) = 100, <span lang="grc">ΗΗ</span> = 200, <span lang="grc">Χ</span> = 1000, <span lang="grc">Μ</span> = 10,000, <span lang="grc">Ι<!-- figure: no image in source --></span> (<span lang="grc">πεντάκις δέκα</span>) = 50, <span lang="grc">ΓχΧ</span> (<span lang="grc">πεντάκις χί̄λιοι ¨ χί̄λιοι</span>) = 6000.

**b.** For the numbers from 1 to 24 the letters, used in continuous succession, are frequently used to designate the books of the _Iliad_ (<span lang="grc">Α, Β, Γ</span>, etc.) and of the _Odyssey_ (<span lang="grc">α, β, γ</span>, etc.).

##### <a id="s349"></a> §349

The cardinals from 1 to 4 are declined as follows: <!-- page 105 -->

|  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- |
|  |  | _one_ |  | _two_ | _three_ | _four_ |
| Nom. | <span lang="grc"> **εἱ̄ς** </span> | <span lang="grc"> **μία** </span> | <span lang="grc"> **ἕν** </span> | N. A. <span lang="grc"> **δύο** </span> | <span lang="grc"> **τρεῖς τρία** </span> | <span lang="grc"> **τέτταρες τέτταρα** </span> |
| Gen. | <span lang="grc"> **ἑνός** </span> | <span lang="grc"> **μιᾶς** </span> | <span lang="grc"> **ἑνός** </span> | G. D.<span lang="grc"> **δυοῖν** </span> | <span lang="grc"> **τριῶν** </span> | <span lang="grc"> **τεττάρων** </span> |
| Dat. | <span lang="grc"> **ἑνί** </span> | <span lang="grc"> **μιᾷ** </span> | <span lang="grc"> **ἑνί** </span> |  | <span lang="grc"> **τρισί** </span>(<span lang="grc"> **ν** </span>) | <span lang="grc"> **τέτταρσι** </span>(<span lang="grc"> **ν** </span>) |
| Acc. | <span lang="grc"> **ἕνα** </span> | <span lang="grc"> **μίαν** </span> | <span lang="grc"> **ἕν** </span> |  | <span lang="grc"> **τρεῖς τρία** </span> | <span lang="grc"> **τέτταρας τέτταρα** </span> |

**a.** <span lang="grc">εἷς</span> is for <span lang="grc">ἑν-ς</span> (cp. [245](04-substantives/05-third-declension.md#s245)). The stem <span lang="grc">ἑν</span> was originally <span lang="grc">σεμ</span> (Lat. _semel_, _simplex_, _singuli_), weak forms of which are <span lang="grc">ἅ-παξ, ἁ-πλοῦς</span>, from <span lang="grc">σμ-π-</span> ([35 b](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s35)). <span lang="grc">μία</span> stands for <span lang="grc">σμ-ια</span>.

**b.** <span lang="grc">οὐδὲ εἷς, μηδὲ εἷς</span> _not even one_ unite (with change in accent) to form the compounds <span lang="grc">οὐδείς, μηδείς</span> _no one_. These words are declined like <span lang="grc">εἷς</span>: thus, <span lang="grc">οὐδείς, οὐδεμία, οὐδέν, οὐδενός, οὐδεμιᾶς, οὐδενός</span>, etc., and sometimes in the plural (_no men_, _none_ or _nobodies_) <span lang="grc">οὐδένες, οὐδένων, οὐδέσι, οὐδένας</span>. For emphasis the compounds may be divided, as <span lang="grc">οὐδὲ εἷς</span> _not_ ONE. A preposition or <span lang="grc">ἄν</span> may separate the two parts, as <span lang="grc">οὐδ᾽ ἀπὸ μιᾶς</span> _from not a single one_, <span lang="grc">οὐδ᾽ ἂν ἑνί</span> _ne uni quidem_.

**c.** <span lang="grc">πρῶτος</span> (_primus_) means the first among more than two, <span lang="grc">πρότερος</span> (_prior_) the first of two.

**d.** <span lang="grc">δύο</span> may be used with the gen. and dat. pl., as <span lang="grc">δύο μνηνῶν</span> _of two months_. <span lang="grc">δὺοῖν</span> occurs rarely with plurals: <span lang="grc">παισὶν . . . δυοῖν</span> <cite data-ref="Dem. 39.32">D. 39.32</cite>. <span lang="grc">δυεῖν</span> for <span lang="grc">δυοῖν</span> does not appear till about 300 B.C.

**e.** <span lang="grc">ἄμφω</span> _both_, N. A. <span lang="grc">ἄμφω</span>, G. D. <span lang="grc">ἀμφοῖν</span> (Lat. _ambo_). But _both_ is more commonly <span lang="grc">ἀμφότεροι, -αι, -α</span>.

**f.** For <span lang="grc">τέτταρες, -ράκοντα</span>, etc., early Attic prose and tragedy have <span lang="grc">τέσσαρες</span>, etc.

**g.** The first numeral is inflected in <span lang="grc">τρεῖς καὶ δέκα</span> 13, <span lang="grc">τέτταρες καὶ δέκα</span> 14 <span lang="grc">τρεισκαίδεκα</span> and Ionic <span lang="grc">τεσσερεσκαίδεκα</span> (very rare in Attic) are indeclinable.

##### <a id="s349D"></a> §349 D

Hom. has, for <span lang="grc">μία, ἴα</span> (<span lang="grc">ἰῆς, ἰῇ, ἴαν</span>); for <span lang="grc">ἑνί, ἰῷ; δύο, δύω</span> (undeclined); the adj. forms <span lang="grc">δοιώ</span> and pl. <span lang="grc">δοιοί</span> regularly declined. For 4, <span lang="grc">τέσσαρες</span>, (Aeolic) <span lang="grc">πίσυρες</span>; Pind. has <span lang="grc">τέτρασιν</span>. Hdt. has <span lang="grc">δύο</span> sometimes undeclined, also <span lang="grc">δυῶν, δυοῖσι; τέσσερες, -α, τεσσέρων, τέσσερσι; τεσσερεσκαίδεκα</span> 14 undeclined. Aeolic <span lang="grc">δύεσιν</span> 2; <span lang="grc">πέσσυρες, πέσυρα</span> for 4.

##### <a id="s350"></a> §350

The cardinals from 5 to 199 are indeclinable; from 200 the cardinals, and all the ordinals from _first_ on, are declined like <span lang="grc">ἀγαθός</span>.

**a.** Compound numbers above 20 are expressed by placing the smaller number first (with <span lang="grc">καί</span>) or the larger number first (with or without <span lang="grc">καί</span>).

| <span lang="grc">εἴκοσι καὶ δύο</span> _twenty and two_, or <span lang="grc">εἴκοσι δύο</span> _twenty-two_ | <span lang="grc">εἰκοστὸς καὶ δεύτερος</span> |

**b.** For 21st, 31st, etc., <span lang="grc">εἷς</span> (for <span lang="grc">πρῶτος</span>) <span lang="grc">καὶ εἰκοστός</span> (<span lang="grc">τριᾱκοστός</span>) is permissible, but otherwise the cardinal is rarely thus joined with the ordinal.

**c.** Compounds of 10, 20, etc., with 8 and 9 are usually expressed by subtraction with the participle of <span lang="grc">δέω</span> _lack_, as 18, 19, <span lang="grc">δυοῖν</span> (<span lang="grc">ἑνὸς</span>) <span lang="grc">δέοντες εἴκοσι</span>. So <span lang="grc">ναυσὶ μιᾶς δεούσαις τεττάρακοντα</span> _with 39 ships_, <span lang="grc">δυοῖν δέοντα πεντήκοντα ἔτη</span> _48 years;_ and with ordinals <span lang="grc">ἑνὸς δέον εἰκοστὸν ἔτος</span> _the 19th year_. The same method may be employed in other numbers than 8's or 9's: <span lang="grc">ἑπτὰ ἀποδέοντες τριᾱκόσιοι</span>, i.e. 293.

**d.** An ordinal followed by <span lang="grc">ἐπὶ δέκα</span> denotes the day of the month from the 13th to the 19th, as <span lang="grc">πέμπτῃ ἐπὶ δέκα</span> _on the 15th_. <!-- page 106 -->

##### <a id="s351"></a> §351

With the collective words ([996](../part-4-syntax/11-peculiarities-in-the-use-of-number.md#s996)) <span lang="grc">ἡ ἵππος</span> _cavalry_, <span lang="grc">ἡ ἀσπίς</span> _men with shields_, numerals in <span lang="grc">-ιοι</span> may appear even in the singular: <span lang="grc">διᾱκοσίᾱ ἵππος</span> 200 _horse_ <cite data-ref="Thuc. 1.62">T. 1.62</cite>, <span lang="grc">ἀσπὶς μῡρίᾱ καὶ τετρακοσίᾱ</span> _10_,_400 horse_ <cite data-ref="Xen. Anab. 1.7.10">X. A. 1.7.10</cite>.

##### <a id="s352"></a> §352

<span lang="grc">μύ̄ριοι</span>, the greatest number expressed by a single word, means 10,000; <span lang="grc">μῡρίοι</span>, _countless_, _infinite_. In the latter sense the singular may be used, as <span lang="grc">μῡρίᾱ ἐρημίᾱ</span> _infinite solitude_ P. L. 677 E.

##### <a id="s353"></a> §353

**Fractions** are expressed in several ways: <span lang="grc">ἥμισυς</span> 1/2, <span lang="grc">ὁ ἥμισυς τοῦ ἀριθμοῦ</span> _half the number_, <span lang="grc">αἱ ἡμίσειαι τῶν νεῶν</span> _half of the ships_, <span lang="grc">τὸ ἥμισυ τοῦ στρατοῦ</span> _half the army_, <span lang="grc">ἡμιτάλαντον</span> _half a talent;_ <span lang="grc">τρία ἡμιτάλαντα</span> 1 1/2 _talents_, <span lang="grc">τρίτον ἡμίμναιον</span> 2 1/2 _minae;_ <span lang="grc">τριτημόριον</span> 1/3, <span lang="grc">πεμπτημόριον</span> 1/5, <span lang="grc">ἐπίτριτος</span> 1 1/3, <span lang="grc">ἐπίπεμπτος</span> 1 1/5, <span lang="grc">τῶν πέντε αί δύο μοῖραι</span> 2/5. But when the numerator is less by _one_ than the denominator, the genitive is omitted and only the article and <span lang="grc">μέρη</span> are used: as <span lang="grc">τὰ τρία μέρη</span> 3/4, i.e. _the three parts_ (scil. _of four_).

##### <a id="s354"></a> §354

Other classes of numeral words.

**a.** _Distributives_ proper, answering the question _how many each?_ are wanting in Greek. Instead, <span lang="grc">ἀνά, εἰς</span>, and <span lang="grc">κατά</span>, with the accus., and compounds of <span lang="grc">σύν</span> _with_, are used: <span lang="grc">κατὰ δύο</span> or <span lang="grc">σύνδυο</span> _two by two, two each_ (Lat. _bini_). The cardinals are often used alone, as <span lang="grc">ἀνδρὶ ἑκάστῳ δώσω πέντε ἀργυρίου μνᾶς</span> _singulis militibus dabo quinas argenti minas_ <cite data-ref="Xen. Anab. 1.4.13">X. A. 1.4.13</cite>.

**b.** _Multiplicatives_ in <span lang="grc">-πλοῦς</span> -_fold_ (from <span lang="grc">-πλοος</span>, Lat. -_plex_), <span lang="grc">ἁπλοῦς</span> _simple_, <span lang="grc">διπλοῦς</span> _twofold_, <span lang="grc">τριπλοῦς</span> _threefold_, <span lang="grc">πολλαπλοῦς</span> _manifold_.

**c.** _Proportionals_ in <span lang="grc">-πλασιος</span>: <span lang="grc">διπλάσιος</span> _twice as great_ or (plur.) _as many_, <span lang="grc">πολλαπλάσιος</span> _many times as great_ (_many_).

**d.** <span lang="grc">διττός</span> means _double_, <span lang="grc">τριττός</span> _treble_ (from <span lang="grc">διχ-ιος, τριχ-ιος</span> [112](../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s112)).

N.—_Multiplication_.—Adverbs answering the question _how many times?_ are used in multiplication: <span lang="grc">τὰ δὶς πέντε δέκα ἐστίν</span> _twice five are ten_. See also [347](#s347) N.

**e.** _Abstract and Collective Numbers_ in <span lang="grc">-άς</span> (gen. <span lang="grc">-άδ-ος</span>), all feminine: <span lang="grc">ἑνάς</span> or <span lang="grc">μονάς</span> _the number one, unity_, _monad_, <span lang="grc">δυάς</span> _the number two, duality_, <span lang="grc">τριάς</span> _trinity_, _triad_, <span lang="grc">δεκάς</span> _decad_, _decade_, <span lang="grc">εἰκάς, ἑκατοντάς, χῑλιάς, μῡριάς</span> _myriad_, <span lang="grc">ἑκατὸν μῡριάδες</span> _a million_. Also in <span lang="grc">-ύς</span>: <span lang="grc">τριττύς</span> (<span lang="grc">-ύος</span>) _the third of a tribe_ (properly _the number three_), <span lang="grc">τετρακύς</span>.

**f.** Adjectives in <span lang="grc">-αῖος</span>, answering the question _on what day?_ <span lang="grc">δευτεραῖος</span> (or <span lang="grc">τῇ δευτεραίᾳ</span>) <span lang="grc">ἀπῆλθε</span> _he departed on the second day_.

**g.** _Adverbs of Division_.—<span lang="grc">μοναχῇ</span> _singly_, _in one way only_, <span lang="grc">δίχα, διχῇ</span> _in two parts_, _doubly_, <span lang="grc">τριχῇ, τέτραχα</span>, etc., <span lang="grc">πολλαχῇ</span> _in many ways_, <span lang="grc">πανταχῇ</span> _in every way_.
