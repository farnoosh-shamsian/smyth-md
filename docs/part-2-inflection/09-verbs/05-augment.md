# VERBS: AUGMENT

<!-- page 145 -->

##### <a id="s428"></a> §428

The augment (_increase_) denotes past time. It appears only in the secondary or past tenses of the indicative mood, namely, imperfect, aorist, and pluperfect. The augment has two forms, the syllabic and the temporal.

##### <a id="s429"></a> §429

**Syllabic Augment**.—Verbs beginning with a consonant prefix <span lang="grc">ε</span> as the augment, which thus increases the word by one syllable. In the pluperfect <span lang="grc">ε</span> is prefixed to the reduplication.

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| <span lang="grc">λύ̄ω</span> | _loose_ | <span lang="grc">ἔ-λῡον</span> | <span lang="grc">ἔ-λῡσα</span> | <span lang="grc">ἐ-λελύκη</span> |
| <span lang="grc">παιδεύω</span> | _educate_ | <span lang="grc">ἐ-παίδευον</span> | <span lang="grc">ἐ-παίδευσα</span> | <span lang="grc">ἐ-πεπαιδεύκη</span> |

**a.** Verbs beginning with <span lang="grc">ρ</span> double the <span lang="grc">ρ</span> after the augment. <span lang="grc">ῥί̄πτω</span> _throw_, <span lang="grc">ἔ-ρρῑπτον, ἔ-ρρῑψα, ἐ-ρρί̄φθην; ῥήγνῡμι</span> _break_, <span lang="grc">ἔ-ρρηξα, ἐ-ρράγην</span>.

N.—<span lang="grc">ρρ</span> is here due to assimilation of <span lang="grc">ϝρ</span>, as in Hom. <span lang="grc">ἔρρεξα</span> _did_ (and <span lang="grc">ἔρεξα</span>); of <span lang="grc">σρ</span> in <span lang="grc">ἔρρεον</span> _flowed_. Cp. [80 a](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s80).

##### <a id="s429aD"></a> §429 a. D

Hom. has <span lang="grc">ἔλλαβε</span> _took_ (for <span lang="grc">ἐ-σλαβε</span>), <span lang="grc">ἔννεον</span> _swam_ (for <span lang="grc">ἐ-σνεον</span>), <span lang="grc">ἐσσείοντο</span> _shook_ (for <span lang="grc">ἐ-τϝειοντο</span>), <span lang="grc">ἔδδεισε</span> _feared_ (for <span lang="grc">ἐ-δϝεισε</span>). <span lang="grc">ἔμμαθε</span> _learned_ is due to analogy.

##### <a id="s430"></a> §430

<span lang="grc">βούλομαι</span> _wish_, <span lang="grc">δύναμαι</span> _am able_, <span lang="grc">μέλλω</span> _intend_ augment with <span lang="grc">ε</span> or with <span lang="grc">η</span> (especially in later Attic); thus, <span lang="grc">ἐβουλόμην</span> and <span lang="grc">ἠβουλόμην, ἐδυνάμην</span> and <span lang="grc">ἠδυνάμην, ἐδυνήθην</span> and <span lang="grc">ἠδυνήθην</span>.

**a.** These forms seem to be due to parallelism with <span lang="grc">ἤθελον</span> (from <span lang="grc">ἐθέλω</span> _wish_) and <span lang="grc">ἔθελον</span> (from <span lang="grc">θέλω</span>).

##### <a id="s431"></a> §431

Some verbs beginning with a vowel take the syllabic augment because they formerly began with a consonant. Thus,

<span lang="grc"> **ἄγνῡμι** </span> _break_ (<span lang="grc"> **Ϝάγνῡμι** </span>), <span lang="grc"> **ἔᾱξα** </span>, aor. pass. <span lang="grc"> **ἐά̄γην** </span>.

<span lang="grc"> **ἁλίσκομαι** </span> _am captured_ (<span lang="grc"> **Ϝαλίσκομαι** </span>), imperf. <span lang="grc"> **ἡλισκόμην** </span>, aor. <span lang="grc"> **ἑά̄λων** </span> (with temporal augment) or <span lang="grc"> **ἥλων** </span>.

<span lang="grc"> **ἁνδάνω** </span> _please_ (<span lang="grc"> **Ϝανδάνω** </span>), aor. <span lang="grc"> **ἕαδον** </span> (Ionic).

<span lang="grc"> **ἀν-οίγω** </span> _open_ (<span lang="grc"> **Ϝοίγνῡμι** </span>), imperf. <span lang="grc"> **ἀν-έῳγον** </span>.

<span lang="grc"> **ἐάω** </span> _permit_ (<span lang="grc"> **σεϜαω** </span>), <span lang="grc">**εἴων**, **εἴᾱσα**, **εἰά̄θην**</span>.

<span lang="grc"> **ἑζόμαι** </span> _sit_ (for <span lang="grc"> **σεδιομαι** </span>), <span lang="grc"> **εἱσάμην** </span>.

<span lang="grc"> **ἐθίζω** </span> _accustom_ (<span lang="grc"> **σϜεθίζω** </span>, cp. [123](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s123)), <span lang="grc">**εἴθιζον**, **εἴθισα**, **εἰθίσθην**</span>.

<span lang="grc"> **ἐλίττω** </span> _roll_ (<span lang="grc"> **Ϝελίττω** </span>), <span lang="grc">**εἴλιττον**, **εἴλιξα**, **εἰλίχθην**</span>.

<span lang="grc"> **ἕλκω** </span> or <span lang="grc">ἑλκύω</span> _draw_ (<span lang="grc"> **σελκω** </span>), <span lang="grc">**εἷλκον**, **εἵλκυσα**, **εἱλκύσθην**</span>.

<span lang="grc"> **ἕπομαι** </span> _follow_ (<span lang="grc"> **σεπομαι** </span>), <span lang="grc"> **εἱπόμην** </span>.

<span lang="grc"> **ἐργάζομαι** </span> _work_ (<span lang="grc"> **Ϝεργάζομαι** </span>), <span lang="grc"> **εἰργασάμην** </span>.

<span lang="grc"> **ἕρπω** </span> _creep_ (<span lang="grc"> **σερπω** </span>), <span lang="grc"> **εἷρπον** </span>.

<span lang="grc"> **ἑστιάω** </span> _entertain_ (<span lang="grc"> **Ϝεστίαω** </span>), <span lang="grc">**εἱστίων**, **εἱστίᾱσα**, **εἱστιά̄θην**</span>. <!-- page 146 -->

<span lang="grc"> **ἔχω** </span> _hold_ (<span lang="grc"> **σεχω** </span>), <span lang="grc"> **εἶχον** </span>.

<span lang="grc"> **ἵημι** </span> _send_ (<span lang="grc"> **σισημι** </span>), aor. du. <span lang="grc"> **εἷτον** </span> for <span lang="grc">**ἐ-ἑ-τον**, **εἵθην**</span> for <span lang="grc"> **ἐ-ἑ-θην** </span>.

<span lang="grc"> **ἵστημι** </span> _put_ (<span lang="grc"> **σιστημι** </span>), plup. <span lang="grc"> **εἱστήκη** </span> for <span lang="grc"> **ἐ-σε-στηκη** </span>.

<span lang="grc"> **ὁράω** </span> _see_ (<span lang="grc"> **Ϝοράω** </span>), <span lang="grc">**ἑώρων**, **ἑώρᾱκα**</span> or <span lang="grc"> **ἑόρᾱκα** </span>.

<span lang="grc"> **ὠθέω** </span> _push_ (<span lang="grc"> **Ϝωθέω** </span>), <span lang="grc">**ἐώθουν**, **ἔωσα**, **ἐώσθην**</span>.

<span lang="grc"> **ὠνέομαι** </span> _buy_ (<span lang="grc"> **Ϝωνέομαι** </span>), <span lang="grc">**ἐωνούμην**, **ἐωνήθην**</span>.

<span lang="grc"> **εἶδον** </span> _saw_, 2 aor. of <span lang="grc"> **ὁράω** </span> (for <span lang="grc"> **ἐ-Ϝιδον** </span>).

<span lang="grc"> **εἷλον** </span> _took_, 2 aor. of <span lang="grc"> **αἱρέω** </span> (for <span lang="grc"> **ἐ-ἑλον** </span>).

##### <a id="s431D"></a> §431 D

Syllabic augment in Homer before a vowel is a sure proof of initial <span lang="grc">ϝ</span> in <span lang="grc">ἔειπον</span> and some other verbs. Similar Ionic and poetic forms occur from <span lang="grc">εἶδον, εἴλω, εἴρω, ἔλπω, ἕννῡμι, ἔρδω, οἰνοχοέω</span>, etc.

##### <a id="s432"></a> §432

Some forms of some verbs in 431 are augmented as if no consonant had preceded the first vowel, as <span lang="grc">ἠργαζόμην</span> (and <span lang="grc">εἰργαζόμην</span>).

##### <a id="s433"></a> §433

Since <span lang="grc">ϝ</span> disappeared early, many augmented forms show no trace of its existence, as, <span lang="grc">ᾤκουν</span> from <span lang="grc">οἰκέω</span> _dwell_ (<span lang="grc">ϝοῖκος</span>). Besides <span lang="grc">ε, **η**</span> was also used as the syllabic augment. This appears in Hom. <span lang="grc">ἠ-είδεις</span> (<span lang="grc">-ης</span>?), Attic <span lang="grc">ᾔδεις</span> _you knew_.

##### <a id="s434"></a> §434

The verbs <span lang="grc">ἄγνῡμι, ἁλίσκομαι</span>, (<span lang="grc">ἀν</span>)<span lang="grc">οίγνῡμι, ὁράω</span>, which began originally with <span lang="grc">ϝ</span>, show forms that appear to have a double augment; as <span lang="grc">ἐά̄γην, ἑά̄λων</span>, (<span lang="grc">ἀν</span>)<span lang="grc">ἐῳγον</span> (rarely <span lang="grc">ἤνοιγον</span>), <span lang="grc">ἑώρων, ἑώρᾱκα</span> (and <span lang="grc">ἑόρᾱκα</span>). These forms appear to be due to transference of quantity ([34](../../part-1-letters-sounds-syllables-accent/01-the-letters.md#s34)) from <span lang="grc">ἠ-ϝᾰγην, ἠ-ϝοιγον, ἠ-ϝορων</span> (cp. [433](#s433)).

##### <a id="s435"></a> §435

**Temporal Augment**.—Verbs beginning with a vowel take the temporal augment by lengthening the initial vowel. The temporal augment is so called because it usually increases the _time_ required to pronounce the initial syllable. Diphthongs lengthen their first vowel.

##### <a id="s435D"></a> §435 D

Initial <span lang="grc">α</span> becomes <span lang="grc">ᾱ</span> in Doric and Aeolic; initial <span lang="grc">αι</span> and <span lang="grc">αυ</span> remain.

##### <a id="s436"></a> §436

Initial <span lang="grc">ᾳ</span> becomes <span lang="grc">ῃ</span>: <span lang="grc">ᾁδω</span> _sing_, <span lang="grc">ᾖδον</span>. Initial <span lang="grc">η, ῑ, ῡ, ω</span> remain unchanged. Initial <span lang="grc">ᾱ</span> usually becomes <span lang="grc">η</span>: <span lang="grc">ἀ̄ριστάω</span> _breakfast_, <span lang="grc">ἠρίστησα. ἀνᾱλίσκω</span> and <span lang="grc">ἀνᾱλόω</span> _expend_ form <span lang="grc">ἀνά̄λωσα</span> and <span lang="grc">ἀνήλωσα, ἀνᾱλώθην</span> and <span lang="grc">ἀνηλώθην</span>.

##### <a id="s437"></a> §437

Initial diphthongs are sometimes unaugmented: <span lang="grc"> **αυ** </span> in <span lang="grc">αὑαίνομαι</span> _dry;_ <span lang="grc"> **ει** </span>: <span lang="grc">εἴκαζον, ᾔκαζον; **ευ**</span>: <span lang="grc">εὑρέθην</span> and <span lang="grc">ηὑρέθην</span> from <span lang="grc">εὑρίσκω</span> _find_, <span lang="grc">εὐξάμην</span> and <span lang="grc">ηὐξάμην</span> from <span lang="grc">εὔχομαι</span> _pray;_ <span lang="grc"> **ου** </span> is never augmented, since it is never a pure diphthong when standing at the beginning of a verb-form. <!-- page 147 -->

##### <a id="s438"></a> §438

**Omission of the Augment**.—a. In Attic tragedy the augment is sometimes omitted in choral passages, rarely in the dialogue parts (messengers' speeches), which are nearer akin to prose.

**b.** In <span lang="grc">χρῆν</span> (from <span lang="grc">χρὴ ¨ ἦν</span>) the augment is strictly unnecessary, but is often added (<span lang="grc">ἐχρῆν</span>) since the composition of <span lang="grc">χρῆν</span> was forgotten.

**c.** In Homer and the lyric poets either the syllabic or the temporal augment is often absent; as <span lang="grc">φάτο</span> and <span lang="grc">ἔφατο, βῆν</span> and <span lang="grc">ἔβην, ἔχον</span> and <span lang="grc">εἶχον</span>. Iteratives ([495](09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s495)) in Hom. usually have no augment (<span lang="grc">ἔχεσκον</span>).

N.—In Homer the absence of the augment represents the usage of the parent language, in which the augment was not necessarily added to mark past time. It is therefore erroneous, historically, to speak of the _omission_ of the augment in Homer.

**d.** In Herodotus the syllabic augment is omitted only in the case of pluperfects and iteratives in <span lang="grc">σκον</span>; the temporal augment is generally preserved, but it is always omitted in verbs beginning with <span lang="grc">αι, αυ, ει, ευ, οι</span>, and in <span lang="grc">ἀγῑνέω, ἀεθλέω, ἀνώγω, ἔρδω, ἐάω, ὁρμέω</span>, etc.; in others it is omitted only in some forms (as <span lang="grc">ἀγορεύω, ἄγω, ἕλκω, ὁρμάω</span>), and in others it is variable (<span lang="grc">ἀγγέλλω, ἅπτω, ἄρχω, ἐπίσταμαι, ἀνέχομαι</span>); in cases of Attic reduplication the augment is never added. Hdt. omits the augment for the reduplication in the above verbs.
