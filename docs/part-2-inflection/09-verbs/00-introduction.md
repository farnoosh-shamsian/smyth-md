##### <a id="s385"></a> §385

### REMARKS ON THE CONTRACTED VERBS

##### <a id="s393"></a> §393

In the present optative active there are two forms: (1) that with the modal sign <span lang="grc">-ιη-</span>, having <span lang="grc">-ν</span> in the 1 sing., and <span lang="grc">-σαν</span> in the 3 pl.; (2) that with the modal sign <span lang="grc">-ῑ-</span>, having <span lang="grc">-μι</span> in the 1 sing., and <span lang="grc">-εν</span> in the 3 pl. The first form is more common in the singular, the second in the dual and plural.

<span lang="grc"> **τῑμῴην** </span> (rarely <span lang="grc">τῑμῷμι</span>), <span lang="grc"> **τῑμῷτον** </span> (rarely <span lang="grc">τῑμῴητον</span>), <span lang="grc"> **τῑμῷμεν** </span> (rarely <span lang="grc">τῑμῴημεν</span>), <span lang="grc"> **ποιοίην** </span> (rarely <span lang="grc">ποιοῖμι</span>), <span lang="grc"> **ποιοῖτον** </span> (rarely <span lang="grc">ποιοίητον</span>), <span lang="grc"> **ποιοῖμεν** </span> (rarely <span lang="grc">ποιοίημεν</span>), <span lang="grc"> **δηλοίην** </span> (rarely <span lang="grc">δηλοῖμι</span>), <span lang="grc"> **δηλοῖτον** </span> (rarely <span lang="grc">δηλοίητον</span>), <span lang="grc"> **δηλοῖμεν** </span> (rarely <span lang="grc">δηλοίημεν</span>).

##### <a id="s394"></a> §394

Ten verbs in <span lang="grc">-αω</span> show <span lang="grc">η</span> where we expect <span lang="grc">ᾱ</span>. **a.** <span lang="grc">δέω</span> _need_ has <span lang="grc">δεῖς, δεῖ</span> _it is necessary_, <span lang="grc">δέῃ, δέοι, δεῖν, τὸ δέον</span> _what is necessary;_ <span lang="grc">δέομαι</span> _want_, _request_, has <span lang="grc">δέει, δεῖται, δεόμεθα, δέωμαι</span>. But <span lang="grc">δέω</span> _bind_ is usually an exception, making <span lang="grc">δεῖς, δεῖ, δοῦμεν, ἔδουν</span> _bound_, <span lang="grc">τὸ δοῦν</span> _that which binds_, <span lang="grc">δοῦμαι, δοῦνται</span>, but <span lang="grc">δεόμενον, δέον</span> appear in some writers.

**b.** <span lang="grc">ξέω</span> _scrape_ contracts. <span lang="grc">βδέω, ξέω</span> and <span lang="grc">τρέω</span> have lost <span lang="grc">ς; πλέω, θέω, πνέω</span> have lost <span lang="grc">\[υγλιδε\]</span>(<span lang="grc">ϝ</span>); <span lang="grc">δέω</span> _need_ is for <span lang="grc">δευσω; δέω</span> _bind_ is for <span lang="grc">δε\[ιγλιδε\]ω</span>.

##### <a id="s398"></a> §398

Two verbs in <span lang="grc">-οω, ἱδρόω</span> _sweat_, <span lang="grc">ῥῑγόω</span> _shiver_, may have <span lang="grc">ω</span> and <span lang="grc">ῳ</span> instead of <span lang="grc">ον</span> and <span lang="grc">οι</span>. **a.** <span lang="grc">λούω</span> _wash_, when it drops its <span lang="grc">υ</span> ([43](../../part-1-letters-sounds-syllables-accent/01-the-letters.md#s43)), contracts like <span lang="grc">δηλόω</span>. Thus, <span lang="grc">λούω, λούεις, λούει</span>, but <span lang="grc">λοῦμεν</span> (for <span lang="grc">λο</span>(<span lang="grc">\[υγλιδε\]</span>)<span lang="grc">ο-μεν</span>), <span lang="grc">λοῦτε, λοῦσι</span>; and so in other forms, as <span lang="grc">ἔλου, λοῦται, λοῦσθαι, λούμενος</span>.

**b.** <span lang="grc">οἵομαι</span> _think_ (imperfect <span lang="grc">ᾠόμην</span>) has the parallel forms <span lang="grc">οἶμαι</span> (<span lang="grc">ᾤμην</span>).

### PERFECT AND PLUPERFECT MIDDLE (AND PASSIVE)

<!-- page 130 -->

##### <a id="s403"></a> §403

In the perfect and pluperfect middle (and passive) of stems ending in a consonant certain euphonic changes ([409](#s409)) occur upon the addition of the personal endings.

##### <a id="s404"></a> §404

Several verbs with stems ending in a short vowel retain that vowel in the perfect (and in other tenses); such stems originally ended in <span lang="grc">ς</span>; as <span lang="grc">τελέ-ω</span> _finish_, from <span lang="grc">τέλος</span> _end_ (<span lang="grc">τελεσ-</span>). This <span lang="grc">ς</span> appears in the perfect middle stem (<span lang="grc">τετέλε-σ-μαι, τετέλε-σ-ται</span>). In the second person singular and plural but one <span lang="grc">ς</span> is found: <span lang="grc">τετέλε-σαι, τετέλε-σθε</span>. By analogy some other verbs have a <span lang="grc">ς</span> at the end of the verbal stem.

##### <a id="s405"></a> §405

In the perfect and pluperfect middle the third person plural of stems ending in a consonant or of stems adding <span lang="grc">ς</span> consists of the perfect middle participle with <span lang="grc">εἰσί</span> _are_ (in the perfect) and <span lang="grc">ἦσαν</span> _were_ (in the pluperfect).

### EXPLANATION OF THE PERFECT AND PLUPERFECT FORMS

##### <a id="s408"></a> §408

The periphrastic third plural is used instead of the forms derived directly from the union of the stem with the ending.

Thus, <span lang="grc">γεγραμμένοι εἰσί</span> is used for <span lang="grc">γεγραφ-νται</span> which would become <span lang="grc">γεγράφαται</span> by 35 b, <span lang="grc">ν</span> between consonants passing into <span lang="grc">α</span>. The periphrastic form is also used in verbs adding <span lang="grc">ς</span> to their stems, as <span lang="grc">τετελε-σ-μένοι εἰσί</span> for <span lang="grc">τετελε-σ-νται</span>. Stems in <span lang="grc">ν</span> that drop <span lang="grc">ν</span> in the perfect system form their perfect and pluperfect regularly; thus, <span lang="grc">κρί̄νω</span> (<span lang="grc">κριν-</span>) _judge_ has <span lang="grc">κέκρινται, ἐκέκριντο</span>.

N.—On the retention of <span lang="grc">-αται, -ατο</span> see [465 f](08-endings-of-the-verb-personal-endings.md#s465).

##### <a id="s409"></a> §409

**Euphonic Changes**.—For the euphonic changes in these forms see [82](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s82)-87, 103.

**a. Labial Stems**.—<span lang="grc">λέλειμ-μαι</span> is for <span lang="grc">λελειπ-μαι, λέλειφ-θον</span> is for <span lang="grc">λελειπ-σθον, λέλειφθε</span> is for <span lang="grc">λελειπ-σθε</span> ([103](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s103)). In the same manner are inflected other labial stems, as <span lang="grc">τρί̄βω</span> (<span lang="grc">τρῑβ-</span>) _rub_, <span lang="grc">ῥί̄πτω</span> (<span lang="grc">ῥῑπ-</span>) _throw:_ <span lang="grc">τέτρῑμ-μαι</span> for <span lang="grc">τετρῑβ-μαι, τέτρῑψαι</span> for <span lang="grc">τετρῑβ-σαι</span>, etc. Stems ending in <span lang="grc">μπ</span> drop <span lang="grc">π</span> before <span lang="grc">μ</span>, but retain it before other consonants. Thus,

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| <span lang="grc">πεπεμπ-μαι</span> | becomes | <span lang="grc">πέπεμμαι</span> | <span lang="grc">πεπεμπ-μεθα</span> | becomes | <span lang="grc">πεπέμμεθα</span> |
| <span lang="grc">πεπεμπ-σαι</span> | “ | <span lang="grc">πέπεμψαι</span> | <span lang="grc">πεπεμπ-σθε</span> | “ | <span lang="grc">πέπεμφθε</span> ([103](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s103)) |
| <span lang="grc">πεπεμπ-ται</span> | “ | <span lang="grc">πέπεμπται</span> |  |  |  |

**b. Dental Stems**.—<span lang="grc">πέπεισ-ται</span> is for <span lang="grc">πεπειθ-ται</span> ([83](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s83)), <span lang="grc">πέπεισ-θον</span> is for <span lang="grc">πεπειθθον</span> ([83](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s83)), <span lang="grc">πέπεισθε</span> is for <span lang="grc">πεπειθ-</span>(<span lang="grc">σ</span>)<span lang="grc">θε</span> ([83](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s83), [103](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s103)). The <span lang="grc">ς</span> thus produced was trans<!-- page 133 --> ferred to the first persons <span lang="grc">πέπεισμαι, πεπείσμεθα</span> ([86](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s86), [87](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s87)). Like <span lang="grc">πέπεισμαι</span>, etc., are formed and inflected <span lang="grc">ἔψευσμαι</span> from <span lang="grc">ψεύδω</span> (<span lang="grc">ψευδ-</span>) _deceive_, <span lang="grc">πέφρασμαι</span> from <span lang="grc">φράζω</span> (<span lang="grc">φραδ-</span>) _declare_, <span lang="grc">ἔσπεισμαι</span> ([100](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s100)) from <span lang="grc">σπένδω</span> (<span lang="grc">σπενδ-</span>) _pour a libation_.

##### <a id="s409bD"></a> §409 b. D

Hom. has the original forms <span lang="grc">πεφραδμένος, κεκορυθμένος</span>.

**c. Paltal Stems**.—<span lang="grc">πέπρᾱξαι</span> is for <span lang="grc">πεπρᾱγ-σαι</span> ([97](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s97)), <span lang="grc">πέπρᾱκται</span> is for <span lang="grc">πεπρᾱγται</span> ([82 a](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s82)), <span lang="grc">πέπρᾱχθε</span> is for <span lang="grc">πεπρᾱγ-σθε</span> ([103](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s103)). Like <span lang="grc">πέπρᾱγμαι</span> are inflected <span lang="grc">πλέκω</span> (<span lang="grc">πλεκ-</span>) _weave_ <span lang="grc">πέπλεγ-μαι, ἄγω</span> (<span lang="grc">ἀγ-</span>) _lead_ <span lang="grc">ἦγμαι, ἀλλάττω</span> (<span lang="grc">ἀλλαγ-</span>) _exchange_ <span lang="grc">ἤλλαγμαι, ταράττω</span> (<span lang="grc">ταραχ-</span>) _confuse_ <span lang="grc">τετάραγμαι</span>. Stems in <span lang="grc">-γχ</span> change <span lang="grc">χ</span> before <span lang="grc">μ</span> to <span lang="grc">γ</span> and drop one <span lang="grc">γ</span> (as in <span lang="grc">ἐλήλεγ-μαι</span> for <span lang="grc">ἐληλεγγ-μαι</span>, 85 and 85 b), but keep the second palatal before other consonants (as in <span lang="grc">ἐλήλεγξαι</span> for <span lang="grc">ἐληλεγχ-σαι</span>, 97; <span lang="grc">ἐλήλεγκ-ται</span> for <span lang="grc">ἐληλεγχ-ται</span>, [82](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s82)). On the reduplication see [446](06-reduplication.md#s446).

**d. Liquid and Nasal Stems**.—Stems in <span lang="grc">λ</span> or <span lang="grc">ρ</span> are inflected like <span lang="grc">ἤγγελμαι</span>, as <span lang="grc">στέλλω</span> (<span lang="grc">στελ-, σταλ-</span>) _send_ <span lang="grc">ἔσταλμαι, αἴρω</span> (<span lang="grc">ἀρ-</span>) _raise_ <span lang="grc">ἦρμαι, ἐγείρω</span> (<span lang="grc">ἐγερ-</span>) _wake_ <span lang="grc">ἐγήγερμαι</span> ([446](06-reduplication.md#s446)). Stems in <span lang="grc">ν</span> retaining the nasal are inflected like <span lang="grc">πέφασμαι</span>, as <span lang="grc">σημαίνω</span> (<span lang="grc">σημαν-</span>) _signify_ <span lang="grc">σεσήμασμαι</span>. (For <span lang="grc">-σμαι</span> see [94](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s94) a and b.) Stems in <span lang="grc">ν</span> dropping the nasal ([559 a](../10-verb-stem-and-present-stem/06-v-first-k-perfect-system.md#s559)) are inflected like <span lang="grc">λέλυμαι</span>, as <span lang="grc">κρί̄νω</span> (<span lang="grc">κριν-</span>) _judge_ <span lang="grc">κέκριμαι</span>.

**e. Vowel Stems adding <span lang="grc">ς</span>**.—Here the stem ends in a vowel except before <span lang="grc">μ</span> and <span lang="grc">τ</span>; thus, <span lang="grc">τετέλε-σαι, τετέλε-σθον, τετέλε-σθε</span>: but <span lang="grc">τετέλε-σ-μαι, τετελέ-σ-μεθα, τετέλε-σ-ται</span>.

N.—Since the stem of <span lang="grc">τελέω</span> is properly <span lang="grc">τελεσ-</span> (<span lang="grc">τελεσ-\[ιγλιδε\]ω</span>, [624](../10-verb-stem-and-present-stem/12-first-conjugation-or-verbs-in-omega.md#s624)), the original inflection is <span lang="grc">τετελεσ-σαι</span>, whence <span lang="grc">τετέλε-σαι</span> ([107](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s107)); <span lang="grc">τετέλεσ-ται; τετελεσ-σθον, τετελεσ-σθε</span>, whence <span lang="grc">τετέλεσθον, τετέλεσθε</span> ([103](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s103)). <span lang="grc">τετέλεσμαι</span> and <span lang="grc">τετελέσμεθα</span> are due to the analogy of the other forms.

##### <a id="s410"></a> §410

The forms <span lang="grc">πέφανσαι, ἐπέφανσο</span>, and <span lang="grc">πέφανσο</span> are not attested. Cp. [707 a](../10-verb-stem-and-present-stem/13-inflection-of-omega-verbs.md#s707).

## CONJUGATION OF <span lang="grc">μι-</span>VERBS

<!-- page 134 -->

##### <a id="s412"></a> §412

The conjugation of <span lang="grc">μι-</span>verbs differs from that of <span lang="grc">ω-</span>verbs only in the present, imperfect, and second aorist active and middle; and (rarely) in the second perfect. The <span lang="grc">μι</span> forms are made by adding the endings _directly_ to the tense-stem without any thematic vowel, except in the subjunctive of all verbs, and in the optative of verbs ending in <span lang="grc">-νῡμι</span>.

##### <a id="s413"></a> §413

Verbs having second aorists and second perfects of the <span lang="grc">μι</span> form are, as a rule, <span lang="grc">ω-</span>verbs, not <span lang="grc">μι-</span>verbs, in the present. Thus, the second aorists: <span lang="grc">ἔβην</span> (<span lang="grc">βαίνω</span> _go_), <span lang="grc">ἔγνων</span> (<span lang="grc">γιγνώσκω</span> _know_); the second perfect: <span lang="grc">τέθναμεν</span> (<span lang="grc">θνῄσκω</span> _die_).

##### <a id="s414"></a> §414

There are two main classes of <span lang="grc">μι-</span>verbs.

A. The root class. This class commonly ends in <span lang="grc">-η-μι</span> or <span lang="grc">-ω-μι</span> (from stems in <span lang="grc">ε, α</span>, or <span lang="grc">ο</span>). The present stem is usually reduplicated, but may be the same as the verb-stem, which is a root.

| Verb-stem | Present Stem | Present |
| <span lang="grc">θε-, θη-</span> | <span lang="grc">τιθε-, τιθη-</span> (for <span lang="grc">θιθε, θιθη</span>, 125 a) | <span lang="grc">τίθημι</span> _place_ |
| <span lang="grc">ἑ-, ἡ-</span> | <span lang="grc">ἱ̄ε-, ἱ̄η-</span> (for <span lang="grc">σισε, σιση</span>) | <span lang="grc">ἵ̄ημι</span> _send_ |
