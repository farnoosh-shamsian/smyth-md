# VERBS: REDUPLICATION

##### <a id="s439"></a> §439

Reduplication is the doubling of the sound standing at the beginning of a word. It is used in the perfect, pluperfect, and future perfect tenses in all the moods, to denote completed action. It is sometimes found also in the present and second aorist.

##### <a id="s439D"></a> §439 D

Reduplication (or the augment for the reduplication) is generally retained in Hom. Exceptions are <span lang="grc">ἔρχαται</span> and <span lang="grc">ἔρχατο</span> from <span lang="grc">ἔργω</span> _shut_, <span lang="grc">ἄνωγα</span> _order_, <span lang="grc">ἕσται</span> from <span lang="grc">ἕννῡμι</span> _clothe_. On <span lang="grc">δέχαται</span> _await_, <span lang="grc">ἐδέγμην</span> _was expecting_ cp. [634](../10-verb-stem-and-present-stem/13-inflection-of-omega-verbs.md#s634).

##### <a id="s440"></a> §440

Verbs beginning with a simple consonant (except <span lang="grc">ρ</span>) or with a stop and a liquid (<span lang="grc">λ, μ, ν, ρ</span>) place the initial consonant with <span lang="grc">ε</span> before the stem. <span lang="grc">λύ̄ω</span> _loose_, <span lang="grc">λέ-λυκα, λε-λυκέναι, λέ-λυμαι, λε-λύ̄σομαι; γράφω</span> _write_, <span lang="grc">γέ-γραφα; κλί̄νω</span> _incline_, <span lang="grc">κέ-κλικα; βλάπτω</span> _injure_, <span lang="grc">βέ-βλαφα; πρί̄ω</span> _saw_, <span lang="grc">πέ-πρῑσμαι</span>.

**a.** Exceptions: verbs beginning with <span lang="grc">γν</span>, most of those with <span lang="grc">γλ</span>, and some with <span lang="grc">βλ</span>. Thus, <span lang="grc">γνωρίζω</span> _recognize_, <span lang="grc">ἐ-γνώρικα; γι-γνώσκω</span> _know_, <span lang="grc">ἔ-γνωκα; γλύφω</span> _carve_, <span lang="grc">ἔ-γλυφα; βλαστάνω</span> _sprout_, <span lang="grc">ἐ-βλάστηκα</span> (usu. <span lang="grc">βεβλάστηκα</span>).

##### <a id="s441"></a> §441

An initial aspirate is reduplicated by the corresponding smooth stop: <span lang="grc">φονεύω</span> _murder_, <span lang="grc">πε-φόνευκα; θύ̄ω</span> _sacrifice_, <span lang="grc">τέ-θυκα; χορεύω</span> _dance_, <span lang="grc">κε-χόρευκα</span>.

##### <a id="s442"></a> §442

In all other cases the reduplication is formed like the augment.

**a.** Verbs beginning with a short vowel lengthen the vowel, as <span lang="grc">ἄγω</span> _lead_, <span lang="grc">ἦχα; ὀρθόω</span> _set upright_, <span lang="grc">ὤρθωκα; ἀγγέλλω</span> _announce_, <span lang="grc">ἤγγελκα</span>.

**b.** Verbs beginning with two or more consonants (except a stop with a liquid), a double consonant, and <span lang="grc">ρ</span> simply prefix <span lang="grc">ε. ρ</span> is here doubled (cp. [429](05-augment.md#s429) a). <!-- page 148 --> Thus, <span lang="grc">κτίζω</span> _found_, <span lang="grc">ἔ-κτικα; σπείρω</span> _sow_, <span lang="grc">ἔ-σπαρμαι; στρατηγέω</span> _am general_, <span lang="grc">ἐ-στρατήγηκα; ζητέω</span> _seek_, <span lang="grc">ἐ-ζήτηκα; ψαύω</span> _touch_, <span lang="grc">ἔ-ψαυκα; ῥί̄πτω</span> _throw_, <span lang="grc">ἔρρῑφα</span>.

N.—<span lang="grc">μιμνῄσκω</span> _remind_ and <span lang="grc">κτάομαι</span> _acquire_ are exceptions: <span lang="grc">μέ-μνημαι, ἐ-μεμνήμην; κέ-κτημαι, ἐ-κε-κτήμην</span>.

##### <a id="s442bD"></a> §442. b. D

Hom. has <span lang="grc">ῥε-ρυπωμένος</span> (<span lang="grc">ῥυπόω</span> _soil_), <span lang="grc">ἔμμορε</span> (<span lang="grc">μείρομαι</span> _obtain_) for <span lang="grc">ἐ-σμορε</span> 445 a, <span lang="grc">ἔσσυμαι</span> (<span lang="grc">σεύω</span> _urge_) for <span lang="grc">ἐ-κ\[ιγλιδε\]υ-μαι</span>; Ionic has <span lang="grc">ἔκτημαι</span>.

##### <a id="s443"></a> §443

The verbs mentioned in 431 which originally began with a consonant now lost, reduplicate regularly. Since the reduplicated consonant has disappeared only <span lang="grc">ε</span> is left, and this often contracts with the initial vowel of the theme. Thus, <span lang="grc">ἔᾱγα</span> for <span lang="grc">ϝε-ϝᾱγα</span> from <span lang="grc">ϝάγνῡμι</span> _break;_ <span lang="grc">ἔωσμαι</span> for <span lang="grc">ϝε-ϝωσμαι</span> from <span lang="grc">ϝωθέω</span> _push;_ <span lang="grc">ἕστηκα</span> for <span lang="grc">σεστηκα</span> from <span lang="grc">ἵστημι</span> _set;_ <span lang="grc">εἷκα</span> for <span lang="grc">σεσεκα</span> from <span lang="grc">ἵ̄ημι</span> (<span lang="grc">σι-σημι</span>) send.

##### <a id="s444"></a> §444

**Pluperfect**.—The pluperfect prefixes the syllabic augment <span lang="grc">ε</span> to the reduplicated perfect beginning with a consonant; when the perfect stem begins with a vowel the pluperfect retains the prefix of the perfect.

Thus perf. <span lang="grc">λέλυκα, λέλυμαι</span>, plup. <span lang="grc">ἐ-λελύκη, ἐ-λελύμην</span>; perf. <span lang="grc">ἔ-σταλκα, ἔ-σταλμαι</span>, plup. <span lang="grc">ἐ-στάλκη, ἐ-στάλμην</span> from <span lang="grc">στέλλω</span> _send;_ perf. <span lang="grc">ἠγόρευκα</span>, plup. <span lang="grc">ἠγορεύκη</span> from <span lang="grc">ἀγορεύω</span> _harangue;_ perf. <span lang="grc">ᾕρηκα</span>, plup. <span lang="grc">ᾑρήκη</span> from <span lang="grc">αἱρέω</span> _seize_.

**a.** Verbs showing ‘Attic’ reduplication ([446](#s446)), in almost all cases augment the pluperfect.

**b.** The verbs of 431 follow the perfects of 443; as <span lang="grc">ἐά̄γη</span> (<span lang="grc">ἄγνῡμι</span>), <span lang="grc">ἐώσμην</span> (<span lang="grc">ὠθέω</span>), <span lang="grc">εἵμην</span> (<span lang="grc">ἵ̄ημι</span>), <span lang="grc">ἐρρώγη</span> from (<span lang="grc">ϝ</span>)<span lang="grc">ρήγνῡμι. ἵστημι</span> forms <span lang="grc">εἱστήκη</span> ( = <span lang="grc">ἐ-</span>(<span lang="grc">σ</span>)<span lang="grc">εστηκη</span>), Ion. and poet. <span lang="grc">ἑστήκη</span> (rare in Att. prose). <span lang="grc">ἔοικα</span> _am like_ forms <span lang="grc">ἐῴκη</span>.

##### <a id="s444bD"></a> §444 b. D

Hdt. has <span lang="grc">οἶκα</span> (for <span lang="grc">ἔοικα</span>), <span lang="grc">ἔωθα, ἐώθεα</span>; Hom. has <span lang="grc">ἔωθεν</span> and <span lang="grc">εἴωθε</span>.

##### <a id="s445"></a> §445

Some verbs beginning with a liquid or <span lang="grc">μ</span> take <span lang="grc">ει</span> instead of the reduplication: <span lang="grc"> **λαμβάνω** </span> (<span lang="grc">λαβ-</span>) _take_, <span lang="grc">εἴ-ληφα, εἴ-λημμαι, εἰ-λήφη; **λαγχάνω**</span> (<span lang="grc">λαχ-</span>) _obtain by lot_, <span lang="grc">εἴ-ληχα, εἰ-λήχη; **λέγω**</span> _collect_ (in composition) <span lang="grc">-εἴ-λοχα, -εἰ-λόχη, -εἴ-λεγμαι</span> (rarely <span lang="grc">λέ-λεγμαι</span>); <span lang="grc"> **μείρομαι** </span> _receive a share_, <span lang="grc">εἵ-μαρται</span> _it is fated_, <span lang="grc">εἵ-μαρτο</span> with rough breathing; also the stems <span lang="grc">**επ**, **ρη**</span> _say_, <span lang="grc">εἴ-ρηκα, εἰ-ρήκη</span>.

##### <a id="s445D"></a> §445 D

Hom. <span lang="grc">δείδω</span> _fear_ stands for <span lang="grc">δε-δϝω</span> from <span lang="grc">δε-δϝο</span>(<span lang="grc">\[ιγλιδε\]</span>)<span lang="grc">α</span> (cp. <span lang="grc">δϝέος</span>). So <span lang="grc">δείδοικα</span> for <span lang="grc">δε-δϝοικα</span>. For <span lang="grc">δείδεκτο</span> _greeted_ we should read <span lang="grc">δήδεκτο</span> with <span lang="grc">η-</span>reduplication. Hdt. has <span lang="grc">λελάβηκα</span> and <span lang="grc">-λελαμμένος. λέλημμαι</span> occurs in tragedy.

**a.** <span lang="grc">εἴληφα</span> is from <span lang="grc">σε-σληφα</span> by 37 (cp. Hom. <span lang="grc">ἔλλαβον</span> for <span lang="grc">ἐ-σλαβον</span>), <span lang="grc">εἵμαρται</span> is from <span lang="grc">σε-σμαρται</span> (cp. Hom. <span lang="grc">ἔμμορε</span>). The other forms are probably analogues of <span lang="grc">εἴληφα</span>.

##### <a id="s446"></a> §446

**Attic Reduplication**.—Some verbs whose themes begin with <span lang="grc">α, ε</span>, or <span lang="grc">ο</span>, followed by a single consonant, reduplicate by repeating the initial vowel and the consonant and by lengthening <span lang="grc">α</span> and <span lang="grc">ε</span> to <span lang="grc">η, ο</span> to <span lang="grc">ω</span>. Thus <span lang="grc">ἀγείρω</span> _collect_, <span lang="grc">ἀγ-ήγερκα, ἀγ-ήγερμαι; ἐγείρω</span> _awaken_, <!-- page 149 --> <span lang="grc">ἐγ-ήγερμαι; ἐλέγχω</span> _confute_, <span lang="grc">ἐλ-ήλεγμαι; ὀρύττω</span> _dig_, <span lang="grc">ὀρ-ώρυχα, ὀρ-ώρυγμαι; ὄμ-νῡμι</span> _swear_, <span lang="grc">ὀμ-ώμοκα; ὄλ-λῡμι</span> _destroy_, <span lang="grc">ὀλ-ώλεκα</span>. So also <span lang="grc">φέρω</span> _bear_, <span lang="grc">ἐν-ήνοχα, ἐν-ήνεγμαι</span>.

**a.** The name ‘Attic’ was given by the Greek grammarians to this form of reduplication though it occurs in Homer and in the other dialects.

**b.** <span lang="grc">ἀκούω</span> _hear_ has <span lang="grc">ἀκ-ήκοα</span> for <span lang="grc">ἀκ-ήκο</span>(<span lang="grc">\[υγλιδε\]</span>)<span lang="grc">α; ἄγω</span> has <span lang="grc">ἀγ-ήοχα</span> for <span lang="grc">ἀγ-ή</span>(<span lang="grc">γ</span>)<span lang="grc">οχα</span>. The pluperfect augments except in the case of verbs with initial <span lang="grc">ε</span>: <span lang="grc">ἠκ-ηκόη, ὠμ-ωμόκη, ἀπωλώλη</span>; but <span lang="grc">ἐλ-ηλύθη, ἐν-ηνέγμην</span>.

##### <a id="s446D"></a> §446 D

—In Hom. ‘Attic’ reduplication is even more frequent than in Attic; thus, <span lang="grc">ἐδηδώς</span> from <span lang="grc">ἔδω</span> _eat_, <span lang="grc">ἐρήριπα</span> _have fallen_, <span lang="grc">ἐρέριπτο</span> (without lengthening) from <span lang="grc">ἐρείπω</span> _overthrow_, <span lang="grc">ὀρωρέχαται</span> from <span lang="grc">ὀρέγω</span> _reach_. For other poetical forms see in the List of Verbs <span lang="grc">ἀγείρω, αἱρέω, ἀλάομαι, ἀραρίσκω, ἐρείδω, ἐρίζω, ἔχω, ὄζω, ὁράω, ὄρνῡμι</span>.

##### <a id="s447"></a> §447

**Reduplication in the Present**.—A few verbs reduplicate in the present by prefixing the initial consonant and <span lang="grc">ι</span>, as <span lang="grc">γί-γνομαι, γι-γνώσκω, μι-μνῄσκω, τί-κτω</span> for <span lang="grc">τι-τ</span>(<span lang="grc">ε</span>)<span lang="grc">κω, πί̄-πτω</span> for <span lang="grc">πι-π</span>(<span lang="grc">ε</span>)<span lang="grc">τω, ἵ-στημι</span> for <span lang="grc">σι-στημι, τί-θημι</span> for <span lang="grc">θι-θημι</span> ([125 a](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s125)), <span lang="grc">δί-δωμι. πίμ-πλη-μι</span> _fill_ (<span lang="grc">πλα-, πλη-</span>) and <span lang="grc">πίμπρημι</span> _burn_ (<span lang="grc">πρα-, πρη-</span>) insert <span lang="grc">μ</span>.

**a.** In some verbs the reduplication belongs to the verbal stem: <span lang="grc">βιβάζω</span> _make go_ <span lang="grc">ἐβίβασα, διδάσκω</span> _teach_ <span lang="grc">ἐδίδαξα</span>.

##### <a id="s448"></a> §448

**Reduplication in the Second Aorist**.—<span lang="grc">ἄγω</span> _lead_ forms the second aorist <span lang="grc">ἤγ-αγον, ἀγ-άγω, ἀγ-άγοιμι, ἀγ-αγεῖν</span>, middle <span lang="grc">ἠγ-αγόμην</span>. So also <span lang="grc">ἤν-εγκα</span> and <span lang="grc">ἤν-εγκον</span> from <span lang="grc">φέρω</span>.

##### <a id="s448D"></a> §448 D

Hom. has many reduplicated second aorists, as <span lang="grc">πέ-πιθον</span> from <span lang="grc">πείθω</span> (<span lang="grc">πιθ-</span>) _persuade_, <span lang="grc">κεκλόμην, κε-κλόμενος</span> from <span lang="grc">κέλομαι</span> _command_, <span lang="grc">λε-λαθέσθαι</span> from <span lang="grc">λανθάνω</span> (<span lang="grc">λαθ-</span>) _escape the notice of_, <span lang="grc">πε-φιδέσθαι</span> from <span lang="grc">φείδομαι</span> (<span lang="grc">φιδ-</span>) _spare_, <span lang="grc">ἤρ-αρον</span> from <span lang="grc">ἀραρίσκω</span> (<span lang="grc">ἀρ-</span>) _join_, <span lang="grc">ὤρ-ορον</span> from <span lang="grc">ὄρνῡμι</span> _arouse_. The indicative forms may take the syllabic augment, as in <span lang="grc">ἐ-πέ-φραδον</span> from <span lang="grc">φράζω</span> (<span lang="grc">φραδ-</span>) _tell_. From <span lang="grc">ἐνίπτω</span> _chide_ and <span lang="grc">ἐρύ̄κω</span> _check_ come <span lang="grc">ἠνί̄παπον</span> and <span lang="grc">ἐνένῑπον</span>, and <span lang="grc">ἠρύ̄κακον</span>.

## POSITION OF AUGMENT AND REDUPLICATION IN COMPOUND VERBS

##### <a id="s449"></a> §449

In verbs compounded with a preposition, augment and reduplication stand between the preposition and the verb.

Thus, <span lang="grc">ὑπερβαίνω</span> _pass over_, <span lang="grc">ὑπερέβαινον, ὑπερβέβηκα; εἰσβάλλω</span> _throw into_, <span lang="grc">εἰσέβαλλον, εἰσβέβληκα</span>.

**a.** Before <span lang="grc">ε</span> of the augment <span lang="grc">ἐκ</span> regains its fuller form <span lang="grc">ἐξ</span> ([133 a](../../part-1-letters-sounds-syllables-accent/04-final-consonants.md#s133)), and <span lang="grc">ἐν</span> and <span lang="grc">σύν</span> reappear in their proper forms which were modified in the present. Thus <span lang="grc">ἐκβάλλω</span> _throw out_, <span lang="grc">ἐξέβαλλον, ἐκβέβληκα; ἐμβάλλω</span> _throw into_, <span lang="grc">ἐνέβαλλον; συλλέγω</span> _collect_, <span lang="grc">συνέλεγον, συνείλοχα; συρρί̄πτω</span> _throw together_, <span lang="grc">συνέρρῑψα, συνέρρῑφα; συσκευάζω</span> _pack together_, <span lang="grc">συνεσκεύαζον, συνεσκευάσθην</span>.

**b.** Prepositions (except <span lang="grc">περί</span> and <span lang="grc">πρό</span>) drop their final vowel: <span lang="grc">ἀποβάλλω</span> _throw away_, <span lang="grc">ἀπ-έβαλλον</span>; but <span lang="grc">περιβάλλω</span> _throw around_, <span lang="grc">περιέβαλλον, προβαίνω</span> _step forward_, <span lang="grc">προέβην</span>. But <span lang="grc">πρό</span> may contract with the augment (<span lang="grc">προὔβην</span>).

##### <a id="s450"></a> §450

But some verbs, which are not often used except as compounds, are treated like uncompound verbs and take the augment before the preposition, as <span lang="grc">ἐκαθήμην</span> _sat_ from <span lang="grc">κάθημαι, ἐκάθιζον</span> _set_, _sat_ from <span lang="grc">καθίζω, ἠμφίεσα</span> _clothed_ from <span lang="grc">ἀμφιέννῡμι, ἐκάθευδον</span> (and <span lang="grc">καθηῡδον</span>) _slept_ from <span lang="grc">καθεύδω, ἠπιστάμην, ἠπιστήθην</span> from <span lang="grc">ἐπίσταμαι</span> _understand_. <span lang="grc">ἵ̄ημι</span> forms <span lang="grc">ἀφί̄ει</span> and <span lang="grc">ἠφί̄ει</span>. The simple verbs occur mostly in poetry. But <span lang="grc">ἀπολαύω</span> _enjoy_ makes <span lang="grc">ἀπολέλαυκα, ἐξετάζω</span> _review_ <span lang="grc">ἐξήτακα</span>. <!-- page 150 -->

##### <a id="s451"></a> §451

**Double Augment**.—Some verbs take two augments, one before and the other after the preposition, as <span lang="grc">ἠν-ειχόμην, ἠν-εσχόμην</span> from <span lang="grc">ἀν-έχομαι</span> _endure_, <span lang="grc">ἠν-ώχλουν</span> from <span lang="grc">ἐνοχλέω</span> _annoy_, <span lang="grc">ἐπηνώρθωμαι</span> from <span lang="grc">ἐπανορθόω</span> _set upright_. So also, by analogy to the foregoing, a few verbs derived from compound words: <span lang="grc">ἠμφεσβήτουν</span> from <span lang="grc">ἀηφισβητέω</span> _dispute_, <span lang="grc">ἠντεδέκει</span> from <span lang="grc">ἀντιδικέω</span> _go to law_ (<span lang="grc">ἀντίδικος</span>).

##### <a id="s452"></a> §452

Compounds of <span lang="grc">**δυσ**-</span> _ill_ and <span lang="grc"> **εὖ** </span> _well_. (1) <span lang="grc">δυστυχέω</span> _am unhappy_, <span lang="grc">ἐ-δυστύχουν, δε-δυσ-τύχηκα. δυσ-ηρέστουν, δυσ-ηρέστηκα</span> from <span lang="grc">δυσ-αρεστέω</span> do not occur. (2) <span lang="grc">εὐεργετέω</span> _do good_, <span lang="grc">εὐεργέτησαν, εὐεργέτηκα</span> (inscrip.) <span lang="grc">εὐηργέτηκα</span> (texts).

##### <a id="s453"></a> §453

Verbs derived from compound nouns take the augment and the reduplication at the beginning; as <span lang="grc">ἐμῡθολόγουν, μεμῡθολόγηκα</span> from <span lang="grc">μῡθολογέω</span> _tell legends_ (<span lang="grc">μῡθολόγος</span> _teller of legends_); <span lang="grc">ᾠκοδόμουν, ᾠκοδόμηκα</span> from <span lang="grc">οἰκοδομέω</span> _build_ (<span lang="grc">οἰκοδόμος</span> _house-builder_); <span lang="grc">ἠμπόλων, ἠμπόληκα</span> from <span lang="grc">ἐμπολάω</span> _traffic in_ (<span lang="grc">ἐμπολή</span> _traffic_).

**a.** <span lang="grc">ἐκκλησιάζω</span> _hold an assembly_ (<span lang="grc">ἐκκλησίᾱ</span>) makes <span lang="grc">ἠκ-κλησίαζον</span> or <span lang="grc">ἐξ-ε-κλησίαζον. ἐγγυάω</span> _pledge_ makes <span lang="grc">ἐνεγύων, ἐνεγύησα</span> and (better) <span lang="grc">ἠγγύων, ἠγγύησα</span>.

##### <a id="s454"></a> §454

Verbs derived from compound nouns whose first part is a preposition are commonly treated as if compounded of a preposition and a simple verb; as <span lang="grc">κατηγορέω</span> _accuse_ (<span lang="grc">κατήγορος</span>), <span lang="grc">κατηγόρουν, κατηγόρηκα; ἐνθῡμέομαι</span> _ponder_ (<span lang="grc">ἔνθῡμος</span>) <span lang="grc">ἐνεθῡμήθην, ἐντεθῡμῆσθαι; ἐπιορκέω</span> _swear falsely_ (<span lang="grc">ἐπίορκος</span>), <span lang="grc">ἐπιώρκηκα; ἐγχειρίζω</span> _entrust_ (<span lang="grc">ἐν χειρί</span>), <span lang="grc">ἐνεχείρισα</span>.

**a.** But several verbs are not treated as compounds, such as <span lang="grc">ἀπατάω</span> _deceive_, <span lang="grc">ἀπιστέω</span> _distrust_, <span lang="grc">ἀπορέω</span> _am in difficulty_, <span lang="grc">παρρησιάζομαι</span> _speak freely_.
