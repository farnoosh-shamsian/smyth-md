# VERB-STEM AND PRESENT STEM: II. FUTURE SYSTEM

##### <a id="s532"></a> §532

Many, if not all, future forms in <span lang="grc">ς</span> are in reality subjunctives of the first aorist. <span lang="grc">λύ̄σω, παιδεύσω, λείψω, στήσω</span> are alike future indicative and aorist subjunctive in form. In poetry and in some dialects there is no external difference between the future indicative and the aorist subjunctive when the latter has (as often in Hom.) a short mood-sign ([457 D.](../09-verbs/07-tense-suffixes-thematic-vowel-mood-suffixes.md#s457)); e.g., Hom. <span lang="grc">βήσομεν, ἀμείψεται</span>, Ionic inscriptions <span lang="grc">ποιήσει</span>.

##### <a id="s533"></a> §533

The future stem is formed by adding the tense-suffix <span lang="grc">-σόε-</span> (<span lang="grc">-εσόε-</span> in liquid stems, [535](#s535)) to the verb-stem: <span lang="grc">λύ̄-σω</span>, _I shall_ (or _will_) _loose_, <span lang="grc">λύ̄σομαι; θή-σω</span> from <span lang="grc">τί-θη-μι</span> _place;_ <span lang="grc">δείξω</span> from <span lang="grc">δείκ-νῡ-μι</span> _show_.

**a.** In verbs showing strong and weak grades ([476](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s476)) the ending is added to the strong stem: <span lang="grc">λείπω λείψω, τήκω τήξω, πνέω πνεύσομαι</span> ([503](02-1-present-system.md#s503)), <span lang="grc">δίδωμι δώσω</span>.

##### <a id="s534"></a> §534

**Vowel Verbs**.—Verb-stems ending in a short vowel lengthen the vowel before the tense suffix (<span lang="grc">α</span> to <span lang="grc">η</span> except after <span lang="grc">ε, ι, ρ</span>). Thus, <span lang="grc">τῑμάω, τῑμήσω; ἐάω, ἐά̄σω; φιλέω, φιλήσω</span>.

**a.** On <span lang="grc">χράω</span> _give oracles_, <span lang="grc">χράομαι</span> _use_, <span lang="grc">ἀκροάομαι</span> _hear_, see [487 a](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s487).

**b.** For verbs retaining a short final vowel, see [488](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s488).

##### <a id="s534D"></a> §534 D

Doric and Aeolic always lengthen <span lang="grc">α</span> to <span lang="grc">ᾱ</span> (<span lang="grc">τῑμά̄σω</span>).

**b.** In verbs with stems originally ending in <span lang="grc">-ς</span> Hom. often has <span lang="grc">σς</span> in the future: <span lang="grc">ἀνύω ἀνύσσεσθαι, τελέω τελε´σσω</span>; by analogy <span lang="grc">ὄλλῡμι ὀλέσσω</span> (and <span lang="grc">ὀλέσω, ὀλεῖται</span>). <!-- page 171 -->

##### <a id="s535"></a> §535

**Liquid Verbs**.—Verb-stems ending in <span lang="grc">λ, μ, ν, ρ</span>, add <span lang="grc">-εσόε-</span>; then <span lang="grc">ς</span> drops and <span lang="grc">ε</span> contracts with the following vowel.

<span lang="grc">φαίνω</span> (<span lang="grc">φαν-</span>) _show_, <span lang="grc">φανῶ, φανεῖς</span> from <span lang="grc">φαν-έ</span>(<span lang="grc">σ</span>)<span lang="grc">ω, φαν-έ</span>(<span lang="grc">σ</span>)<span lang="grc">εις; στέλλω</span> (<span lang="grc">στελ-</span>) _send_, <span lang="grc">στελοῦμεν, στελεῖτε</span> from <span lang="grc">στελ-έ</span>(<span lang="grc">σ</span>)<span lang="grc">ομεν, στελ-έ</span>(<span lang="grc">σ</span>)<span lang="grc">ετε</span>. See p. 128.

##### <a id="s535D"></a> §535 D

These futures are often uncontracted in Homer (<span lang="grc">βαλέω, κτενέεις, ἀγγελέουσιν</span>); regularly in Aeolic; in Hdt. properly only when <span lang="grc">ε</span> comes before <span lang="grc">ο</span> or <span lang="grc">ω</span>.

##### <a id="s536"></a> §536

<span lang="grc">ς</span> is retained in the poetic forms <span lang="grc">κέλσω</span> (<span lang="grc">κέλλω</span> _land_, <span lang="grc">κελ-</span>), <span lang="grc">κύρσω</span> (<span lang="grc">κύ̄ρω</span> _meet_, <span lang="grc">κυρ-</span>), <span lang="grc">θέρσομαι</span> (<span lang="grc">θέρομαι</span> _warm myself_, <span lang="grc">θερ-</span>), <span lang="grc">ὄρσω</span> (<span lang="grc">ὄρνῡμι</span> _rouse_, <span lang="grc">ὀρ-</span>). So also in the aorist. See <span lang="grc">ἀραρίσκω, εἴλω, κείρω, φθείρω, φύ̄ρω</span> in the List of Verbs.

##### <a id="s537"></a> §537

**Stop Verbs**.—Labial (<span lang="grc">π, β, φ</span>) and palatal (<span lang="grc">κ, γ, χ</span>) stops at the end of the verb-stem unite with <span lang="grc">ς</span> to form <span lang="grc">ψ</span> or <span lang="grc">ξ</span>. Dentals (<span lang="grc">τ, δ, θ</span>) are lost before <span lang="grc">ς</span> ([98](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s98)).

<span lang="grc">κόπ-τ-ω</span> (<span lang="grc">κοπ-</span>) _cut_, <span lang="grc">κόψω, κόψομαι; βλάπ-τ-ω</span> (<span lang="grc">βλαβ-</span>) _injure_, <span lang="grc">βλάψω, βλάψομαι; γράφ-ω</span> _write_, <span lang="grc">γράψω, γράψομαι; πλέκ-ω</span> _weave_, <span lang="grc">πλέξω, πλέξομαι; λέγ-ω</span> _say_, <span lang="grc">λέξω, λέξομαι; ταράττω</span> (<span lang="grc">ταραχ-</span>) _disturb_, <span lang="grc">ταράξω, ταράξομαι; φράζω</span> (<span lang="grc">φραδ-</span>) _say_, <span lang="grc">φράσω; πείθω</span> (<span lang="grc">πιθ-, πειθ-</span>) _persuade_, <span lang="grc">πείσω, πείσομαι</span>.

**a.** When <span lang="grc">ε</span> or <span lang="grc">ο</span> is added to the verb-stem, it is lengthened to <span lang="grc">η</span> or <span lang="grc">ω</span>: as <span lang="grc">βούλομαι</span> (<span lang="grc">βουλ-ε-</span>) _wish_ <span lang="grc">βουλήσομαι, ἁλίσκομαι</span> (<span lang="grc">ἁλ-ο-</span>) _am captured_ <span lang="grc">ἁλώσομαι</span>. So also in the first aorist and in other tenses where lengthening is regular.

##### <a id="s537D"></a> §537 D

Doric has <span lang="grc">-ξω</span> from most verbs in <span lang="grc">-ζω</span> ([516 D.](02-1-present-system.md#s516)).

##### <a id="s538"></a> §538

**Attic Future**.—Certain formations of the future are called _Attic_ because they occur especially in that dialect in contrast to the later language; they occur also in Homer, Herodotus, and in other dialects.

##### <a id="s539"></a> §539

These futures usually occur when <span lang="grc">ς</span> is preceded by <span lang="grc">ᾰ</span> or <span lang="grc">ε</span> and these vowels are not preceded by a syllable long by nature or position. Here <span lang="grc">ς</span> is dropped and <span lang="grc">-άω</span> and <span lang="grc">-έω</span> are contracted to <span lang="grc">-ῶ</span>. When <span lang="grc">ι</span> precedes <span lang="grc">ς</span>, the ending is <span lang="grc">ι-</span>(<span lang="grc">σ</span>)<span lang="grc">έω</span> which contracts to <span lang="grc">-ιῶ</span>.

**a.** <span lang="grc">καλέω</span> _call_, <span lang="grc">τελέω</span> _finish_ drop the <span lang="grc">ς</span> of <span lang="grc">καλέσω καλέσομαι, τελέσω τελέσομαι</span> and the resulting Attic forms are <span lang="grc">καλῶ καλοῦμαι, τελῶ</span> (<span lang="grc">τελοῦμαι</span> poetic).

**b.** <span lang="grc">ἐλαύνω</span> (<span lang="grc">ἐλα-</span>) _drive_ has Hom. <span lang="grc">ἐλάω</span>, Attic <span lang="grc">ἐλῶ.—καθέζομαι</span> (<span lang="grc">καθεδ-</span>) _sit_ has Attic <span lang="grc">καθεδοῦμαι.—μάχομαι</span> (<span lang="grc">μαχ-ε-</span>) _fight_ has Hom. <span lang="grc">μαχέσομαι</span> (and <span lang="grc">μαχήσομαι</span>), Attic <span lang="grc">μαχοῦμαι.—ὄλλῡμι</span> (<span lang="grc">ὀλ-ε-</span>) _destroy_ has Hom. <span lang="grc">ὀλέσω</span>, Attic <span lang="grc">ὀλῶ</span>.

##### <a id="s539bD"></a> §539. b. D

For Hom. <span lang="grc">-οω</span> for <span lang="grc">-αω</span>, see [645](13-inflection-of-omega-verbs.md#s645).

**c.** All verbs in <span lang="grc">-αννῡμι</span> have futures in <span lang="grc">-ά</span>(<span lang="grc">σ</span>)<span lang="grc">ω, -ῶ</span>. Thus, <span lang="grc">σκεδάννῡμι</span> (<span lang="grc">σκεδα-</span>) _scatter_, poet. <span lang="grc">σκεδάσω</span>, Attic <span lang="grc">σκεδῶ</span>. Similarly some verbs in <span lang="grc">-εννῡμι</span>: <span lang="grc">ἀμφιέννῡμι</span> (<span lang="grc">ἀμφιε-</span>) _clothe_, Epic <span lang="grc">ἀμφιέσω</span>, Attic <span lang="grc">ἀμφιῶ; στόρνῡμι</span> (<span lang="grc">στορ-ε-</span>) _spread_, late <span lang="grc">στορέσω</span>, Attic <span lang="grc">στορῶ</span>.

**d.** A very few verbs in <span lang="grc">-αζω</span> have the contracted form. <span lang="grc">βιβάζω</span> (<span lang="grc">βιβαδ-</span>) _cause to go_ usually has Attic <span lang="grc">βιβῶ</span> from <span lang="grc">βιβάσω</span>. So <span lang="grc">ἐξετῶμεν ῀ ἐξετάσομεν</span> from <span lang="grc">ἐξετάζω</span> _examine_.

**e.** Verbs in <span lang="grc">-ιζω</span> of more than two syllables drop <span lang="grc">ς</span> and insert <span lang="grc">ε</span>, thus making <span lang="grc">-ι</span>(<span lang="grc">σ</span>)<span lang="grc">έω, -ι</span>(<span lang="grc">σ</span>)<span lang="grc">έομαι</span>, which contract to <span lang="grc">-ιῶ</span> and <span lang="grc">-ιοῦμαι</span>, as in the Doric future ([540](#s540)). <!-- page 172 --> So <span lang="grc">νομίζω</span> (<span lang="grc">νομιδ-</span>) _consider_ makes <span lang="grc">νομισεω, νομι-εω, νομιῶ</span> and in like manner <span lang="grc">νομιοῦμαι</span>, both inflected like <span lang="grc">ποιῶ, ποιοῦμαι</span>. So <span lang="grc">ἐθιοῦσι, οἰκιοῦντες</span> from <span lang="grc">ἐθίζω</span> _accustom_, <span lang="grc">οἰκίζω</span> _colonize_. But <span lang="grc">σχίζω</span> (<span lang="grc">σχιδ-</span>) _split_ makes <span lang="grc">σχίσω. νομιῶ</span> etc. are due to the analogy of the liquid verbs.

N.—Such forms in Attic texts as <span lang="grc">ἐλάσω, τελέσω, νομίσω, βιβάσω</span> are erroneous.

##### <a id="s539D"></a> §539 D

Hom. has <span lang="grc">ἀεικιῶ, κομιῶ, κτεριῶ</span>; and also <span lang="grc">τελέω, καλέω, ἐλάω, ἀντιόω, δαμόωσι</span> ([645](13-inflection-of-omega-verbs.md#s645)), <span lang="grc">ἀνύω, ἐρύουσι, τανύουσι</span>. Hdt. always uses the <span lang="grc">-ιῶ</span> and <span lang="grc">-ιοῦμαι</span> forms. Homeric futures in <span lang="grc">-εω</span> have a liquid before <span lang="grc">ε</span>, and are analogous to the futures of liquid verbs.

##### <a id="s540"></a> §540

**Doric Future**.—Some verbs, which have a future middle with an active meaning, form the stem of the future middle by adding <span lang="grc">-σεόε-</span>, and contracting <span lang="grc">-σέομαι</span> to <span lang="grc">-σοῦμαι</span>. Such verbs (except <span lang="grc">νέω, πί̄πτω</span>) have also the regular future in <span lang="grc">-σομαι</span>.

<span lang="grc">κλαίω</span> (<span lang="grc">κλαυ-</span>, [520](02-1-present-system.md#s520)) _weep_ <span lang="grc">κλαυσοῦμαι, νέω</span> (<span lang="grc">νυ-, νευ-</span>) _swim_ <span lang="grc">νευσοῦμαι</span> (doubtful), <span lang="grc">πλέω</span> (<span lang="grc">πλυ-, πλευ-</span>) _sail_ <span lang="grc">πλευσοῦμαι, πνέω</span> (<span lang="grc">πνυ-, πνευ-</span>) _breathe_ <span lang="grc">πνευσοῦμαι, πί̄πτω</span> (<span lang="grc">πετ-</span>) _fall_ <span lang="grc">πεσοῦμαι, πυνθάνομαι</span> (<span lang="grc">πυθ-, πευθ-</span>) <span lang="grc">πευσοῦμαι</span> (once), <span lang="grc">φεύγω</span> (<span lang="grc">φυγ-, φευγ-</span>) <span lang="grc">φευξοῦμαι, χέζω</span> (<span lang="grc">χεδ-</span>) <span lang="grc">χεσοῦμαι</span>.

**a.** The inflection of the Doric future is as follows:—

|  |  |  |
| --- | --- | --- |
| <span lang="grc">λῡσῶ, -σοῦμαι</span> | <span lang="grc">λῡσοῦμες, -σούμεθα</span> | <span lang="grc">λῡσῶν, -σούμενος</span> |
| <span lang="grc">λῡσεῖς, -σῇ</span> | <span lang="grc">λῡσεῖτε, -σεῖσθε</span> | <span lang="grc">λῡσεῖν, -σεῖσθαι</span> |
| <span lang="grc">λῡσεῖ, -σεῖται</span> | <span lang="grc">λῡσοῦντι, -σοῦνται</span> |  |

**b.** These are called _Doric_ futures because Doric usually makes all futures (active and middle) in <span lang="grc">-σέω -σῶ, -σέομαι -σοῦμαι</span>.

**c.** Attic <span lang="grc">πεσοῦμαι</span> (Hom. <span lang="grc">πεσέομαι</span>) from <span lang="grc">πί̄πτω</span> _fall_ comes from <span lang="grc">πετεομαι</span>. Attic <span lang="grc">ἔπεσον</span> is derived from 2 aor. <span lang="grc">ἔπετον</span> (Dor. and Aeol.) under the influence of <span lang="grc">πεσοῦμαι</span>.

##### <a id="s540D"></a> §540 D

Hom. <span lang="grc">ἐσσεῖται</span> (and <span lang="grc">ἔσσεται, ἔσεται, ἔσται</span>). In Doric there are three forms: (1) <span lang="grc">-σέω</span> (and <span lang="grc">-σῶ</span>), <span lang="grc">-σέομαι</span> (and <span lang="grc">-σοῦμαι</span>); and often with <span lang="grc">ευ</span> from <span lang="grc">εο</span> as <span lang="grc">-εῦντι, -εῦμες</span>; (2) <span lang="grc">-σίω</span> with <span lang="grc">ι</span> from <span lang="grc">ε</span> before <span lang="grc">ο</span> and <span lang="grc">ω</span>; (3) the Attic forms.

##### <a id="s541"></a> §541

**Futures with Present Forms**.—The following verbs have no future suffix, the future thus having the form of a present: <span lang="grc">ἔδομαι</span> (<span lang="grc">ἐδ-</span>) _eat_, <span lang="grc">πί̄ομαι</span> (<span lang="grc">πι-</span>) _drink_, <span lang="grc">χέω</span> (<span lang="grc">χυ-</span>) and <span lang="grc">χέομαι</span>, _pour_. See [529](02-1-present-system.md#s529). 5, 8.

**a.** These are probably old subjunctives which have retained their future meaning. In <span lang="grc">ἔδομαι</span> and <span lang="grc">πί̄ομαι</span> the mood-sign is short ([457 D.](../09-verbs/07-tense-suffixes-thematic-vowel-mood-suffixes.md#s457)). Hom. has <span lang="grc">βέομαι</span> or <span lang="grc">βείομαι</span> _live_, <span lang="grc">δήω</span> _find_, <span lang="grc">κήω</span> (written <span lang="grc">κείω</span>) _lie_, <span lang="grc">ἐξανύω</span> _achieve_, <span lang="grc">ἐρύω</span> _draw_, <span lang="grc">τανύω</span> _strelch_, and <span lang="grc">ἀλεύεται</span> _avoid_. <span lang="grc">νέομαι</span> _go_ is for <span lang="grc">νεσομαι</span>.
