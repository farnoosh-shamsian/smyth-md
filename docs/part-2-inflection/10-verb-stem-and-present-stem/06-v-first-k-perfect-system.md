# VERB-STEM AND PRESENT STEM: V. FIRST (K) PERFECT SYSTEM

<!-- page 176 -->

##### <a id="s555"></a> §555

The stem of the first perfect is formed by adding <span lang="grc">-κα</span> to the reduplicated verb-stem. <span lang="grc">λέ-λυ-κα</span> _I have loosed_, <span lang="grc">ἐ-λε-λύκη</span> _I had loosed_.

**a.** The <span lang="grc">κ-</span>perfect is later in origin than the second perfect and seems to have started from verb-stems in <span lang="grc">-κ</span>, as <span lang="grc">ἔ-οικ-α</span> (= <span lang="grc">ϝέ-ϝοικ-α</span>) from <span lang="grc">εἴκω</span> _resemble_.

**b.** Verbs showing the gradations <span lang="grc">ει, ευ</span>: <span lang="grc">οι, ου</span>: <span lang="grc">ι, υ</span> ([476](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s476)) have <span lang="grc">ει, ευ</span>; as <span lang="grc">πείθω</span> (<span lang="grc">πιθ-, πειθ-</span>) _persuade_ <span lang="grc">πέπεικα</span> ([560](#s560)). But <span lang="grc">δέδοικα</span> _fear_ has <span lang="grc">οι</span> (cp. [564](07-vi-second-perfect-system.md#s564)).

##### <a id="s555bD"></a> §555 b. D

Hom. <span lang="grc">δείδω</span> (used as a present) is for <span lang="grc">δε-δϝο</span> (<span lang="grc">\[ιγλιδε\]</span>)<span lang="grc">-α. δειδ-</span> was written on account of the metre when <span lang="grc">ϝ</span> was lost. Hom. <span lang="grc">δέδια</span> is for <span lang="grc">δε-δ</span>(<span lang="grc">ϝ</span>)<span lang="grc">ι-α</span> with the weak root that is used in <span lang="grc">δέδιμεν</span>. See [703 D](13-inflection-of-omega-verbs.md#s703).

##### <a id="s556"></a> §556

The first perfect is formed from verb-stems ending in a vowel, a liquid, or a dental stop (<span lang="grc">τ, δ, θ</span>).

##### <a id="s557"></a> §557

**Vowel Verbs**.—Vowel verbs lengthen the final vowel (if short) before <span lang="grc">-κα</span>, as <span lang="grc">τῑμά-ω</span> _honour_ <span lang="grc">τε-τί̄μη-κα, ἐά-ω</span> _permit_ <span lang="grc">εἴᾱ-κα, ποιέ-ω</span> _make_ <span lang="grc">πε-ποίη-κα, τίθημι</span> (<span lang="grc">θε-, θη-</span>) _place_ <span lang="grc">τέ-θη-κα, δίδωμι</span> (<span lang="grc">δο-, δω-</span>) _give_ <span lang="grc">δέ-δω-κα</span>.

##### <a id="s557D"></a> §557 D

\1. Hom. has the <span lang="grc">κ-</span>perfect only in verbs with vowel verb-stems. Of these some have the second perfect in <span lang="grc">-α</span>, particularly in participles. Thus <span lang="grc">κεκμηώς</span>, Attic <span lang="grc">κεκμηκώς</span> (<span lang="grc">κάμ-ν-ω</span> _am weary_); <span lang="grc">κεκορηώς</span> (<span lang="grc">κορέ-ννῡμι</span> _satiate_); <span lang="grc">πεφύ̄κᾱσι</span> and <span lang="grc">πεφύᾱσι</span> (<span lang="grc">φύω</span> _produce_).

\2. In some dialects a present was derived from the perfect stem; as Hom. <span lang="grc">ἀνώγω</span>, Theocr. <span lang="grc">δεδοίκω, πεφύ̄κει</span> (in the 2 perf.: Theocr. <span lang="grc">πεπόνθω</span>). Inf. <span lang="grc">τεθνάκην</span> (Aeol.), part. <span lang="grc">κεκλήγοντες</span> (Hom.), <span lang="grc">πεφρί̄κων</span> (Pind.).

\3. From <span lang="grc">μέμηκα</span> (<span lang="grc">μηκάομαι</span> _bleat_) Hom. has the plup. <span lang="grc">ἐμέμηκον</span>.

##### <a id="s558"></a> §558

This applies to verbs that add <span lang="grc">ε</span> ([485](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s485)). For verbs that retain a short final vowel, see [488](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s488). (Except <span lang="grc">σβέννῡμι</span> (<span lang="grc">σβε-</span>) _extinguish_, which has <span lang="grc">ἔσβηκα</span>.)

##### <a id="s559"></a> §559

**Liquid Verbs**.—Many liquid verbs have no perfect or employ the second perfect. Examples of the regular formation are <span lang="grc">φαίνω</span> (<span lang="grc">φαν-</span>) _show_, <span lang="grc">πέφαγκα, ἀγγέλλω</span> (<span lang="grc">ἀγγελ-</span>) _announce_, <span lang="grc">ἤγγελκα</span>.

**a.** Some liquid verbs drop <span lang="grc">ν</span>; as <span lang="grc">κέκρικα, κέκλικα</span> from <span lang="grc">κρί̄νω</span> (<span lang="grc">κριν-</span>) _judge_, <span lang="grc">κλί̄νω</span> (<span lang="grc">κλιν-</span>) _incline_. <span lang="grc">τείνω</span> (<span lang="grc">τεν-</span>) _stretch_ has <span lang="grc">τέτακα</span> from <span lang="grc">τετṇκα</span>.

**b.** Monosyllabic stems change <span lang="grc">ε</span> to <span lang="grc">α</span>; as <span lang="grc">ἔσταλκα, ἔφθαρκα</span> from <span lang="grc">στέλλω</span> (<span lang="grc">στελ-</span>) _send_, <span lang="grc">φθείρω</span> (<span lang="grc">φθερ-</span>) _corrupt_.

N. For <span lang="grc">α</span> we expect <span lang="grc">ο; α</span> is derived from the middle (<span lang="grc">ἔσταλμαι, ἔφθαρμαι</span>).

**c.** All stems in <span lang="grc">μ</span> and many others add <span lang="grc">ε</span> ([485](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s485)); as <span lang="grc">νέμω</span> (<span lang="grc">νεμ-ε-</span>), _distribute_ <span lang="grc">νενέμηκα, μέλω</span> (<span lang="grc">μελ-ε-</span>) _care for_ <span lang="grc">μεμέληκα, τυγχάνω</span> (<span lang="grc">τυχ-ε</span>) _happen_ <span lang="grc">τετύχηκα</span>.

**d.** Many liquid verbs suffer metathesis ([492](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s492)) and thus get the form of vowel verbs; as <span lang="grc">βάλλω</span> (<span lang="grc">βαλ-</span>) _throw_ <span lang="grc">βέβληκα; θνῄσκω</span> (<span lang="grc">θαν-</span>) _die_ <span lang="grc">τέθνηκα; καλέω</span> (<span lang="grc">καλε-, κλη-</span>) _call_ <span lang="grc">κέκληκα; κάμνω</span> (<span lang="grc">καμ-</span>) _am weary_ <span lang="grc">κέκμηκα; τέμνω</span> (<span lang="grc">τεμ-</span>) _cut_ <span lang="grc">τέτμηκα</span>. Also <span lang="grc">πί̄πτω</span> (<span lang="grc">πετ-, πτο-</span>) _fall_ <span lang="grc">πέπτωκα</span>. See [128 a](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s128). <!-- page 177 -->

##### <a id="s560"></a> §560

**Stop Verbs**.—Dental stems drop <span lang="grc">τ, δ, θ</span> before <span lang="grc">-κα</span>; as <span lang="grc">πείθω</span> (<span lang="grc">πιθ-, πειθ-, ποιθ-</span>) _persuade_ <span lang="grc">πέπεικα, κομίζω</span> (<span lang="grc">κομιδ-</span>) _carry_ <span lang="grc">κεκόμικα</span>.
