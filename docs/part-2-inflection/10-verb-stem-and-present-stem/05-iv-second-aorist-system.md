# VERB-STEM AND PRESENT STEM: IV. SECOND AORIST SYSTEM

<!-- page 174 -->

##### <a id="s546"></a> §546

The second aorist is formed without any tense-suffix and only from the simple verb-stem. Only primitive verbs ([372](../09-verbs/02-stems.md#s372)) have second aorists.

##### <a id="s546D"></a> §546 D

Hom. has more second aorists than Attic, which favoured the first aorist. Some derivative verbs have Homeric second aorists classed under them for convenience only, as <span lang="grc">κτυπέω</span> _sound_ <span lang="grc">ἔκτυπον; μῡκάομαι</span> _roar_ <span lang="grc">ἔμυκον; στυγέω</span> _hate_ <span lang="grc">ἔστυγον</span>. These forms are derived from the pure verb-stem ([485 d](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s485), [553](#s553)).

##### <a id="s547"></a> §547

(I) **<span lang="grc">Ω-</span>Verbs**.—<span lang="grc">Ω-</span>verbs make the second aorist by adding <span lang="grc">όε-</span> to the verb-stem, which regularly ends in a consonant. Verbs showing vowel gradations ([476](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s476)) use the weak stem (otherwise there would be confusion with the imperfect).

<span lang="grc">λείπω</span> (<span lang="grc">λιπ-, λειπ-</span>) _leave_ <span lang="grc">ἔλιπον, -ἐλιπόμην; φεύγω</span> (<span lang="grc">φυγ-, φευγ-</span>) _flee_ <span lang="grc">ἔφυγον; πέτομαι</span> _fly_ <span lang="grc">ἐπτόμην</span> ([476 a](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s476)); <span lang="grc">λαμβάνω</span> (<span lang="grc">λαβ-</span>) _take_ <span lang="grc">ἔλαβον</span>.

##### <a id="s547D"></a> §547 D

Hom. often has no thematic vowel in the middle voice of <span lang="grc">ω-</span>verbs (<span lang="grc">ἐδέγμην</span> from <span lang="grc">δέχομαι</span> _receive_). See [634](13-inflection-of-omega-verbs.md#s634). 688.

##### <a id="s548"></a> §548

**a.** Vowel verbs rarely form second aorists, as the irregular <span lang="grc">αἰρέω</span> _seize_ (<span lang="grc">εἶλον</span>, 529. 1), <span lang="grc">ἐσθίω</span> _eat_ (<span lang="grc">ἔφαγον</span>), <span lang="grc">ὁράω</span> (<span lang="grc">εἶδον</span>). <span lang="grc">ἔπιον</span> _drank_ (<span lang="grc">πί̄νω</span>) is the only second aorist in prose from a vowel stem and having thematic inflection.

**b.** Many <span lang="grc">ω-</span>verbs with stems ending in a vowel have second aorists formed like those of <span lang="grc">μι-</span>verbs. These are enumerated in 687.

##### <a id="s549"></a> §549

Verbs of the First Class ([499](02-1-present-system.md#s499)) adding a thematic vowel to the verbstem form the second aorist (1) by reduplication ([494](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s494)), as <span lang="grc">ἄγω</span> _lead_ <span lang="grc">ἤγαγον</span>, and <span lang="grc">εἶπον</span> probably for <span lang="grc">ἐ-ϝε-ϝεπ-ον</span>; (2) by syncope ([493](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s493)), as <span lang="grc">πέτομαι</span> _fly_ <span lang="grc">ἐπτόμην, ἐγείρω</span> (<span lang="grc">ἐγερ-</span>) _rouse_ <span lang="grc">ἠγρόμην, ἕπομαι</span> (<span lang="grc">σεπ-</span>) _jollow_ <span lang="grc">ἐσπόμην</span>, imperf. <span lang="grc">είπόμην</span> from <span lang="grc">ἐ-σεπομην, ἔχω</span> (<span lang="grc">σεχ-</span>) _hare_ <span lang="grc">ἔσχον</span>; (3) by using <span lang="grc">α</span> for <span lang="grc">ε</span> ([476 b](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s476)) in poetic forms ([480](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s480)), as <span lang="grc">τρέπω</span> _turn_ <span lang="grc">ἔτραπον</span>; (4) by metathesis ([492](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s492)), as poet. <span lang="grc">δέρκομαι</span> _see_ <span lang="grc">ἔδρακον</span>.

##### <a id="s549D"></a> §549 D

(1) Hom. has (<span lang="grc">ε᾽</span>)<span lang="grc">κέκλετο</span> (<span lang="grc">κέλο-μαι</span> _command_), <span lang="grc">λέλαθον</span> (<span lang="grc">λήθ-ω</span> _lie hid_), <span lang="grc">ἐπέφραδε</span> (<span lang="grc">φράζω</span> _tell_), <span lang="grc">πεπιθεῖν</span> (<span lang="grc">πείθ-ω</span> _persuade_). <span lang="grc">ἠρύ̄κακον</span> (<span lang="grc">ἐρύ̄κ-ω</span> _check_), <span lang="grc">ἠνί̄παπον</span> and <span lang="grc">ἐνένῑπον</span> (<span lang="grc">ἐνίπτω</span> _chide_, <span lang="grc">ἐνιπ-</span>) have unusual formation. (2) <span lang="grc">ἐ-πλ-όμην</span> (<span lang="grc">πέλο-μαι</span> _am_, _come_, <span lang="grc">πελ-</span>). (3) <span lang="grc">ἔπραθον</span> (<span lang="grc">πέρθ-ω</span> _sack_), <span lang="grc">ἔταμον</span> (<span lang="grc">τέμ-ν-ω</span> _cut_). (4) <span lang="grc">βλῆτο</span> (<span lang="grc">βάλλω</span> _hit_, 128 a).

##### <a id="s550"></a> §550

(II) **<span lang="grc">Μι-</span>Verbs**.—The stem of the second aorist of <span lang="grc">μι-</span>verbs is the verb-stem without any thematic vowel. In the indicative active the strong form of the stem, which ends in a vowel, is regularly employed. The middle uses the weak stem form. <!-- page 175 -->

<span lang="grc">ἵ-στη-μι</span> (<span lang="grc">στα-, στη-</span>) _set_, second aorist <span lang="grc">ἔστην, ἔστης, ἔστη, ἔστητον, ἐστήτην, ἔστημεν, ἔστητε, ἔστησαν</span>; middle <span lang="grc">ἐ-θέ-μην</span> from <span lang="grc">τίθημι</span> (<span lang="grc">θε-, θη-</span>) _place_, <span lang="grc">ἐ-δό-μην</span> from <span lang="grc">δίδωμι</span> (<span lang="grc">δο-, δω-</span>) _give_.

##### <a id="s551"></a> §551

Originally only the dual and plural showed the weak forms, which are retained in the second aorists of <span lang="grc">τίθημι, δίδωμι</span>, and <span lang="grc">ἵ̄ημι</span>: <span lang="grc">ἔθεμεν, ἔδομεν, εἷμεν</span> (<span lang="grc">ἐ-έμεν</span>), and in Hom. <span lang="grc">βάτην</span> (also <span lang="grc">βήτην</span>) from <span lang="grc">ἔβην</span> _went_. Elsewhere the weak grades have been displaced by the strong grades, which forced their way in from the singular. Thus, <span lang="grc">ἔγνον, ἔφῠν</span> in Pindar (= <span lang="grc">ἔγνω-σαν, ἔφῡ-σαν</span>), which come from <span lang="grc">ἐγνων</span>(<span lang="grc">τ</span>), <span lang="grc">ἐφῡν</span>(<span lang="grc">τ</span>) by 40. So Hom. <span lang="grc">ἔτλᾰν, ἔβᾰν</span>. Such 3 pl. forms are rare in the dramatic poets.

a. For the singular of <span lang="grc">τίθημι, δίδωμι, ἵ̄ημι</span>, see [755](15-present-system.md#s755); for the imperatives, 759; for the infinitives, 760.

##### <a id="s551D"></a> §551 D

Hom. has <span lang="grc">ἔκτᾰν</span> _I slew_ (<span lang="grc">κτείνω, κτεν-</span>) with <span lang="grc">ᾰ</span> taken from <span lang="grc">ἔκτᾰμεν</span>, and <span lang="grc">οὖτα</span> _he wounded_ (<span lang="grc">οὐτάω</span>).

##### <a id="s552"></a> §552

No verb in <span lang="grc">-ῡμι</span> has a second aorist in Attic from the stem in <span lang="grc">υ</span>.

##### <a id="s553"></a> §553

The difference between an imperfect and an aorist depends _formally_ on the character of the present. Thus <span lang="grc">ἔ-φη-ν</span> _said_ is called an ‘imperfect’ of <span lang="grc">φη-μί</span>: but <span lang="grc">ἔ-στη-ν</span> _stood_ is a ‘second aorist’ because it shows a different tense-stem than that of <span lang="grc">ἵστημι</span>. Similarly <span lang="grc">ἔ-φερ-ον</span> is ‘imperfect’ to <span lang="grc">φέρω</span>, but <span lang="grc">ἔ-τεκ-ον</span> ‘second aorist’ to <span lang="grc">τίκτω</span> because there is no present <span lang="grc">τεκω. ἔστιχον</span> is imperfect to <span lang="grc">στίχω</span>, but second aorist to <span lang="grc">στείχω</span>. Cp. [546 D](#s546).

## NOTE ON THE SECOND AORIST AND SECOND PERFECT

##### <a id="s554"></a> §554

**a.** The second aorist and the second perfect are usually formed only from primitive verbs ([372](../09-verbs/02-stems.md#s372)). These tenses are formed by adding the personal endings (inclusive of the thematic or tense vowel) to the verb-stem without any consonant tense-suffix. Cp. <span lang="grc">ἔλιπο-ν</span> with <span lang="grc">ἔλῡ-σ-α, ἐτράπ-ην</span> with <span lang="grc">ἐτρέφ-θ-ην</span> (<span lang="grc">τρέπω</span> _turn_), <span lang="grc">γέ-γραφ-α</span> with <span lang="grc">λέλυ-κ-α</span>.

**b.** The second perfect and second aorist passive are historically older than the corresponding first perfect and first aorist.

**c.** <span lang="grc">τρέπω</span> _turn_ is the only verb that has three first aorists and three second aorists ([596](10-ix-second-passive-system-h-passive.md#s596)).

**d.** Very few verbs have both the second aorist active and the second aorist passive. In cases where both occur, one form is rare, as <span lang="grc">ἔτυπον</span> (once in poetry), <span lang="grc">ἐτύπην</span> (<span lang="grc">τύπτω</span> _strike_).

**e.** In the same voice both the first and the second aorist (or perfect) are rare, as <span lang="grc">ἔφθασα, ἔφθην</span> (<span lang="grc">φθάνω</span> _anticipate_). When both occur, the first aorist (or perfect) is often transitive, the second aorist (or perfect) is intransitive ([819](16-irregular-mi-verbs.md#s819)); as <span lang="grc">ἔστησα</span> _I erected_, i.e. _made stand_, <span lang="grc">ἔστην</span> _I stood_. In other cases one aorist is used in prose, the other in poetry: <span lang="grc">ἔπεισα</span>, poet. <span lang="grc">ἔπιθον</span> (<span lang="grc">πείθω</span> _persuade_); or they occur in different dialects, as Attic <span lang="grc">ἐτάφην</span>, Ionic <span lang="grc">ἐθάφθην</span> (<span lang="grc">θάπτω</span> _bury_); or one is much later than the other, as <span lang="grc">ἔλειψα</span>, late for <span lang="grc">ἔλιπον</span>.
