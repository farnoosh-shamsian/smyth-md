# VERB-STEM AND PRESENT STEM: VI. SECOND PERFECT SYSTEM

##### <a id="s561"></a> §561

The stem of the second perfect is formed by adding <span lang="grc">α</span> to the reduplicated verb-stem: <span lang="grc">γέ-γραφ-α</span> _I have written_ (<span lang="grc">γράφ-ω</span>).

##### <a id="s561D"></a> §561 D

Hom. has several forms unknown to Attic: <span lang="grc">δέδουπα</span> (<span lang="grc">δουπ-έ-ω</span> _sound_), <span lang="grc">ἔολπα</span> (<span lang="grc">ἔλπ-ω</span> _hope_), <span lang="grc">ἔοργα</span> (<span lang="grc">ῥέζω</span> _work_), <span lang="grc">προ-βέβουλα</span> (<span lang="grc">βούλομαι</span> _wish_), <span lang="grc">μέμηλα</span> (<span lang="grc">μέλω</span> _care for_).

##### <a id="s562"></a> §562

The second perfect is almost always formed from stems ending in a liquid or a stop consonant, and not from vowel stems.

**a.** <span lang="grc">ἀκήκοα</span> (<span lang="grc">ἀκούω</span> _hear_) is for <span lang="grc">ἀκηκο</span>(<span lang="grc">ϝ</span>)<span lang="grc">-α</span> (<span lang="grc">ἀκοϝ- ῀ ἀκο\[υγλιδε\]-</span>, [43](../../part-1-letters-sounds-syllables-accent/01-the-letters.md#s43)).

##### <a id="s562D"></a> §562 D

But <span lang="grc">δέδια</span> _fear_ from <span lang="grc">δϝι-</span>. See [555 b](06-v-first-k-perfect-system.md#s555). D., 703.

##### <a id="s563"></a> §563

Verb-stems showing variation between short and long vowels ([476](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s476)) have long vowels in the second perfect (<span lang="grc">ᾰ</span> is thus regularly lengthened). Thus, <span lang="grc">τήκω</span> (<span lang="grc">τακ-, τηκ-</span>) _melt_ <span lang="grc">τέτηκα, κρά̄ζω</span> (<span lang="grc">κραγ-</span>) _cry out_ <span lang="grc">κέκρᾱγα, φαίνω</span> (<span lang="grc">φαν-</span>) _show_ <span lang="grc">πέφηνα</span> _have appeared_ (but <span lang="grc">πέφαγκα</span> _have shown_), <span lang="grc">ῥήγνῡμι</span> (<span lang="grc">ῥαγ-, ῥηγ-, ῥωγ-</span>, 477 c) _break_ <span lang="grc">ἔρρωγα</span>.

a. <span lang="grc">εἴωθα</span> _am accustomed_ ( = <span lang="grc">σε-σϝωθ-α</span>) has the strong form <span lang="grc">ω</span> (cp. <span lang="grc">ἦθος</span> _custom_, [123](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s123)); Hom. <span lang="grc">ἔθω</span> (Attic <span lang="grc">ἐθίζω</span> _accustom_).

##### <a id="s564"></a> §564

The second perfect has <span lang="grc">ο, οι</span> when the verb-stem varies between <span lang="grc">α, ε, ο</span> ([478](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s478), [479](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s479)) or <span lang="grc">ι, ει, οι</span> ([477 a](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s477)): <span lang="grc">τρέφ-ω</span> (<span lang="grc">τρεφ-, τροφ-, τραφ-</span>) _nourish_ <span lang="grc">τέτροφα, λείπω</span> (<span lang="grc">λιπ-, λειπ-, λοιπ-</span>) _leave_ <span lang="grc">λέλοιπα, πείθω</span> (<span lang="grc">πιθ-, πειθ-, ποιθ-</span>) _persuade_ <span lang="grc">πέποιθα</span> _trust_.

##### <a id="s565"></a> §565

Similarly verbs with the variation <span lang="grc">υ, ευ, ου</span> ([476](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s476)) should have <span lang="grc">ου</span>; but this occurs only in Epic <span lang="grc">εἰλήλουθα</span> ( = Att. <span lang="grc">ἐλήλυθα</span>); cp. <span lang="grc">ἐλεύ</span>(<span lang="grc">θ</span>)<span lang="grc">-σομαι</span>. Other verbs have <span lang="grc">ευ</span>, as <span lang="grc">φεύγω</span> _flee_ <span lang="grc">πέφευγα</span>.

##### <a id="s566"></a> §566

After Attic reduplication ([446](../09-verbs/06-reduplication.md#s446)) the stem of the second perfect has the weak form; <span lang="grc">ἀλείφω</span> (<span lang="grc">ἀλειφ-, ἀλιφ-</span>) _anoint_ <span lang="grc">ἀλήλιφα</span>.

##### <a id="s567"></a> §567

Apart from the variations in 563-566 the vowel of the verb-stem remains unchanged: as <span lang="grc">γέγραφα</span> (<span lang="grc">γράφω</span> _write_), <span lang="grc">κέκῡφα</span> (<span lang="grc">κύ̄πτω</span> _stoop_, <span lang="grc">κῡφ-</span>).

##### <a id="s568"></a> §568

The meaning of the second perfect may differ from that of the present; as <span lang="grc">ἐγρήγορα</span> _am awake_ from <span lang="grc">ἐγείρω</span> _wake up_, <span lang="grc">σέσηρα</span> _grin_ from <span lang="grc">σαίρω</span> _sweep_. The second perfect often has the force of a present; as <span lang="grc">πέποιθα</span> _trust_ (<span lang="grc">πέπεικα</span> _have persuaded_). See [819](16-irregular-mi-verbs.md#s819).

##### <a id="s569"></a> §569

**Aspirated Second Perfects**.—In many stems a final <span lang="grc">π</span> or <span lang="grc">β</span> changes to <span lang="grc">φ</span>: a final <span lang="grc">κ</span> or <span lang="grc">γ</span> changes to <span lang="grc">χ</span>. (<span lang="grc">φ</span> and <span lang="grc">χ</span> here imitate verb-stems in <span lang="grc">φ</span> and <span lang="grc">χ</span>, as <span lang="grc">τρέφω, ὀρύττω</span>.) <!-- page 178 -->

<span lang="grc">κόπτω</span> (<span lang="grc">κοπ-</span>) _cut_ <span lang="grc">κέκοφα, πέμπ-ω</span> _send_ <span lang="grc">πέπομφα, βλάπτω</span> (<span lang="grc">βλαβ-</span>) _injure_ <span lang="grc">βέβλαφα, τρί̄βω</span> (<span lang="grc">τρῑβ-</span>) _rub_ <span lang="grc">τέτρῐφα, φυλάττω</span> (<span lang="grc">φυλακ-</span>) _guard_ <span lang="grc">-πεφύλαχα; τρέφ-ω</span> (<span lang="grc">τρεφ-</span>) _nourish_ <span lang="grc">τέτροφα; ὀρύττω</span> (<span lang="grc">ὀρυχ-</span>) _dig_ <span lang="grc">ὀρώρυχα</span>.

##### <a id="s569D"></a> §569 D

Hom. never aspirates <span lang="grc">π, β, κ, γ</span>. Thus <span lang="grc">κεκοπώς</span> = Att. <span lang="grc">κεκοφώς</span> (<span lang="grc">κόπ-τ-ω</span> _cut_). The aspirated perfect occurs once in Hdt. (<span lang="grc">ἐπεπόμφει</span> 1. [85](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s85)); but is unknown in Attic until the fifth century B.C. Soph. _Tr._ 1009 (<span lang="grc">ἀνατέτροφας</span>) is the only example in tragedy.

##### <a id="s570"></a> §570

Most such stems have a short vowel immediately before the final consonant; a long vowel precedes <span lang="grc">ε.γ.</span> in <span lang="grc">δείκ-νῡ-μι δέδειχα, κηρύ̄ττω</span> (<span lang="grc">κηρῡκ-</span>) <span lang="grc">-κεκηρῡχα, πτήσσω</span> (<span lang="grc">πτηκ-</span>) <span lang="grc">ἔπτηχα. τέτριφα</span> and <span lang="grc">τέθλιφα</span> show <span lang="grc">ῐ</span> in contrast to <span lang="grc">ῑ</span> in the present (<span lang="grc">τρί̄βω, θλί̄βω</span>). <span lang="grc">στέργω, λάμπω</span> do not aspirate (<span lang="grc">ἔστοργα</span>, poet. <span lang="grc">λέλαμπα</span>).

##### <a id="s571"></a> §571

The following verbs have aspirated second perfects: <span lang="grc">ἄγω, ἀλλάττω, ἀνοίγω, βλάπτω, δείκνῡμι, διώκω</span> (rare), <span lang="grc">θλί̄βω, κηρύ̄ττω, κλέπτω, κόπτω, λαγχάνω, λαμβάνω, λάπτω, λέγω</span> _collect_, <span lang="grc">μάττω, μείγνῡμι, πέμπω, πλέκω, πρά̄ττω, πτήσσω, τάττω, τρέπω, τρί̄βω, φέρω</span> (<span lang="grc">ἐνήνοχα</span>), <span lang="grc">φυλάττω. ἀνοίγω</span> or <span lang="grc">ἀνοίγνῡμι</span> has two perfects: <span lang="grc">ἀνέῳχα</span> and <span lang="grc">ἀνέῳγα. πρά̄ττω</span> _do_ has <span lang="grc">πέπρᾱγα</span> _have done_ and _fare_ (_well_ or _ill_), and (generally later) <span lang="grc">πέπρᾱχα</span> _have done_.

##### <a id="s572"></a> §572

**Second Perfects of the <span lang="grc">μι-</span>form**.—Some verbs add the endings directly to the reduplicated verb-stem. Such second perfects lack the singular of the indicative.

<span lang="grc">ἵστημι</span> (<span lang="grc">στα-, στη-</span>) _set_, 2 perf. stem <span lang="grc">ἑστα-</span>: <span lang="grc">ἕστα-μεν, ἕστα-τε, ἑστᾶσι</span>, inf. <span lang="grc">ἑστά-ναι</span>; 2 plup. <span lang="grc">ἕστα-σαν</span> ([417](../09-verbs/00-introduction.md#s417)). The singular is supplied by the forms in <span lang="grc">-κα</span>; as <span lang="grc">ἕστηκα</span>. These second perfects are enumerated in 704.

##### <a id="s573"></a> §573

**Stem Gradation**.—Originally the second perfect was inflected throughout without any thematic vowel (cp. the perfect middle), but with stem-gradation: strong forms in the singular, weak forms elsewhere. <span lang="grc">-α</span> (1 singular) was introduced in part from the aorist and spread to the other persons. Corresponding to the inflection of <span lang="grc">οἶδα</span> ([794](16-irregular-mi-verbs.md#s794)) we expect <span lang="grc">πέποιθα, πέποισθα, πέποιθε, πέπιστον, πέπιθμεν, πέπιστε, πεπίθατι</span> (from <span lang="grc">πεπιθṇτι</span>). Traces of this mode of inflection appear in Hom. <span lang="grc">γεγάτην</span> (from <span lang="grc">γεγṇτην</span>, 35 b) <span lang="grc">γέγαμεν</span> from <span lang="grc">γέγονα; ἔϊκτον, ἐΐκτην, ἐϊκώς</span> from <span lang="grc">ἔοικα; ἐπέπιθμεν; μέμαμεν</span> from <span lang="grc">μέμονα; πέπασθε</span> (for <span lang="grc">πεπαθτε ῀ πεπṇθτε</span>) from <span lang="grc">πέπονθα</span> (other examples 704, [705](13-inflection-of-omega-verbs.md#s705)). So the masc. and neut. participles have the strong forms, the feminine has the weak forms (<span lang="grc">μεμηκώς, μεμακυῖα</span> as <span lang="grc">εἰδώς, ἰδυῖα</span>).
