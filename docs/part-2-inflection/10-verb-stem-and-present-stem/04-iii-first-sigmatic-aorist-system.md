# VERB-STEM AND PRESENT STEM: III. FIRST (SIGMATIC) AORIST SYSTEM

## (FIRST AORIST ACTIVE AND MIDDLE)

##### <a id="s542"></a> §542

The first aorist stem is formed by adding the tense suffix <span lang="grc">-σα</span> to the verb-stem: <span lang="grc">ἔ-λῡ-σα</span> _I loosed_, <span lang="grc">λύ̄σω, λύ̄σαιμι; ἔ-δειξα</span> _I showed_, from <span lang="grc">δείκ-νῡ-μι</span>. See [666](13-inflection-of-omega-verbs.md#s666). <!-- page 173 -->

**a.** In verbs showing strong and weak grades ([476](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s476)), the tense-suffix is added to the strong stem: <span lang="grc">πείθω ἔπεισα, τήκω ἔτηξα, πνέω ἔπνευσα, ἵστημι</span> (<span lang="grc">στα-, στη-</span>) <span lang="grc">ἔστησα, ἐστησάμην</span>.

N.—<span lang="grc">τίθημι</span> (<span lang="grc">θε-, θη-</span>) _place_, <span lang="grc">δίδωμι</span> (<span lang="grc">δο-, δω-</span>) _give_, <span lang="grc">ἵ̄ημι</span> (<span lang="grc">ἑ-, ἡ-</span>) _send_ have aorists in <span lang="grc">-κα</span> (<span lang="grc">ἔθηκα, ἔδωκα, ἧκα</span> in the singular: with <span lang="grc">κ</span> rarely in the plural). See [755](15-present-system.md#s755).

##### <a id="s542D"></a> §542 D

**Mixed Aorists**.—Hom. has some forms of the first aorist with the thematic vowel (<span lang="grc">όε</span>) of the second aorist; as <span lang="grc">ἄξετε, ἄξεσθε</span> (<span lang="grc">ἄγω</span> _lead_), <span lang="grc">ἐβήσετο</span>, imper. <span lang="grc">βήσεο</span> (<span lang="grc">βαίνω</span> _go_), <span lang="grc">ἐδύ̄σετο</span> (<span lang="grc">δύω</span> _set_), <span lang="grc">ἷξον</span> (<span lang="grc">ἵ̄κω</span> _come_), <span lang="grc">οἶσε, οἴσετε, οἰσέμεν, οἰσέμεναι</span> (<span lang="grc">φέρω</span> _bring_), imper. <span lang="grc">ὄρσεο</span> _rise_ (<span lang="grc">ὄρνῡμι</span> _rouse_).

##### <a id="s543"></a> §543

**Vowel Verbs**.—Verb-stems ending in a vowel lengthen a short final vowel before the tense-suffix (<span lang="grc">α</span> to <span lang="grc">η</span> except after <span lang="grc">ε, ι, ρ</span>). Thus, <span lang="grc">τῑμάω ἐτί̄μησα, ἐάω εἴᾱσα</span> ([431](../09-verbs/05-augment.md#s431)), <span lang="grc">φιλέω ἐφίλησα</span>.

**a.** <span lang="grc">χέω</span> (<span lang="grc">χυ-, χευ-, χεϝ-</span>) _pour_ has the aorists <span lang="grc">ἔχεα, ἐχεάμην</span> (Epic <span lang="grc">ἔχευα, ἐχευάμην</span>) from <span lang="grc">ἐχευσα, ἐχευσαμην</span>.

##### <a id="s543aD"></a> §543 a. D

Homeric <span lang="grc">ἠλευάμην</span> and <span lang="grc">ἠλεάμην</span> _avoided_, <span lang="grc">ἔκηα</span> _burned_ (Att. <span lang="grc">ἔκαυσα</span>), <span lang="grc">ἔσσευα</span> _drove_, also have lost <span lang="grc">ς</span>.

**b.** For verbs retaining a short final vowel see [488](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s488).

##### <a id="s543bD"></a> §543 b. D

Hom. often has original <span lang="grc">σς</span>, as <span lang="grc">γελάω ἐγέλασσα, τελέω ἐτέλεσσα</span>; in others by analogy, as <span lang="grc">ὄλλῡμι ὄλεσσα, ὄμνῡμι ὄμοσσα, καλέω κάλεσσα</span>.

##### <a id="s544"></a> §544

**Liquid Verbs**.—Verb-stems ending in <span lang="grc">λ, μ, ν, ρ</span> lose <span lang="grc">ς</span> and lengthen their vowel in compensation ([37](../../part-1-letters-sounds-syllables-accent/01-the-letters.md#s37)): <span lang="grc">α</span> to <span lang="grc">η</span> (after <span lang="grc">ι</span> or <span lang="grc">ρ</span> to <span lang="grc">ᾱ</span>), <span lang="grc">ε</span> to <span lang="grc">ει, ῐ</span> to <span lang="grc">ῑ, ῠ</span> to <span lang="grc">ῡ</span>.

<span lang="grc">φαίνω</span> (<span lang="grc">φαν-</span>) _show_, <span lang="grc">ἔφηνα</span> for <span lang="grc">ἐφανσα; περαίνω</span> (<span lang="grc">περαν-</span>) _finish_, <span lang="grc">ἐπέρᾱνα</span> for <span lang="grc">ἐπερανσα; στέλλω</span> (<span lang="grc">στελ-</span>) _send_, <span lang="grc">ἔστειλα</span> for <span lang="grc">ἐστελσα; κρί̄νω</span> (<span lang="grc">κριν-</span>) _judge_, <span lang="grc">ἔκρῑνα</span> for <span lang="grc">ἐκρινσα; ἅλλομαι</span> (<span lang="grc">ἁλ-</span>) _leap_, <span lang="grc">ἡλάμην</span> for <span lang="grc">ἡλσαμην</span>.

**a.** Some verbs in <span lang="grc">-αινω</span> (<span lang="grc">-αν-</span>) have <span lang="grc">-ᾱνα</span> instead of <span lang="grc">-ηνα</span>; as <span lang="grc">γλυκαίνω</span> _sweeten_ <span lang="grc">ἐγλύκᾱνα</span>. So <span lang="grc">ἰσχναίνω</span> _make thin_, <span lang="grc">κερδαίνω</span> _gain_, <span lang="grc">κοιλαίνω</span> _hollow out_, <span lang="grc">λιπαίνω</span> _fatten_, <span lang="grc">ὀργαίνω</span> _be angry_, <span lang="grc">πεπαίνω</span> _make ripe_. Cp. [30 a](../../part-1-letters-sounds-syllables-accent/01-the-letters.md#s30).

**b.** The poetic verbs retaining <span lang="grc">ς</span> in the future ([536](03-ii-future-system.md#s536)) retain it also in the aorist.

**c.** <span lang="grc">αἴρω</span> (<span lang="grc">ἀρ-</span>) _raise_ is treated as if its verb-stem were <span lang="grc">ἀ̄ρ-</span> (contracted from <span lang="grc">ἀερ-</span> in <span lang="grc">ἀείρω</span>): aor. <span lang="grc">ἦρα, ἄ̄ρω, ἄ̄ραιμι, ἆρον, ἆραι, ἄ̄ρας</span>, and <span lang="grc">ἠράμην, ἄ̄ρωμαι, ἀ̄ραίμην, ἄ̄ρασθαι, ἀ̄ράμενος</span>.

**d.** <span lang="grc">ἤνεγκα</span> is used as the first aorist of <span lang="grc">φέρω</span> _bear_. <span lang="grc">εἶπα</span> is rare for <span lang="grc">εἶπον</span> ([549](05-iv-second-aorist-system.md#s549)).

##### <a id="s544D"></a> §544 D

Hom. has Ionic <span lang="grc">-ηνα</span> for <span lang="grc">-ᾱνα</span> after <span lang="grc">ι</span> or <span lang="grc">ρ</span>. Aeolic assimilates <span lang="grc">ς</span> to a liquid; as <span lang="grc">ἔκριννα, ἀπέστελλα, ἐνέμματο, συνέρραισα</span> (= <span lang="grc">συνείρᾱσα</span>). Cp. Hom. <span lang="grc">ὤφελλε</span> (<span lang="grc">ὀφέλλω</span> _increase_).

##### <a id="s545"></a> §545

**Stop Verbs**.—Labial (<span lang="grc">π, β, φ</span>) and palatal (<span lang="grc">κ, γ, χ</span>) stops at the end of the verb-stem unite with <span lang="grc">ς</span> to form <span lang="grc">ψ</span> or <span lang="grc">ξ</span>. Dentals (<span lang="grc">τ, δ, θ</span>) are lost before <span lang="grc">ς</span> (cp. [98](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s98)).

<span lang="grc">πέμπ-ω</span> _send_ <span lang="grc">ἔπεμψα, ἐπεμψάμην; βλάπτω</span> (<span lang="grc">βλαβ-</span>) _injure_ <span lang="grc">ἔβλαψα; γράφ-ω</span> _write_ <span lang="grc">ἔγραψα, ἐγραψάμην; πλέκ-ω</span> _weave_ <span lang="grc">ἔπλεξα, ἐπλεξάμην; λέγ-ω</span> _say_ <span lang="grc">ἔλεξα; ταράττω</span> (<span lang="grc">ταραχ-</span>) _disturb_ <span lang="grc">ἐτάραξα, ἐταραξάμην</span>; poetic <span lang="grc">ἐρέσσω</span> (<span lang="grc">ἐρετ-</span>) _row_ <span lang="grc">ἤρεσα; φράζω</span> (<span lang="grc">φραδ-</span>) _tell_ <span lang="grc">ἔφρασα, ἐφρασάμην; πείθ-ω</span> (<span lang="grc">πιθ-, πειθ-, ποιθ-</span>) _persuade_ <span lang="grc">ἔπεισα</span>.

**a.** On forms in <span lang="grc">ς</span> from stems in <span lang="grc">γ</span> see [516](02-1-present-system.md#s516).

##### <a id="s545D"></a> §545 D

Hom. often has <span lang="grc">σς</span> from dental stems, as <span lang="grc">ἐκόμισσα ἐκομισσάμην</span> (<span lang="grc">κομίζω</span>). Doric has <span lang="grc">-ξα</span> from most verbs in <span lang="grc">-ζω</span>; Hom. also has <span lang="grc">ξ</span> (<span lang="grc">ἥρπαξε</span>). See [516 D](02-1-present-system.md#s516).
