# VERB-STEM AND PRESENT STEM: IX. SECOND PASSIVE SYSTEM (H PASSIVE)

## SECOND AORIST PASSIVE

##### <a id="s590"></a> §590

The stem of the second aorist passive is formed by adding <span lang="grc">-η-</span> (or <span lang="grc">-ε-</span>) directly to the verb-stem. Thus, <span lang="grc">ἐβλάβην</span> _I was injured_ from <span lang="grc">βλάπτω</span> (<span lang="grc">βλαβ-</span>).

**a.** <span lang="grc">-η-</span> appears in the indicative, imperative (except the third plural), and infinitive; <span lang="grc">-ε-</span> appears in the other moods. <span lang="grc">-η-</span> is found before a single consonant, <span lang="grc">-ε-</span> before two consonants or a vowel except in the nom. neut. of the participle.

##### <a id="s590aD"></a> §590 a. D

For <span lang="grc">-ησαν</span> we generally find <span lang="grc">-εν</span> (from <span lang="grc">-ηντ</span>, [40](../../part-1-letters-sounds-syllables-accent/01-the-letters.md#s40)) in Hom.; also in Doric.

##### <a id="s591"></a> §591

The second aorist passive agrees in form with the second aorist active of <span lang="grc">μι-</span>verbs; cp. intransitive <span lang="grc">ἐχάρην</span> _rejoiced_ with <span lang="grc">ἔστην</span> _stood_. The passive use was developed from the intransitive use.

##### <a id="s592"></a> §592

Primitive verbs showing in their stems the grades <span lang="grc">ε</span>: <span lang="grc">ο</span>: <span lang="grc">α</span> have <span lang="grc">α</span>. Thus an <span lang="grc">ε</span> of a monosyllabic verb-stem becomes <span lang="grc">α</span>, as in <span lang="grc">πλέκ-ω</span> _weave_ <span lang="grc">ἐπλάκην, κλέπ-τ-ω</span> _steal_ <span lang="grc">ἐκλάπην, φθείρω</span> (<span lang="grc">φθερ-</span>) _corrupt_ <span lang="grc">ἐφθάρην, στέλλω</span> (<span lang="grc">στελ-</span>) _send_ <span lang="grc">ἐστάλην</span>. But <span lang="grc">λέγω</span> _collect_ has <span lang="grc">ἐλέγην</span>.

##### <a id="s593"></a> §593

Primitive verbs showing in their stems a variation between a short and long vowel have, in the second aorist passive, the short vowel. Thus <span lang="grc">τήκω</span> (<span lang="grc">τακ-, τηκ-</span>) _melt_ <span lang="grc">ἐτάκην, ῥήγνῡμι</span> (<span lang="grc">ῥαγ-, ῥηγ-, ῥωγ-</span>) _break_ <span lang="grc">ἐρράγην</span>.

**a.** But <span lang="grc">πλήττω</span> (<span lang="grc">πλαγ-, πληγ-</span>) _strike_ has <span lang="grc">ἐπλάγην</span> only in composition, as <span lang="grc">ἐξεπλάγην</span>; otherwise <span lang="grc">ἐπλήγην</span>.

##### <a id="s594"></a> §594

The second aorist passive is the only aorist passive formed in Attic prose by <span lang="grc">ἄγνῡμι</span> (<span lang="grc">ἐά̄γην</span>), <span lang="grc">γράφω</span> (<span lang="grc">ἐγράφην</span>), <span lang="grc">δέρω</span> (<span lang="grc">ἐδάρην</span>), <span lang="grc">θάπτω</span> (<span lang="grc">ἐτάφην</span>), <span lang="grc">κόπτω</span> (<span lang="grc">ἐκόπην</span>), <span lang="grc">μαίνω</span> (<span lang="grc">ἐμάνην</span>), <span lang="grc">πνί̄γω</span> (<span lang="grc">ἐπνί̆γην</span>), <span lang="grc">ῥάπτω</span> (<span lang="grc">ἐρράφην</span>), <span lang="grc">ῥέω</span> (<span lang="grc">ἐρρύην</span> active), <span lang="grc">ῥήγνῡμι</span> (<span lang="grc">ἐρράγην</span>), <span lang="grc">σήπω</span> (<span lang="grc">ἐσάπην</span>), <span lang="grc">σκάπτω</span> (<span lang="grc">ἐσκάφην</span>), <span lang="grc">σπείρω</span> (<span lang="grc">ἐσπάρην</span>), <span lang="grc">στέλλω</span> (<span lang="grc">ἐστάλην</span>), <span lang="grc">σφάζω</span> or <span lang="grc">σφάττω</span> (<span lang="grc">ἐσφάγην</span>), <span lang="grc">σφάλλω</span> (<span lang="grc">ἐσφάλην</span>), <span lang="grc">τύ̄φω</span> (<span lang="grc">ἐτύφην</span>), <span lang="grc">φθείρω</span> (<span lang="grc">ἐφθάρην</span> pass. and intr.), <span lang="grc">φύ̄ω</span> (in subj. <span lang="grc">φυῶ</span>), <span lang="grc">χαίρω</span> (<span lang="grc">ἐχάρην</span> active). <!-- page 182 -->

##### <a id="s595"></a> §595

Both the first aorist passive and the second aorist passive are formed by <span lang="grc">ἀλείφω</span> (<span lang="grc">ἠλείφθην</span>), <span lang="grc">ἀλλάττω</span> (<span lang="grc">-ηλλάχθην, ἠλλάγην</span>), <span lang="grc">βάπτω</span> (<span lang="grc">ἐβάφην</span>), <span lang="grc">βλάπτω</span> (<span lang="grc">ἐβλάφθην, ἐβλάβην</span>), <span lang="grc">βρέχω</span> (<span lang="grc">ἐβρέχθην</span>), <span lang="grc">ζεύγνῡμι</span> (<span lang="grc">ἐζύγην</span>), <span lang="grc">θλί̄βω</span> (<span lang="grc">ἐθλί̄φθην</span>), <span lang="grc">κλέπτω</span> (<span lang="grc">ἐκλάπην</span>), <span lang="grc">κλί̄νω</span> (<span lang="grc">-εκλίνην</span>), <span lang="grc">κρύπτω</span> (<span lang="grc">ἐκρύφθην</span>), <span lang="grc">λέγω</span> _collect_ (<span lang="grc">διελέχθην</span>, but <span lang="grc">συνελέγην</span>), <span lang="grc">μάττω</span> (<span lang="grc">ἐμάγην</span>), <span lang="grc">μείγνῡμι</span> (<span lang="grc">ἐμίγην</span>), <span lang="grc">πήγνῡμι</span> (<span lang="grc">ἐπάγην</span>), <span lang="grc">πλέκω</span> (<span lang="grc">ἐπλάκην</span>), <span lang="grc">πλήττω</span> (<span lang="grc">ἐπλήγην</span> and <span lang="grc">-επλάγην</span>), <span lang="grc">ῥί̄πτω</span> (<span lang="grc">ἐρρί̄φθην, ἐρρίφην</span>), <span lang="grc">στερίσκω</span> (<span lang="grc">ἐστερήθην</span>), <span lang="grc">στρέφω</span> (<span lang="grc">ἐστράφην</span>), <span lang="grc">τάττω</span> (<span lang="grc">ἐτάχθην</span>), <span lang="grc">τήκω</span> (<span lang="grc">ἐτάκην</span>), <span lang="grc">τρέπω</span> (<span lang="grc">ἐτράπην</span> pass. and intr.), <span lang="grc">τρέφω</span> (<span lang="grc">ἐτράφην</span> pass. and intr.), <span lang="grc">τρί̄βω</span> (<span lang="grc">ἐτρίβην, ἐτρί̄φθην</span>), <span lang="grc">φαίνω</span> (<span lang="grc">ἐφάνθην</span> _was shown_, <span lang="grc">ἐφάνην</span> _appeared_), <span lang="grc">φράγνῡμι</span> (<span lang="grc">ἐφράχθην</span>), <span lang="grc">ψύ̄χω</span> (<span lang="grc">ἐψύχην</span>). Most of these verbs use either the one in prose and the other in poetry, the dialects, or late Greek. Only the forms in common prose use are inserted in brackets.

##### <a id="s596"></a> §596

Only those verbs which have no second aorist active show the second aorist passive; except <span lang="grc">τρέπω</span>, which has all the aorists: active <span lang="grc">ἔτρεψα</span> and <span lang="grc">ἔτραπον</span> _turned;_ middle <span lang="grc">ἐτρεψάμην</span> _put to flight_, <span lang="grc">ἐτραπόμην</span> _turned myself, took to flight;_ passive <span lang="grc">ἐτρέφθην</span> _was turned_, <span lang="grc">ἐτράπην</span> _was turned_ and _turned myself_.

## SECOND FUTURE PASSIVE

##### <a id="s597"></a> §597

The stem of the second future passive is formed by adding <span lang="grc">-ς όε-</span> to the stem of the second aorist passive. It ends in <span lang="grc">-ησομαι</span>. Thus, <span lang="grc">βληβήσομαι</span> _I shall be injured_ from <span lang="grc">βλάπτω</span> (<span lang="grc">βλαβ-</span>) <span lang="grc">ἐ-βλάβη-ν</span>.

<span lang="grc">κόπ-τ-ω, ἐκόπην κοπήσομαι; γράφω, ἐγράφην γραφήσομαι; φαίνω, ἐφάνην</span> _appeared_, <span lang="grc">φανήσομαι; φθείρω, ἐφθάρην φθαρήσομαι; πήγνῡμι</span> _fix_, <span lang="grc">ἐπάγην παγήσομαι</span>.

##### <a id="s597D"></a> §597 D

Hom. has only <span lang="grc">δαήσεαι</span> (<span lang="grc">ἐδάην</span> _learned_), <span lang="grc">μιγήσεσθαι</span> (<span lang="grc">μείγνῡμι</span> _mix_).

##### <a id="s598"></a> §598

Most of the verbs in 594, 595 form second futures passive except <span lang="grc">ἄγνῡμι, ἀλείφω, βάπτω, βρέχω, ζεύγνῡμι, θλί̄βω, κλέπτω, μαίνω, μάττω, ῥάπτω</span>. But many of the second futures appear only in poetry or in late Greek, and some are found only in composition.
