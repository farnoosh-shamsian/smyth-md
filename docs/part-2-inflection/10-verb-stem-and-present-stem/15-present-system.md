# VERB-STEM AND PRESENT STEM: PRESENT SYSTEM

##### <a id="s722"></a> §722

Verbs in <span lang="grc">-μι</span> belong to the first or simple class ([504](02-1-present-system.md#s504)) or to the fourth class ([523](02-1-present-system.md#s523)).

## FIRST OR SIMPLE CLASS

##### <a id="s723"></a> §723

The present is made by adding the personal endings directly to the verb-stem, which is a root. This verb-stem may be used in its pure form or it may be reduplicated.

**a.** Some verbs of this class with no active have a verb-stem of more than one syllable (usually two syllables).

##### <a id="s724"></a> §724

**Unreduplicated Presents**: <span lang="grc">εἰμί</span> (<span lang="grc">ἐσ-</span>) _am_, <span lang="grc">εἶμι</span> (<span lang="grc">ἰ-, εἰ-</span>) _go_, <span lang="grc">ἧμαι</span> (<span lang="grc">ἡσ-</span>) _sit_, <span lang="grc">ἠμί</span> _say_ (<span lang="grc">ἦ</span> _said_, 3 sing.), <span lang="grc">κεῖμαι</span> (<span lang="grc">κει-</span>) _lie_, <span lang="grc">φημί</span> (<span lang="grc">φα-, φη-</span>) _say_, <span lang="grc">χρή</span> _it is necessary_ ([793](16-irregular-mi-verbs.md#s793)); and poet. <span lang="grc">ἄημι</span> (<span lang="grc">ἀη-</span>) _blow_.

##### <a id="s725"></a> §725

**Deponents**.—<span lang="grc">ἄγα-μαι</span> (and <span lang="grc">ἀγάομαι</span>) _admire_, <span lang="grc">δέα-μαι</span> _appear_, <span lang="grc">δίε-μαι</span> _flee_, _make flee_ (cp. <span lang="grc">δίω</span>), <span lang="grc">δύνα-μαι</span> _am able_ ([737 a](#s737)), <span lang="grc">ἐπί-στα-μαι</span> _understand_, <span lang="grc">ἔρα-μαι</span> _love_ (poet. for <span lang="grc">ἐράω</span>), <span lang="grc">ἵπταμαι</span> _fly_ (late, see [726](#s726) a), <span lang="grc">κρέμα-μαι</span> _hang_ (intrans.), <span lang="grc">ὄνο-μαι</span> _insult_, <span lang="grc">πέτα-μαι</span> (poet. by-form of <span lang="grc">πέτομαι</span>) _fly_, <span lang="grc">ἐπριάμην</span> _bought_ a second aorist, <span lang="grc">στεῦμαι</span> _affirm_.

**a.** Other such forms are Hom. <span lang="grc">ἵ̄εμαι</span> (<span lang="grc">ϝί̄εμαι</span>) _strive_, <span lang="grc">εἴρυμαι</span> and <span lang="grc">ἔρυμαι</span> _rescue_, Ion. <span lang="grc">λάζυμαι</span> _take_. <span lang="grc">ἐπίστηται</span> II 243 owes its <span lang="grc">η</span> to such non-present forms as <span lang="grc">ἐπιστήσομαι</span>.

##### <a id="s726"></a> §726

**Reduplicated Presents**.—<span lang="grc">δίδημι</span> _bind_ (rare for <span lang="grc">δέω</span>), <span lang="grc">δίδωμι</span> (<span lang="grc">δο-, δω-</span>) _give_, <span lang="grc">ἵ̄ημι</span> (<span lang="grc">ἑ-, ἡ-</span>) _send_, <span lang="grc">ἵστημι</span> (<span lang="grc">στα-, στη-</span>) _set_, <span lang="grc">κίχρημι</span> (<span lang="grc">χρα-, χρη-</span>) _lend_, <span lang="grc">ὀνίνημι</span> (<span lang="grc">ὀνα-, ὀνη-</span>) _benefit_, <span lang="grc">πίμπλημι</span> (<span lang="grc">πλα-, πλη-</span>) _fill_, <span lang="grc">πίμπρημι</span> (<span lang="grc">πρα-, πρη-</span>) _burn_, <span lang="grc">τίθημι</span> (<span lang="grc">θε-, θη-</span>) _place_.

**a.** Also poetic <span lang="grc">βίβημι</span> (<span lang="grc">βα-, βη-</span>) _go_, in Hom. <span lang="grc">βιβά̄ς</span> _striding_, <span lang="grc">δί-ζημαι</span> (also Ion.) _seek_, for <span lang="grc">δι-δ\[ιγλιδε\]η-μαι</span> by 116 (cp. <span lang="grc">ζητέω</span> _seek_), <span lang="grc">ἵλημι</span> (<span lang="grc">ἱ̄λα-, ἱ̄λη-</span> for <span lang="grc">σισλα-, σισλη-</span>) _am propitious_. <span lang="grc">ἵπταμαι</span> (late) for <span lang="grc">πέτομαι</span> _fly_ is an analogue of <span lang="grc">ἵσταμαι</span> and is not properly reduplicated. <span lang="grc">τίτρημι</span> _bore_ is late.

##### <a id="s727"></a> §727

Verbs in <span lang="grc">-μι</span> reduplicate with <span lang="grc">ι</span> in the present. See [414](../09-verbs/00-introduction.md#s414), [447](../09-verbs/06-reduplication.md#s447). <span lang="grc">πί-μ-πλημι</span> and <span lang="grc">πί-μ-πρημι</span> may lose the inserted nasal in compounds of <span lang="grc">ἐν</span>, but only when <span lang="grc">ἐν-</span> takes the form <span lang="grc">ἐμ-</span>; as <span lang="grc">ἐμπίπλημι</span>, but <span lang="grc">ἐνεπίμπλασαν</span>. Doric has <span lang="grc">κίγχημι</span>. In <span lang="grc">ὀ-νί-νη-μι</span> the reduplication takes place after a vowel (verb-stem <span lang="grc">ὀνα-, ὀνη-</span>). <!-- page 204 -->

**a.** Reduplication is in place only in present and imperfect; but Hom. has <span lang="grc">διδώσομεν</span>.

## FOURTH CLASS

##### <a id="s728"></a> §728

Most <span lang="grc">μι-</span>verbs of the fourth class add <span lang="grc">-νυ-</span> (after a vowel, <span lang="grc">-ννυ-</span>) to the verb-stem.

##### <a id="s729"></a> §729

Verb-stems in <span lang="grc">-α</span>: <span lang="grc">κερά-ννῡμι</span> _mix_, <span lang="grc">κρεμά-ννῡμι</span> _hang_ (intrans.), <span lang="grc">πετάννῡμι</span> _spread_, <span lang="grc">σκεδά-ννῡμι</span> _scatter_.

##### <a id="s730"></a> §730

Verb-stems in <span lang="grc">ε</span> (for <span lang="grc">ες</span>): <span lang="grc">ἕ-ννῡμι</span> (in prose <span lang="grc">ἀμφιέ-ννῡμι</span>) _clothe_, <span lang="grc">κορέννῡμι</span> _satiate_, <span lang="grc">σβέ-ννῡμι</span> _extinguish_.

##### <a id="s731"></a> §731

Verb-stems in <span lang="grc">ω</span>: <span lang="grc">ζώ-ννῡμι</span> _gird_, <span lang="grc">ῥώ-ννῡμι</span> _strengthen_, <span lang="grc">στρώ-ννῡμι</span> _spread_.

##### <a id="s732"></a> §732

All the forms in <span lang="grc">-ννῡμι</span> started from verb-stems ending in <span lang="grc">ς</span>: <span lang="grc">ἕννῡμι</span> from <span lang="grc">ἑσ-νῡ-μι, σβέννῡμι</span> from <span lang="grc">σβεσ-νῡ-μι, ζώννῡμι</span> from <span lang="grc">ζωσ-νῡ-μι</span>. All the other verbs are analogues of these.

##### <a id="s733"></a> §733

Verb-stems in a consonant: <span lang="grc">ἄγ-νῡμι</span> _break_, <span lang="grc">ἄρ-νυμαι</span> _earn_, <span lang="grc">δείκ-νῡμι</span> _show_, <span lang="grc">εἴργ-νῡμι</span> ( = <span lang="grc">εἴργω</span>) _shut in_, <span lang="grc">ζεύγ-νῡμι</span> _yoke_ (<span lang="grc">ἀπο</span>)<span lang="grc">κτει-νῡμι</span> often written <span lang="grc">-κτίννῡμι</span> ( = <span lang="grc">κτείνω</span>) _kill_, <span lang="grc">μείγ-νῡμι</span> (miswritten <span lang="grc">μί̄γ-νῡμι</span>) _mix_, <span lang="grc">-οἰγ-νῡμι</span> ( = <span lang="grc">-οἴγω</span>) _open_, <span lang="grc">ὄλλῡμι</span> (<span lang="grc">ὀλ-ε</span>) _destroy_, <span lang="grc">ὄμ-νῡμι</span> (<span lang="grc">ὀμ-ε-, ὀμ-ο</span>) _swear_, <span lang="grc">ὀμόργ-νῡμι</span> _wipe off_, <span lang="grc">ὄρ-νῡμι</span> _rouse_, <span lang="grc">πήγ-νῡμι</span> (<span lang="grc">παγ-, πηγ-</span>) _fix_, <span lang="grc">πλήγ-νῡμι</span> (once, in <span lang="grc">ἐκπλήγνυσθαι</span> Thuc. 4. 125; cp. <span lang="grc">πλήττω</span>), <span lang="grc">πτάρ-νυμαι</span> _sneeze_, <span lang="grc">ῥήγ-νῡμι</span> (<span lang="grc">ῥαγ-, ῥηγ-, ῥωγ-</span>) _break_, <span lang="grc">στόρνῡμι</span> _spread_, <span lang="grc">φράγ-νῡμι</span> ( = <span lang="grc">φράττω</span>) _inclose_.

##### <a id="s734"></a> §734

Poetic verbs: <span lang="grc">αἴ-νυμαι</span> _take_, <span lang="grc">ἄ-νῡμι</span> _complete_ (<span lang="grc">ἀνύω</span>), <span lang="grc">ἄχ-νυμαι</span> _am troubled_, <span lang="grc">γά-νυμαι</span> _rejoice_, <span lang="grc">δαί-νῡμι</span> _entertain_, <span lang="grc">καί-νυμαι</span> _excel_, <span lang="grc">κί̄-νυμαι</span> _move myself_ (cp. <span lang="grc">κῑνέω</span>), <span lang="grc">ὀρέγ-νῡμι</span> _reach_, <span lang="grc">τά-νυμαι</span> _stretch_, with <span lang="grc">νυ</span> carried into other tenses (<span lang="grc">τανύω</span>), <span lang="grc">τί̄-νυμαι</span> (cp. Epic <span lang="grc">τί̄νω</span> from <span lang="grc">τι-νϝ-ω</span>) better <span lang="grc">τείνυμαι</span>, _chastise_.

##### <a id="s735"></a> §735

The verbs whose verb-stem ends in a liquid or nasal often form the tenses other than the present by adding <span lang="grc">ε</span> or <span lang="grc">ο</span>, as <span lang="grc">ὄλλῡμι</span> (from <span lang="grc">ὀλνῡμι</span>) <span lang="grc">ὤλεσα, ὀλώλεκα</span> (<span lang="grc">ὀλ-ε-</span>), <span lang="grc">ὄμνῡμι ὤμοσα</span> (<span lang="grc">ὀμ-ο-</span>).

##### <a id="s736"></a> §736

<span lang="grc">νῡμι-</span>verbs form only the present and imperfect according to the <span lang="grc">μι-</span> conjugation; with the exception of <span lang="grc">σβέ-ννῡμι</span>, which has 2 aor. <span lang="grc">ἔσβην</span>. The 2 aorist passive and 2 future passive are rare, as <span lang="grc">ῥήγνῡμι ἐρράγην ἐκραγήσομαι, ζεύγνῡμι ἐζύγην</span>.

##### <a id="s736D"></a> §736 D

From verbs in <span lang="grc">-νῡμι</span> second aorists middle are formed in Hom. by only three verbs: <span lang="grc">μείγνῡμι</span> (commonly written <span lang="grc">μί̄γνῡμι</span>) _mix_ <span lang="grc">ἔμικτο, ὄρνῡμι</span> _rouse_ <span lang="grc">ὦρτο, πήγνῡμι</span> _fix_ <span lang="grc">κατέπηκτο</span>.

##### <a id="s737"></a> §737

<span lang="grc">-νημι</span> class. A few verbs add <span lang="grc">νη-</span> in the singular, <span lang="grc">να-</span> in the plural, to the verb-stem. These verbs are almost entirely poetical or dialectical; and show by-forms in <span lang="grc">-ναω</span>. They are:

<span lang="grc">δάμνημι</span> (<span lang="grc">δαμνάω</span>) _subdue_, <span lang="grc">κίρνημι</span> (<span lang="grc">κιρνάω</span> also Epic) _mix_, <span lang="grc">κρίμνημι</span> (miswritten <span lang="grc">κρήμνημι</span>) _suspend_, <span lang="grc">πέρνημι</span> _sell_, <span lang="grc">πίτνημι</span> (<span lang="grc">πετνάω</span>) _spread_, <span lang="grc">σκίδνημι</span> (and <span lang="grc">κίδνημι</span>) _scatter_. <!-- page 205 -->

**a.** Only in the middle: <span lang="grc">μάρναμαι</span> _fight_, <span lang="grc">πίλναμαι</span> (<span lang="grc">πιλνάω</span>) _approach_. In <span lang="grc">δύναμαι</span> _am able_, <span lang="grc">να</span> has grown fast (cp. <span lang="grc">δυνατός</span>).

##### <a id="s738"></a> §738

**Stem Gradation**.—Verbs of the root class show in the stem vowel a variation between strong and weak grades in the present and imperfect indicative active. The singular has the strong grade, the dual and plural have the weak grade. The optative active and most middle forms have the weak grade.

**a.** <span lang="grc"> **η** </span> strong (original and Dor. <span lang="grc">ᾱ</span>), <span lang="grc"> **α** </span> weak; <span lang="grc">φημί φαμέν, ἔφην ἔφαμεν; ἵστημι ἵσταμεν, ἵ̄στην ἵ̄σταμεν; δάμνημι δάμναμεν</span>.

**b.** <span lang="grc"> **η** </span> strong, <span lang="grc"> **ε** </span> weak: <span lang="grc">τίθημι τίθεμεν, ἐτίθην ἐτίθεμεν; ἵ̄ημι ἵ̄εμεν</span>.

**c.** <span lang="grc"> **ω** </span> strong, <span lang="grc"> **ο** </span> weak: <span lang="grc">δίδωμι δίδομεν</span>.

**d.** <span lang="grc"> **ει** </span> strong, <span lang="grc"> **ι** </span> weak (cp. <span lang="grc">λείπω ἔλιπον</span>): <span lang="grc">εἶμι</span> _will go_, <span lang="grc">ἴμεν</span>. The grades <span lang="grc">**ει**, **οι**, **ι**</span> appear in <span lang="grc">εἰδῶ</span>, subjunctive of <span lang="grc">οἶδα</span> _know_, pl. <span lang="grc">ἴσμεν</span> for <span lang="grc">ἴδμεν</span> ([799](16-irregular-mi-verbs.md#s799)).

##### <a id="s739"></a> §739

In the second aorist <span lang="grc">ἔστην</span> _I stood_ the strong form has been carried from the singular through the dual and plural of the indicative. The strong stem occurs also in the imperative (<span lang="grc">στῆθι, στῆτε</span>) and infinitive (<span lang="grc">στῆναι</span>).

##### <a id="s740"></a> §740

The second aorist infinitive shows the weak stem: <span lang="grc">θεῖναι</span> from <span lang="grc">θέ-εναι, δοῦναι</span> from <span lang="grc">δό-εναι</span>. Cp. [469](../09-verbs/08-endings-of-the-verb-personal-endings.md#s469) N. <span lang="grc">δτῆναι</span> is, however, from <span lang="grc">στή-εναι</span> ([469 c](../09-verbs/08-endings-of-the-verb-personal-endings.md#s469). N.).

##### <a id="s741"></a> §741

A few root verbs retain the strong grade <span lang="grc">η</span> throughout. Thus, poet. <span lang="grc">ἄημι</span> _blow_ <span lang="grc">ἄημεν; ἀέντες</span> is from <span lang="grc">ἀηντες</span> by 40; <span lang="grc">δίζημαι</span> _seek_ (poet. <span lang="grc">δίζεσθαι</span> is from <span lang="grc">δίζομαι</span>); <span lang="grc">πίμπλημι</span> _fill_ 2 aor. <span lang="grc">ἐνεπλήμην</span>, opt. <span lang="grc">ἐμπλῄμην</span>.

##### <a id="s742"></a> §742

Verbs adding <span lang="grc">νυ</span> show the strong form of the verb-stem in the present. <span lang="grc">ῥήγ-νῡ-μι</span> _break_ 2 aor. pass. <span lang="grc">ἐρράγην, μείγ-νῡ-μι</span> (miswritten <span lang="grc">μί̄γνῡμι</span>) _mix_ 2 aor. pass. <span lang="grc">ἐμίγην, ζεύγ-νῡ-μι</span> _yoke_ 2 aor. pass. <span lang="grc">ἐζύγην</span>.

##### <a id="s743"></a> §743

The ending <span lang="grc">νυ</span> varies between strong <span lang="grc">νῡ</span> and weak <span lang="grc">νῠ</span>. Thus <span lang="grc">δείκνῡμι δείκνῠμεν, ἐδείκνῡν ἐδείκνῠμεν</span>.

## INFLECTION OF MI-VERBS

##### <a id="s744"></a> §744

Verbs in <span lang="grc">-μι</span> differ in inflection from verbs in <span lang="grc">-ω</span> in the present and second aorist systems and (rarely) in the second perfect system. Verbs in <span lang="grc">-μι</span> have the following peculiarities of inflection:

**a.** The endings <span lang="grc">-μι</span> and <span lang="grc">-σι</span> (for original <span lang="grc">-τι</span>) occur in the present indicative active: <span lang="grc">τίθη-μι, τίθη-σι; φη-μί φη-σί</span>.

**b.** The 3 plural present indicative active has generally the ending <span lang="grc">-ᾱσι</span>, from <span lang="grc">α-αντι</span>, as <span lang="grc">τιθέᾱσι, ἱστᾶσι</span>. So in the 2 perf. active <span lang="grc">ἑστᾶσι</span>.

**c.** The 3 plural of active past tenses has <span lang="grc">-σαν</span>: <span lang="grc">ἐτίθε-σαν</span>.

**d.** The imperative ending <span lang="grc">-θι</span> is sometimes retained: <span lang="grc">φα-θί, στῆ-θι</span>; some forms never had it: <span lang="grc">τίθει, ἵστη</span>.

**e.** The middle endings <span lang="grc">-σαι</span> and <span lang="grc">-σο</span> regularly retain <span lang="grc">ς</span>: <span lang="grc">τίθε-σαι, ἐτίθε-σο</span>.

N.—But not in the subjunctive or optative; and usually not in the second aorist; as <span lang="grc">τιθῇ</span> for <span lang="grc">τιθέη-σαι, τιθεῖο</span> for <span lang="grc">τιθέ-ῑ-σο, ἔθου</span> for <span lang="grc">ἔθε-σο</span>.

**f.** The infinitive active has <span lang="grc">-ναι</span>: <span lang="grc">τιθέ-ναι, διδό-ναι</span>; the 2 aorist active has <span lang="grc">-εναι</span> rarely: <span lang="grc">θεῖναι</span> for <span lang="grc">θέ-εναι, δοῦναι</span> for <span lang="grc">δό-εναι</span>. <!-- page 206 -->

**g.** Active participles with stems in <span lang="grc">-οντ-</span> have the nominative sing. masc. in <span lang="grc">-ούς</span> ([301 a](../04-substantives/08-declension-of-participles.md#s301), [307](../04-substantives/08-declension-of-participles.md#s307) a): <span lang="grc">διδούς, διδό-ντ-ος</span>.

##### <a id="s745"></a> §745

Forms of <span lang="grc">-μι</span> verbs which are inflected according to the thematic conjugation are included under the Second Conjugation.

##### <a id="s746"></a> §746

<span lang="grc">μι-</span>verbs may pass into the <span lang="grc">ω</span> inflection elsewhere than in the subjunctive. **a.** Verbs in <span lang="grc">-νῡμι</span> often inflect the present and imperfect active (not the middle) from a present in <span lang="grc">-νύω</span>; as <span lang="grc">δεικνύω</span> (but usually <span lang="grc">δείκνῡμι</span>), <span lang="grc">δεικνύεις, δεικνύει</span>, imperf. <span lang="grc">ἐδείκνυον, -ες, -ε</span>, etc.,; imper. <span lang="grc">δείκνυε</span>, inf. <span lang="grc">δεικνύειν</span>, part. <span lang="grc">δεικνύων</span>.

**b.** <span lang="grc">τίθημι, ἵστημι, δίδωμι, ἵ̄ημι</span>, etc., show some <span lang="grc">ω-</span>forms in pres. (and imperf.) indic. opt. imper. and infin.; but the forms <span lang="grc">τιθέω, ἱστέω, διδόω, ἱ̄έω</span>, do not occur in the 1 sing.

**c.** In the present and second aorist optative of <span lang="grc">τίθημι</span> and <span lang="grc">ἵ̄ημι</span> there is a transition to the <span lang="grc">ω-</span>conjugation but not in the 1 and 2 singular. The accent is differently reported: (1) as if the presents were <span lang="grc">τιθέω, ἱ̄έω</span>; (2) as if the presents were <span lang="grc">τίθω, ἵ̄ω</span>. Thus:

Active: <span lang="grc">ἀφί̄οιτε</span> for <span lang="grc">ἀφῑεῖτε, ἀφί̄οιεν</span> for <span lang="grc">ἀφῑεῖεν</span>.—Middle: <span lang="grc">τιθοῖτο, ἐπιθοίμεθα, συνθοῖτο, ἐπιθοῖντο</span> (also accented <span lang="grc">τίθοιτο, ἐπίθοιντο</span>); <span lang="grc">προοῖτο, προοῖσθε, προοῖντο</span> (also accented <span lang="grc">πρόοιτο, πρόοιντο</span>). Hdt. has <span lang="grc">-θέοιτο</span> and <span lang="grc">-θεῖτο</span>. The form in <span lang="grc">-οῖτο</span> for <span lang="grc">-εῖτο</span> occurs especially in Plato.

**d.** The Mss. vary between <span lang="grc">τιθῶμαι</span> and <span lang="grc">τίθωμαι, ἀποθῶμαι</span> and <span lang="grc">ἀπόθωμαι</span> ([426 f](../09-verbs/04-accent.md#s426)).

**e.** Some other <span lang="grc">μι-</span>verbs show alternative <span lang="grc">ω-</span>forms, as <span lang="grc">πιμπλάω, -εω</span> (<span lang="grc">πίμπλημι</span>), <span lang="grc">πιπράω</span> (<span lang="grc">πίμπρημι</span>), Hom. <span lang="grc">ἀγάομαι</span> (<span lang="grc">ἄγαμαι</span>), and <span lang="grc">ἱ̄λάομαι</span> (<span lang="grc">ἵ̄λημι</span>). So often with <span lang="grc">-νημι</span> verbs ([737](#s737)), as <span lang="grc">δαμνᾷ</span> and <span lang="grc">δάμνησι, ἐκίρνᾱ</span> and <span lang="grc">κιρνά̄ς</span>.

##### <a id="s746D"></a> §746 D

The tragic poets never have the <span lang="grc">ω-</span>forms; the poets of the Old Comedy seldom; those of the New Comedy often have the <span lang="grc">ω-</span>forms.—Plato usually has <span lang="grc">-νυᾱσι</span>. Hom. has <span lang="grc">ζεύγνυον</span> (and <span lang="grc">ζεύγνυσαν, ὤρνυον, ὤμνυε, ὀμνυέτω</span>, etc.). Hdt. usually keeps the <span lang="grc">μι-</span>forms, but has some <span lang="grc">ω-</span>forms in 2, 3 sing. 3 pl. present indic. and part., and 1 sing., 3 pl. imperfect. Doric usually has the <span lang="grc">ω-</span>forms; Aeolic has <span lang="grc">ζεύγνῡ</span>, and <span lang="grc">ὄμνῡν</span> infin.

### PRESENT AND IMPERFECT ACTIVE AND MIDDLE (PASSIVE)

##### <a id="s747"></a> §747

**Present Indicative**.—**a.** The primary personal endings are added to the stem with the strong form in the singular and the weak form in the dual and plural.

**b.** In the 2 sing. <span lang="grc">τίθης, ἵ̄ης, ἵστης, δείκνῡς</span>, etc., <span lang="grc">ς</span> has been added to the stem. This <span lang="grc">ς</span> is obscure in origin, but cannot be derived from <span lang="grc">-σι. τιθει-ς</span> is rare.

**c.** 3 sing. <span lang="grc">τίθησι, ἵστησι</span>, etc., with <span lang="grc">-σι</span> for <span lang="grc">-τι</span> ([463 c](../09-verbs/08-endings-of-the-verb-personal-endings.md#s463)).

**d.** 3 plur. <span lang="grc">τιθέᾱσι, ἱστᾶσι</span>, etc., from <span lang="grc">τιθέ-αντι, ἱστά-αντι</span> ([463 d](../09-verbs/08-endings-of-the-verb-personal-endings.md#s463)).

**e.** For the retention of <span lang="grc">ς</span> in <span lang="grc">τίθε-σαι</span>, etc., see [465 a](../09-verbs/08-endings-of-the-verb-personal-endings.md#s465), b, and N. 2.

**f.** <span lang="grc">δίδομαι</span> in the middle present and imperfect is used only in composition, as <span lang="grc">ἀποδίδομαι</span>. But the simple form occurs in the passive.

##### <a id="s747D"></a> §747 D

\1. Hom. has <span lang="grc">τίθησθα, τίθησι</span> and <span lang="grc">τιθεῖ, τιθεῖσι; διδοῖς</span> and <span lang="grc">διδοῖσθα, δίδωσι</span> (usually) and <span lang="grc">διδοῖ, διδοῦσι, ῥηγνῦσι</span> from <span lang="grc">ῥηγνυ-ντι, ἴᾱσι</span> _they go_ and <span lang="grc">ἔᾱσι</span> _they are_. On <span lang="grc">ἵ̄στασκε</span> see [495](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s495). Mid. <span lang="grc">ἐμάρναο</span> from <span lang="grc">μάρναμαι</span>.

\2. Hdt. has <span lang="grc">τιθεῖ τιθεῖσι; ἱστᾷ</span> is doubtful; <span lang="grc">διδοῖς, διδοῖ, διδοῦσι, ἴᾱσι ἔᾱσι, -νῦσι</span> and <span lang="grc">-νύουσι</span>. Middle: <span lang="grc">-αται</span> and <span lang="grc">-ατο</span> (imperf.) for <span lang="grc">-νται, -ντο</span> in <span lang="grc">τιθέαται ἐτιθέατο, ἱστέαται ἱ̄στέατο, δυνέαται ἐδυνέατο. -αται, -ατο</span> have been transferred from the perfect and pluperfect of consonant stems, such as <span lang="grc">γεγράφαται, ἐγεγράφατο</span> ([465 f](../09-verbs/08-endings-of-the-verb-personal-endings.md#s465)).

\3. Doric has <span lang="grc">ἵστᾱμι</span>, and <span lang="grc">ᾱ</span> for <span lang="grc">η</span> in all tenses (<span lang="grc">στά̄σω, ἔστᾱσα, ἔστᾱν</span>); <span lang="grc">-τι</span> in 3 sing. <span lang="grc">τίθητι; -ντι</span> in 3 pl. <span lang="grc">τίθεντι, δίδοντι</span>.

\4. Aeolic has <span lang="grc">τίθης, τίθη, τίθεισι; ἴστᾱς, ἴστᾱ; δίδως, δίδω; δάμνᾱς</span>. <!-- page 207 -->

##### <a id="s748"></a> §748

**Imperfect**.—<span lang="grc">ἐτίθεις ἐτίθει, ἐδίδουν ἐδίδους ἐδίδου</span> (for <span lang="grc">ἐδιδων, -ως, -ω</span>) are thematic forms ([746 b](#s746)). For the imperfect of <span lang="grc">δύναμαι</span> and <span lang="grc">ἐπίσταμαι</span> see [465 b](../09-verbs/08-endings-of-the-verb-personal-endings.md#s465), N. 1. For the retention of <span lang="grc">ς</span> in <span lang="grc">ἐτίθεσο</span> see [465 b](../09-verbs/08-endings-of-the-verb-personal-endings.md#s465).

##### <a id="s748D"></a> §748 D

Hom. has <span lang="grc">ἐτίθει, ἐδίδους, ἐδίδου</span>.—Hdt. has <span lang="grc">ὑπερετίθεα</span> 1 sing., <span lang="grc">ἐδίδουν, ἐδίδου, ἵ̄στᾱ</span> and <span lang="grc">ἀνί̄στη</span> (both in Mss.).—In poetry <span lang="grc">-ν</span> occurs for <span lang="grc">-σαν</span> as <span lang="grc">τίθεν, ἵ̄στᾰν, δίδον</span> ([464 e](../09-verbs/08-endings-of-the-verb-personal-endings.md#s464). D.).

##### <a id="s749"></a> §749

**Subjunctive**.—Attic <span lang="grc">τιθῶ</span>, etc., are derived by contraction from the forms of the weak stem to which the thematic vowel <span lang="grc">ώη</span> has been added. Thus <span lang="grc">τιθέω, -έῃς, -έῃ, τιθέωμεν, -έητε, -έωσι; διδόω, -όῃς, -όῃ, διδόωμεν, -όητε, -όωσι. ἱστῶ</span> is derived from <span lang="grc">ἱστέω</span>. See [746 b](#s746). Verbs in <span lang="grc">-νῡμι</span> regularly inflect the subjunctive like <span lang="grc">ω-</span>verbs: <span lang="grc">δεικνύω, -ύῃς, -ύῃ</span>.

**a.** Similarly the middle (passive) forms are derived from <span lang="grc">τιθέω-μαι τιθέη-</span>(<span lang="grc">σ</span>)<span lang="grc">αι</span>, etc., <span lang="grc">διδόω-μαι διδόη-</span>(<span lang="grc">σ</span>)<span lang="grc">αι, ἱστέω-μαι ἱστέη-</span>(<span lang="grc">σ</span>)<span lang="grc">αι</span>, etc. For the loss of <span lang="grc">ς</span> in <span lang="grc">-σαι</span> see [465 a](../09-verbs/08-endings-of-the-verb-personal-endings.md#s465). <span lang="grc">-νῡμι</span> verbs inflect the mid. subj. like <span lang="grc">λύ̄ωμαι</span>.

**b.** <span lang="grc">δύναμαι</span> _am able_, <span lang="grc">ἐπίσταμαι</span> _understand_, <span lang="grc">κρέμαμαι</span> _hang_, and <span lang="grc">ἄγαμαι</span> _admire_ put <span lang="grc">ώη</span> in place of the stem-vowel so that there is no contraction: <span lang="grc">δύνωμαι, δύνῃ, δύνηται, δυνώμεθα</span>, etc. So, too, <span lang="grc">ἐπριάμην, πρίωμαι</span> ([757 a](#s757)).

**c.** Traces of <span lang="grc">-ῡται</span> in <span lang="grc">-νῡμι</span> verbs are very rare: <span lang="grc">ῥήγνῡται</span> Hipponax 19; cp. <span lang="grc">διασκεδάννῡται</span> <cite data-ref="Plat. Phaedo 77b">P. Ph. 77b</cite>.

##### <a id="s749D"></a> §749 D

Dor. has <span lang="grc">τιθέω, -έωμεν</span>, but contracts <span lang="grc">ε</span> + <span lang="grc">η</span> to <span lang="grc">η</span>; pl. <span lang="grc">διδῶντι</span> (and <span lang="grc">τίθηντι</span>). Dor. has <span lang="grc">δύνᾱμαι, ἵστᾱται</span>; Hdt. <span lang="grc">ἐνίστηται, ἐπιστέωνται, δυνέωνται</span>.

##### <a id="s750"></a> §750

**Present Optative**.—The optative active has the secondary endings and the mood sign <span lang="grc">-ιη-</span> in the singular, <span lang="grc">-ῑ-</span> (<span lang="grc">-ιε-</span> 3 pl.) in the dual and plural. In the dual and plural the longer (<span lang="grc">-ιη-</span>) forms are rare. Thus <span lang="grc">τιθείην</span> (<span lang="grc">τιθε-ίη-ν</span>), <span lang="grc">τιθεῖμεν</span> (<span lang="grc">τιθέ-ῑ-μεν</span>), <span lang="grc">ἱσταίην</span> (<span lang="grc">ἱστα-ίη-ν</span>) <span lang="grc">ἱσταῖεν</span> (<span lang="grc">ι·στά-ιε-ν</span>). The shorter forms in dual and plural occur in poetry and prose, the longer forms only in prose.

**a.** The middle (passive) has the secondary endings and the mood sign <span lang="grc">-ῑ-</span> throughout: <span lang="grc">τιθείμην</span> (<span lang="grc">τιθε-ί̄-μην</span>), <span lang="grc">ἱσταίμην</span> (<span lang="grc">ἱστα-ί̄-μην</span>), <span lang="grc">ἱσταίμεθα</span> (<span lang="grc">ἱστα-ί̄-μεθα</span>), <span lang="grc">διδοῖντο</span> (<span lang="grc">διδό-ῑ-ντο</span>). On <span lang="grc">τιθοῖτο</span>, etc., see [746 c](#s746).

**b.** The accent follows 424 c, N. 1 (<span lang="grc">τιθεῖτο</span> not <span lang="grc">τίθειτο</span>). But the verbs of 749 b are exceptional: <span lang="grc">δύναιο δύναιτο</span>; and so <span lang="grc">ὄναιο ὄναιτο</span> from <span lang="grc">ὀνίνημι</span> _benefit_ ([424 c](../09-verbs/04-accent.md#s424), N. 2).

##### <a id="s750D"></a> §750 D

Hom. has the <span lang="grc">μι-</span>forms <span lang="grc">δαινῦτο</span> and <span lang="grc">δαινύ̄ατο</span>, Plato has <span lang="grc">πηγνῦτο</span>.

##### <a id="s751"></a> §751

**Present Imperative**.—<span lang="grc">τίθει</span> and <span lang="grc">δίδου</span> are formed (cp. <span lang="grc">ποίει</span> and <span lang="grc">δήλου</span>) from <span lang="grc">τίθε-ε, δίδο-ε. ἵστη</span> and <span lang="grc">δείκνῡ</span> show the stronger stem forms.

For the middle endings and the retention of <span lang="grc">ς</span>, see [466](../09-verbs/08-endings-of-the-verb-personal-endings.md#s466). 2. a.—On the forms <span lang="grc">τιθέτωσαν</span> for <span lang="grc">τιθέντων, τιθέσθωσαν</span> for <span lang="grc">τιθέσθων</span>, see [466](../09-verbs/08-endings-of-the-verb-personal-endings.md#s466). 2. b.

##### <a id="s751D"></a> §751 D

Hom. has <span lang="grc">ἵστη</span> and <span lang="grc">καθίστᾱ, δίδωθι, ἐμπίπληθι, ὄμνυθι, ὄρνυθι, ἵστασο</span> and <span lang="grc">ἵσταο. τίθου, ἵστω</span> occur in the drama. Pind. has <span lang="grc">δίδοι</span> (active). <!-- page 208 -->

##### <a id="s752"></a> §752

**Present Infinitive**.—The active adds <span lang="grc">-ναι</span>, the middle <span lang="grc">-σθαι. δείκνῡμι</span> admits the form <span lang="grc">δεικνύειν</span>.

##### <a id="s752D"></a> §752 D

Hom. has <span lang="grc">-μεναι</span> or <span lang="grc">-ναι</span> preceded by <span lang="grc">η</span> in <span lang="grc">ἀήμεναι ἀῆναι</span> from <span lang="grc">ἄημι</span> _blow_, <span lang="grc">τιθήμεναι, κιχήμεναι</span> and <span lang="grc">κιχῆναι</span> as from <span lang="grc">κίχημι</span>. Also <span lang="grc">ἱστάμεναι</span> (and <span lang="grc">ἱστάμεν</span>), <span lang="grc">ζευγνύμεναι</span> (and <span lang="grc">ζευγνύμεν</span>, once <span lang="grc">ζευγνῦμεν</span>). <span lang="grc">-μεν</span> after a short vowel, as <span lang="grc">τιθέμεν, διδόμεν</span> (once <span lang="grc">διδοῦναι</span>). Doric has <span lang="grc">τιθέμεν, διδόμεν</span>. Theognis has <span lang="grc">τιθεῖν, συνιεῖν</span>.

##### <a id="s753"></a> §753

**Present Participle**.—The active adds <span lang="grc">-ντ-</span>, the middle <span lang="grc">-μενος</span>. Thus <span lang="grc">τιθείς</span> (<span lang="grc">τιθε-ντ-ς</span>), <span lang="grc">τιθεῖσα</span> (<span lang="grc">τιθε-ντ-\[ιγλιδε\]α</span>); <span lang="grc">τιθέ-μενος</span>. For <span lang="grc">δεικνύ̄ς</span> we find <span lang="grc">δεικνύων</span>.

##### <a id="s753D"></a> §753 D

Hom. has <span lang="grc">τιθήμενος</span> K 34.

### THE FUTURES

##### <a id="s754"></a> §754

The futures of verbs in <span lang="grc">-μι</span> do not differ in formation and inflection from those of verbs in <span lang="grc">-ω</span>.

<span lang="grc">τίθημι</span>: <span lang="grc">θήσω, θήσομαι, τεθήσομαι; ἵστημι</span>: <span lang="grc">στήσω, στήσομαι, σταθήσομαι, ἑστήξω; ἵ̄ημι</span>: <span lang="grc">ἥσω, -ἤσομαι, -ἑθήσομαι; δίδωμι</span>: <span lang="grc">δώσω, -δώσομαι, δοθήσομαι; δείκνῡμι</span>: <span lang="grc">δείξω, δείξομαι, δειχθήσομαι, δεδείξομαι</span> (late) or <span lang="grc">δεδειγμένος ἔσομαι; μείγνῡμι</span>: <span lang="grc">μείξω, -μιχθήσομαι, μιγήσομαι</span> (poet.), <span lang="grc">μεμείξομαι</span> (poet.); <span lang="grc">πήγνῡμι</span>: <span lang="grc">πήξω, παγήσομαι</span>.

**a.** <span lang="grc">ἑστήξω</span> is the only future perfect from a <span lang="grc">μι-</span>verb ([584](08-vii-perfect-middle-system.md#s584)).

### FIRST AORIST ACTIVE AND MIDDLE

##### <a id="s755"></a> §755

The verbs <span lang="grc">τίθημι, ἵ̄ημι, δίδωμι</span> form the singular active of the first aorist in <span lang="grc">-κ-α</span>, thus, <span lang="grc">ἔθηκα, ἔδωκα, ἧκα</span>. The forms of the second aorist ([756](#s756)) are generally used in the dual and plural and in the other moods.

**a.** The form in <span lang="grc">κ</span> rarely appears outside of the singular, chiefly in the 3 pl., as <span lang="grc">ἔδωκαν</span> ( = <span lang="grc">ἔδοσαν</span>), less frequently in the 1 and 2 pl., as <span lang="grc">ἐδώκαμεν, -ατε</span>.

**b.** That <span lang="grc">κ</span> was not a suffix but a part of an alternative root appears from a comparison of <span lang="grc">θηκ-</span> in <span lang="grc">ἔθηκα</span> and perf. <span lang="grc">τέθηκα</span> with _fēc-_ in _fēci_.

**c.** <span lang="grc">ἵστημι</span> has <span lang="grc">ἔστησα</span> _I set_, _placed_ (mid. <span lang="grc">ἐστησάμην</span>), to be distinguished from 2 aor. <span lang="grc">ἔστην</span> _I stood_.

**d.** <span lang="grc">ἐθηκάμην</span> is un-Attic; <span lang="grc">ἡκάμην</span> (in comp.) is rare and probably found only in the indic.; <span lang="grc">ἐδωκάμην</span> is very late.

##### <a id="s755D"></a> §755 D

Hom. has <span lang="grc">ἔθηκαν, ἔδωκαν, ἐνήκαμεν, θήκατο</span>; Hdt. <span lang="grc">συνθήκαντο</span>; Pind. <span lang="grc">θηκάμενος</span>.

### SECOND AORIST ACTIVE AND MIDDLE

##### <a id="s756"></a> §756

**Indicative**.—<span lang="grc">τίθημι, ἵ̄ημι, δίδωμι</span> use the short grade forms in dual and plural active: <span lang="grc">ἔ-θε-τον, ἔ-θε-μεν, ἔθε-σαν; εἷ-τον, εἷ-μεν, εἷ-σαν</span> (for <span lang="grc">ἐ-ἑ-τον</span>, etc.); <span lang="grc">ἔ-δο-μεν, ἔ-δο-σαν</span>. In the singular the <span lang="grc">κ-</span>forms, <span lang="grc">ἔθηκα, ἧκα, ἔδωκα</span>, are used. <span lang="grc">ἵστημι</span> has <span lang="grc">ἔστην, ἔστης, ἔστη</span> (for <span lang="grc">ἐστητ</span>, 464 c), <span lang="grc">ἔστημεν</span>, etc. (p. [138](../../part-1-letters-sounds-syllables-accent/06-syllables-and-their-quantity.md#s138)).

**a.** <span lang="grc">σβέννῡμι</span> _extinguish_ is the only verb in <span lang="grc">-νῡμι</span> forming a second aorist (<span lang="grc">ἔσβην, σβῶ, σβείην, σβῆθι, σβῆναι, σβείς</span>). <!-- page 209 -->

**b.** The middle uses the weak stems <span lang="grc">-θε-, -ἑ-, -δο-</span> in <span lang="grc">ἑ-θί-μην, -εἵμην</span> (for <span lang="grc">ἐ-ἑ-μην</span>), <span lang="grc">ἐ-δό-μην</span> (only in composition). For the loss of <span lang="grc">ς</span> in <span lang="grc">-σο</span> (<span lang="grc">ἔθου, ἔδου</span>) see [465 b](../09-verbs/08-endings-of-the-verb-personal-endings.md#s465).

**c.** In prose the only uncompounded second aorists middle are <span lang="grc">ἐπριάμην</span> _bought_ (pres. <span lang="grc">ὠνέομαι</span>) and <span lang="grc">ὠνήμην</span> _derived benefit_ (<span lang="grc">ὀνίνημι</span>). <span lang="grc">ὠνήμην</span> keeps <span lang="grc">η</span> (poet. <span lang="grc">ὄνησο, ὀνήμενος</span>). <span lang="grc">ἵστημι</span> does not make the form <span lang="grc">ἐσταμην</span>.

##### <a id="s756D"></a> §756 D

Hom. has older <span lang="grc">-ν</span> for <span lang="grc">-σαν</span> in <span lang="grc">ἔστᾰν</span> (he uses <span lang="grc">ἔστησαν</span> also), Dor. has <span lang="grc">ἔθεν, ἔστᾰν, ἔδον</span>. For the iterative <span lang="grc">στά-σκε, δό-σκον</span> see [495](../09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s495).

**c. D.** In poetry: <span lang="grc">ἐπτάμην</span> (prose <span lang="grc">-ἐπτόμην</span>) from <span lang="grc">πέταμαι</span> _fly;_ Hom. <span lang="grc">πλῆτο</span> _approached_, <span lang="grc">ἔβλητο</span> _was hit_ (others, [688](13-inflection-of-omega-verbs.md#s688)).

##### <a id="s757"></a> §757

**Second Aorist Subjunctive**.—All the forms of the 2 aor. subj. are due to contraction of the thematic vowel with the weak stem-vowel. Thus <span lang="grc">θῶ</span>, etc., from <span lang="grc">θέω, θέῃς, θέῃ, θέωμεν</span>, etc.; <span lang="grc">ὧ</span>, etc., from <span lang="grc">ἕω, ἕῃς, ἕωσι; δῶ</span>, etc., from <span lang="grc">δόω, δόῃς, δόῃ; στῶ</span>, etc., from <span lang="grc">στέω, στέῃς</span>, etc., with <span lang="grc">ε</span> from <span lang="grc">η</span> before a vowel. Cp. [682](13-inflection-of-omega-verbs.md#s682).

**a.** <span lang="grc">ἐπριάμην</span> has <span lang="grc">πρίωμαι</span> with <span lang="grc">ώη</span> in place of the final vowel of the stem ([749 b](#s749)).

##### <a id="s757D"></a> §757 D

The subjunctive shows traces of an earlier double form of inflection:

\1. With short thematic vowel: <span lang="grc">θήεις, θήει, θήετον, θήομεν, θήετε, θήουσι</span>. Homer: <span lang="grc">θήομεν, στήομεν, -στήετον, κιχήομεν, δώομεν, ἀποθήομαι</span>.

\2. With long thematic vowel: <span lang="grc">θήω, θήῃς, θήῃ, θήητον, θήωμεν, θήητε, θήωσι</span>. Hom. <span lang="grc">θήω, θήῃς, θήῃ, στήῃς, στήῃ, ἀνήῃ, δώῃ</span> or <span lang="grc">δώῃσι, περιστήωσι, δώωσι</span>.

By shortening of the long vowel of the stem we obtain a third form:

\3. <span lang="grc">θέω, θέῃς, θέῃ, θέητον, θέωμεν, θέητε, θέωσι</span>. Hom. <span lang="grc">ἀφέῃ, θέωμεν, στέωμεν</span>, Hdt. <span lang="grc">θέω, θέωμεν, θέωσι, θέωμαι, στέωμεν, ἀποστέωσι</span>, Aeolic <span lang="grc">θέω</span>.

\4. From 3 are derived the contracted forms <span lang="grc">θῶ, θῇς, θῇ</span>, etc. Hom. <span lang="grc">ἀναστῇ, δῷς, δῷ</span> or <span lang="grc">δῷσι, δῶμεν</span>; Dor. <span lang="grc">δῶντι</span>; Hdt. <span lang="grc">-θῇ, -θῆται; δῶμεν, -δῶτε, δῶσι</span>.

N.—In Hom. the Mss. often have <span lang="grc">ει</span> for <span lang="grc">η</span> of the stem, as <span lang="grc">θείω, βείω, θείομεν, κιχείομεν</span>.

##### <a id="s758"></a> §758

**Second Aorist Optative**.—The forms of the optative of the second aorist are made and inflected like those of the present except for the reduplication. Thus, in the active: <span lang="grc">θείην</span> (<span lang="grc">θε-ίη-ν</span>), <span lang="grc">σταίην</span> (<span lang="grc">στα-ίη-ν</span>), <span lang="grc">δοῖμεν</span> (<span lang="grc">δό-ῑ-μεν</span>), <span lang="grc">δοῖεν</span> (<span lang="grc">δό-ιε-ν</span>). The shorter forms are preferred in the dual and plural, and poetry has only these; prose admits either the longer or the shorter forms.

**a.** In the 2 pl. cases of <span lang="grc">-ιη-τε</span> (<span lang="grc">δοίητε</span>) are more numerous than <span lang="grc">-ι-τε</span>; but they usually lack metrical warrant.

**b.** Second aorists of stems in <span lang="grc">υ</span> lack the optative in Attic.

**c.** In the middle: <span lang="grc">θείμην</span> (<span lang="grc">θε-ί̄-μην</span>), <span lang="grc">δοίμην</span> (<span lang="grc">δο-ί̄-μην</span>), <span lang="grc">-εἵμην</span> (<span lang="grc">ἑ-ί̄-μην</span>). For <span lang="grc">θοίμεθα</span> see [746 c](#s746). For the accent of <span lang="grc">πρίαιο</span> see [424 c](../09-verbs/04-accent.md#s424), N. 2.

##### <a id="s758D"></a> §758 D

Hom. has <span lang="grc">σταίησαν</span> P 733, the only case of <span lang="grc">-ιη-</span> outside of the singular; <span lang="grc">δύ̄η</span> (for <span lang="grc">δυ-ίη</span>), <span lang="grc">ἐκδῦμεν</span> (for <span lang="grc">-δύ-ῑ-μεν</span>), and <span lang="grc">φθῖτο</span> (for <span lang="grc">φθί-ῑ-το</span>) from <span lang="grc">φθί̄νω</span> _perish_.

##### <a id="s759"></a> §759

**Second Aorist Imperative**.—On <span lang="grc">θέ-ς, δό-ς, ἕ-ς</span>, see [466](../09-verbs/08-endings-of-the-verb-personal-endings.md#s466). 1. b. These verbs show the weak form of the stem (<span lang="grc">θέ-τω, θέ-ντων</span>). <span lang="grc">ἵστημι</span> and <span lang="grc">σβέννῡμι</span> have <span lang="grc">-θι</span> in <span lang="grc">στῆ-θι, σβῆ-θι</span>. For <span lang="grc">στη῀-θι</span> the poets may use <span lang="grc">-στᾱ</span> in composition, as <span lang="grc">ἀπόστᾱ</span> _stand off_.

**a.** The middle adds <span lang="grc">-σο</span>, which loses its <span lang="grc">ς</span> after a short vowel, as in <span lang="grc">θοῦ</span> for <span lang="grc">θέ-σο, δοῦ</span> for <span lang="grc">δό-σο, πρίω</span> (and poet. <span lang="grc">πρία-σο</span>). <span lang="grc">ς</span> is not dropped after a long vowel (<span lang="grc">ὄνησο</span>). Cp. [465 b](../09-verbs/08-endings-of-the-verb-personal-endings.md#s465), N. 2. <!-- page 210 -->

**b.** In composition <span lang="grc">περίθες, ἀπόδος, παράστηθι, ἐνθοῦ, προδοῦ</span>; but <span lang="grc">κατάθου, περιδου, περίδοσθε</span> ([426 b](../09-verbs/04-accent.md#s426)-c).

**c.** For the 3 pl. <span lang="grc">θέτωσαν, δότωσαν, ἕσθωσαν</span>, see [466](../09-verbs/08-endings-of-the-verb-personal-endings.md#s466). 2. b.

##### <a id="s759D"></a> §759 D

Hom. has <span lang="grc">θέο</span> and <span lang="grc">ἔνθεο</span>.

##### <a id="s760"></a> §760

**Second Aorist Infinitive**.—The active adds <span lang="grc">-εναι</span> in <span lang="grc">θεῖναι</span> (<span lang="grc">θέ-εναι</span>), <span lang="grc">στῆναι</span> (<span lang="grc">στή-εναι</span>), <span lang="grc">δοῦναι</span> (<span lang="grc">δό-εναι</span>), <span lang="grc">εἷναι</span> (<span lang="grc">ἕ-εναι</span>). The middle adds <span lang="grc">-σθαι</span>, as <span lang="grc">θέ-σθαι</span>.

##### <a id="s760D"></a> §760 D

Hom. has <span lang="grc">θέμεναι, θέμεν; στήμεναι; δόμεναι, δόμεν</span>; and <span lang="grc">θεῖναι, στῆναι, δοῦναι</span>. Dor. has <span lang="grc">θέμεν, δόμεν, στᾶμεν</span>.

##### <a id="s761"></a> §761

**Second Aorist Participle**.—The active adds <span lang="grc">-ντ-</span> like the present: <span lang="grc">θείς</span> (<span lang="grc">θε-ντ-ς</span>), <span lang="grc">θεῖσα</span> (<span lang="grc">θε-ντ-\[ιγλιδε\]α</span>), <span lang="grc">θέν</span> (<span lang="grc">θε-ντ</span>); <span lang="grc">στά̄ς</span> (<span lang="grc">στα-ντ-ς</span>), <span lang="grc">στᾶσα</span> (<span lang="grc">στα-ντ-\[ιγλιδε\]α</span>), <span lang="grc">στάν</span> (<span lang="grc">στα-ντ</span>). The middle adds <span lang="grc">-μενος</span>, as <span lang="grc">θέ-μενος</span>.

### FIRST AND SECOND PERFECT (AND PLUPERFECT) ACTIVE

##### <a id="s762"></a> §762

**Indicative**.—The perfect of <span lang="grc">τίθημι</span> is <span lang="grc">τέθηκα</span>. A later form <span lang="grc">τέθεικα</span>, not found on Attic inscriptions till after 200 B.C. and due to the analogy of <span lang="grc">εἷκα</span>, still appears in some texts. <span lang="grc">τέθεκα</span> is Doric. For <span lang="grc">καθέστακα</span> Attic used <span lang="grc">καταστήσᾱς ἔχω</span> (cp. [599](11-periphrastic-forms.md#s599) b).

**a.** The dual and plural of the second perfect and pluperfect of <span lang="grc">ἵστημι</span> ([417](../09-verbs/00-introduction.md#s417)) are formed without <span lang="grc">κ</span>: <span lang="grc">ἕστατον, ἕσταμεν</span> (without augment in the pluperf.), <span lang="grc">ἑστᾶσι</span> from <span lang="grc">ἑ-στα-αντι</span>, pluperf. <span lang="grc">ἕστα-σαν</span>. The singular is supplied by the 1 perf. <span lang="grc">ἕστηκα</span> _I stand_.

##### <a id="s763"></a> §763

**Subjunctive**.—<span lang="grc">ἑστήκω</span> and <span lang="grc">ἑστῶ</span> appear in prose and poetry, <span lang="grc">ἑστηκὼς ὦ</span> in prose.

##### <a id="s764"></a> §764

**Optative**.—<span lang="grc">ἑστήκοιμι</span> occurs in comp. in prose, <span lang="grc">ἀφεστῶτες εἶεν</span> in Plato, <span lang="grc">τεθηκὼς εἴης</span> and <span lang="grc">δεδωκότες εἶεν</span> in Demosthenes. <span lang="grc">ἑσταίην</span> is poetical.

##### <a id="s765"></a> §765

**Imperative**.—<span lang="grc">ἕσταθι</span> is poetical.

##### <a id="s766"></a> §766

**Infinitive and Participle**.—<span lang="grc">ἑστάναι</span> and <span lang="grc">ἑστώς</span> are much more common than <span lang="grc">ἑστηκέναι</span> and <span lang="grc">ἑστηκώς</span>.

##### <a id="s766D"></a> §766 D

Hom. has <span lang="grc">ἑστάμεναι</span> and <span lang="grc">ἑστάμεν, ἑσταώς, -αότος</span>. Hdt. has <span lang="grc">ἑστεώς, -εῶτος</span>. Doric has <span lang="grc">-εῖα</span> for <span lang="grc">-υῖα</span> (<span lang="grc">ἑστᾱκεῖα</span>).

### PERFECT MIDDLE (PASSIVE)

##### <a id="s767"></a> §767

<span lang="grc">τέθειμαι</span> even in composition is rare and is unknown on Attic inscriptions. For the pass. perf. <span lang="grc">κεῖμαι</span> ([791](16-irregular-mi-verbs.md#s791)) was used. Doric has <span lang="grc">τέθεμαι</span>.
