# COMPARISON OF ADJECTIVES

##### <a id="s313"></a> §313

**Comparison by <span lang="grc">-τερος, -τατος</span>**.—The usual endings are:

For the comparative: <span lang="grc">-τερος</span> m. <span lang="grc">-τερᾱ</span> f. <span lang="grc">-τερον</span> n.

For the superlative: <span lang="grc">-τατος</span> m. <span lang="grc">-τατη</span> f. <span lang="grc">-τατον</span> n.

The endings are added to the masculine stem of the positive. Comparatives are declined like <span lang="grc">ἄξιος</span>, superlatives like <span lang="grc">ἀγαθός</span> ([287](04-substantives/07-adjectives.md#s287)).

<span lang="grc"> **δῆλος** </span> (<span lang="grc">δηλο-</span>) _clear_, <span lang="grc">**δηλό-τερος**, **δηλό-τατος**; **ἰσχῡρός**</span> (<span lang="grc">ἰσχῡρο-</span>) _strong_, <span lang="grc">**ἰσχῡρότερος**, **ἰσχῡρό-τατος**; **μέλᾱς**</span> (<span lang="grc">μελαν-</span>) _black_, <span lang="grc">**μελάν-τερος**, **μελάν-τατος**; **βαρύς**</span> (<span lang="grc">βαρυ-</span>) _heavy_, <span lang="grc">**βαρύ-τερος**, **βαρύ-τατος**; **ἀληθής**</span> (<span lang="grc">ἀληθεσ-</span>) _true_, <span lang="grc">**ἀληθέσ-τερος, ἀληθέσ-τατος**; **εὐκλεής**</span> (<span lang="grc">εὐκλεεσ-</span>) _famous_, <span lang="grc">**εὐκλεέσ-τερος**, **εὐκλεέσ-τατος**</span>. <!-- page 87 -->

**a.** <span lang="grc">χαριέστερος, -έστατος</span> are from <span lang="grc">χαριετ-τερος, -τατος</span> ([83](../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s83), [299](04-substantives/07-adjectives.md#s299) b), from <span lang="grc">χαρίεις</span> _graceful_. Compounds of <span lang="grc">χάρις</span> _grace_ add <span lang="grc">ο</span> to the stem (<span lang="grc">χαριτ-ο-</span>), whence <span lang="grc">ἐπιχαριτώτερος</span> _more pleasing_. <span lang="grc">πένης</span> _poor_ has <span lang="grc">πενέσ-τερος</span> from <span lang="grc">πενετ-τερος</span>, with <span lang="grc">ε</span> for <span lang="grc">η</span>.

**b.** Originally <span lang="grc">-τερος</span> had no other force than to contrast one idea with another, and this function is retained in <span lang="grc">δεξίτερος</span> _right_) (<span lang="grc">ἀρίστερος</span> _left_, <span lang="grc">ἡμέτερος</span> _our_) ( <span lang="grc">ὑ̄μέτερος</span> _your_. Hom. has several such words: <span lang="grc">ἀγρότερος</span> _wild_) (_tame_, <span lang="grc">θηλύτεραι γυναῖκες</span>) (_men_, cp. Arcadian <span lang="grc">ἀρρέντερος</span> from <span lang="grc">ἄρρην</span> _male_. Cp. [1082 b](../part-4-syntax/14-adjectives.md#s1082).

##### <a id="s314"></a> §314

Adjectives in <span lang="grc">-ος</span> with a short penult lengthen <span lang="grc">ο</span> to <span lang="grc">ω</span>: <span lang="grc">ϝέο-ς</span> _new_, <span lang="grc">ϝεώ-τερος, νεώ-τατος, χαλεπό-ς</span> _difficult_, <span lang="grc">χαλεπώ-τερος, χαλεπώ-τατος</span>. An undue succession of short syllables is thus avoided.

**a.** If the penult is long either by nature or by position ([144](../part-1-letters-sounds-syllables-accent/06-syllables-and-their-quantity.md#s144)), <span lang="grc">ο</span> is not lengthened: <span lang="grc">λεπτός</span> _lean_, <span lang="grc">λεπτότερος, λεπτότατος</span>. A stop and a liquid almost always make position here (cp. [145](../part-1-letters-sounds-syllables-accent/06-syllables-and-their-quantity.md#s145)); as <span lang="grc">πικρός</span> _bitter_, <span lang="grc">πικρότερος, πικρότατος. κενός</span> _empty_ and <span lang="grc">στενός</span> _narrow_ were originally <span lang="grc">κενϝος, στενϝος</span> (Ionic <span lang="grc">κεινός, στεινός</span>, 37 D. 1), hence <span lang="grc">κενότερος, στενότερος</span>.

##### <a id="s314aD"></a> §314 a. D

Hom. <span lang="grc">ὀιζῡρώτατος</span> (but cp. Att. <span lang="grc">οἰζῠρός</span>), <span lang="grc">λᾱρώτατος</span> (<span lang="grc">λᾰερώτατος</span>?).

##### <a id="s315"></a> §315

The following drop the stem vowel <span lang="grc">ο</span>: <span lang="grc">γεραιό-ς</span> _aged_, <span lang="grc">γεραί-τερος, γεραίτατος; παλαιό-ς</span> _ancient_, <span lang="grc">παλαί-τερος, παλαί-τατος; σχολαῖο-ς</span> _slow_, <span lang="grc">σχολαί-τερος, σχολαί-τατος; φίλο-ς</span> _dear_, <span lang="grc">φίλ-τερος</span> (poetic), <span lang="grc">φίλ-τατος</span> ([319](#s319), [11](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s11)).

**a.** Some other adjectives reject the stem vowel <span lang="grc">ο</span> and end in <span lang="grc">-αιτερος, -αιτατος</span>, as <span lang="grc">ἥσυχος</span> _quiet_, <span lang="grc">ἴσος</span> _equal_, <span lang="grc">ὄρθριος</span> _early_. These, like <span lang="grc">σχολαίτερος</span> and <span lang="grc">γεραίτερος</span>, imitate <span lang="grc">παλαίτερος</span>, which is properly derived from the adverb <span lang="grc">πάλαι</span> _long ago_. So <span lang="grc">μεσαίτερος, -αίτατος</span> imitate <span lang="grc">μεσαι-</span> in Hom. <span lang="grc">μεσαι-πόλιος</span> _middle-aged_.

##### <a id="s316"></a> §316

<span lang="grc">**-εστερος**, **-εστατος**</span>.—By imitation of words like <span lang="grc">ἀληθέσ-τερος, ἀληθέστατος</span> ([313](#s313)), <span lang="grc">-εστερος, -εστατος</span> are added to stems in <span lang="grc">ον</span> and to some in <span lang="grc">οο</span> (contracted to <span lang="grc">ου</span>). Thus, <span lang="grc">εὐδαίμων</span> _happy_, <span lang="grc">εὐδαιμον-έστερος, -έστατος; ἁπλοῦς</span> _simple_, <span lang="grc">ἁπλούστερος</span> (for <span lang="grc">ἁπλο-εστερος</span>), <span lang="grc">ἁπλούστατος; εὔνους</span> _well-disposed_, <span lang="grc">εὐνούστερος, -ούστατος</span>, and so in all others in <span lang="grc">-νους</span> from <span lang="grc">νοῦς</span> _mind_. (Others in <span lang="grc">-οος</span> have <span lang="grc">-οωτερος</span>: <span lang="grc">ἀθροώτερος</span> _more crowded_ from <span lang="grc">ἀθρόος</span>.)

**a.** Some stems in <span lang="grc">ον</span> substitute <span lang="grc">ο</span> for <span lang="grc">ον</span>; as (from <span lang="grc">ἐπιλήσμων</span> _forgetful_, <span lang="grc">ἐπιλησμονέσ-τερος</span>) <span lang="grc">ἐπιλησμό-τατος; πί̄ων</span> _fat_, <span lang="grc">πῑότερος, πῑότατος; πέπων</span> _ripe_ has <span lang="grc">πεπαίτερος, πεπαίτατος</span>. Cp. [315 a](#s315).

**b.** Other cases: (with loss of <span lang="grc">ο</span>) <span lang="grc">ἐρρωμένο-ς</span> _strong_, <span lang="grc">ἐρρωμενέστερος, -έστατος, ἄκρᾱτο-ς</span> _unmixed_, <span lang="grc">ἀκρᾱτέστατος, ἄσμενο-ς</span> _glad_, <span lang="grc">ἄφθονο-ς</span> _abundant_.

##### <a id="s317"></a> §317

<span lang="grc">**-ιστερος**, **-ιστατος**</span>.—By imitation of words like <span lang="grc">ἀχαρίστερος</span> for <span lang="grc">ἀχαριττερος</span> ([83](../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s83)) from <span lang="grc">ἄχαρις</span> _disagreeable_, <span lang="grc">-ιστερος, -ιστατος</span> are used especially with adjectives of a bad meaning, as <span lang="grc">κλεπτ-ίστατος</span> (<span lang="grc">κλέπτης</span> _thief_, [321](#s321)), <span lang="grc">κακηγορίστερος</span> (<span lang="grc">κακήγορος</span> _abusive_), <span lang="grc">λαλ-ίστερος</span> (<span lang="grc">λάλος</span> _talkative_).

##### <a id="s318"></a> §318

**Comparison by** <span lang="grc">**-ῑων**, **-ιστος**</span>.—Some adjectives add to the _root_ of the positive the endings <span lang="grc">-ῑων</span> for the masculine and feminine, <span lang="grc">-ῑον</span> <!-- page 88 --> for the neuter to form the comparative, and <span lang="grc">-ιστος -η -ον</span> to form the superlative. The vowel (or the syllable <span lang="grc">ρο</span>) standing before <span lang="grc">ς</span> of the nominative is thus lost.

##### <a id="s318D"></a> §318 D

Hom. and Doric poetry have also <span lang="grc">-ῐων</span>, which is as old as <span lang="grc">-ῑων</span>. Forms in <span lang="grc">-ῑων, -ιστος</span> are much commoner in poetry than in prose. Hom. has <span lang="grc">βάθιστος</span> (<span lang="grc">βαθύς</span> _deep_), <span lang="grc">βράσσων</span> (<span lang="grc">βραχύς</span> _short_), <span lang="grc">βάρδιστος</span> (<span lang="grc">βραδύς</span> _slow_), <span lang="grc">κύ̄διστος</span> (<span lang="grc">κῡδρός</span> _glorious_), <span lang="grc">ὤκιστος</span> (<span lang="grc">ὠκύς</span> _quick_).

##### <a id="s320"></a> §320

##### <a id="s320D"></a> §320 D

Hom. has <span lang="grc">ὁπλότερος</span> _younger_, <span lang="grc">ὁπλότατος</span>. Several defectives denote _place;_ <span lang="grc">ἐπασσύτερος</span> (<span lang="grc">ἆσσον</span> _nearer_), <span lang="grc">παροίτερος</span> (<span lang="grc">πάροιθεν</span> _before_), <span lang="grc">μυχοίτατος</span> (<span lang="grc">μυχοῖ</span> _in a recess_). <span lang="grc">-ατος</span> in <span lang="grc">μέσατος, μέσσατος</span> (<span lang="grc">μέσος</span> _middle_), <span lang="grc">πύματος</span> _last_, <span lang="grc">νέατος</span> _lowest_. For <span lang="grc">ὕστατος</span> Hom. has <span lang="grc">ὑστάτιος</span>; and <span lang="grc">δεύτατος</span> _last_ from <span lang="grc">δεύτερος</span> _second_.

##### <a id="s321"></a> §321

In poetry and sometimes in prose comparatives and superlatives are formed from substantives and pronouns. Hom. has <span lang="grc">βασιλεύτερος</span> _more kingly_, <!-- page 90 --> <span lang="grc">-τατος</span> (<span lang="grc">βασιλεύς</span> _king_), <span lang="grc">ἑταιρότατος</span> _a closest companion_ (<span lang="grc">ἑταῖρος</span> _comrade_), <span lang="grc">κύντερος</span> _more doglike_, <span lang="grc">-τατος</span> (<span lang="grc">κύων</span> _dog_), <span lang="grc">κουρότερος</span> _more youthful_ (<span lang="grc">κοῦρος</span> _a youth_). Aristophanes has <span lang="grc">κλεπτίστατος</span> _most thievish_ (<span lang="grc">κλέπτης</span> _thief_, [317](#s317)), and <span lang="grc">αὐτότατος</span> _his very self, ipsissimus_.

##### <a id="s322"></a> §322

**Double Comparison**.—A double comparative occurs sometimes to produce a comic effect, as <span lang="grc">κυντερώτερος</span> ([321](#s321)). A double superlative is <span lang="grc">πρώτιστος</span>.

##### <a id="s323"></a> §323

**Comparison by** <span lang="grc">μᾶλλον, μάλιστα</span>.—Instead of the forms in <span lang="grc">-τερος, -τατος</span> or <span lang="grc">-ῑων, -ιστος</span> the adverbs <span lang="grc">μᾶλλον</span> _more_, <span lang="grc">μάλιστα</span> _most_, may be used with the positive; as <span lang="grc">μᾶλλον φίλος</span> _more dear, dearer_, <span lang="grc">μάλιστα φίλος</span> _most dear, dearest_. This is the only way of comparing participles and words that do not take the comparative and superlative endings (<span lang="grc">μᾶλλον ἑκών</span> _more willing_).

**a.** Comparison by <span lang="grc">μᾶλλον, μάλιστα</span> is common in the case of compound adjectives, adjectives with a prepositional prefix, verbal adjectives in <span lang="grc">-τός</span>, and adjectives in <span lang="grc">-ιος</span>.

##### <a id="s324"></a> §324

To express _equality_ or _inferiority_ <span lang="grc">οὕτω</span> _as_ (often in correlation with <span lang="grc">ὥσπερ</span>), <span lang="grc">ἧττον</span> _less_, may be placed before the positive. Thus, _as good as handsome_ may be expressed by <span lang="grc">οὕτως ἀγαθὸς ὥσπερ καὶ καλός, ὥσπερ ἀγαθὸς οὕτω καὶ καλός, οὖχ ἧττον καλὸς ἢ καὶ ἀγαθός</span>.
