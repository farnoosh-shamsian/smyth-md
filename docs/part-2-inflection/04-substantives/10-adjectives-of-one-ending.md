# SUBSTANTIVES: ADJECTIVES OF ONE ENDING

##### <a id="s312"></a> §312

Adjectives of one ending have the same termination for masculine and feminine. The neuter (like masc. and fem.) sometimes occurs in oblique cases. Examples: <span lang="grc">ἀγνώς ἀγνῶτ-ος</span> _unknown_ or _unknowing_, <span lang="grc">ἄπαις ἄπαιδ-ος</span> _childless_, <span lang="grc">ἀργής ἀργῆτ-ος</span> _white_, <span lang="grc">ἅρπαξ ἅρπαγ-ος</span> _rapacious_, <span lang="grc">μάκαρ μάκαρ-ος</span> _blessed_, <span lang="grc">ἀκάμᾱς ἀκάμαντ-ος</span> _unwearied_. Here belong also certain other adjectives commonly used as substantives, as <span lang="grc">γυμνής γυμνῆτ-ος</span> _light armed_, <span lang="grc">πένης πένητ-ος</span> _poor_, <span lang="grc">φυγάς φυγάδ-ος</span> _fugitive_, <span lang="grc">ἧλιξ ἥλικ-ος</span> _comrade_, <span lang="grc">ἀλαζών ἀλαζόν-ος</span> _flatterer_. Some are masculine only, as <span lang="grc">ἐθελοντής</span> (<span lang="grc">-οῦ</span>) _uolunteer_. Adj. in <span lang="grc">-ίς -ίδος</span> are feminine only. <span lang="grc">Ἑλληνίς</span> _Greek_, <span lang="grc">πατρίς</span> (_scil_. <span lang="grc">γῆ</span>) _fatherland_, <span lang="grc">συμμαχίς</span> (<span lang="grc">πόλις</span>) _an allied state_.
