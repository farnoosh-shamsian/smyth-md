# SUBSTANTIVES: IRREGULAR DECLENSION

##### <a id="s281"></a> §281

The gender in the singular and in the plural may not be the same: <span lang="grc">ὁ σῖτος</span> _grain_, <span lang="grc">τὰ σῖτα; ὁ δεσμός</span> _chain_, <span lang="grc">τὰ δεσμά</span> _chains_ (<span lang="grc">οἱ δεσμοί</span> _cases of imprisonment_); <span lang="grc">τὸ στάδιον</span> _stade_, _race-course_, pl. <span lang="grc">τὰ στάδια</span> and <span lang="grc">οἱ στάδιοι</span>.

##### <a id="s282"></a> §282

Usually the irregularity consists in a word having two different stems.

**a.** Both stems have a common nominative singular: <span lang="grc">σκότος</span> _darkness_, <span lang="grc">σκότου σκότῳ</span>, etc. (like <span lang="grc">ἵππου ἵππῳ</span>) or <span lang="grc">σκότους σκότει</span> (like <span lang="grc">γένους γένει</span>). So <span lang="grc">τὸν Ἄθω</span>, and <span lang="grc">τὸν Ἄθων</span> from <span lang="grc">Ἄθως</span> ([238 d](04-attic-declension.md#s238)), <span lang="grc">τὸν Σωκράτη</span> and <span lang="grc">τὸν Σωκράτην</span> ([264 b](05-third-declension.md#s264)). These are called _heteroclites_ (<span lang="grc">ἑτερόκλιτα</span> _differently declined_).

N. Many compound proper names in <span lang="grc">-ης</span> (especially names of foreigners) have forms of the 1 and 3 decl., as <span lang="grc">Τισσαφέρνης, -νους, -νῃ</span> and <span lang="grc">-νει</span>. So <span lang="grc">Θεοκρί̄νη</span> (voc.) in Demosth., <span lang="grc">Λεωνίδην</span> and <span lang="grc">Λεωνίδεα</span> in Hdt.

**b.** Certain cases are formed from another stem than that of the nom. singular: <span lang="grc">ὁ ὄνειρο-ς</span> _dream_, gen. <span lang="grc">ὀνείρατ-ος</span> (as if from <span lang="grc">τὸ ὄνειραρ</span>), or (less freq.) <span lang="grc">ὀνείρου</span>; so <span lang="grc">τὸν Ἀπόλλωνα</span> and <span lang="grc">τὸν Ἀπόλλω</span> ([260](05-third-declension.md#s260)), <span lang="grc">τοῦ υἱέος</span> and <span lang="grc">τοῦ υἱοῦ</span> ([285](#s285), [27](../../part-1-letters-sounds-syllables-accent/01-the-letters.md#s27)). These are called _metaplastic_ forms (<span lang="grc">μεταπλασμός</span> _change of formation_).

##### <a id="s283"></a> §283

**Defectives** are substantives having, by reason of their meaning or use, only one number or only certain cases. Thus, sing. only: <span lang="grc">ὁ ἀήρ</span> _air_, <span lang="grc">ὁ αἰθήρ</span> _upper air;_ plur. only: <span lang="grc">τὰ Διονύ̄σια, τὰ Ὀλύμπια</span> _the Dionysiac_ (_Olympic_) _festival_, <span lang="grc">οἱ ἐτησίαι</span> _annual winds;_ in some cases only: <span lang="grc">ὦ μέλε</span> _my good sir_ or _madam;_ <span lang="grc">ὄναρ</span> _dream;_ <span lang="grc">ὄφελος</span> _use_ only in nom.; <span lang="grc">λιβός λίβα</span> from \*<span lang="grc">λίψ</span> _stream_, _libation_.

##### <a id="s284"></a> §284

**Indeclinables** are substantives having one form for all cases: <span lang="grc">τὸ χρεών, τοῦ χρεών</span>, etc. _fatality_, <span lang="grc">τὸ ἄλφα</span> _alpha_, <span lang="grc">τὸ λέγειν</span> _to speak_, most cardinal numbers (<span lang="grc">τὸ δέκα</span> _ten_), several foreign words, as <span lang="grc">Ἰακώβ</span> _Jacob_, <span lang="grc">Δαβίδ</span> _David_. <!-- page 72 -->

##### <a id="s285"></a> §285

**LIST OF THE PRINCIPAL IRREGULAR SUBSTANTIVES**

\1. <span lang="grc"> **Ἄρης** </span> (<span lang="grc">ὁ</span>) _Ares_, stems <span lang="grc">Ἀρεσ-, Ἀρευ-</span> from <span lang="grc">Ἀρες ϝ-</span>. G. <span lang="grc">Ἄρεως</span> (poet. <span lang="grc">Ἄρεος</span>), D. <span lang="grc">Ἄρει</span>, A. <span lang="grc">Ἄρη</span> (poet. <span lang="grc">Ἄρεα</span>), <span lang="grc">Ἄρην</span>. Epic G. <span lang="grc">Ἄρηος, Ἄρεος</span>, D. <span lang="grc">Ἄρηι, Ἄρεϊ</span>, A. <span lang="grc">Ἄρηα, Ἄρην</span>. Hdt. <span lang="grc">Ἄρεος, Ἄρει, Ἄρεα</span>. Aeolic <span lang="grc">Ἄρευς, Ἄρευος</span>, etc.

\2. <span lang="grc"> **ἀρήν** </span> (<span lang="grc">ὁ, ἡ</span>) _lamb_, _sheep_, stems <span lang="grc">ἀρεν-, ἀρν-, ἀρνα-</span>. Thus, <span lang="grc">ἀρν-ός, ἀρν-ί, ἄρν-α, ἄρν-ες, ἀρν-ῶν, ἀρνά-σι</span> (Hom. <span lang="grc">ἄρν-εσσι</span>), <span lang="grc">ἄρν-ας</span> (declined like a subst. in <span lang="grc">-ηρ</span>). Nom. <span lang="grc">ἀρήν</span> occurs on inscript. but <span lang="grc">ἀμνός</span> (2 decl.) is commonly used.

\3. <span lang="grc"> **γάλα** </span> (<span lang="grc">τό</span>) _milk_ ([133](../../part-1-letters-sounds-syllables-accent/04-final-consonants.md#s133)), <span lang="grc">γάλακτ-ος, γάλακτ -ι</span>, etc.

\4. <span lang="grc"> **γέλως** </span> (<span lang="grc">ὁ</span>) _laughter_, <span lang="grc">γέλωτ-ος</span>, etc. Attic poets A. <span lang="grc">γέλωτα</span> or <span lang="grc">γέλων</span>. Hom. has D. <span lang="grc">γέλῳ</span>, A. <span lang="grc">γέλω, γέλων</span> or <span lang="grc">γέλοι</span> (?) from Aeol. <span lang="grc">γέλος</span>. Cp. [257 D](05-third-declension.md#s257).

\5. <span lang="grc"> **γόνυ** </span> (<span lang="grc">τό</span>) _knee_, <span lang="grc">γόνατ-ος</span>, etc. Ionic and poetic <span lang="grc">γούνατ-ος, γούνατ-ι</span>, etc. Epic also <span lang="grc">γουν-ός, γουν-ί, γοῦν-α</span>, pl. <span lang="grc">γούν-ων, γούν-εσσι</span> ([250 D.](05-third-declension.md#s250) 2). The forms in <span lang="grc">ου</span> are from <span lang="grc">γονϝ-</span> ([37 D.](../../part-1-letters-sounds-syllables-accent/01-the-letters.md#s37) 1, 253 c); cf. Lat. _genu._

\6. <span lang="grc"> **γυνή** </span> (<span lang="grc">ἡ</span>) _woman_, <span lang="grc">γυναικ-ός, γυναικ-ί, γυναῖκ-α, γύναι</span> ([133](../../part-1-letters-sounds-syllables-accent/04-final-consonants.md#s133)); dual <span lang="grc">γυναῖκ-ε, γυναικ-οῖν</span>; pl. <span lang="grc">γυναῖκ-ες, γυναικ-ῶν, γυναιξί, γυναῖκ-ας</span>. The gen. and dat. of all numbers accent the last syllable (cp. <span lang="grc">ἀνήρ</span>). Comic poets have A. <span lang="grc">γυνήν, γυνάς</span>, N. pl. <span lang="grc">γυναί</span>.

\7. <span lang="grc"> **δάκρυον** </span> (<span lang="grc">τό</span>) _tear_, <span lang="grc">δακρύου</span>, etc., in prose and poetry. <span lang="grc">δάκρυ</span> (<span lang="grc">τό</span>) is usually poetic, D. pl. <span lang="grc">δάκρυσι</span>.

\8. <span lang="grc"> **δένδρον** </span> (<span lang="grc">τό</span>) _tree_, <span lang="grc">δένδρου</span>, etc. Also D. sing. <span lang="grc">δένδρει</span>, pl. <span lang="grc">δένδρη, δένδρεσι</span>. Hdt. has <span lang="grc">δένδρον, δένδρεον</span> and <span lang="grc">δένδρος</span>.

\9. <span lang="grc"> **δέος** </span> (<span lang="grc">τό</span>) _fear_ (<span lang="grc">δεεσ-</span>), <span lang="grc">δέους, δέει</span>. Hom. <span lang="grc">δείους</span>, 55 D. Cp. [265](05-third-declension.md#s265).

\10. <span lang="grc"> **δόρυ** </span> (<span lang="grc">τό</span>) _spear_, <span lang="grc">δόρατ-ος, δόρατ-ι</span>, pl. <span lang="grc">δόρατ-α</span>, etc. Poetic <span lang="grc">δορ-ός, δορ-ί</span> (also in prose) and <span lang="grc">δόρ-ει</span> (like <span lang="grc">ἄστει</span>). Ionic and poetic <span lang="grc">δούρατ-ος</span>, etc., Epic also <span lang="grc">δουρ-ός δουρ-ί</span>, dual <span lang="grc">δοῦρ-ε</span>, pl. <span lang="grc">δοῦρ-α, δούρ-ων, δούρ-εσσι</span> ([250 D.](05-third-declension.md#s250) 2). The forms with <span lang="grc">ου</span> are from <span lang="grc">δορϝ-</span> ([37 D.](../../part-1-letters-sounds-syllables-accent/01-the-letters.md#s37) 1).

\11. <span lang="grc"> **ἔρως** </span> (<span lang="grc">ὁ</span>) _love_, <span lang="grc">ἔρωτ-ος</span>, etc. Poetical <span lang="grc">ἔρος, ἔρῳ, ἔρον</span>. Cp. [257 D](05-third-declension.md#s257).

\12. <span lang="grc"> **Ζεύς** </span> (<span lang="grc">ὁ</span>) _Zeus_, <span lang="grc">Δι-ός, Δι-ί, Δί-α, Ζεῦ. Ζεύς</span> is from <span lang="grc">Διευς, Δι-ός</span>, etc., from <span lang="grc">Διϝ-</span>. Ionic and poetic <span lang="grc">Ζηνός, Ζηνί, Ζῆνα</span>.

\13. <span lang="grc"> **θέμις** </span> (<span lang="grc">ἡ</span>) _justice_ and the goddess _Themis_ (<span lang="grc">θεμιδ-</span>), <span lang="grc">θέμιδ-ος, θέμιδ-ι, θέμι-ν</span>. Hom. has <span lang="grc">θέμιστ-ος</span>, etc. Pind. <span lang="grc">θέμιτ-ος, θέμι-ν, θέμιτ-ες</span>. Hdt. <span lang="grc">θέμι-ος</span>. In the phrase <span lang="grc">θέμις εἶναι</span> _fas esse_ (indic. <span lang="grc">θέμις ἐστί</span>), <span lang="grc">θέμις</span> is indeclinable.

\14. <span lang="grc"> **κάρᾱ** </span> (<span lang="grc">τό</span>) _head_ (poetic) used in Attic only in N. A. V. sing., but dat. <span lang="grc">κάρᾳ</span>. Other cases are from the stem <span lang="grc">κρᾱτ-</span>, G. <span lang="grc">κρᾱτ-ός</span>, D. <span lang="grc">κρᾱ-τί</span>; also <span lang="grc">τὸ κρᾶτ-α</span> N. A. sing., <span lang="grc">κρᾶτ-ας</span> A. pl.

Epic shows the stems <span lang="grc">κρᾱατ-, κρᾱτ-, καρηατ-, καρητ-</span>. N. <span lang="grc">κάρη</span>, G. <span lang="grc">κρά̄ατος, κρᾱτός, καρήατος, κάρητος</span>, D. <span lang="grc">κρά̄ατι, κρᾱτί, καρήατι, κάρητι</span>, A. <span lang="grc">κάρ</span>. N. pl. <span lang="grc">κάρᾱ, κρά̄ατα, καρήατα</span>, and <span lang="grc">κάρηνα</span>, G. <span lang="grc">κρά̄των, καρήνων</span>, D. <span lang="grc">κρᾱσί</span>, A. <span lang="grc">κρᾶτα</span>.

\15. <span lang="grc"> **κύων·** </span> (<span lang="grc">ὁ, ἡ</span>) _dog_, <span lang="grc">κυν-ός, κυν-ί, κύν-α, κύον; κύν-ε, κυν-οῖν; κύν-ες, κυν-ῶν, κυσί, κύν-ας</span>.

\16. <span lang="grc"> **λᾶας** </span> (<span lang="grc">ὁ</span>) _stone_, poetic also <span lang="grc">λᾶς</span>, G. <span lang="grc">λᾶος</span> (or <span lang="grc">λά̄ου</span>), D. <span lang="grc">λᾶϊ</span>, A. <span lang="grc">λᾶαν, λᾶα</span>; dual <span lang="grc">λᾶε</span>; pl. <span lang="grc">λᾶ-ες, λά̄-ων, λά̄-εσσι, λά̄-εσι</span>.

\17. <span lang="grc"> **μάρτυς** </span> (<span lang="grc">ὁ, ἡ</span>) _witness_, <span lang="grc">μάρτυρ-ος</span>, etc., but D. pl. <span lang="grc">μάρτυ-σι</span>. Hom. has N. <span lang="grc">μάρτυρος</span>, pl. <span lang="grc">μάρτυροι</span>.

\18. <span lang="grc"> **Οἰδίπους** </span> (<span lang="grc"> **ὁ** </span>) _Oedipus_, G. <span lang="grc">Οἰδίποδος, Οἰδίπου, Οἰδιπόδᾱ</span> (Dor.), D. <span lang="grc">Οἰδίποδι</span>, A. <span lang="grc">Οἰδίπουν, Οἰδιπόδᾱν</span>, V. <span lang="grc">Οἰδίπους, Οἰδίπου</span>. <!-- page 73 -->

\19. <span lang="grc"> **ὄνειρος** </span> (<span lang="grc">ὁ</span>) and <span lang="grc">ὄνειρον</span> (<span lang="grc">τό</span>, Ionic and poetic) _dream_, <span lang="grc">ὀνείρου</span>, etc., but also <span lang="grc">ὀνείρατ-ος</span>, etc. <span lang="grc">τὸ ὄναρ</span> only in N. A.

\20. <span lang="grc"> **ὄρνῑς** </span> (<span lang="grc">ὁ, ἡ</span>) _bird_ ([257](05-third-declension.md#s257)). A. <span lang="grc">ὄρνῑθα</span> and <span lang="grc">ὄρνῑν</span> ([247](05-third-declension.md#s247)). Poetic <span lang="grc">ὄρνῐς</span>, A. <span lang="grc">ὄρνῐν</span>; pl. N. <span lang="grc">ὄρνεις</span>, G. <span lang="grc">ὄρνεων</span>, A. <span lang="grc">ὄρνεις</span> or <span lang="grc">ὄρνῑς</span>. Dor. G. <span lang="grc">ὄρνῑχ-ος</span>, etc.

\21. <span lang="grc"> **ὄσσε** </span> dual, _two eyes_, pl. G. <span lang="grc">ὄσσων</span>, D. <span lang="grc">ὄσσοις</span> (<span lang="grc">-οισι</span>).

\22. <span lang="grc"> **οὖς** </span> (<span lang="grc">τό</span>) _ear_, <span lang="grc">ὠτ-ός, ὠτ-ί</span>, pl. <span lang="grc">ὦτ-α, ὤτ-ων</span> ([252 a](05-third-declension.md#s252)), <span lang="grc">ὠσί</span>; from the stem <span lang="grc">ὠτ-</span> contracted from <span lang="grc">οὐ</span>(<span lang="grc">σ</span>)<span lang="grc">ατ-</span>, whence <span lang="grc">ο᾽</span>(<span lang="grc">\[υγλιδε\]</span>)<span lang="grc">ατ-. οὖς</span> is from <span lang="grc">ὀος</span>, whence also the Doric nom. <span lang="grc">ὦς</span>. Hom. G. <span lang="grc">οὔατ-ος</span>, pl. <span lang="grc">οὔατ-α, οὔασι</span> and <span lang="grc">ὠσί</span>.

\23. <span lang="grc"> **Πνύξ** </span> (<span lang="grc">ἡ</span>) _Pnyx_ ([128](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s128)), <span lang="grc">Πυκν-ός, Πυκν-ί, Πύκν-α</span>, and also <span lang="grc">Πνυκ-ός, Πνυκ-ί, Πνύκ-α</span>.

\24. <span lang="grc"> **πρεσβευτής** </span> (<span lang="grc">ὁ</span>) _envoy_ has in the pl. usually the forms of the poetic <span lang="grc">πρέσβυς</span> _old man_, properly an adj., _old_. Thus, N. sing. <span lang="grc">πρεσβευτής</span>, G. <span lang="grc">πρεσβευτοῦ</span>, etc., N. pl. <span lang="grc">πρέσβεις</span>, G. <span lang="grc">πρέσβεων</span>, D. <span lang="grc">πρέσβεσι</span>, A. <span lang="grc">πρέσβεις</span> (rarely <span lang="grc">πρεσβευταί</span>, etc.). <span lang="grc">πρέσβυς</span> meaning _old man_ is poetic in the sing. (A. <span lang="grc">πρέσβυν</span>, V. <span lang="grc">πρέσβυ</span>) and pl. (<span lang="grc">πρέσβεις</span>); meaning _envoy_ <span lang="grc">πρέσβυς</span> is poetic and rare in the sing. (dual <span lang="grc">πρεσβῆ</span> from <span lang="grc">πρεσβεύς</span>). <span lang="grc">πρεσβύ̄της</span> _old man_ is used in prose and poetry in all numbers.

\25. <span lang="grc"> **πῦρ** </span> (<span lang="grc">τό</span>) _fire_ (<span lang="grc">πῠρ-</span>, 254 b), <span lang="grc">πυρ-ός, πυρ-ί</span>, pl. <span lang="grc">τὰ πυρά</span> _watch-fires_, 2nd decl.

\26. <span lang="grc"> **ὕδωρ** </span> (<span lang="grc">τό</span>) _water_, <span lang="grc">ὕδατ-ος, ὕδατ-ι</span>, pl. <span lang="grc">ὕδατ-α, ὑδάτ-ων</span>, etc. Cp. [253 b](05-third-declension.md#s253).

\27. <span lang="grc"> **υἱός** </span> (<span lang="grc">ὁ</span>) _son_ has three stems: 1. <span lang="grc">υἱο-</span>, whence <span lang="grc">υἱοῦ</span>, etc., according to the 2nd decl. 2. <span lang="grc">υἱυ-</span>, whence <span lang="grc">υἱέος, υἱεῖ</span>, dual <span lang="grc">υἱεῖ, υἱέοιν</span>, pl. <span lang="grc">υἱεῖς, υἱέων, υἱέσι, υἱεῖς</span>. The stems <span lang="grc">υἱο-</span> and <span lang="grc">υἱυ-</span>, usually lose their <span lang="grc">ι</span> ([43](../../part-1-letters-sounds-syllables-accent/01-the-letters.md#s43)): <span lang="grc">ὑοῦ, ὑέος</span>, etc. 3. <span lang="grc">υἱ-</span> in Hom. G. <span lang="grc">υἷος</span>, D. <span lang="grc">υἷι</span>, A. <span lang="grc">υἷα</span>, dual <span lang="grc">υἷε</span>, pl. <span lang="grc">υἷες, υἱάσι, υἷας</span>.

\28. <span lang="grc"> **χείρ** </span> (<span lang="grc">ἡ</span>) _hand_, <span lang="grc">χειρ-ός, χειρ-ί, χεῖρ-α</span>; dual <span lang="grc">χεῖρ-ε, χερ-οῖν</span>; pl. <span lang="grc">χεῖρ-ες, χειρ-ῶν, χερ-σί, χεῖρ-ας</span>. Poetic also <span lang="grc">χερ-ός, χερ-ί</span>, etc.; dual, <span lang="grc">χειρ-οῖν</span>. Att. inscr. have <span lang="grc">χειροῖν, χειρσί</span>. Hom. agrees with Att. prose and Hdt. except that he has also <span lang="grc">χερ-ί, χείρ-εσσι χείρ-εσι</span>.

\29. <span lang="grc"> **χρώς** </span> (<span lang="grc">ὁ</span>) _skin_, <span lang="grc">χρωτ-ός, χρωτ-ί</span> (but <span lang="grc">χρῷ</span> in the phrase <span lang="grc">ἐν χρῷ</span>), <span lang="grc">χρῶτα</span>. Poetic <span lang="grc">χρο-ός, χρο-ί̄, χρό-α</span>, like <span lang="grc">αἰδώς</span>, 266.

##### <a id="s285D"></a> §285 D

\27. Hom. has also <span lang="grc">υἱός, υἱοῦ, υἱόν, υἱέ, υἱῶν, υἱοῖσι; υἱέος, υἱέϊ, υἱέα, υἱέες</span> and <span lang="grc">υἱεῖς, υἱέας. υι</span> sometimes makes a short syllable in <span lang="grc">υἱός, υἱόν, υἱέ</span> ([148 D.](../../part-1-letters-sounds-syllables-accent/06-syllables-and-their-quantity.md#s148) 3).
