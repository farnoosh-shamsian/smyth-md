# SUBSTANTIVES: THIRD DECLENSION

##### <a id="s240"></a> §240

This declension includes stems ending in a consonant, in <span lang="grc">ι, υ</span>, or a diphthong, and some in <span lang="grc">ω</span> and <span lang="grc">ο</span>, representing <span lang="grc">ωϝ</span> and <span lang="grc">οι</span>.

N.—To determine whether a noun belongs to the third declension it is necessary in most cases to know the _stem_, which is usually found by dropping <span lang="grc">-ος</span> of the genitive singular. Stems in <span lang="grc">ι</span> and <span lang="grc">υ</span> are classed under the consonant declension because neither of these vowels admits contraction with the case endings beginning with a vowel, herein being like a consonant.

## FORMATION OF CASES: NOMINATIVE SINGULAR

##### <a id="s241"></a> §241

Masculine and feminine stems _not ending in_ <span lang="grc">ν, ρ, ς</span> _and_ <span lang="grc">οντ</span>, add <span lang="grc">ς</span>.

**a.** A labial (<span lang="grc">π, β, φ</span>) + <span lang="grc">ς</span> becomes <span lang="grc">ψ</span> ([97](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s97)).

**b.** A dental (<span lang="grc">τ, δ, θ</span>) + <span lang="grc">ς</span> becomes <span lang="grc">σς</span> ([98](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s98)), which is reduced to <span lang="grc">ς</span> ([107](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s107)).

**c.** A palatal (<span lang="grc">κ, γ, χ</span>) or <span lang="grc">κτ ¨ ς</span> becomes <span lang="grc">ξ</span> ([97](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s97)).

(The same changes occur in the dative plural.)

<span lang="grc">γύ̄ψ</span> _vulture_ <span lang="grc">γῡπ-ός, Ἄραψ</span> _Arab_ <span lang="grc">Ἄραβ-ος; κακότης</span> _baseness_ <span lang="grc">κακότητ-ος, ἐλπίς</span> _hope_ <span lang="grc">ἐλπίδ-ος, ὄρνῑς</span> _bird_ <span lang="grc">ὄρνῑθ-ος; φύλαξ</span> _guard_ <span lang="grc">φύλακ-ος, μάστῐξ</span> _scourge_ <span lang="grc">μάστῑγ-ος, σάλπιγξ</span> _trumpet_ <span lang="grc">σάλπιγγ-ος, ὄνυξ</span> _nail_ <span lang="grc">ὄνυχ-ος, νύξ</span> _night_ <span lang="grc">νυκτ-ός; ἅλ-ς</span> _salt_ <span lang="grc">ἁλ-ός, ἰχθύ̄ς</span> _fish_ <span lang="grc">ἰχθύ-ος; ἐλέφᾱς</span> _elephant_ <span lang="grc">ἐλέφαντ-ος</span>.

##### <a id="s242"></a> §242

Masculine and feminine stems ending in <span lang="grc">ν, ρ</span>, and <span lang="grc">ς</span> reject <span lang="grc">ς</span> and lengthen a preceding vowel if short (<span lang="grc">ε</span> to <span lang="grc">η, ο</span> to <span lang="grc">ω</span>).

<span lang="grc">δαίμων</span> _divinity_ <span lang="grc">δαίμον-ος, χειμών</span> _winter_ <span lang="grc">χειμῶν-ος, λιμήν</span> _harbour_ <span lang="grc">λιμέν-ος, Ἕλλην</span> _Greek_ <span lang="grc">Ἕλλην-ος; ῥήτωρ</span> _orator_ <span lang="grc">ῥήτορ-ος, ἀήρ</span> _air_ <span lang="grc">ἀέρ-ος, φώρ</span> _thief_ <span lang="grc">φωρ-ός</span>, <!-- page 57 --> <span lang="grc">τριήρης</span> _trireme_ (stem <span lang="grc">τριηρεσ-</span>, 263 b), <span lang="grc">αἰδώς</span> _shame_ (stem <span lang="grc">αἰδοσ-</span>, [266](#s266)). On <span lang="grc">μήν</span> see [259](#s259) end. For stems in <span lang="grc">ες</span>, nominative <span lang="grc">-ος</span>, see [263 c](#s263).

##### <a id="s243"></a> §243

Masculine stems in <span lang="grc">οντ</span> drop <span lang="grc">τ</span> ([133](../../part-1-letters-sounds-syllables-accent/04-final-consonants.md#s133)) and lengthen <span lang="grc">ο</span> to <span lang="grc">ω</span>: <span lang="grc">γέρων</span> _old man_ <span lang="grc">γέροντ-ος, λέων</span> _lion_ <span lang="grc">λέοντ-ος</span>.

##### <a id="s243D"></a> §243 D

Hdt. has <span lang="grc">ὀδών</span> _tooth_ <span lang="grc">ὀδόντ-ος</span>. Attic <span lang="grc">ὀδούς</span> has the inflection of a participle in <span lang="grc">-ους</span> ([307](08-declension-of-participles.md#s307)).

##### <a id="s244"></a> §244

Neuters show the pure stem, from which final <span lang="grc">τ</span> and other consonants not standing at the end of a word ([133](../../part-1-letters-sounds-syllables-accent/04-final-consonants.md#s133)) are dropped: <span lang="grc">ἅρμα</span> _chariot_ <span lang="grc">ἅρματ-ος, πρᾶγμα</span> _thing_ <span lang="grc">πρά̄γματ-ος, γάλα</span> _milk_ <span lang="grc">γάλακτ-ος</span> ([133 b](../../part-1-letters-sounds-syllables-accent/04-final-consonants.md#s133)).

##### <a id="s245"></a> §245

**Summary**.—<span lang="grc">ς</span> is added to stems ending in a labial, dental, palatal, and in <span lang="grc">αντ, εντ, υντ</span>; to some stems in <span lang="grc">ν</span> (as <span lang="grc">εἷς</span> _one_ <span lang="grc">ἑν-ός, μέλᾱς</span> _black_ <span lang="grc">μέλαν-ος</span>); to stems in <span lang="grc">ευ, αυ, ου</span>; and to masc. and fem. stems in <span lang="grc">ι</span> and <span lang="grc">υ. ς</span> is not added to most stems ending in <span lang="grc">ν</span>, nor to those in <span lang="grc">οντ, ρ, ες, ας, ος, υ</span> (neut.), <span lang="grc">ω</span>(<span lang="grc">ϝ</span>), <span lang="grc">ο</span>(<span lang="grc">ι</span>).

## ACCUSATIVE SINGULAR

##### <a id="s246"></a> §246

Masculines and feminines usually add <span lang="grc">α</span> to stems ending in a consonant; <span lang="grc">ν</span> to stems ending in <span lang="grc">ι</span> or <span lang="grc">υ</span>.

<span lang="grc">γῦπ-α, ὄνυχ-α, ἐλέφαντ-α, λιμέν-α, ῥήτορ-α, λέοντ-α; πόλι-ν, ἰχθύ̄-ν, βοῦ-ν</span> from <span lang="grc">πόλι-ς</span> _city_, <span lang="grc">ἰχθύ̄-ς</span> _fish_, <span lang="grc">βοῦ-ς</span> _ox_, _cow_. Stems in <span lang="grc">ευ</span> take <span lang="grc">α</span> ([275](#s275)).

##### <a id="s247"></a> §247

Barytone stems of two syllables ending in <span lang="grc">ιτ, ιδ, ῑθ</span> usually drop the dental and add <span lang="grc">ν</span>.

<span lang="grc">χάρις</span> _grace_ (stem <span lang="grc">χαριτ-</span>) <span lang="grc">χάριν, ἔρις</span> _strife_ (<span lang="grc">ἐριδ-</span>) <span lang="grc">ἔριν, ὄρνῑς</span> _bird_ (<span lang="grc">ὀρνῑθ-</span>) <span lang="grc">ὄρνῑν</span>. So <span lang="grc">εὔελπις</span> _hopeful_ (<span lang="grc">εὐελπιδ-</span>) <span lang="grc">εὔελπιν</span> ([292](07-adjectives.md#s292)). Oxytones end in <span lang="grc">α</span>: <span lang="grc">ἐλπίδ-α, σφρᾱγῖδα</span> (<span lang="grc">σφρᾱγί̄ς</span> _seal_).

**a.** <span lang="grc">κλεῖς</span> _key_ (<span lang="grc">κλειδ-</span>), Old Att. <span lang="grc">κλῄς</span>, has <span lang="grc">κλεῖν</span> (late <span lang="grc">κλεῖδα</span>), acc. pl. <span lang="grc">κλεῖς</span> (late <span lang="grc">κλεῖδας</span>).

##### <a id="s247D"></a> §247 D

The acc. in <span lang="grc">α</span> (<span lang="grc">χάριτα, ἔριδα, ὄρνῑθα</span>) occurs in Hom., Hdt., and in Attic poetry. So <span lang="grc">κόρυθα</span> and <span lang="grc">κόρυν</span> (<span lang="grc">κόρυς</span> _helmet_) in Hom.

## VOCATIVE SINGULAR

##### <a id="s248"></a> §248

The vocative of masculines and feminines is usually the pure stem.

<span lang="grc">πόλι</span> (<span lang="grc">πόλι-ς</span> _city_), <span lang="grc">βοῦ</span> (<span lang="grc">βοῦ-ς</span> _ox_, _cow_), <span lang="grc">Σώκρατες</span> (<span lang="grc">Σωκράτης</span>). Stems in <span lang="grc">ιδ</span> and <span lang="grc">ντ</span> cannot retain final <span lang="grc">δ</span> and <span lang="grc">τ</span> ([133](../../part-1-letters-sounds-syllables-accent/04-final-consonants.md#s133)), hence <span lang="grc">Ἄρτεμι</span> from <span lang="grc">Ἄρτεμις</span> (<span lang="grc">Ἀρτεμιδ-</span>), <span lang="grc">παῖ</span> from <span lang="grc">παῖς</span> _boy_, _girl_ (<span lang="grc">παιδ-</span>), <span lang="grc">νεᾶνι</span> from <span lang="grc">νεᾶνις</span> _maiden_ (<span lang="grc">νεᾱνιδ-</span>); <span lang="grc">γέρον</span> from <span lang="grc">γέρων</span> _old man_ (<span lang="grc">γεροντ-</span>), <span lang="grc">γίγαν</span> from <span lang="grc">γίγᾱς</span> _giant_ (<span lang="grc">γιγαντ-</span>).

##### <a id="s249"></a> §249

The vocative is the same as the nominative:

**a.** In stems ending in a stop ([16](../../part-1-letters-sounds-syllables-accent/01-the-letters.md#s16)) consonant (except those in <span lang="grc">ιτ, ιδ, ῑθ; ντ</span> in nouns): <span lang="grc">ὦ φύλαξ</span> _watchman_. (<span lang="grc">Αἴᾱς</span> _Ajax_ (<span lang="grc">Αἰαντ-</span>) is nom. and voc.) <!-- page 58 -->

**b.** In oxytone stems ending in a liquid and not taking <span lang="grc">ς</span> to form their nominative ([242](#s242)): <span lang="grc">ὦ ποιμήν</span> _shepherd_ (<span lang="grc">ποιμεν-</span>); but <span lang="grc">ἀνήρ</span> _man_, <span lang="grc">πατήρ</span> _father_ have <span lang="grc">ἄνερ, πάτερ</span> ([262](#s262)). Barytones use the stem as the vocative: <span lang="grc">δαῖμον, ῥη̈τορ</span> from <span lang="grc">δαίμων</span> _divinity_, <span lang="grc">ῥήτωρ</span> _orator_.

**c.** In all participles.

##### <a id="s249D"></a> §249 D

Hom. has <span lang="grc">ἄνα</span> _oh king_ as well as <span lang="grc">ἄναξ</span> (<span lang="grc">ἀνακτ-</span>); <span lang="grc">Αἶαν</span> from <span lang="grc">Αἰαντ-. Πουλυδάμᾱ, Λᾱοδάμᾱ</span> (from stems in <span lang="grc">αντ</span>) are later forms due to analogy.

## DATIVE DUAL AND PLURAL

##### <a id="s250"></a> §250

The dative plural adds <span lang="grc">-σι</span> to the stem.

<span lang="grc">Ἄραψ</span> (<span lang="grc">Ἀραβ-</span>) <span lang="grc">Ἄραψι, μάστῐξ</span> (<span lang="grc">μαστῑγ-</span>) <span lang="grc">μάστιξι, φύλαξ</span> (<span lang="grc">φυλακ-</span>) <span lang="grc">φύλαξι, σῶμα</span> (<span lang="grc">σωματ-</span>) <span lang="grc">σώμασι</span> ([98](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s98)), <span lang="grc">ἐλπίς</span> (<span lang="grc">ἐλπιδ-</span>) <span lang="grc">ἐλπίσι</span> ([98](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s98)), <span lang="grc">ὄρνῑς</span> (<span lang="grc">ὀρνῑθ-</span>) <span lang="grc">ὄρνῑσι</span> ([98](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s98)), <span lang="grc">ἐλέφᾱς</span> (<span lang="grc">ἐλεφαντ-</span>) <span lang="grc">ἐλέφᾱσι, θήρ</span> (<span lang="grc">θηρ-</span>) <span lang="grc">θηρσί</span>.

**a.** Stems in <span lang="grc">ντ</span> drop <span lang="grc">ντ</span> and lengthen the preceding vowel ([100](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s100)): <span lang="grc">λέων</span> (<span lang="grc">λεοντ-</span>) <span lang="grc">λέουσι, γίγᾱς</span> (<span lang="grc">γιγαντ-</span>) <span lang="grc">γίγᾱσι</span>.

**b.** Stems in <span lang="grc">ν</span> drop <span lang="grc">ν</span> without lengthening the preceding vowel (if short): <span lang="grc">δαίμων</span> (<span lang="grc">δαιμον-</span>) <span lang="grc">δαίμοσι, ποιμήν</span> (<span lang="grc">ποιμεν-</span>) <span lang="grc">ποιμέσι, φρήν</span> _mind_ (<span lang="grc">φρεν-</span>) <span lang="grc">φρεσί</span>.

N.—Strictly <span lang="grc">ν</span> is not dropped, but since the stem of the dat. pl. is weak in form ([253 a](#s253)) the <span lang="grc">ν</span> stood originally between two consonants and should become <span lang="grc">α</span> ([35 b](../../part-1-letters-sounds-syllables-accent/01-the-letters.md#s35)). Thus, <span lang="grc">φρασί</span> in Pindar is for <span lang="grc">φρṇσι</span>. Attic <span lang="grc">φρεσί</span> borrows its <span lang="grc">ε</span> from <span lang="grc">φρένες, φρενῶν</span>, etc. So <span lang="grc">ποιμέσι</span>, for <span lang="grc">ποιμασι</span> from <span lang="grc">ποιμṇσι</span>, because of <span lang="grc">ποιμένες</span>, etc.

**c.** <span lang="grc">ρς</span> is not changed to <span lang="grc">ρρ</span> ([79 a](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s79)).

##### <a id="s250D"></a> §250 D

\1. Hom. has only <span lang="grc">-οιιν</span> in the gen. and dat. dual.

\2. In the dat. pl. Hom. has <span lang="grc">-σι</span> (<span lang="grc">βέλεσ-σι, δέπασ-σι</span>), and in a few cases <span lang="grc">-εσι</span>, reduced from <span lang="grc">-εσσι</span> (<span lang="grc">ἀνάκτ-εσι</span>); <span lang="grc">-σσι</span> occurs after vowels (<span lang="grc">γένυ-σσι</span>; for <span lang="grc">γένῡσι</span>?). <span lang="grc">-εσσι</span> was added both to stems not ending in <span lang="grc">ς</span> (<span lang="grc">πόδ-εσσι, βό-εσσι, ἄνδρ-εσσι, ὀΐ-εσσι</span>, 274 D.), and even to stems in <span lang="grc">ς</span> (<span lang="grc">έπέ-εσσι</span>). Hom. has also <span lang="grc">ποσσί, ποσί</span>; Pind. <span lang="grc">χαρίτεσσι, θέμισσι</span>. Tragedy has this <span lang="grc">-εσσι</span> (<span lang="grc">κορύθ-εσσι</span>), and so Aeolic, and the Doric of Corinth.

## ACCUSATIVE PLURAL

##### <a id="s251"></a> §251

**a.** The ending <span lang="grc">-ας</span> is produced by adding <span lang="grc">νς</span> to the stem (<span lang="grc">ν</span> becoming <span lang="grc">α</span> between two consonants by 35 b). Thus <span lang="grc">φύλακ-ας</span> is from <span lang="grc">φυλακ-ṇς</span>. This <span lang="grc">-ας</span> may be added even to <span lang="grc">ι</span> and <span lang="grc">υ</span> stems: Hom. <span lang="grc">πόλι-ας, ἰχθύ-ας</span>, Hdt. <span lang="grc">πήχε-ας</span>. Hom. <span lang="grc">πόλῑς</span> is from <span lang="grc">πόλι-νς</span> (Cretan).

**b.** The nominative pl. masc. or fem. is sometimes used instead of the accusative pl.: <span lang="grc">τριήρεις</span> 264, <span lang="grc">πόλεις</span> and <span lang="grc">πήχεις</span> 268.

## ACCENT, STEM FORMATION, QUANTITY, GENDER

##### <a id="s252"></a> §252

**Accent**.—Stems of one syllable accent the case ending in the genitive and dative of all numbers; and <span lang="grc">-ων</span> and <span lang="grc">-οιν</span> take the circumflex accent. Thus, <span lang="grc">φλέψ</span> _vein_, <span lang="grc">φλεβ-ός, φλεβ-ῶν; θήρ</span> _wild beast_, <span lang="grc">θηρ-ός, θηρ-οῖν, θηρ-ῶν; θρίξ</span> _hair_, <span lang="grc">τριχ-ός, τριχ-ῶν</span>.

**a.** Exceptions. The ending of the gen. dual and pl. is not accented in the case of <span lang="grc">ὁ, ἡ παῖς</span> _boy_, _girl_, <span lang="grc">ὁ δμώς</span> _slave_, <span lang="grc">ὁ θώς</span> _jackal_, <span lang="grc">ὁ Τρώς</span> _Trojan_, <span lang="grc">ἡ δᾴς</span> _torch_, <!-- page 59 --> <span lang="grc">τὸ φῶς</span> _light_, <span lang="grc">τὸ οὖς</span> _ear_. Thus, <span lang="grc">παίδων</span> (but <span lang="grc">παισί</span>), <span lang="grc">Τρώων, ὤτων</span>, etc. So <span lang="grc">ὤν</span> _being_, <span lang="grc">ὄντων</span> ([305](08-declension-of-participles.md#s305)).

**b.** A trisyllabic form, if contracted, does not show the accent on the case ending: <span lang="grc">ἦρ-ος</span> for <span lang="grc">ἔαρ-ος, ἦρ-ι</span> for <span lang="grc">ἔαρ-ι</span>, from <span lang="grc">τὸ ἔαρ</span> _spring_.

##### <a id="s253"></a> §253

**Variation of Stem Formation**.—Many words of the third declension show traces of an original variation of stem that is due to the influence of a shifting accent which is seen in some of the cognate languages. In Greek this variation has often been obscured by the analogy of other forms. Thus <span lang="grc">πατέρων</span>, in comparison with Hom. <span lang="grc">πατρῶν</span>, Lat. _patrum_, gets its <span lang="grc">ε</span> from <span lang="grc">πατέρες</span>.

**a.** Variation of stem is seen in <span lang="grc">ων, ον</span> ([259](#s259)); <span lang="grc">ηρ, ερ, ρα</span> ([262](#s262)); <span lang="grc">ης, εσ-</span> ([264](#s264)); in stems in <span lang="grc">ι, ει</span> ([270](#s270)); <span lang="grc">υ, ευ</span> ([270](#s270)); <span lang="grc">ευ, ηυ</span> ([278](#s278)); <span lang="grc">οι, ω</span> ([279](#s279)), etc. Words in <span lang="grc">ων, ην</span> show a middle form <span lang="grc">ον, εν</span>, and a weak form in <span lang="grc">ν</span> ([250](#s250) N.).

**b.** Several words ending in <span lang="grc">ρ</span> show a parallel stem in <span lang="grc">τ</span>; thus, <span lang="grc">ὕδωρ</span> _water_ <span lang="grc">ὕδατ-ος, ἧπαρ</span> _liver_ <span lang="grc">ἥπατ-ος, φρέᾱρ</span> _tank_ <span lang="grc">φρέᾱτ-ος</span> (but poet. <span lang="grc">δάμᾱρ</span> _wife_ <span lang="grc">δάμαρτ-ος</span>). The reason for this change is uncertain, but <span lang="grc">ατ</span> is derived from <span lang="grc">ντ</span> after a consonant ([35 b](../../part-1-letters-sounds-syllables-accent/01-the-letters.md#s35)): <span lang="grc">ὑδντος, ἡπντος</span>, cp. Lat. _jecinoris_, nom. _jecur_. <span lang="grc">ἧπαρ</span> is probably derived from <span lang="grc">ἡπαρτ</span> ([133](../../part-1-letters-sounds-syllables-accent/04-final-consonants.md#s133)).

**c.** <span lang="grc">-ατος</span> was transferred from such genitives as <span lang="grc">ὀνόματος, ἥπατος</span> to other neuter words: <span lang="grc">γόνατος</span> from <span lang="grc">γόνυ</span> _knee_, instead of <span lang="grc">γονϝ-ος</span>, whence Hom. <span lang="grc">γουνός. φῶς</span> _light_, for <span lang="grc">φάος</span> (stem <span lang="grc">φαεσ-</span>), has taken on the <span lang="grc">τ</span> inflection (<span lang="grc">φωτ-ός</span>, etc.).

**d.** Neuter stems in <span lang="grc">-ες</span> show <span lang="grc">-ος</span> in the nominative. Cp. <span lang="grc">ἔτος</span> _year_ (stem <span lang="grc">ἐτεσ-</span>) with Lat. _vetus_, _veter-is_ (for _vetes-is_).

##### <a id="s254"></a> §254

**Variation of Quantity**.—**a.** In poetry the quantity of <span lang="grc">ι</span> in words in <span lang="grc">-ις</span> may differ from that of prose; as in tragedy <span lang="grc">ὄρνῐς</span> _bird_, <span lang="grc">κόνῑς</span> _dust_, <span lang="grc">ὄφῑς</span> _serpent_ (in prose <span lang="grc">ὄρνῑς, κόνῐς, ὄφῐς</span>); so in Pind. <span lang="grc">ἰχθύ̆ς</span> (prose <span lang="grc">ἰχθύ̄ς</span>) _fish_.

**b.** <span lang="grc">κῆρῠξ</span> _herald_, <span lang="grc">Φοῖνῐξ</span> _Phoenician_, <span lang="grc">μάστῐξ</span> _whip_ have long <span lang="grc">υ</span> and <span lang="grc">ι</span> in the oblique cases except the dat. pl. (<span lang="grc">κήρῡκος, Φοίνῑκι, μάστῑγα</span>, etc.). <span lang="grc">ἀλώπηξ</span> _fox_ has <span lang="grc">ε</span> in the gen. <span lang="grc">ἀλώπεκος</span>, etc., by analogy to such words as <span lang="grc">ποιμήν, ποιμένος</span> (<span lang="grc">ἀλωπήκων</span> occurs in Ionic). <span lang="grc">πῦρ</span> _fire_ has <span lang="grc">πῠρός, πῠρί</span>, etc. ([285](06-irregular-declension.md#s285), [25](../../part-1-letters-sounds-syllables-accent/01-the-letters.md#s25)).

Hom. has <span lang="grc">ἄνδρεσσι</span> and <span lang="grc">ἀνδράσι</span> (with <span lang="grc">-ασι</span> only in this word), <span lang="grc">Δήμητρος</span> and <span lang="grc">Δημήτερος</span>.

## STEMS IN SIGMA (<span lang="grc">ες, ας, οσ</span>)

##### <a id="s263"></a> §263

Stems in sigma are contracted where <span lang="grc">ς</span> falls out between the vowel of the stem and the vowel of the ending ([120](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s120)). Thus, <span lang="grc">γένος</span> _race_, gen. <span lang="grc">γενε</span>(<span lang="grc">σ</span>)<span lang="grc">-ος γένους</span>, dat. <span lang="grc">γενε</span>(<span lang="grc">σ</span>)<span lang="grc">-ι γένει</span>, cp. Lat. _genus gener-is_ (for _genes-is_), _gener-i_.

**a.** The masculine and feminine accusative plural, when it is contracted, borrows the form of the contracted nominative plural. <span lang="grc">-εις</span> is not derived from <span lang="grc">-εας</span>. In the dative plural the union of <span lang="grc">ς</span> of the stem and <span lang="grc">ς</span> of the ending produces <span lang="grc">σς</span>, which is reduced to <span lang="grc">ς</span> without lengthening the preceding vowel ([107](../../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s107)).

**b.** Masculine stems in <span lang="grc">ες</span> with the nominative in <span lang="grc">-ης</span> are proper names; the feminine <span lang="grc">τριήρης</span> _trireme_ is an adjective used substantively (properly, _triply fitted;_ <span lang="grc">ἡ τριήρης</span> (<span lang="grc">ναῦς</span>) ‘ship with three banks of oars’).

**c.** Neuters with stems in <span lang="grc">ες</span> have <span lang="grc">-ος</span> in the nominative, accusative, and vocative singular; neuters with stems in <span lang="grc">ας</span> have <span lang="grc">-ας</span> in these cases.

**d.** Some stems in <span lang="grc">ας</span> have also a stem in <span lang="grc">ατ</span> or <span lang="grc">ᾱτ</span> ([258](#s258)). <!-- page 65 -->

This <span lang="grc">ᾳ</span> may possibly be due to the analogy of <span lang="grc">ᾳ</span> in <span lang="grc">ᾱ</span> stems.

##### <a id="s264D"></a> §264 D

\1. Hom. uses the open or the closed forms according to convenience. <span lang="grc">-ευς</span> occurs in the gen. of a few words in <span lang="grc">-ος</span> (<span lang="grc">βέλευς</span>); <span lang="grc">-εων</span> is often a monosyllable ([60](../../part-1-letters-sounds-syllables-accent/02-euphony-of-vowels.md#s60)), as is the accus. sing. and pl. <span lang="grc">-εα</span> from nom. <span lang="grc">-ης</span> or <span lang="grc">-ος</span>. Hdt. has open <span lang="grc">-εος, -εα, -εες</span> (?), <span lang="grc">-εα</span>. In the dat. pl. Hom. has <span lang="grc">βέλεσσι, βέλεσι</span>, and <span lang="grc">βελέεσσι</span> ([250 D.](#s250) 2) from <span lang="grc">βέλος</span> _missile_.

\2. Stems in <span lang="grc">ας</span> are generally uncontracted in Hom. (<span lang="grc">γήραος, γήραϊ</span>), but we find <span lang="grc">-αι</span> in the dat. sing., <span lang="grc">κρεῶν</span> and <span lang="grc">κρειῶν</span> in the gen. pl. In the nom. and acc. pl. <span lang="grc">α</span> is short (<span lang="grc">γέρᾰ</span>), and this is sometimes the case even in Attic poetry (<span lang="grc">κρέᾰ</span>). The explanation is obscure (<span lang="grc">γέρᾰ</span> does not stand for <span lang="grc">γέρα᾽</span>). Hom. has <span lang="grc">δέπασσι</span> and <span lang="grc">δεπάεσσι</span> (<span lang="grc">δέπας</span> _cup_).

\3. In Hom. and Hdt. several words in <span lang="grc">-ας</span> show <span lang="grc">ε</span> for <span lang="grc">α</span> before a vowel (cp. <span lang="grc">ὁρέω</span> in Hdt. for <span lang="grc">ὁράω</span>). Hom.: <span lang="grc">οὖδας</span> _ground_, <span lang="grc">οὔδεος, οὔδεϊ</span> and <span lang="grc">οὔδει; κῶας</span> _fleece_, <span lang="grc">κώεα, κώεσι</span>; Hdt.: <span lang="grc">γέρας, γέρεος</span>, but <span lang="grc">κρέας, κρέως, κρεῶν</span>. In Attic poetry: <span lang="grc">βρέτας</span> _image_, <span lang="grc">βρέτεος, βρέτει</span>, etc. Cp. [258 D](#s258). <!-- page 66 -->

## STEMS IN <span lang="grc">ος</span>

##### <a id="s266"></a> §266

<span lang="grc">ἡ αἰδώς</span> _shame_ is the only <span lang="grc">ος</span> stem in Attic. It is inflected in the singular only. Nom. <span lang="grc"> **αἰδώς** </span>, Gen. <span lang="grc"> **αἰδοῦς** </span> (<span lang="grc">αἰδό-ος</span>), Dat. <span lang="grc"> **αἰδοῖ** </span> (<span lang="grc">αἰδό-ι</span>), Acc. <span lang="grc"> **αἰδῶ** </span> (<span lang="grc">αἰδό-α</span>), Voc. <span lang="grc"> **αἰδώς** </span>.

##### <a id="s266D"></a> §266 D

Hom. and Ion. <span lang="grc">ἡ ἠώς</span> _dawn_ (<span lang="grc">ἠοσ-</span>) is inflected like <span lang="grc">αἰδώς</span>. For <span lang="grc">αἰδοῦς, ἠῶ</span> we may read <span lang="grc">αἰδόος, ἠόα</span> and some other open forms in Hom. The Attic form <span lang="grc">ἕως</span> is declined according to 238; but the accus. is <span lang="grc">ἕω</span> ([238 d](04-attic-declension.md#s238)). Hom. has <span lang="grc">ἱδρόα</span> from <span lang="grc">ἱδρώς</span> _sweat_ (usually a <span lang="grc">τ</span> stem). Cp. [257 D](#s257).

##### <a id="s268D"></a> §268 D

\1. <span lang="grc"> **ι** </span> stems. **a.** Doric, Aeolic, and New Ionic retain the <span lang="grc">ι</span> stem without variation in all cases: <span lang="grc">πόλις, πόλιος, πόλῑ</span> (from <span lang="grc">πολι-ι</span>) and rarely <span lang="grc">πόλει</span> in Hdt., <span lang="grc">πόλιν, πόλι, πόλιες, πολίων, πόλισι, πόλῑς</span> from <span lang="grc">πόλινς</span> (Cretan), and <span lang="grc">πόλιας</span>.

**b.** Hom. has <span lang="grc">πόλις, πόλιος, πόλῑ, πόλει</span> or <span lang="grc">-ιϊ</span> (for which some read <span lang="grc">πόλῑ</span>, as <span lang="grc">κόνῑ; πόσεϊ</span> is correct) and <span lang="grc">πτόλεϊ, πόλιν, πόλι</span>; pl. <span lang="grc">πόλιες, πολίων, πόλεσι</span> (some read instead <span lang="grc">πόλισι</span>) or <span lang="grc">πολίεσσι</span> ([250 D.](#s250) 2) <span lang="grc">ἐπάλξεσιν, πόλῑς</span> or <span lang="grc">πόλιας</span> (<span lang="grc">πόλεις</span> appears in some texts).

**c.** Hom. has also forms with <span lang="grc">η</span>: <span lang="grc">πόληος, πόληι, πόληες, πόληας</span>.

\2. <span lang="grc"> **υ** </span> stems. **a.** Ionic, Doric, and Aeolic have the open forms <span lang="grc">πήχεες, ἄστεϊ, ἄστεα</span>; in the gen. sing. <span lang="grc">-ος</span>, never <span lang="grc">-ως</span> (<span lang="grc">πήχεος, ἄστεος</span>). In the dat. sing. of words of more than one syllable Hom. has <span lang="grc">-υϊ</span> or <span lang="grc">-υι</span>, as <span lang="grc">νέκυι</span> (<span lang="grc">νέκυς</span> _corpse_), but Hdt. does not show <span lang="grc">-υι</span>.

**b.** The gen. pl. has the regular accent (<span lang="grc">πηχέων, ἀστέων</span>). On the dat. <span lang="grc">πελέκεσσι, νέκυσσι, πίτυσσι</span> (some would read <span lang="grc">νέκῡσι, πίτῡσι</span>), <span lang="grc">νεκύεσσι</span>, see [250 D](#s250). 2. Hom. has accus. <span lang="grc">ἰχθῦς</span> and <span lang="grc">ἰχθύας</span>, Hdt. has <span lang="grc">ἰχθύας</span> very rarely. <!-- page 68 -->

##### <a id="s269"></a> §269

**Stems in <span lang="grc">ι</span> and <span lang="grc">υ</span> are of two kinds**:—

\1. **a.** Stems in <span lang="grc">ι</span>, with genitive in <span lang="grc">-εως</span>, as (masc.) <span lang="grc">μάντις</span> _seer_, <span lang="grc">ἔχις</span> _viper;_ (fem.) <span lang="grc">πόλις</span> _city_, <span lang="grc">ποίησις</span> _poetry_, <span lang="grc">δύναμις</span> _power_, <span lang="grc">στάσις</span> _faction_, <span lang="grc">ὕβρις</span> _outrage_. Neuter nominatives in <span lang="grc">-ι</span> are not used in classical prose.

**b.** Stems in <span lang="grc">ι</span>, with genitive in <span lang="grc">-ιος</span>, as <span lang="grc">ὁ κί̄ς</span> _weevil_, gen. <span lang="grc">κῑ-ός</span>, dat. <span lang="grc">κῑ-ί</span>; and so in proper names in <span lang="grc">-ις</span>, as <span lang="grc">Λύγδαμις</span> _Lygdamis_, gen. <span lang="grc">Λυγδάμιος</span>.

\2. **a.** Stems in <span lang="grc">υ</span>, with genitive in <span lang="grc">-υος</span>; as (masc.) <span lang="grc">μῦς</span> _mouse_, <span lang="grc">βότρυς</span> _cluster of grapes_, <span lang="grc">ἰχθύ̄ς</span> _fish;_ (fem.) <span lang="grc">δρῦς</span> _oak_, <span lang="grc">ὀφρύ̄ς</span> _eyebrow_, <span lang="grc">ἰσχύ̄ς</span> _force_.

**b.** Stems in <span lang="grc">υ</span>, with genitive in <span lang="grc">-εως</span>: (masc.) <span lang="grc">πῆχυς</span> _forearm_, <span lang="grc">πέλεκυς</span> _axe;_ (neut.) <span lang="grc">ἄστυ</span> _town_.

N. 1.—In the nom., acc., and voc. sing. barytone stems in <span lang="grc">υ</span> have short <span lang="grc">υ</span>; oxytone substantives (usually) and monosyllables have <span lang="grc">ῡ</span>; and monosyllables circumflex the <span lang="grc">ῡ</span> (<span lang="grc">σῦς, σῦν, σῦ</span>).

N. 2.—<span lang="grc">ἡ ἔγχελυς</span> _eel_ follows <span lang="grc">ἰχθύ̄ς</span> in the singular (<span lang="grc">ἐγχέλυ-ος</span>, etc.), but <span lang="grc">πῆχυς</span> in the plural (<span lang="grc">ἐγχέλεις</span>, etc.). But this does not hold for Aristotle.

##### <a id="s270"></a> §270

Stems in <span lang="grc">ι</span> and <span lang="grc">υ</span> vary with stronger stems, of which <span lang="grc">ε</span> in the cases other than nom., acc., and voc. sing. is a survival. Thus:

**a.** <span lang="grc">ι, υ</span>, as in <span lang="grc">πόλι-ς, πῆχυ-ς</span>.

**b.** <span lang="grc">ει, ευ</span>, which before vowels lost their <span lang="grc">ι</span> and <span lang="grc">υ</span> ([43](../../part-1-letters-sounds-syllables-accent/01-the-letters.md#s43)), as in <span lang="grc">πολε</span>(<span lang="grc">\[ιγλιδε\]</span>)<span lang="grc">-ι, πολε</span>(<span lang="grc">\[ιγλιδε\]</span>)<span lang="grc">-ες, πηχε</span>(<span lang="grc">\[υγλιδε\]</span>)<span lang="grc">-ες</span>; which contract to <span lang="grc">πόλει, πόλεις, πήχεις</span>.

**c.** There is also a stem in <span lang="grc">η</span>, as in Hom. <span lang="grc">πόλη-ος</span> ([268 D.](#s268) 1, c), whence <span lang="grc">πόλε-ως</span>.

N. 1.—<span lang="grc">πόλε-ος</span> in Attic poetry for the sake of the metre is due to the analogy of <span lang="grc">υ</span> stems with gen. in <span lang="grc">-ε-ος</span> (<span lang="grc">ἡδέ-ος</span>, [297](07-adjectives.md#s297)). Hom. <span lang="grc">πήχε-ος</span> is the regular form (from <span lang="grc">πηχε</span>(<span lang="grc">\[υγλιδε\]</span>)<span lang="grc">-ος</span>). Attic <span lang="grc">πήχε-ως</span> follows <span lang="grc">πόλεως. πόλε-σι</span> and <span lang="grc">πήχε-σι</span> for <span lang="grc">πόλι-σι</span> and <span lang="grc">πήχυ-σι</span> are due to the analogy of forms from stems in <span lang="grc">ει, ευ</span> (<span lang="grc">πόλε-ων, πήχε-ων</span>, etc.).

N. 2.—The dual <span lang="grc">πόλεε</span> occurs in some Mss.

##### <a id="s271"></a> §271

**Accent**.—Final <span lang="grc">-ως</span> of the genitive singular does not prevent the acute from standing on the antepenult ([163 a](../../part-1-letters-sounds-syllables-accent/07-accent-general-principles.md#s163)). Thus <span lang="grc">πόλε-ως, πήχε-ως, ἄστε-ως. πόλε-ως</span> retains the accent of the earlier <span lang="grc">πόλη-ος</span>, which, by transference of quantity ([34](../../part-1-letters-sounds-syllables-accent/01-the-letters.md#s34)), became <span lang="grc">πόλε-ως</span>. The accent of the gen. pl. follows that of the gen. sing.

##### <a id="s272"></a> §272

**Accusative plural**.—<span lang="grc">πόλεις, πήχεις</span> are borrowed from the nominative. <span lang="grc">ἰχθῦς</span> is from <span lang="grc">ἰχθυν-ς. ἰχθύας</span> occurs in late Greek. Cp. [251 a](#s251). <!-- page 69 -->

##### <a id="s273"></a> §273

**Contraction**.—<span lang="grc">ἰχθῦ</span> (once) for <span lang="grc">ἰχθύε</span> and <span lang="grc">ἰχθῦς</span> for <span lang="grc">ἰχθύες</span> occur in comedy. <span lang="grc">ἰχθῦ</span> is not a legitimate contraction, as <span lang="grc">υ</span> cannot contract with <span lang="grc">ε</span> ([51 c](../../part-1-letters-sounds-syllables-accent/02-euphony-of-vowels.md#s51)). <span lang="grc">ἰχθῦς</span> (for <span lang="grc">ἰχθύες</span>) is the accus. form used as the nom. ([251 b](#s251)).

##### <a id="s274"></a> §274

<span lang="grc"> **οἶς** </span> _sheep_ is declined as follows: <span lang="grc">οἶς, οἰ-ός, οἰ-ι´, οἶ-ν, οἶ</span>; dual, <span lang="grc">οἶ-ε, οἰ-οῖν</span>; pl. <span lang="grc">οἶ-ες, οἰ-ῶν, οἰ-σί, οἶ-ς</span>. Here the stem is <span lang="grc">οι᾽</span>, representing <span lang="grc">ὀϝι</span>, which is properly an <span lang="grc">ι</span> stem: <span lang="grc">ὀϝι-ς</span>, Lat. _ovi-s_.

##### <a id="s274D"></a> §274 D

Hom. has <span lang="grc">ὄϊς, ὀΐος</span> and <span lang="grc">οἰός, ὄϊν, ὄϊες, ὀΐων</span> and <span lang="grc">οἰῶν, ὀΐεσσι</span> (<span lang="grc">οἴεσσι ο</span> [386](../09-verbs/00-introduction.md#s386)) and <span lang="grc">ὄεσσι, ὄϊσ</span>(<span lang="grc">ῑ</span>).

##### <a id="s276"></a> §276

Substantives in <span lang="grc">-εύς</span> preceded by a vowel may contract in the gen. and acc. sing. and pl. Thus, <span lang="grc">ἁλιεύς</span> _fisherman_ has gen. <span lang="grc">ἁλιέως</span> or <span lang="grc">ἁλιῶς</span>, acc. <span lang="grc">ἁλιέᾱ</span> or <span lang="grc">ἁλιᾶ</span>, gen. pl. <span lang="grc">ἁλιέων</span> or <span lang="grc">ἁλιῶν</span>, acc. pl. <span lang="grc">ἁλιέᾱς</span> or <span lang="grc">ἁλιᾶς</span>. All other forms are regular. The contracted forms were in use in the fifth century, but in the fourth (especially after 350 B.C.) the open forms are common. So are declined <span lang="grc">Εὐβοεύς</span> _Euboean_ from <span lang="grc">Εὐβοιεύς, Παιραιεύς</span> _Peiraeus_, <span lang="grc">Πλαταιεύς</span> _Plataean_.

##### <a id="s277"></a> §277

**Other Forms**.—**a.** In the drama from words in <span lang="grc">-εύς</span> we find rarely <span lang="grc">-έᾰ</span> in acc. sing., <span lang="grc">-έᾰς</span> in acc. pl. <span lang="grc">-έος</span> and <span lang="grc">-ῆος, -ῆες, -ῆας</span> are occasionally found.

**b.** The nom. pl. in older Attic ended in <span lang="grc">-ῆς</span> (<span lang="grc">βασιλῆς</span>), derived either from <span lang="grc">-ῆες</span> by contraction or from <span lang="grc">-έης</span> (once on an inscription) by 34. <span lang="grc">-ῆς</span> occurs on inscriptions till about 350 B.C., and is the form to be adopted in the texts of authors of the fifth century and in Plato. <span lang="grc">-έες</span> occurs rarely, but is suspected. <span lang="grc">βασιλεῖς</span> (regular on inscriptions after 329 B.C.) is from analogy to <span lang="grc">ἡδεῖς</span>.

**c.** The acc. pl. <span lang="grc">βασιλεῖς</span> was not used till the end of the fourth century. <span lang="grc">-ῆς</span> (the nom. form) is used for the acc. in a few passages ([251 b](#s251)).

##### <a id="s278"></a> §278

**Stem Variation**.—Stems ending in <span lang="grc">ευ, αυ, ου</span> lose <span lang="grc">υ</span> before case endings beginning with a vowel, <span lang="grc">\[υγλιδε\]</span> passing into <span lang="grc">ϝ</span> ([43](../../part-1-letters-sounds-syllables-accent/01-the-letters.md#s43)). Stems in <span lang="grc">ευ</span> show the pure form only in the vocative; other forms are derived from the stronger stem <span lang="grc">ηυ. ηυ</span> and <span lang="grc">ᾱυ</span> before a consonant become <span lang="grc">ευ, ᾰυ</span> ([40](../../part-1-letters-sounds-syllables-accent/01-the-letters.md#s40)) as in <span lang="grc">βασιλεύς, βασιλεῦσι, ναῦς, ναυσί</span> from <span lang="grc">βασιληυς, νᾱυς</span>, etc. From <span lang="grc">βασιλῆ</span>(<span lang="grc">ϝ</span>)<span lang="grc">-ος, -ῆ</span>(<span lang="grc">ϝ</span>)<span lang="grc">-ι, -ῆ</span>(<span lang="grc">ϝ</span>)<span lang="grc">-α, -ῆ</span>(<span lang="grc">ϝ</span>)<span lang="grc">-ας</span> come, by transfer of quantity ([34](../../part-1-letters-sounds-syllables-accent/01-the-letters.md#s34)), the Attic forms. So <span lang="grc">νεώς</span> is derived from <span lang="grc">νη</span>(<span lang="grc">ϝ</span>)<span lang="grc">-ός</span>. In <span lang="grc">βασιλέων, νεῶν, ε</span> is shortened from the <span lang="grc">η</span> of <span lang="grc">βασιλήων, νηῶν</span> by 39. <span lang="grc">βο-ός</span>, etc. are from the stem <span lang="grc">βου- βοϝ-</span>, cp. Lat. _bovis_.

## STEMS IN <span lang="grc">οι</span>

##### <a id="s279"></a> §279

Stems in <span lang="grc">οι</span>, with nominative in <span lang="grc">-ώ</span>, turn <span lang="grc">ι</span> into unwritten <span lang="grc">\[ιγλιδε\]</span> (_y_) ([43](../../part-1-letters-sounds-syllables-accent/01-the-letters.md#s43)) before the endings beginning with a vowel. <span lang="grc">ἡ πειθώ</span> _persuasion_ is thus declined:

N. <span lang="grc"> **πειθώ** </span>. G. <span lang="grc"> **πειθοῦς** </span> (<span lang="grc">πειθό-ος</span>). D. <span lang="grc"> **πειθοῖ** </span> (<span lang="grc">πειθό-ι</span>). A. <span lang="grc"> **πειθώ** </span> (<span lang="grc">πειθό-α</span>). V. <span lang="grc"> **πειθοῖ** </span>. Dual and plural are wanting. <!-- page 71 -->

So <span lang="grc">ἠχώ</span> _echo_, <span lang="grc">εὐεστώ</span> _well-being_, <span lang="grc">φειδώ</span> _sparing_, <span lang="grc">Σαπφώ, Λητώ, Καλυψώ. οι</span> stems are chiefly used for women's names.

**a.** A stronger form of the stem is <span lang="grc">ωι</span>, seen in the earlier form of the nominative (<span lang="grc">Σαπφῴ, Λητῴ</span>). The accusative has the accent of the nominative.

**b.** When dual and plural occur, they are of the second declension: nom. <span lang="grc">λεχοί</span> (late) from <span lang="grc">λεχώ</span> _woman in child-bed_, acc. <span lang="grc">γοργούς</span> from <span lang="grc">γοργώ</span> _gorgon_.

**c.** <span lang="grc">ἡ εἰκών</span> _image_, <span lang="grc">ἡ ἀηδών</span> _nightingale_, properly from stems in <span lang="grc">ον</span>, have certain forms from this declension (<span lang="grc">εἰκοῦς, εἰκώ</span>, voc. <span lang="grc">ἀηδοῖ</span>).

##### <a id="s279D"></a> §279 D

In Ionic the forms are contracted (<span lang="grc">πειθοῦς</span>, etc.). Hdt. has acc. <span lang="grc">Ἰ̄οῦν</span> from <span lang="grc">Ἰ̄ώ, Λητοῦν</span>, but also <span lang="grc">πειθώ</span>.

## CASES IN <span lang="grc">-φι</span>(<span lang="grc">ν</span>)

##### <a id="s280"></a> §280

**Cases in <span lang="grc">-φι</span>**(<span lang="grc"> **ν** </span>).—<span lang="grc">-φι</span>(<span lang="grc">ν</span>) is often added to noun stems in Hom. to express the relations of the lost instrumental, locative, and ablative, both singular and (more commonly) plural; rarely to express the relations of the genitive and dative cases. From <span lang="grc">ᾱ</span> stems are made singulars, from <span lang="grc">ο</span> stems singulars or plurals, from consonant stems almost always plurals. Except in <span lang="grc">θεό-φιν</span> _with the gods_ <span lang="grc">-φι</span>(<span lang="grc">ν</span>) is not added to a stem denoting a person. (_a_) Instrumental: <span lang="grc">βίη-φι</span> _by might_, <span lang="grc">ἑτέρη-φι</span> _with the other_ (_hand_), <span lang="grc">δακρυό-φιν</span> _with tears;_ (_b_) Locative: <span lang="grc">θύρη-φι</span> _at the door_, <span lang="grc">ὄρεσ-φι</span> _on the mountains;_ (_c_) Ablative: <span lang="grc">κεφαλῆ-φιν</span> _from off the head;_ especially with prepositions, as <span lang="grc">ἐκ ποντό-φιν</span> _from off the sea_, <span lang="grc">ἀπὸ ναῦ-φιν</span> _from the ships_.
