# PRONOUNS

##### <a id="s325"></a> §325

**The Personal Pronouns**.—The pronouns of the first, second, and third person are declined as follows:

|  |  |  |  |
| --- | --- | --- | --- |
| SINGULAR |  |  |  |
| Nom. | <span lang="grc"> **ἐγώ** </span> _I_ | <span lang="grc"> **σύ** </span> _thou_ | — _he_, _she_, _it_ ([325 d](#s325)) |
| Gen. | <span lang="grc">**ἐμοῦ**; **μου**</span> enclitic | <span lang="grc">**σοῦ**; **σου**</span> enclitic | <span lang="grc">οὗ; οὑ</span> enclitic |

| Acc. | <span lang="grc">**ἐμέ**; **με**</span> enclitic | <span lang="grc">**σέ**; **σε**</span> enclitic | <span lang="grc">ἕ; ἑ</span> enclitic |

| Dat. | <span lang="grc"> **ἡμῖν** </span> | <span lang="grc"> **ὑ̄μῖν** </span> | <span lang="grc"> **σφίσι** </span>(<span lang="grc"> **ν** </span>) |

<!-- page 91 -->

**a.** The enclitic forms <span lang="grc">μου, μοι, με; σου, σοι, σε</span> are used when the pronoun is unemphatic, the longer forms <span lang="grc">ἐμοῦ, ἐμοί, ἐμέ</span> and the accented <span lang="grc">σοῦ, σοί, σέ</span> are <!-- page 92 --> used when the pronoun is emphatic. Thus, <span lang="grc">δός μοι τὸ βιβλίον</span> _give me the book_, <span lang="grc">οὺκ ἐμοί, ἀλλὰ σοὶ ἐπιβουλεύουσι</span> _they are plotting not against_ me, _but against_ you. See [187 a](../part-1-letters-sounds-syllables-accent/07-accent-general-principles.md#s187). On the use after prepositions see [187](../part-1-letters-sounds-syllables-accent/07-accent-general-principles.md#s187) N. 2.

**b.** For <span lang="grc">ἐγώ, ἐμοί, σύ</span> the emphatic <span lang="grc">ἔγωγε, ἔμοιγε</span> ([186 a](../part-1-letters-sounds-syllables-accent/07-accent-general-principles.md#s186)), <span lang="grc">σύγε</span> occur. Also <span lang="grc">ἐμοῦγε, ἐμέγε</span>.

**c.** The use of the plural _you_ for _thou_ is unknown in Ancient Greek; hence <span lang="grc">ὑ̄μεῖς</span> is used only in addressing more than one person.

**d.** Of the forms of the third personal pronoun only the datives <span lang="grc">οἷ</span> and <span lang="grc">σφίσι</span> (<span lang="grc">ν</span>) are commonly used in Attic prose, and then only as indirect reflexives ([1228](../part-4-syntax/17-pronouns.md#s1228)). To express the personal pronouns of the third person we find usually: <span lang="grc">ἐκεῖνος, οὗτος</span>, etc., in the nominative ([1194](../part-4-syntax/17-pronouns.md#s1194)), and the oblique forms of <span lang="grc">αὐτός</span> in all other cases.

**e.** For the accus. of <span lang="grc">οὗ</span> the tragic poets use <span lang="grc">νιν</span> (encl.) and <span lang="grc">σφε</span> (encl.) for masc. and fem., both sing. and pl. (= _eum_, _eam; eos_, _eas_). Doric so uses <span lang="grc">νιν. σφίν</span> is rarely singular (_ei_) in tragedy.

**f.** <span lang="grc">ἡμῶν, ἡμῖν, ἡμᾶς, ὑ̄μῶν, ὑ̄μῖν, ὑ̄μᾶς</span>, when unemphatic, are sometimes accented in poetry on the penult, and <span lang="grc">-ῑν</span> and <span lang="grc">-ᾱς</span> are usually shortened. Thus, <span lang="grc">ἥμων, ἧμιν, ἧμας, ὕ̄μων, ὗμιν, ὗμας. -ῑν</span> and <span lang="grc">-ᾱς</span> are sometimes shortened even if the pronouns are emphatic, and we have <span lang="grc">ἡμίν, ἡμάς, ὑ̄μίν, ὑ̄μάς. σφάς</span> occurs for <span lang="grc">σφᾶς</span>.

##### <a id="s326"></a> §326

_Stems_.—I. (<span lang="grc">ε᾽</span>) <span lang="grc">με-</span> (cp. Lat. _me_), <span lang="grc">νω-</span> (cp. Lat. <span lang="grc">νο̄-ς</span>), (<span lang="grc">ε᾽</span>)<span lang="grc">μο-, ἡμε-. ἐμοῦ</span> is from <span lang="grc">ἐμέο; ἡμεῖς</span> from <span lang="grc">ἀμμε-ες</span> ([37](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s37)) with the rough breathing in imitation of <span lang="grc">ὑ̄μεῖς; ἡμῶν</span> from <span lang="grc">ἡμέων, ἡμᾶς</span> from <span lang="grc">ἡμέας</span> with <span lang="grc">ᾱ</span> not <span lang="grc">η</span> by 56. <span lang="grc">ἐγώ</span> is not connected with these stems. II. <span lang="grc">συ-</span> and <span lang="grc">σε-</span> from <span lang="grc">τϝε; το-; σφω-; ὑ̄με-</span> from <span lang="grc">ὑμμε-</span> ([37](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s37)). III. <span lang="grc">ἕ</span> for <span lang="grc">σϝε</span> (cp. Lat. _se_), <span lang="grc">ἑέ</span> for <span lang="grc">σεϝε, οἷ</span> for <span lang="grc">σϝο-ι</span>, and <span lang="grc">σφε-</span>. The form of the stems and formation of the cases is often obscure.

##### <a id="s328"></a> §328

<span lang="grc">αὐτός</span> is a definite adjective and a pronoun. It has three meanings:

**a.** _self:_ standing by itself in the nominative, <span lang="grc">αὐτὸς ὁ ἀνήρ</span> or <span lang="grc">ὁ ἀνὴρ αὐτός</span> _the man himself_, or (without the article) in agreement with a substantive or pronoun; as <span lang="grc">ἀνδρὸς αὐτοῦ</span> _of the man himself_. <!-- page 93 -->

**b.** _him_, _her_, _it_, _them_, etc.: standing by itself in an oblique case (never in the nominative). The oblique cases of <span lang="grc">αὐτός</span> are generally used instead of <span lang="grc">οὗ, οἷ, ἕ</span>, etc., as <span lang="grc">ὁ πατὴρ αὐτοῦ</span> _his father_, <span lang="grc">οἱ παῖδες αὐτῶν</span> _their children_.

**c.** _same:_ when it is preceded by the article in any case: <span lang="grc">ὁ αὐτὸς ἀνήρ</span> _the same man_, <span lang="grc">τοῦ αὐτοῦ ἀνδρός</span> _of the same man_.

N.—The article and <span lang="grc">αὐτός</span> may unite by crasis ([68 a](../part-1-letters-sounds-syllables-accent/02-euphony-of-vowels.md#s68)): <span lang="grc">αὑτός, αὑτή, ταὐτό</span> or <span lang="grc">ταὐτόν; ταὐτοῦ, ταὐτῆς; ταὐτῷ, ταὐτῇ</span>, etc. Distinguish <span lang="grc">αὑτή</span> _the same_ f. from <span lang="grc">αὕτη</span> _this_ f.; <span lang="grc">ταὐτά</span> _the same_ n. from <span lang="grc">ταῦτα</span> _these things_ n.; <span lang="grc">ταὐτῇ</span> from <span lang="grc">ταύτῃ</span>.

##### <a id="s329"></a> §329

##### <a id="s329D"></a> §329 D

Hom. never compounds the two pronouns: thus, <span lang="grc">ἐμέθεν αὐτῆς, σοὶ αὐτῷ, οἷ αὐτῷ, ἑὲ αὐτόν, ἓ αὐτήν</span>. Hdt. has a few cases of the uncompounded forms; usually <span lang="grc">ἐμεωυτοῦ, -τῷ, -τόν, σεωυτοῦ, ἑωυτοῦ, ἑωυτῶν, -οῖσι, -ούς</span>, and <span lang="grc">σφέων αὐτῶν</span>, etc. The forms with <span lang="grc">εωυ</span> started with <span lang="grc">ἑωυτῷ</span> in the dative from <span lang="grc">ἑο</span>(<span lang="grc">ῖ</span>) <span lang="grc">αὐτῷ</span>, and spread thence to the other cases.

##### <a id="s330"></a> §330

**Possessive Pronouns**.—Possessive pronouns, formed from the stems of the personal pronouns, are declined like <span lang="grc">ἀγαθός, ἄξιος</span> ([287](04-substantives/07-adjectives.md#s287)).

**a.** Distinguish the adjectival from the pronominal use: <span lang="grc">ὁ ἐμὸς φίλος</span> or <span lang="grc">ὁ φίλος ὁ ἐμός</span> _my friend_ (adj.) from <span lang="grc">φίλος ἐμός</span> _a friend of mine_ (pron.). See [1196 a](../part-4-syntax/17-pronouns.md#s1196).

**b.** <span lang="grc">ὅς</span> is not used in Attic prose. For _his_, _her_, _its_, <span lang="grc">αὐτοῦ, -ῆς, -οῦ</span> are used.

##### <a id="s330D"></a> §330 D

\1. For <span lang="grc">ἐμός</span> Attic poetry may use <span lang="grc">ἁ̄μός</span> (sometimes printed <span lang="grc">ἀ̄μός</span>) _our_.

\2. <span lang="grc">ὅς, ἑός</span> in Hom. may mean _my own, your own_ ([1230 a](../part-4-syntax/17-pronouns.md#s1230)).

##### <a id="s335"></a> §335

<span lang="grc"> **ἄλλος** </span>.—The indefinite pronoun <span lang="grc">ἄλλος</span> _another_ (Lat. _alius_, cp. [110](../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s110)) is declined like <span lang="grc">αὐτός</span>: <span lang="grc">ἄλλος, ἄλλη, ἄλλο</span> (never <span lang="grc">ἄλλον</span>).

##### <a id="s336"></a> §336

<span lang="grc"> **Δεῖνα** </span>.—The indefinite pronoun <span lang="grc">δεῖνα</span>, always used with the article, means _such a one_. It is declined thus: sing. <span lang="grc">ὁ, ἡ, τὸ δεῖνα; τοῦ, τῆς, τοῦ δεῖνος; τῷ, τῇ, τῷ δεῖνι; τὸν, τὴν, τὸ δεῖνα</span>; plur. (masc.) <span lang="grc">οἱ δεῖνες, τῶν δείνων, τοὺς δεῖνας</span>. Example: <span lang="grc">ὁ δεῖνα τοῦ δεῖνος τὸν δεῖνα εἰσήγγειλεν</span> _such a one son of such a one impeached such a one_ \[D.\] 13. 5. <span lang="grc">δεῖνα</span> is rarely indeclinable. Its use is colloquial and it occurs (in poetry) only in comedy.

##### <a id="s337"></a> §337

Other indefinite pronominal adjectives are: <span lang="grc">**ἕτερος**, **-ᾱ**, **-ον**</span>: with article, _the other, one of two, the one_ (Lat. _alter_, _alteruter_); without article, _other_, _another_, _a second_ (_alius_). By crasis ([69](../part-1-letters-sounds-syllables-accent/02-euphony-of-vowels.md#s69)) <span lang="grc">ἅ̄τερος, θά̄τερον</span>, etc. <span lang="grc">**ἑκάτερος**, **-ᾱ**, **-ον**</span>: _each_ (of two) _uterque;_ pl. _either party, both parties_, as _utrique_. <span lang="grc">**ἕκαστος**, **-η**, **-ον**</span>: _each_, _each one, every_, _every one_, used of more than one (_quisque_). <span lang="grc">**μόνος**, **-η**, **-ον**</span>: _alone_, _only_, _sole_. <span lang="grc"> **πᾶς** </span> ([299](04-substantives/07-adjectives.md#s299)): _all_, _entire_, _every_. The negatives <span lang="grc">**οὐδείς**, **μηδείς**</span> ([349 b](08-numerals.md#s349)) _no one_ (poetical <span lang="grc">οὔτις, μήτις</span>, in prose only <span lang="grc">οὔτι, μήτι</span>, declined like <span lang="grc">τὶς</span>; accent [186](../part-1-letters-sounds-syllables-accent/07-accent-general-principles.md#s186)), Lat. _nemo_, _nullus_. <span lang="grc">**οὐδέτερος**, **μηδέτερος**</span> _neither of two_ (Lat. _neuter_).

##### <a id="s338D"></a> §338 D

\1. Hom. uses the demonstrative forms <span lang="grc">ὁ, ἡ, τό</span> ([332](#s332)) as relatives ([1105](../part-4-syntax/16-the-article-origin-and-development.md#s1105)). In this case the nom. pl. has <span lang="grc">τοί, ταί</span> ([332 D.](#s332)).

\2. Besides the forms in 338, Hom. has gen. <span lang="grc">ὅο</span> (miswritten <span lang="grc">ὅου</span>) and <span lang="grc">ἕης</span>.

\3. Hdt. has <span lang="grc">ὅς, ἥ, τό, οἵ, αἵ, τά</span>. In the oblique cases he uses <span lang="grc">τοῦ, τῆς</span>, etc.; though, especially after prepositions capable of elision, he has the relative forms, as <span lang="grc">δι᾽ οὗ, παρ᾽ ᾧ, κατ᾽ ἥν, ὑπ᾽ ὧν</span>; also <span lang="grc">ἐς ὅ</span>.
