# Verbs beginning with θ

<span lang="grc">θάλλω</span> (<span lang="grc">θαλ-</span>) _bloom_, rare in prose: <span lang="grc">ἔθαλλε</span> _made grow_ Pind., 2 perf. <span lang="grc">τέθηλα</span> (as pres.) is poetic. By-form <span lang="grc">θαλέθω</span> ([490](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s490)). ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=qa/llw">LSJ</cite>

<span lang="grc">θάπ-τω</span> (<span lang="grc">θαφ-</span>, [125](../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s125) g) _bury:_ <span lang="grc">θάψω, ἔθαψα, τέθαμμαι</span>, 2 aor. pass. <span lang="grc">ἐτάφην</span>, 2 fut. pass. <span lang="grc">ταφήσομαι</span>, fut. perf. <span lang="grc">τεθάψομαι, θαπτέος</span>; 1 aor. pass. <span lang="grc">ἐθάφθην</span> Ion. (rare). ([II.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s505)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=qa/ptw">LSJ</cite>

<span lang="grc">θαυμάζω</span> (<span lang="grc">θαυμ-αδ-</span>) _wonder_, _admire:_ fut. <span lang="grc">θαυμάσομαι</span> ([806](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s806)), otherwise regular. [512.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s512) ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=qauma/zw">LSJ</cite>

<span lang="grc">θείνω</span> (<span lang="grc">θεν-</span>) _smite:_ <span lang="grc">θενῶ, ἔθεινα</span> Epic, 2 aor. <span lang="grc">ἔθενον</span>. Poetic (and in Att. comedy). ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507)) <cite data-ref="Perseus:text:1999.04.0057:entry=qei/nw">LSJ</cite>

<span lang="grc">θέλω</span> _wish:_ see <span lang="grc">ἐθέλω</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=qe/lw">LSJ</cite>

<span lang="grc">θεραπεύω</span> _serve_, _heal:_ regular, but fut. mid. <span lang="grc">θεραπεύσομαι</span> is usu. pass. ([808](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s808)). (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=qerapeu/w">LSJ</cite>

<span lang="grc">θέρομαι</span> _warm myself_ (in prose only pres. and imperf.), fut. <span lang="grc">θέρσομαι τ</span> [23](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s23) ([536](../part-2-inflection/10-verb-stem-and-present-stem/03-ii-future-system.md#s536)), 2 aor. pass. as intrans. <span lang="grc">ἐθέρην</span> (only in the subj. <span lang="grc">θερέω ρ</span> [23](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s23)). (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=qe/romai">LSJ</cite>

<span lang="grc">θέω</span> (<span lang="grc">θευ-, θεϝ-, θυ-</span>, [503](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s503)) _run:_ <span lang="grc">θεύσομαι</span> ([806](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s806)). Other forms supplied by other verbs (see <span lang="grc">τρέχω</span>). (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=qe/w">LSJ</cite>

<span lang="grc">θη-</span> in <span lang="grc">θῆσθαι</span> _milk_, <span lang="grc">ἐθησάμην</span> _sucked_. Epic. <cite data-ref="Perseus:text:1999.04.0057:entry=qh">LSJ</cite>

<span lang="grc">θηπ-</span>: see <span lang="grc">ταφ-</span>. <cite data-ref="Perseus:text:1999.04.0057:entry=qhp">LSJ</cite>

<span lang="grc">θι-γ-γ-άνω</span> (<span lang="grc">θιγ-</span>) _touch:_ <span lang="grc">θίξομαι</span> ([806](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s806)), 2 aor. <span lang="grc">ἔθιγον, ἄ-θικτος</span>. Poetic, rare in prose (Xen.). ([IV.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s523)) <cite data-ref="Perseus:text:1999.04.0057:entry=qigga/nw">LSJ</cite>

<span lang="grc">θλάω</span> _bruise_, _break:_ <span lang="grc">θλάσω, ἔθλασα, τέθλασμαι</span> ([489](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s489) c) Theocr., <span lang="grc">ἐθλάσθην</span> Hippocr., <span lang="grc">θλαστός</span>. Ion. and poetic. See <span lang="grc">φλάω</span>. <cite data-ref="Perseus:text:1999.04.0057:entry=qla/w">LSJ</cite>

<span lang="grc">θλί̄βω</span> (<span lang="grc">θλῑβ-, θλῐβ-</span>, [501](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s501)) _press:_ <span lang="grc">ἔθλῑψα, τέθλῐφα, ἐθλί̄φθην, τέθλιμμαι</span> and <span lang="grc">ἐθλί̆βην</span> Aristotle. Fut. mid. <span lang="grc">θλί̄ψομαι</span> Hom. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=qli/bw">LSJ</cite>

<span lang="grc">θνῄ-σκω</span>, older <span lang="grc">θνή-σκω</span> (<span lang="grc">θαν-, θνη-</span>, [492](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s492), [526](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s526) b) _die:_ <span lang="grc">ἀπο-θανοῦμαι</span> ([806](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s806)), 2 aor. <span lang="grc">ἀπ-έθανον, τέθνηκα</span> _am dead_, 2 perf. <span lang="grc">τέθνατον</span> ([704](../part-2-inflection/10-verb-stem-and-present-stem/13-inflection-of-omega-verbs.md#s704) c), fut. perf. <span lang="grc">τεθνήξω</span> ([659](../part-2-inflection/10-verb-stem-and-present-stem/13-inflection-of-omega-verbs.md#s659) a, [1958](../part-4-syntax/20-the-verb-voices/10-the-tenses.md#s1958)), <span lang="grc">θνητός</span>. In prose regularly <span lang="grc">ἀπο-θνῄσκω</span> in fut. and 2 aor., but always <span lang="grc">τέθνηκα</span>. ([V.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s526)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=qnh/|skw">LSJ</cite>

<span lang="grc">θρά̄ττω</span> (<span lang="grc">θρᾱχ-, τρᾱχ-</span>) _disturb:_ <span lang="grc">ἔθρᾱξα, ἐθρά̄χθην</span> Soph. See <span lang="grc">ταράττω</span>. Mostly poetic. ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=qra/ttw">LSJ</cite>

<span lang="grc">θραύω</span> _break_, _bruise:_ <span lang="grc">θραύσω, ἔθραυσα, τέθραυμαι</span> and <span lang="grc">τέθραυσμαι</span> ([489](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s489) c), <span lang="grc">ἐθραύσθην</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=qrau/w">LSJ</cite>

<span lang="grc">θρύπ-τω</span> (<span lang="grc">θρυφ-</span>, [125](../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s125) g and N.) _crush_, _weaken:_ <span lang="grc">τέθρυμμαι, ἐθρύφθην</span> Aristotle, 2 aor. pass. <span lang="grc">ἐτρύφην</span> Hom., <span lang="grc">ἔν-θρυπτος. θρύπτομαι</span> _put on airs_. ([II.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s505)) <!-- page 700 --> (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=qru/ptw">LSJ</cite>

<span lang="grc">θρῴ-σκω</span> and <span lang="grc">θρώ-σκω</span> (<span lang="grc">θρω-, θορ-</span>, [492](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s492)) _leap:_ <span lang="grc">-θοροῦμαι</span> ([806](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s806); W. <span lang="grc">ὑπέρ</span>) poetic, 2 aor. <span lang="grc">ἔθορον</span>. Mainly poetic. By-form <span lang="grc">θορνύομαι</span> Hdt. ([V.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s526)) <cite data-ref="Perseus:text:1999.04.0057:entry=qrw/|skw">LSJ</cite>

<span lang="grc">θύ̄ω</span> (<span lang="grc">θυ-, θῡ-</span>, [500.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s500) 1 a) _sacrifice:_ <span lang="grc">θύ̄σω, ἔθῡσα, τέθυκα, τέθυμαι, ἐτύθην, θυτέος</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=qu/w">LSJ</cite>

<span lang="grc">θύ̄ω</span> and <span lang="grc">θύ̄νω</span> _rush_ poetic: in the classical language only pres. and imperf. <span lang="grc">θῡνέω</span> Hesiod. <cite data-ref="Perseus:text:1999.04.0057:entry=qu/w">LSJ</cite>
