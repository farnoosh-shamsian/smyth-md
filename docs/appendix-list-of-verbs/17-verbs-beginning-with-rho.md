# Verbs beginning with ρ

<span lang="grc">ῥαίνω</span> (<span lang="grc">ῥα-, ῥαν-</span>, [523](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s523) h, perhaps for <span lang="grc">ῥαδ-ν\[ιγλιδε\]ω</span>) _sprinkle:_ <span lang="grc">ῥανῶ, ἔρρᾱνα, ἔρρασμαι</span>, ([489](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s489) h), <span lang="grc">ἐρράνθην</span>. Apparently from <span lang="grc">ῥαδ-</span> come Epic aor. <span lang="grc">ἔρασσα</span>, Epic perf. <span lang="grc">ἐρράδαται</span> and plup. <span lang="grc">ἐρράδατο</span>. Perf. <span lang="grc">ἔρρανται</span> Aesch. Ion., poetic. ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507) [IV.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s523)) <cite data-ref="Perseus:text:1999.04.0057:entry=r(ai/nw">LSJ</cite>

<span lang="grc">ῥαίω</span> _strike:_ <span lang="grc">ῥαίσω, ἔρραισα, ἐρραίσθην</span> ([489](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s489) e). Fut. mid. as pass. <span lang="grc">δια-ρραίσεσθαι Ω</span> [355.](../part-2-inflection/09-verbs/01-inflection-preliminary-remarks-355-380.md#s355) Poetic, mainly Epic. <cite data-ref="Perseus:text:1999.04.0057:entry=r(ai/w">LSJ</cite>

<span lang="grc">ῥάπ-τω</span>(<span lang="grc">ῥαφ-</span>) _stitch:_ <span lang="grc">ἀπο-ρράψω, ἔρραψα, ἔρραμαι</span>, 2 aor. pass. <span lang="grc">ἐρράφην, ῥαπτός</span>. ([II.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s505)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=r(a/ptw">LSJ</cite>

<span lang="grc">ῥάττω</span> (<span lang="grc">ῥαγ-</span>) _throw down_ (late pres. for <span lang="grc">ἀράττω</span>): <span lang="grc">ξυρ-ράξω, ἔρραξα</span>. ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=r(a/ttw">LSJ</cite>

<span lang="grc">ῥέζω</span> (<span lang="grc">ϝρεγ-\[ιγλιδε\]ω</span>, [511](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s511)) _do:_ <span lang="grc">ῥέξω, ἔρεξα</span> (less often <span lang="grc">ἔρρεξα</span>), aor. pass. part. <span lang="grc">ῥεχθείς, ἄ-ρεκτος</span>. Poetic. Cp. <span lang="grc">ἔρδω</span>. ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507)) <!-- page 714 --> <cite data-ref="Perseus:text:1999.04.0057:entry=r(e/zw">LSJ</cite>

<span lang="grc">ῥέω</span> (<span lang="grc">ῥευ-, ῥεϝ-, ῥυ-</span>, and <span lang="grc">ῥυε-</span>) _flow_ (on the contraction in Att. see [397](../part-2-inflection/09-verbs/00-introduction.md#s397)): <span lang="grc">ῥυήσομαι</span> [806](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s806) (2 fut. pass. as act.; <span lang="grc">ῥεύσομαι</span> rare in Att.), <span lang="grc">ἐρρύην</span> (2 aor.; pass. as act.; <span lang="grc">ἔρρευσα</span> rare in Att.), <span lang="grc">ἐρρύηκα, ῥυτός</span> and <span lang="grc">ῥευστέος</span> poetic. <span lang="grc">ῥευσοῦμαι</span> Aristotle. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=r(e/w">LSJ</cite>

<span lang="grc">ῥη-</span> stem of <span lang="grc">εἴρηκα, εἴρημαι, ἐρρήθην, ῥηθήσομαι, εἰρήσομαι</span>. See <span lang="grc">εἴρω</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=r(h">LSJ</cite>

<span lang="grc">ῥήγ-νῡμι</span> (<span lang="grc">ῥηγ-</span>, for <span lang="grc">ϝρηγ-, ρ῾ωγ-, ῥαγ-</span>) _break_, in prose mostly in comp. W. <span lang="grc">ἀνά, διά</span>: <span lang="grc">-ρήξω, ἔρρηξα</span>, 2 perf. <span lang="grc">-έρρωγα</span> _am broken_, 2 aor. pass. <span lang="grc">ἐρράγην</span>, 2 fut. pass. <span lang="grc">-ραγήσομαι; -έρρηγμαι</span> and <span lang="grc">-ερρήχθην</span> Ion., <span lang="grc">ῥη·κτός</span> Hom. ([IV.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s523)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=r(h/gnumi">LSJ</cite>

<span lang="grc">ῥῑγέω</span> (<span lang="grc">ῥῑγ-, ῥῑγε-</span>, [485](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s485)) _shudder:_ <span lang="grc">ῥῑγήσω, ἐρρί̄γησα</span> and <span lang="grc">ῥί̄γησα</span>, 2 perf. <span lang="grc">ἔρρῑγα</span> as pres. Chiefly poetic. <cite data-ref="Perseus:text:1999.04.0057:entry=r(ige/w">LSJ</cite>

<span lang="grc">ῥῑγόω</span> _shiver_. On the contraction in the pres. see [398](../part-2-inflection/09-verbs/00-introduction.md#s398): <span lang="grc">ῥῑγώσω, ἐρρί̄γωσα</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=r(igo/w">LSJ</cite>

<span lang="grc">ῥί̄πτω</span> (<span lang="grc">ῥῑπ-, ῥιπ-</span>) and <span lang="grc">ῥῑπ-τ-έω</span> ([485](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s485) d) _throw:_ <span lang="grc">ῥί̄ψω, ἔρρῑψα</span>, 2 perf. <span lang="grc">ἔρρῑφα, ἔρρῑμμαι, ἐρρί̄φθην</span>, 2 aor. pass. <span lang="grc">ἐρρίφην</span>, fut. pass. <span lang="grc">ἀπο-ρρῑφθήσομαι, ῥῑπτός</span> Soph. ([II.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s505)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=r(i/ptw">LSJ</cite>

<span lang="grc">ῥοφέω</span> _sup up:_ <span lang="grc">ῥοφήσω</span> and <span lang="grc">ῥοφήσομαι</span> ([806](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s806)), <span lang="grc">ἐρρόφησα</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=r(ofe/w">LSJ</cite>

<span lang="grc">ῥύ̄ομαι</span> (Epic also <span lang="grc">ῥύομαι</span>, rare in Att.) for <span lang="grc">ϝρῡομαι</span>, _defend:_ <span lang="grc">ῥύ̄σομαι, ἐρρῡσάμην</span>, and <span lang="grc">ῤυσάμην</span> O [29](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s29), <span lang="grc">ῥῡτός</span>. Chiefly poetic. <cite data-ref="Perseus:text:1999.04.0057:entry=r(u/omai">LSJ</cite>

<span lang="grc">ῥυπόω</span> _soil:_ Epic perf. part. <span lang="grc">ῥερυπωμένος</span> ([442](../part-2-inflection/09-verbs/06-reduplication.md#s442) b. D.). Cp. <span lang="grc">ῥυπάω</span> _am dirty_. <cite data-ref="Perseus:text:1999.04.0057:entry=r(upo/w">LSJ</cite>
