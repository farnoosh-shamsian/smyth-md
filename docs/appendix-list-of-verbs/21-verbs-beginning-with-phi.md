# Verbs beginning with φ

<span lang="grc">φαείνω</span> (<span lang="grc">φαεν-</span>) _appear_, _show:_ aor. pass. <span lang="grc">ἐφαάνθην</span> (W. <span lang="grc">αα</span> for <span lang="grc">αε</span>, [643](../part-2-inflection/10-verb-stem-and-present-stem/13-inflection-of-omega-verbs.md#s643)) _appeared_. Epic. ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507)) <cite data-ref="Perseus:text:1999.04.0057:entry=faei/nw">LSJ</cite>

<span lang="grc">φαίνω</span> (<span lang="grc">φαν-</span>) _show:_ <span lang="grc">φανῶ, ἔφηνα</span>, perf. <span lang="grc">πέφαγκα</span> (rare in good Att.) _have shown_, 2 perf. <span lang="grc">πέφηνα</span> _have appeared_, <span lang="grc">πέφασμαι</span> ([489](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s489) h), <span lang="grc">ἐφάνθην</span> (rare in prose) _was shown_, 2 aor. pass. <span lang="grc">ἐφάνην</span> as intrans. _appeared_, 2 fut. pass. <span lang="grc">φανήσομαι</span> _shall appear;_ fut. mid. <span lang="grc">φανοῦμαι</span> _shall show_ and _shall appear_. On the trans. and intrans. use see [819](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s819); for the inflection of certain tenses see [401](../part-2-inflection/09-verbs/00-introduction.md#s401) ff. Hom. has 2 aor. iter. <span lang="grc">φάνεσκε</span> _appeared_, v. a. <span lang="grc">ἄ-φαντος</span>; and, from root <span lang="grc">φα-</span>: <span lang="grc">φάε</span> _appeared_ and fut. perf. <span lang="grc">πεφήσεται</span> _shall appear_. Connected forms <span lang="grc">πι-φαύσκω, φαείνω, φαντάζομαι</span>. ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=fai/nw">LSJ</cite>

<span lang="grc">φά-σκω</span> (<span lang="grc">φα-</span>) _say:_ only pres. and imperf.: see <span lang="grc">φημί</span>. ([V.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s526)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=fa/skw">LSJ</cite>

<span lang="grc">φείδομαι</span> (<span lang="grc">φειδ-, φιδ-</span>) _spare:_ <span lang="grc">φείσομαι, ἐφεισάμην, φειστέος</span>. Epic 2 aor. mid. redupl. <span lang="grc">πεφιδόμην</span> ([448](../part-2-inflection/09-verbs/06-reduplication.md#s448) D.). Epic fut. <span lang="grc">πεφιδήσομαι</span> (<span lang="grc">φιδε-</span>). (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=fei/domai">LSJ</cite>

<span lang="grc">φεν-, φν-, φα-</span> (for <span lang="grc">φṇ-</span>, [35](../part-1-letters-sounds-syllables-accent/01-the-letters.md#s35) b) _kill:_ 2 aor. <span lang="grc">ἔπεφνον</span> and <span lang="grc">πέφνον</span> (part. <span lang="grc">κατα-πεφνών</span>, also accented <span lang="grc">-πέφνων</span>), perf. mid. <span lang="grc">πέφαμαι</span>, fut. perf. <span lang="grc">πεφήσομαι</span>. Epic. Cp <span lang="grc">φόνος</span> _murder_ and <span lang="grc">θείνω</span> (<span lang="grc">θεν-</span>) _smite_. <cite data-ref="Perseus:text:1999.04.0057:entry=fen, fn, fa">LSJ</cite>

<span lang="grc">φέρω</span> (<span lang="grc">φερ-, οἰ-, ἐνεκ-, ἐνεγκ-</span> for <span lang="grc">ἐν-ενεκ</span>, [529](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s529)) _bear_, _carry:_ fut. <span lang="grc">οἴσω</span>, 1 aor. <span lang="grc">ἤνεγκα</span>, <!-- page 720 --> 2 aor. <span lang="grc">ἤνεγκον</span>, 2 perf. <span lang="grc">ἐνήνοχα</span>, perf. mid. <span lang="grc">ἐνήνεγμαι</span> (3 s. <span lang="grc">-γκται</span> inscr.), aor. pass. <span lang="grc">ἠνέχθην</span> also intrans., fut. pass. <span lang="grc">κατ-ενεχθήσομαι</span> and <span lang="grc">οἰσθήσομαι</span>, v. a. <span lang="grc">οἰστός, -τέος</span>. [470](../part-2-inflection/09-verbs/08-endings-of-the-verb-personal-endings.md#s470)). Poetic and dial. forms are: 2 pl. pres. imper. <span lang="grc">φέρτε</span> (for <span lang="grc">φέρετε</span>) Epic, 1 aor. imper. <span lang="grc">οἶσε</span> for <span lang="grc">οἶσον</span> Epic (and Aristoph.), 1 aor. inf. <span lang="grc">ἀν-οῖσαι</span> or <span lang="grc">ἀν-ῷσαι</span> (once in Hdt.), fut. inf. <span lang="grc">οἴσειν</span> Pind., <span lang="grc">οἰσέμεν</span> (<span lang="grc">αι</span>) Hom., 1 aor. <span lang="grc">ἤνεικα, -άμην</span> Hom., Hdt., <span lang="grc">ἤνικα</span> Aeol., Dor., etc., 2 aor. <span lang="grc">ἤνεικον</span> rare in Hom., perf. mid. <span lang="grc">ἐνήνειγμαι</span> Hdt., aor. pass. <span lang="grc">ἠνείχθην</span> Hdt., v. a. <span lang="grc">φερτός</span> Hom., Eur., <span lang="grc">ἀν-ώιστος</span> Hdt. (<span lang="grc">ἄνοιστος</span>?). ([VI.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s526)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=fe/rw">LSJ</cite>

<span lang="grc">φεύγω</span> (<span lang="grc">φευγ-, φυγ-</span>) _flee:_ <span lang="grc">φεύξομαι</span> [806](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s806) (<span lang="grc">φευξοῦμαι</span>, [540](../part-2-inflection/10-verb-stem-and-present-stem/03-ii-future-system.md#s540), rare in prose), 2 aor. <span lang="grc">ἔφυγον</span>, 2 perf. <span lang="grc">πέφευγα, φευκτός, -τέος</span>. Hom. has perf. act. part. <span lang="grc">πεφυζότες</span> as if from a verb <span lang="grc">φύζω</span> (cp. <span lang="grc">φύζα</span> _flight_), perf. mid. part. <span lang="grc">πεφυγμένος</span>, v. a. <span lang="grc">φυκτός</span>. By-form <span lang="grc">φυγ-γάνω</span>, New Ion. and Att. poetry, in comp. in prose. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=feu/gw">LSJ</cite>

<span lang="grc">φη-μί</span> (<span lang="grc">φη-, φα-</span>) _say_, inflected [783](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s783): <span lang="grc">φήσω, ἔφησα, φατός, -τέος</span>. Poetical and dial. forms [783](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s783) D. ff. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=fhmi/">LSJ</cite>

<span lang="grc">φθά-νω</span> (<span lang="grc">φθη-, φθα-</span>) _anticipate:_ <span lang="grc">φθήσομαι</span> ([806](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s806)), <span lang="grc">ἔφθασα</span>, 2 aor. <span lang="grc">ἔφθην</span> (like <span lang="grc">ἔστην</span>). <span lang="grc">φθείρω</span> (<span lang="grc">φθερ-, φθορ-, φθαρ-</span>) _corrupt:_ <span lang="grc">φθερῶ, ἔφθειρα, ἔφθαρκα</span>, but usu. 2 perf. <span lang="grc">δι-έφθορα</span> _am ruined_ (_have corrupted_ in Att. poetry), <span lang="grc">ἔφθαρμαι</span>, 2 aor. pass. <span lang="grc">ἐφθάρην, δια-φθαρήσομαι, φθαρτός</span> Aristotle. <span lang="grc">φθίνω</span> (<span lang="grc">φθι-</span>) _waste_, _perish_, mostly poetical and usu. intrans., Epic <span lang="grc">φθί̄νω</span> (= <span lang="grc">φθινϝω</span>): fut. <span lang="grc">φθίσω</span> poetic (Hom. <span lang="grc">φθί̄σω</span>) trans., aor. <span lang="grc">ἔφθισα</span> poetic (Hom. <span lang="grc">ἔφθῑσα</span>) trans., 2 aor. mid. athematic <span lang="grc">ἐφθίμην</span> _perished_ poetic (<span lang="grc">φθίωμαι, φθί̄μην</span> for <span lang="grc">φθι-ῑμην, φθίσθω, φθίσθαι, φθίμενος</span>), <span lang="grc">ἔφθιμαι</span> poetic (plup. 3 pl. <span lang="grc">ἐφθίατο</span>), <span lang="grc">ἐφθίθην</span> Hom., <span lang="grc">φθιτός</span> Tragic. ([IV.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s523)) <cite data-ref="Perseus:text:1999.04.0057:entry=fqi/nw">LSJ</cite>
