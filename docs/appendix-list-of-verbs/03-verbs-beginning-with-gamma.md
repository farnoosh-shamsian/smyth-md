# Verbs beginning with γ

<span lang="grc">γαμέω</span> (<span lang="grc">γαμ-, γαμε-</span>, [485](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s485)) _marry_ (of the man): fut. <span lang="grc">γαμῶ, ἔγημα, γεγάμηκα</span>. Mid. <span lang="grc">γαμέομαι</span> (of the woman): fut. <span lang="grc">γαμοῦμαι, ἐγημάμην, γεγάμημαι</span>, v. a. <span lang="grc">γαμετός</span> (<span lang="grc">γαμετή</span> _wife_), <span lang="grc">-τέος</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=game/w">LSJ</cite>

<span lang="grc">γά-νυμαι</span> (<span lang="grc">γα-</span>) _rejoice:_ Epic fut. <span lang="grc">γανύσσομαι</span> (W. <span lang="grc">νυ</span> of the pres. stem). Chiefly poetic. ([IV.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s523)) <cite data-ref="Perseus:text:1999.04.0057:entry=ga/numai">LSJ</cite>

<span lang="grc">γέγωνα</span> (<span lang="grc">γων-, γωνε-</span>) 2 perf. as pres. _shout:_ part. <span lang="grc">γεγωνώς</span> Epic. Other forms may be referred to <span lang="grc">γεγώνω</span> or <span lang="grc">γεγωνέω</span>; as subj. <span lang="grc">γεγώνω</span>, imper. <span lang="grc">γέγωνε</span>, inf. <span lang="grc">γεγωνέμεν</span> (Epic) and <span lang="grc">γεγωνεῖν</span>, imperf. <span lang="grc">ἐγεγώνει</span> and <span lang="grc">ἐγέγωνε</span>, 1 pl. <span lang="grc">ἐγεγώνευν</span>, fut. <span lang="grc">γεγωνήσω</span>, aor. <span lang="grc">ἐγεγώνησα</span>, v. a. <span lang="grc">γεγωνητέος</span>. Poetic, occasionally in prose. By-form <span lang="grc">γεγωνίσκω</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=ge/gwna">LSJ</cite>

<span lang="grc">γείνομαι</span> (<span lang="grc">γεν-</span>) _am born_ Epic; aor. <span lang="grc">ἐγεινάμην</span> _begat_ (poetic) yields in Hdt., Xen. <span lang="grc">γεινάμενος, γειναμένη</span> _parent_. ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507)) <cite data-ref="Perseus:text:1999.04.0057:entry=gei/nomai">LSJ</cite>

<span lang="grc">γελάω</span> (<span lang="grc">γελα-</span> for <span lang="grc">γελασ-</span>) _laugh:_ <span lang="grc">γελάσομαι</span> ([806](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s806)), <span lang="grc">ἐγέλασα, ἐγελάσθην</span> ([489](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s489) e), <span lang="grc">κατα-γέλαστος</span>. [488.](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s488) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=gela/w">LSJ</cite>

<span lang="grc">γέντο</span> _seized_, Epic 2 aor. <span lang="grc">Σ</span> [476.](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s476) Also = <span lang="grc">ἐγένετο</span> (<span lang="grc">γίγνομαι</span>). (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=ge/nto">LSJ</cite>

<span lang="grc">γηθέω</span> (<span lang="grc">γηθ-, γηθε-</span>, [485](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s485)) _rejoice:_ <span lang="grc">γέγηθα</span> as pres.; <span lang="grc">γηθήσω</span> and <span lang="grc">ἐγήθησα</span> poetic. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=ghqe/w">LSJ</cite>

<span lang="grc">γηρά-σκω</span> and less com. <span lang="grc">γηράω</span> (<span lang="grc">γηρα-</span>) _grow old:_ <span lang="grc">γηρά̄σομαι</span> ([806](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s806)), less often <span lang="grc">γηρά̄σω, ἐγήρᾱσα, γεγήρᾱκα</span> _am old_. 2 aor. <span lang="grc">ἐγήρᾱ</span> Epic and Ion., inf. <span lang="grc">γηρᾶναι</span> poetic, part. <span lang="grc">γηρά̄ς</span> Hom. ([687](../part-2-inflection/10-verb-stem-and-present-stem/13-inflection-of-omega-verbs.md#s687)). ([V.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s526)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=ghra/skw">LSJ</cite>

<span lang="grc">γηρύ̄ω</span> ([500.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s500) 1. a) _speak out:_ <span lang="grc">γηρύ̄σομαι</span> ([806](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s806)), <span lang="grc">ἐγήρῡσα, ἐγηρύ̄θην</span>. Poetic. <cite data-ref="Perseus:text:1999.04.0057:entry=ghru/w">LSJ</cite>

<span lang="grc">γίγνομαι</span> (<span lang="grc">γεν-, γενε-, γον-</span>, [478](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s478)) _become_, _am:_ <span lang="grc">γενήσομαι</span>, 2 aor. <span lang="grc">ἐγενόμην</span>, 2 perf. <span lang="grc">γέγονα</span> _am_, _have been_, <span lang="grc">γεγένημαι, γενηθήσομαι</span> rare. <span lang="grc">γί̄νομαι</span> Doric and New Ion. ([89](../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s89)). 2 aor. 3 s. <span lang="grc">γέντο</span> Epic; aor. pass. <span lang="grc">ἐγενήθην</span> Doric, Ion., late Att. comedy; 2 perf. part. <span lang="grc">γεγώς</span> (other <span lang="grc">-μι</span> forms W. <span lang="grc">γα-</span> for <span lang="grc">γṇ-</span> [479](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s479), [482](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s482), [573](../part-2-inflection/10-verb-stem-and-present-stem/07-vi-second-perfect-system.md#s573), [704](../part-2-inflection/10-verb-stem-and-present-stem/13-inflection-of-omega-verbs.md#s704) b). (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=gi/gnomai">LSJ</cite>

<span lang="grc">γι-γνώ-σκω</span> (<span lang="grc">γνω-, γνο-</span>) _know:_ <span lang="grc">γνώσομαι</span> ([806](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s806)), 2 aor. <span lang="grc">ἔγνων</span> ([687](../part-2-inflection/10-verb-stem-and-present-stem/13-inflection-of-omega-verbs.md#s687)) _perceived_, <span lang="grc">ἔγνωκα, ἔγνωσμαι</span> ([489](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s489) c), <span lang="grc">ἐγνώσθην, γνωσθήσομαι, γνωστός</span> (<span lang="grc">γνωτός</span> poetic), <span lang="grc">-στέος</span>. 1 aor. <span lang="grc">ἀν-έγνωσα</span> _persuaded_ Hdt. Doric, New Ion. <span lang="grc">γῑνώσκω</span> ([89](../part-1-letters-sounds-syllables-accent/03-euphony-of-consonants.md#s89)). ([V.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s526)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=gignw/skw">LSJ</cite>

<span lang="grc">γλύφω</span> _carve:_ <span lang="grc">γέγλυμμαι</span> and <span lang="grc">ἔγλυμμαι</span> ([440](../part-2-inflection/09-verbs/06-reduplication.md#s440) a). Hdt. has <span lang="grc">ἐνέγλυψα</span>. Other forms are late. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=glu/fw">LSJ</cite>

<span lang="grc">γνάμπ-τω</span> (<span lang="grc">γναμπ-</span>) _bend:_ <span lang="grc">γνάμψω, ἔγναμψα, ἀν-εγνάμφθην</span>. Poetic for <span lang="grc">κάμπτω</span>. ([II.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s505)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=gna/mptw">LSJ</cite>

<span lang="grc">γοάω</span> _bewail:_ inf. <span lang="grc">γοήμεναι</span> Hom., 2 aor. <span lang="grc">γόον</span> (<span lang="grc">γο-</span>) Epic. Mid. <span lang="grc">γοάομαι</span> poetic: <span lang="grc">γοήσομαι</span> Hom. <cite data-ref="Perseus:text:1999.04.0057:entry=goa/w">LSJ</cite>

<span lang="grc">γράφω</span> _write:_ <span lang="grc">γράψω, ἔγραψα, γέγραφα, γέγραμμαι</span>, 2 aor. pass. <span lang="grc">ἐγράφην</span>, 2 fut. pass. <span lang="grc">γραφήσομαι</span>, fut. perf. pass. <span lang="grc">γεγράψομαι, γραπτός, -τέος. γεγράφηκα, ἔγραμμαι</span>, and <span lang="grc">ἐγράφθην</span> are late. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=gra/fw">LSJ</cite>

<span lang="grc">γρύζω</span> (<span lang="grc">γρυγ-</span>) _grunt:_ <span lang="grc">γρύξομαι</span> ([806](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s806), late <span lang="grc">γρύξω</span>); <span lang="grc">ἔγρυξα, γρυκτός</span>. Mostly in Att. comedy. ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=gru/zw">LSJ</cite>
