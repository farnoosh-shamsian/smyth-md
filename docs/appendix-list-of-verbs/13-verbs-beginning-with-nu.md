# Verbs beginning with ν

<span lang="grc">ναίω</span> (<span lang="grc">νασ-\[ιγλιδε\]ω</span>, [624](../part-2-inflection/10-verb-stem-and-present-stem/12-first-conjugation-or-verbs-in-omega.md#s624) a) _dwell:_ <span lang="grc">ἔνασσα</span> _caused to dwell_, <span lang="grc">ἐνασσάμην</span> _took up my abode_ and _caused to dwell_, <span lang="grc">ἐνάσθην</span> _was settled_ or _dwelt_. Poetic. ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507)) <cite data-ref="Perseus:text:1999.04.0057:entry=nai/w">LSJ</cite>

<span lang="grc">ναίω</span> (<span lang="grc">ναϝ-\[ιγλιδε\]ω</span>, [624](../part-2-inflection/10-verb-stem-and-present-stem/12-first-conjugation-or-verbs-in-omega.md#s624) b) _swim:_ <span lang="grc">ναῖον ι</span> [222](../part-2-inflection/04-substantives/01-first-declension-stems-in-alpha.md#s222) (_v. l._ <span lang="grc">νᾶον</span>). ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507)) <cite data-ref="Perseus:text:1999.04.0057:entry=nai/w">LSJ</cite>

<span lang="grc">νάττω</span> (<span lang="grc">ναδ-, ναγ-</span>, [514](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s514) a, [515](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s515) b) _compress:_ <span lang="grc">ἔναξα</span> Epic and Ion., <span lang="grc">νένασμαι</span> Aristoph. (<span lang="grc">νέναγμαι</span> Hippocr.), <span lang="grc">ναστός</span> Aristoph. Mostly Ion. and poetic. ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=na/ttw">LSJ</cite>

<span lang="grc">νάω</span> (<span lang="grc">ναϝ-ω</span>) _flow_ only in pres. Epic. Cp. <span lang="grc">ναίω</span> _swim_. <cite data-ref="Perseus:text:1999.04.0057:entry=na/w">LSJ</cite>

\*<span lang="grc">νάω</span> (<span lang="grc">νῶ</span>) _spin_ (<span lang="grc">να-, νη-</span>, [394](../part-2-inflection/09-verbs/00-introduction.md#s394)): pres. <span lang="grc">νῇς, νῇ, νῶσι</span>, inf. <span lang="grc">νῆν</span>, part. <span lang="grc">νῶν</span>, fut. <span lang="grc">νήσω</span>, aor. <span lang="grc">ἔνησα</span>, aor. pass. <span lang="grc">ἐνήθην</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=na/w">LSJ</cite>

<span lang="grc">νεικέω</span> (<span lang="grc">νεικε-</span> for <span lang="grc">νεικεσ-</span>; cp. <span lang="grc">τὸ νεῖκος</span> _strife_) _chide_, usu. <span lang="grc">νεικείω</span> in Hom.: <span lang="grc">νεικέσω, ἐνείκεσ</span>(<span lang="grc">σ</span>)<span lang="grc">α</span>. Epic (also Hdt.). ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507)) <cite data-ref="Perseus:text:1999.04.0057:entry=neike/w">LSJ</cite>

<span lang="grc">νείφει</span> (<span lang="grc">νειφ-, νιφ-</span>, [477](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s477); better form than <span lang="grc">νί̄φει</span>) _snows_, _covers with snow:_ <span lang="grc">κατένειψε</span>. Pass. <span lang="grc">νείφεται</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=nei/fei">LSJ</cite>

<span lang="grc">νέμω</span> (<span lang="grc">νεμ-, νεμε-</span>) _distribute_, mid. also _go to pasture:_ <span lang="grc">νεμῶ, ἔνειμα, δια-νενέμηκα, νενέμημαι, ἐνεμήθην, δια-νεμητέος</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=ne/mw">LSJ</cite>

<span lang="grc">νέομαι</span> (<span lang="grc">νεσ-</span>) _go_, _come_, only in pres. and imperf.: usu. in fut. sense. Mainly poetic. Cp. <span lang="grc">νί̄σομαι</span>. [541.](../part-2-inflection/10-verb-stem-and-present-stem/03-ii-future-system.md#s541) <cite data-ref="Perseus:text:1999.04.0057:entry=ne/omai">LSJ</cite>

<span lang="grc">νεύω</span> _nod:_ <span lang="grc">-νεύσομαι</span> W. <span lang="grc">ἀνά</span> or <span lang="grc">κατά</span> ([806](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s806)), <span lang="grc">ἔνευσα, νένευκα</span>. Hom. has fut. <span lang="grc">νεύσω</span> and <span lang="grc">κατα-νεύσομαι</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=neu/w">LSJ</cite>

<span lang="grc">νέω</span> (<span lang="grc">νευ-, νεϝ-, νυ-</span>, originally <span lang="grc">σνευ-</span>, etc.) _swim_, often comp. W. <span lang="grc">διά, ἐξ· νευσοῦμαι</span> Xen. ([540](../part-2-inflection/10-verb-stem-and-present-stem/03-ii-future-system.md#s540), [806](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s806)), <span lang="grc">-ένευσα, -νένευκα, νευστέος</span>. Cp. <span lang="grc">νήχομαι</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=ne/w">LSJ</cite>

<span lang="grc">νέω</span> _heap up_, pres. in comp. and only in Hdt. (Att. usu. has <span lang="grc">χόω</span>): <span lang="grc">ἔνησα, νένημαι</span> (<span lang="grc">νένησμαι</span> ? [489](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s489) g), <span lang="grc">νητός</span> Hom. Epic <span lang="grc">νηέω</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=ne/w">LSJ</cite>

<span lang="grc">νίζω</span> (<span lang="grc">νιβ-, νιγ-</span>, [509](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s509) a) _wash_, in Att. usu. comp. W. <span lang="grc">ἀπό, ἐξ</span>: <span lang="grc">-νίψομαι</span> (<span lang="grc">νίψω</span> poetic), <!-- page 708 --> <span lang="grc">-ένιψα, -νένιμμαι, -ενίφθην</span> Hippocr., <span lang="grc">ἄ-νιπτος</span> Hom. = <span lang="grc">ἀν-από-νιπτος. νίπτω</span> is late, <span lang="grc">νίπτομαι</span> Hom. ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=ni/zw">LSJ</cite>

<span lang="grc">νί̄σομαι</span> _go_ or _will go:_ from <span lang="grc">νι-ν</span>(<span lang="grc">ε</span>)<span lang="grc">σ-\[ιγλιδε\]ομαι</span>, cp. <span lang="grc">νόσ-τος</span> _return_. Often printed <span lang="grc">νίσσομαι</span> (MSS. often have <span lang="grc">νείσομαι</span>). Poetic. ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507)) <cite data-ref="Perseus:text:1999.04.0057:entry=ni/somai">LSJ</cite>

<span lang="grc">νοέω</span> _think_, _perceive_, regular in Att. Mid. <span lang="grc">νοοῦμαι</span> usu. in comp., fut. <span lang="grc">δια-νοήσομαι</span> (rare) and <span lang="grc">δια-νοηθήσομαι</span> ([812](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s812)). Ion. contracts <span lang="grc">οη</span> to <span lang="grc">ω</span> in <span lang="grc">ἔνωσα, νένωκα, νένωμαι</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=noe/w">LSJ</cite>
