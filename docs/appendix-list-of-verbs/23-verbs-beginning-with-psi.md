# Verbs beginning with ψ

\*<span lang="grc">ψάω</span> (<span lang="grc">ψῶ</span>) _rub_ (<span lang="grc">ψα-, ψη-</span>): pres. <span lang="grc">ψῇς, ψῇ</span>, etc., [394](../part-2-inflection/09-verbs/00-introduction.md#s394); <span lang="grc">ἀπο-ψήσω, ἔψησα</span>, perf. <span lang="grc">κατ-έψηγμαι</span> from the by-form <span lang="grc">ψήχω</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=ya/w">LSJ</cite>

<span lang="grc">ψέγω</span> _blame:_ <span lang="grc">ψέξω, ἔψεξα, ἔψεγμαι</span> Hippocr., <span lang="grc">ψεκτός</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=ye/gw">LSJ</cite>

<span lang="grc">ψεύδω</span> _deceive_, mid. _lie:_ <span lang="grc">ψεύσω, ἔψευσα, ἔψευσμαι</span> usu. _have deceived_ or _lied_, but also _have been deceived_, <span lang="grc">ἐψεύσθην, ψευσθήσομαι</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=yeu/dw">LSJ</cite>

<span lang="grc">ψύ̄χω</span> (<span lang="grc">ψυχ-, ψῡχ-</span>) _cool:_ <span lang="grc">ψύξω</span> ([147](../part-1-letters-sounds-syllables-accent/06-syllables-and-their-quantity.md#s147) c), <span lang="grc">ἔψυξα, ἔψῡγμαι, ἐψύ̄χθην, ψῡχθήσομαι</span> (?) Hippocr., 2 aor. pass. <span lang="grc">ἀπ-εψύχην</span> as intrans. _cooled_, <span lang="grc">ψῡκτέος</span> Hippocr. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=yu/xw">LSJ</cite>
