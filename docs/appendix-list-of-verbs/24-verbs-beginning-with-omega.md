# Verbs beginning with ω

<span lang="grc">ὠθέω</span> (<span lang="grc">ὠθ-</span> for <span lang="grc">ϝωθ-, ὠθε-</span>, [485](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s485) a) _push:_ imperf. <span lang="grc">ἐώθουν</span> ([431](../part-2-inflection/09-verbs/05-augment.md#s431)), <span lang="grc">ὤσω, ἔωσα</span> ([431](../part-2-inflection/09-verbs/05-augment.md#s431)), <span lang="grc">ἔωσμαι</span> ([443](../part-2-inflection/09-verbs/06-reduplication.md#s443)), <span lang="grc">ἐώσθην, ὠσθήσομαι</span>. Fut. <span lang="grc">ὠθήσω</span> only in Att. poetry, aor. <span lang="grc">ὦσα</span> and perf. <span lang="grc">ὦσμαι</span> Ion., <span lang="grc">ἀπ-ωστός</span> Ion., poetic, <span lang="grc">ἀπ-ωστέος</span> poetic. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=w)qe/w">LSJ</cite>

<span lang="grc">ὠνέομαι</span> (<span lang="grc">ϝωνε-</span>; cp. Lat. _ve-num_) _buy:_ imperf. <span lang="grc">ἐωνούμην</span> ([431](../part-2-inflection/09-verbs/05-augment.md#s431)), <span lang="grc">ὠνήσομαι, ἐώνημαι</span> ([443](../part-2-inflection/09-verbs/06-reduplication.md#s443)) _have bought_ or _been bought_, <span lang="grc">ἐωνήθην</span> _was bought_, <span lang="grc">ὠνητός, -τέος</span>. For <span lang="grc">ἐωνησάμην</span> (late), Att. has <span lang="grc">ἐπριάμην</span> (p. [138](../part-1-letters-sounds-syllables-accent/06-syllables-and-their-quantity.md#s138)). Imperf. <span lang="grc">ὠνεόμην</span> Hdt., <span lang="grc">ὠνούμην</span> Att. in comp. (<span lang="grc">ἀντί, ἐξ</span>).
