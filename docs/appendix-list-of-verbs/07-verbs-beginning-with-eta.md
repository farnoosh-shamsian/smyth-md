# Verbs beginning with η

<span lang="grc">ἡβά̄-σκω</span> _come to manhood_, <span lang="grc">ἡβάω</span> _am at manhood:_ <span lang="grc">ἐφ-ηβήσω, ἥβησα, παρ-ήβηκα</span>, Epic <span lang="grc">ἡβώοντα</span>, etc. ([643](../part-2-inflection/10-verb-stem-and-present-stem/13-inflection-of-omega-verbs.md#s643)). ([V.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s526)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=h(ba/skw">LSJ</cite>

<span lang="grc">ἠγερέθομαι</span> _am collected:_ see <span lang="grc">ἀγείρω</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=h)gere/qomai">LSJ</cite>

<span lang="grc">ἥδομαι</span> _am pleased:_ <span lang="grc">ἡσθήσομαι</span> ([812](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s812)), <span lang="grc">ἥσθην</span>, aor. mid. <span lang="grc">ἡσάμην ι</span> [353.](../part-2-inflection/08-numerals.md#s353) <span lang="grc">ἥδω</span> (<span lang="grc">ἧσα</span>) is very rare. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=h(/domai">LSJ</cite>

<span lang="grc">ἡδύ̄νω</span> (<span lang="grc">ἡδυν-</span>) _sweeten:_ <span lang="grc">ἥδῡνα, ἥδυσμαι, ἡδύνθην, ἡδυντέος</span>. ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=h(du/nw">LSJ</cite>

<span lang="grc">ἠερέθομαι</span> _am raised:_ see <span lang="grc">αἴρω</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=h)ere/qomai">LSJ</cite>

<span lang="grc">ἧμαι</span> _sit:_ see [789.](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s789) <cite data-ref="Perseus:text:1999.04.0057:entry=h(=mai">LSJ</cite>

<span lang="grc">ἠμί</span> _say:_ see [792.](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s792) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=h)mi/">LSJ</cite>

<span lang="grc">ἠμύω</span> _sink_, _bow:_ <span lang="grc">ἤμῡσα, ὑπ-εμν-ήμῡκε</span> X [491](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s491) from <span lang="grc">ἐμ-ημῡκε</span> with <span lang="grc">ν</span> inserted. Poetic, mostly Epic. <cite data-ref="Perseus:text:1999.04.0057:entry=h)mu/w">LSJ</cite>

<span lang="grc">ἡττῶμαι</span> from <span lang="grc">ἠττάομαι</span> (Ion. <span lang="grc">ἑσσοῦμαι</span> from <span lang="grc">ἑσσόομαι</span>) _am vanquished:_ regular, but fut. <span lang="grc">ἡττήσομαι</span> and <span lang="grc">ἡττηθήσομαι</span> ([812](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s812)). (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=h(ttw=mai">LSJ</cite>
