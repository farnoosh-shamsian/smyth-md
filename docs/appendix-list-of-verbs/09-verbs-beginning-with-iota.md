# Verbs beginning with ι

<span lang="grc">ἰαίνω</span> (<span lang="grc">ἰαν-</span>) _warm:_ <span lang="grc">ἴ̄ηνα, ἰάνθην</span> without augm. Epic and Lyric. ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507)) <cite data-ref="Perseus:text:1999.04.0057:entry=i)ai/nw">LSJ</cite>

<span lang="grc">ἰάλλω</span> (<span lang="grc">ἰαλ-</span>) and <span lang="grc">ἱάλλω</span> _send:_ <span lang="grc">-ιαλῶ, ἴηλα</span> without augm. Epic. Poetic (comp. with <span lang="grc">ἐπί</span> in Aristoph.). ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507)) <cite data-ref="Perseus:text:1999.04.0057:entry=i)a/llw">LSJ</cite>

<span lang="grc">ἰαχέω</span> and <span lang="grc">ἰάχω</span> (for <span lang="grc">ϝιϝαχω</span>) _sound_, _shout:_ <span lang="grc">ἰαχήσω, ἰ̄άχησα</span>, 2 perf. part. <span lang="grc">ἀμφιαχυῖα</span>. Hom. has both <span lang="grc">ἴ̄αχον</span> and <span lang="grc">ἴ̆αχον</span>. For <span lang="grc">ἰᾱχ-</span> in tragedy <span lang="grc">ἰακχ-</span> is commonly written. Poetic, mainly Epic. [485](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s485) d. <cite data-ref="Perseus:text:1999.04.0057:entry=i)axe/w">LSJ</cite>

<span lang="grc">ἰδ-, εἰδ-, οἰδ-</span> (for <span lang="grc">ϝιδ-</span>, etc.) in <span lang="grc">εἶδον</span> _saw_ from <span lang="grc">ἐ-ϝιδον</span> [431](../part-2-inflection/09-verbs/05-augment.md#s431) (<span lang="grc">ἴδω, ἴδοιμι, ἰδέ, ἰδεῖν, ἰδών</span>), fut. <span lang="grc">εἴσομαι</span> _shall know_ (Epic <span lang="grc">εἰδήσω</span>), plup. <span lang="grc">ᾔδη</span> or <span lang="grc">ᾔδειν</span> _knew_ ([794](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s794) ff.), <span lang="grc">ἰστέος</span>. Mid. <span lang="grc">εἴδομαι</span> _seem_, _resemble_ Epic, poetic, New Ion.: <span lang="grc">εἰσάμην</span> and <span lang="grc">ἐεισάμην</span>, 2 aor. <span lang="grc">εἰδόμην</span> _saw_ Epic, poetic, Hdt., <span lang="grc">προ-ιδέσθαι</span> Thuc. <span lang="grc">οἰδ-</span> in <span lang="grc">οἶδα</span>, [794](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s794) ff. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=i)d, ei)d, oi)d">LSJ</cite>

<span lang="grc">ἱδρόω</span> _sweat:_ <span lang="grc">ἱδρώσω, ἵ̄δρωσα</span>. For the contraction to <span lang="grc">ω</span> instead of <span lang="grc">ου</span> (<span lang="grc">ἱδρῶσι</span>, etc.) see [398.](../part-2-inflection/09-verbs/00-introduction.md#s398) Epic <span lang="grc">ἱδρώω, ἱδρώουσα</span>, etc. <cite data-ref="Perseus:text:1999.04.0057:entry=i(dro/w">LSJ</cite>

<span lang="grc">ἱδρύ̄ω</span> _place_ (Epic <span lang="grc">ἱδρύ̆ω</span>): often comp. W. <span lang="grc">κατά</span>: <span lang="grc">-ιδρύ̄σω, -ί̄δρῡσα, -ί̄δρῡκα, ἵ̄δρῡμαι, ἱ̄δρύ̄θην</span> (<span lang="grc">ἱδρύνθην</span> Epic), <span lang="grc">ἱδρῡτέος</span>. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=i(dru/w">LSJ</cite>

<span lang="grc">ἵ̄ε-μαι</span> (<span lang="grc">ϝῑε-</span>, cp. Lat. _in-vi-tus_) _strive:_ usu. in comp., as <span lang="grc">παρ-ί̄εμαι</span> _beg_. The forms are like those from the mid. of <span lang="grc">ἵ̄ημι</span> _send_ (cp. [778](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s778)). Epic aor. <span lang="grc">ἐεισάμην</span> and <span lang="grc">εἰσάμην</span>. <cite data-ref="Perseus:text:1999.04.0057:entry=i(/emai">LSJ</cite>

<span lang="grc">ἵζω</span> (for <span lang="grc">σι-σ</span>(<span lang="grc">ε</span>)<span lang="grc">δ-ω</span>, cp. _sedeo_) _seat_, usu. _sit_, mid. <span lang="grc">ἵζομαι</span> _sit_, classic only in pres. and imperf. Mainly Ionic and poetic. See <span lang="grc">καθίζω, καθίζομαι</span>, the usual forms in prose. See also <span lang="grc">ἕζομαι, κάθημαι</span> _sit_. By-form <span lang="grc">ἱζάνω</span> _seat_, _place_. ([III.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s507)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=i(/zw">LSJ</cite>

<span lang="grc">ἵ̄ημι</span> (<span lang="grc">σι-ση-μι</span>) _send:_ <span lang="grc">ἥσω, ἧκα</span>, 2 aor. <span lang="grc">εἷτον</span>, etc., <span lang="grc">εἷκα, εἷμαι, εἵθην, ἑθήσομαι, ἑτός, ἑτέος</span> (except pres. all forms in comp. in prose). For inflection and synopsis, see [777](../part-2-inflection/10-verb-stem-and-present-stem/16-irregular-mi-verbs.md#s777) ff. (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=i(/hmi">LSJ</cite>

<span lang="grc">ἱκνέομαι</span> (<span lang="grc">ἱκ-</span>) _come_, in prose usu. <span lang="grc">ἀφ-ικνέομαι</span>: <span lang="grc">ἀφ-ίξομαι</span>, 2 aor. <span lang="grc">ἀφ-ῑκόμην, ἀφ-ῖγμαι</span>. Uncomp. <span lang="grc">ἱκνούμενος</span> _suitable_ (rare). The simple forms <span lang="grc">ἱκνέομαι, ἵξομαι, ἱ̄κόμην</span> are poetic. Connected forms are poetic <span lang="grc">ἵ̄κω</span> (imperf. <span lang="grc">ἷκον</span>, aor. <span lang="grc">ἷξον</span>) and <span lang="grc">ἱκά̄νω</span>, only pres. and imperf. (Epic and Tragic). ([IV.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s523)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=i(kne/omai">LSJ</cite>

<span lang="grc">ἱ̄λά-σκο-μαι</span> (<span lang="grc">ἱ̄λα-</span>) _propitiate:_ <span lang="grc">ἱ̄λάσομαι, ἱ̄λασάμην, ἱ̄λάσθην</span> ([489](../part-2-inflection/09-verbs/09-formation-of-the-tense-systems-omega-and-mi-verbs.md#s489) e). Epic aor. <span lang="grc">ἱ̄λασσάμην</span>, Epic pres. also <span lang="grc">ἱλάομαι</span>. ([V.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s526)) (Attic) <cite data-ref="Perseus:text:1999.04.0057:entry=i(la/skomai">LSJ</cite>

<span lang="grc">ἵ̄λημι</span> (<span lang="grc">ἱ̄λη-, ἱ̄λα-</span> for <span lang="grc">σι-σλη-, σι-σλα-</span>) _am propitious:_ pres. imper. <span lang="grc">ἵ̄ληθι</span> or <span lang="grc">ἵ̄λαθι</span>, perf. <span lang="grc">ἵ̄ληκα</span>. Mid. <span lang="grc">ἵλαμαι</span> _propitiate_. Epic. <cite data-ref="Perseus:text:1999.04.0057:entry=i(/lhmi">LSJ</cite>

<span lang="grc">ἴλλω</span> (<span lang="grc">ἴλλομαι</span>) _roll:_ <span lang="grc">ἶλα</span>. See <span lang="grc">εἰλέω</span> and <span lang="grc">εἴλω</span>. (III or [IV.](../part-2-inflection/10-verb-stem-and-present-stem/02-1-present-system.md#s523)) <cite data-ref="Perseus:text:1999.04.0057:entry=i)/llw">LSJ</cite>

<span lang="grc">ἱμάσσω</span> (<span lang="grc">ἱμαντ-</span>) _lash:_ <span lang="grc">ἵμασ</span>(<span lang="grc">σ</span>)<span lang="grc">α</span> Epic. <span lang="grc">ἱ̄μείρω</span> (<span lang="grc">ἱ̄μερ-</span>) and <span lang="grc">ἱ̄μείρομαι</span> _desire:_ <span lang="grc">ἱ̄μειράμην</span> Epic, <span lang="grc">ἱ̄μέρθην</span> Hdt., <span lang="grc">ἱ̄μερτός</span>. <span lang="grc">ἵστημι</span> (<span lang="grc">στη-, στα-</span>) _set_, _place:_ <span lang="grc">στήσω</span> _shall set_, <span lang="grc">ἔστησα</span> _set_, _caused to stand_, 2 aor. <span lang="grc">ἔστην</span> _stood_, 1 perf. <span lang="grc">ἕστηκα</span> _stand_ ( = <span lang="grc">σε-στηκα</span>), plup. <span lang="grc">εἱστήκη</span> _stood_ (<span lang="grc">ἑστήκη</span>, rare, [444](../part-2-inflection/09-verbs/06-reduplication.md#s444) b), 2 perf. <span lang="grc">ἕστατον</span> _stand_ ([417](../part-2-inflection/09-verbs/00-introduction.md#s417)), perf. mid. <span lang="grc">ἕσταμαι</span> rare, <!-- page 701 --> fut. perf. <span lang="grc">ἑστήξω</span> _shall stand_ ([754](../part-2-inflection/10-verb-stem-and-present-stem/15-present-system.md#s754) a, [1958](../part-4-syntax/20-the-verb-voices/10-the-tenses.md#s1958)), aor. pass. <span lang="grc">ἐστάθην</span> _was set_, v. a. <span lang="grc">στατός, -τέος</span>.
